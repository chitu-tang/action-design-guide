# 身份设计（身份型习惯与身份重定义）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 2、20 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f05`、`f06`、`f83`），不随公开版分发。

## I — Interpretation

身份设计不是「先定一个远大目标、再靠意志力冲」，而是把改变的着力点从「我想要什么结果」移到「我想成为哪种人」，并把日常的每一个行动当成给这个身份投票。骨架分四块：

1. **三层定位（诊断前置步）**：改变发生在结果层（你得到什么）、过程层（你做什么）、身份层（你相信什么）三层，像洋葱。多数人从结果层入手，本方法主张把着力点放到最深的身份层。
2. **两步法（核心）**：①决定想成为哪种人；②用一个个小胜向自己证明。想不出身份时，从想要的结果倒推——问「能拿到这个结果的是哪类人？」。
3. **投票累积**：每一次行动是一张给某个身份的选票，多数即可、不必全票；身份由习惯提供的证据累积而成，习惯又反过来体现身份，构成双向反馈回路。
4. **身份健壮化**：身份抓得越紧越容易僵化——把某个信念奉为神圣，人就会为它辩护、拒绝成长；对策是别让单一身份占满自我（keep your identity small），并在角色可能消失时，把「角色型身份」（我是运动员）改写为「特质型身份」（我是心理坚韧、热爱身体挑战的人），使它在角色变化后依然成立。

注意方向张力：作者同时写「身份先行」（身份改变是北极星，第一步是「谁」）与「身份由习惯长出」。本卡不替他调和，两序并存照录（见 B 段）。

## A1 — Application Example

**主例 · 作者的朋友靠「健康的人会怎么做」减重逾 100 磅**（`nature: 作者转述友人自述`，c11）

- **输入/问题**：一位女性朋友想减重。
- **怎么执行**：她把身份定位成「一个健康的人」，全天用一句问句当决策指南——「一个健康的人会怎么做？」（走路还是打车？点卷饼还是沙拉？）。每个选择都是给这个身份的一张选票、一个小胜。
- **结论/输出**：先落一句身份句，再用一连串日常小胜去印证。原书交代结果：她最终成了那种人，减重 100 磅以上。
- **注**：作者转述的友人案例，单例、无对照。

**辅例 · Brian Clark 咬指甲与修甲**（`nature: 作者采访的第三人自述`，c08）

- **输入**：多年咬指甲的习惯。
- **怎么执行**：先靠意志力忍住让指甲长出来，再请妻子预约首次修甲；修甲后他「为自己的指甲感到骄傲」。
- **结论/输出**：原书交代他此后再没咬过指甲。说明身份改变靠的是「成为那种人」的内在动机，而非外在理由（他自陈不是为省钱才戒掉，而是骄傲感接住了新习惯）。

**身份健壮化例 · 作者失去运动员身份**（`nature: 作者亲历`，c116）

- 作者自述年轻时把「运动员」当成身份核心，棒球生涯结束后陷入迷茫。
- 原书**未交代**该迷茫的具体结局；此例只用来引出对策：把角色型身份重写为可延续的特质型身份（「我是运动员」→「我是心理坚韧、热爱身体挑战的人」）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**
- 想「从根上变成另一种人」：某种模式反复失败，不满足于只改行为。
- 定了目标（瘦几斤、读完几本书、跑一次马拉松）却总反弹，想换一个更稳的起点。
- 想用一个「人设 / 身份」来带动一串行为和目标，来问「我该把自己定位成什么样的人」。
- 角色变化后自我崩塌：退役、离职、卖掉公司、被迫改变饮食或生活方式，觉得「不知道自己是谁了」。
- 想把既有目标改写：把「减肥 5 公斤」这类结果型目标，改成「成为……的人」这类身份型目标。

**2. 语言信号（中英双写）**
- 中文：想成为什么样的人 / 身份 / 身份型习惯 / 从根上改变 / 我是哪种人 / 用什么身份带习惯 / 角色变了不知道我是谁 / 把目标改写成「成为……的人」/ 身份僵化。
- English: identity-based habits / who do I want to become / change my identity / become a runner, become a reader / identity crisis after losing a role / keep your identity small / reframe goals as identity / you are what you repeatedly do.

**3. 与相邻能力怎么区分**
- 与 four-step-diagnosis（四步模型诊断）：那条是「往回想」——某个行为为什么没发生，卡在提示 / 渴望 / 反应 / 奖赏哪一步；本卡是「往前定」——选一个身份当靶子。要归因诊断走它，要定身份走本卡。
- 与 four-laws-framework（四定律建立侧 SOP）：那条输出「显而易见 / 有吸引力 / 简便易行 / 令人满足」四条动作；本卡不产出这四条，只产出「身份句 + 首个印证身份的小胜」。用户在问「用什么人设带这些行为」时走本卡；在问「给我一套建立行为的具体做法」时走四律。
- 与 four-laws-inversion（反向四律）：那条是改掉 / 打断坏习惯；本卡是身份层的方向选择，两者不互相替代（身份句常被引作动机，但改坏习惯的四条动作不在本卡）。
- 与环境 / 追踪 / 承诺等其他晋级卡：那些是在身份确定后「怎么让它发生 / 维持 / 锁定」；本卡只回答「要成为谁」。
- 与来源路由入口「原子习惯」：入口回答「这套模型是什么、怎么系统性用」。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「帮我诊断早起为什么总做不到」→ 不触发本卡，应走 four-step-diagnosis。
- 「给我一套建立每天读书习惯的具体做法（显而易见 / 有吸引力 / 简便易行 / 令人满足）」→ 不触发本卡，应走 four-laws-framework。
- 「帮我戒掉睡前刷手机」→ 不触发本卡，应走 four-laws-inversion。
- 「我已经想清楚要成为自律的人，帮我把行为排进日程 / 改造环境」→ 不触发本卡，应走执行 / 线索或环境类能力。
- 「原子习惯这本书讲了什么」→ 不触发本卡，应走来源路由入口。

## E — Execution

### 输入契约
- **必需**（二选一）：一个想成为的身份方向；或一个想要的结果 / 反复失败的行为（用于倒推身份）。
- **可选**：用户对某一角色的依恋程度（判断是否需要走健壮化支线）、已有目标表述（用于改写）。
- **适用条件**：用户要「定身份 / 改身份」。若实际是「诊断某行为为何没发生」「建习惯的具体做法」「改坏习惯」，按 B 段分流。
- 缺身份方向、又给不出结果时**先问**，不许静默替用户编一个身份。

### 输出契约

**产出类型**：`design`（新建一个身份设计块；+ 适度 `patch`：改写用户已有目标 / 计划里的身份句）

可检查产物：
1. **1 句身份句**：写成「我是（想成为）……的人」，可被日常行为印证（否则退回重写）。
2. **≥1 个起始小胜**：一个当天可做、能为该身份提供证据的具体行动。
3. **（可选）1 句身份重述**：若涉及可能的角色丧失，给出角色型 → 特质型的重写句。

**完成标准**：用户能说出「这句话我明天用哪个具体行为印证」，并说得出「多数即可、不必全票」。

### 步骤

**第 1 步 · 三层定位（诊断前置步，f05）**
- 动作：把用户的诉求归到结果层 / 过程层 / 身份层；若停在结果层或过程层，指出并引向身份层。
- 完成标准：说清诉求当前停在哪一层，并给出引向身份层的那一步。
- 判停：若诉求本身就是「改身份」（如角色丧失），跳到第 3 步。

**第 2 步 · 定身份句（f06 第一步，p17）**
- 动作：写一句「想成为哪种人」。想不出就从想要的结果倒推，问「能拿到这个结果的是哪类人？」；并把用户的原有结果型目标改写成身份型表述（如「读一本书」→「成为读书人」）。
- 完成标准：得到一句可被日常行为印证的「成为……的人」句。
- 判停：若改写的句子找不到任何可印证的具体行为，判为口号 → 回第 2 步重写。

**第 3 步 · 落第一个小胜（f06 第二步）**
- 动作：为该身份选一个当天可做的小胜，并明确「每次行动是一张选票，多数即可、不必全票」。
- 完成标准：产出一个当天可执行、且明确「这一件事为哪个身份投票」的动作。
- 判停：若涉及角色丧失 / 身份僵化风险，继续第 4 步；否则到此结束。

**第 4 步 · 身份健壮化（f83 并入 f84，仅在涉及角色丧失 / 身份僵化时走）**
- 动作：提醒别让单一身份占满自我（keep your identity small）；把窄而脆弱的角色型身份改写成更宽、角色变化后仍成立的特质型身份。
- 完成标准：得到一句在角色变化后仍成立的身份重述句。
- 判停：不涉及角色丧失 / 身份僵化时，跳过本步。

**回流**：第 2 步身份句不能被行为印证 → 回第 2 步；第 3 步找不到小胜 → 回第 2 步。

## B — Boundary

### 不要用（反场景）
- 诊断一个行为为什么没发生 → four-step-diagnosis。
- 要一套建立好习惯的具体做法（显而易见 / 有吸引力 / 简便易行 / 令人满足）→ four-laws-framework。
- 戒掉 / 打断一个坏习惯 → four-laws-inversion。
- 身份已定，只要落地执行 / 改造环境 / 建追踪或承诺机制 → 相应的执行、环境、追踪、承诺类能力。
- 只想了解整套模型 → 来源路由入口「原子习惯」。

### 作者警告过的失败模式（反例素材）
- **只改行为、不动身份信念**（c09 / x16）：说「我在戒 / 我在努力」的人仍是旧身份，行为在跟旧身份打架；应说「我不是那种人」。这限制了一切只在行为层下功夫的做法。
- **身份僵化**（f83）：越把某个信念奉为神圣、把身份抓得越紧，越会为它辩护、拒绝成长，角色一失即自我崩塌（c116）。
- **把身份句当口号**（p17 适用条件）：改写后若找不到具体行为印证，它就只是口号，不产出真实改变。

### 作者盲点与待核查（含身份因果张力，不替作者调和）
- **身份因果张力（本卡必写）**：作者同时主张两个方向、优先次序含混，本卡**不替作者调和**，照录两造：
  - 主张**身份先行**：作者把身份改变称作习惯改变的北极星，说第一步不是「做什么、怎么做」，而是「成为谁」；并称改变习惯最有效的做法是聚焦于想成为谁，而不是想达成什么；两步法的第一步也是「决定你想成为哪种人」。
  - 主张**习惯造身份**：作者说身份是从习惯里长出来的，每个行动都是给想成为的那种人投一票；并以自身为例——他并非一开始就是作家，而是靠习惯成了作家。
  - **这是与《福格行为模型》融合时的核心冲突点**：Fogg 主张先做小、先感受成功，身份是成功的结果；Clear 主张身份先行（North Star）。本书原文并未消解这个先后之争，本卡照录不裁决。
- **身份健壮化只给定性对策、无门槛**：f83 / f84 只给「别让单一身份占满自我」与「角色型 → 特质型」的改写规则，原文未给「身份多小算小」「何时算出问题」的量化判据。
- **无临床 / 分诊判据**（跨分区备注）：原书没有「何时放弃 / 转介专业人士」的分诊判据。本卡虽属身份层、不涉戒断与成瘾，但若用户的「身份崩塌」实为严重心理病理（抑郁、进食障碍、自伤等）或需要临床干预，本卡方法不适用，应提示转介专业人士；原书对此**未给判据**。

### 相邻易混
- four-step-diagnosis（对比）：往回想「为什么没发生」vs 本卡「往前定身份」。
- four-laws-framework / four-laws-inversion（对比）：出四条动作的建立 / 打破清单 vs 本卡只出身份句与小胜。
- 环境 / 追踪 / 承诺三张晋级卡（组合）：身份定好后的落地、维持与锁定手段；本卡只回答「要成为谁」。

## 相关能力

- **four-step-diagnosis**（对比）：它「往回看」某个行为为什么没发生；本卡「往前定」想成为谁。要要素级归因走它。
- **four-laws-framework**（对比）：它出「建立好习惯」四条动作清单；本卡只出身份句与小胜。要动作清单走它。
- **four-laws-inversion**（对比）：它给「停下 / 换掉坏习惯」的反向清单；本卡是身份层方向选择。
- **habit-tracking-reflection**（组合）：身份定好后，用追踪「看见自己」印证身份句。
- **commitment-accountability**（组合）：身份定了之后，「让它不靠意志力发生」的约束 / 见证层。
- **environment-design**（组合）：身份定了之后，用空间线索让身份相关行为最显眼。
- **reinforcement**（组合）：`f61`「奖赏须与身份一致」是奖赏层的身份视角；身份句由本卡产出。
- **find-your-field**（对比）：它挑外在赛场（游戏化 / 专业化 / 人格匹配）；本卡定内在身份。

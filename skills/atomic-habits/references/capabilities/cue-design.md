# 线索设计（执行意图 · 习惯叠加 · 线索陷阱）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 5 章与第 7 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f16`、`f17`、`f19`、`p44`），不随公开版分发。

## I — Interpretation

本卡管一件事：**把一个新习惯落到一个既有线索上**——也就是决定「**何时何地做**」或「**挂在哪个既有习惯后面**」。它不问「你该拿哪一类提示」（那是福格 `prompt-types`），也不问「这个锚点配不配」（那是福格 `anchor-matching`）；它给的是**把线索写下来的格式**和**写不具体时的排障**。

三种落法：

1. **执行意图（implementation intention）**：把模糊意图写成一句「我会在【时间】于【地点】做【行为】」。作者指出，人缺的常常不是动机，而是**清晰度**——最常见的两类线索就是**时间**与**地点**。一般句式是「当情境 X 出现，我就执行 Y」。
2. **习惯叠加（habit stacking）**：执行意图的变体，不绑时间地点，而是**挂到一个当前已有的习惯**后面，公式是 `After I [当前习惯], I will [新习惯]`。**作者明说这个方法取自 BJ Fogg 的 Tiny Habits，不是本书原创**。做法：先用习惯记分卡或两栏清单找出「每天必做、不落空」的既有习惯，再把新习惯挂到合适的锚点后；可把多个小习惯**串成链**（前一行为成为后一行为的线索，即 Diderot 效应的正向利用）。
3. **排障（f19）**：叠加执行不稳、老忘，通常是两处出问题——**线索太模糊**（「当我午休时」不知饭前饭后、在哪做），或**锚点频率与目标习惯不一致**（想每天做却挂在一周一次的习惯上）。改法：把线索改到「高度具体、立刻可执行」，并让锚点频率等于目标频率。

一条**边界规则（p44）**：线索要小心——若处理不当，你引入的线索可能**反过来诱发你想制止的行为**（如用羞辱/恐吓去打击坏习惯，结果引发压力、反而触发原来的应对行为）。

一句话：**执行意图给「时间+地点」格式，习惯叠加给「挂到既有习惯后面」格式，f19 负责把线索改具体、把频率对齐，p44 提醒别把线索做反。**

## A1 — Application Example

**主例 · 作者修正自己的俯卧撑习惯叠加**（c25，**原书亲历**）

- **输入/问题**：作者想加一个俯卧撑习惯，最初把线索写成「当我午休时做十个俯卧撑」。
- **怎么执行**：他发现这个线索**太模糊**——是饭前做还是饭后做？在哪儿做？歧义让执行不稳。于是改成「**当我为午饭合上笔记本电脑时，我在桌边做十个俯卧撑**」。
- **结论/输出**：把线索改到「高度具体、立刻可执行」。
- **原书交代的结果**：改成「合上电脑」后「歧义消失」，执行稳定。
- 同一处原文也是失败模式 x04（习惯叠加用了模糊 / 频率不匹配的线索 → 无法触发）。

**补充案例（执行意图的量化证据 / 习惯叠加链条）**

- c23（**研究转述**）：2001 年英国一项 248 人、两周的锻炼实验——写执行意图的第三组 **91%** 每周至少运动一次，远高于对照组与动机组的 **35–38%**。（**未给效应值 / 统计显著性 / 出处**，出处见英文版注释。）
- c26（**作者演示例题，非真人**）：晨间习惯叠加链——「倒完晨间咖啡 → 冥想 60 秒 → 写当日待办 → 立刻开始第一项任务」；每条前一行为是后一条的线索。**原书未交代实际执行结果**（例题即演示）。

（c25 为作者自述经验，无对照样本量。）

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 「我想开始一个新习惯（冥想 / 每天写日记 / 喝水），可总忘、不知道从哪接起。」
- 「我知道要做，但说不清到底**什么时候、在哪**做。」
- 「想把这个新习惯**挂到某件我每天都做的事后面**，怎么挂？」
- 「我已经有叠加配方了，但执行不稳、老漏——是哪里写错了？」
- 「把好几件小事串成一串一起做，行不行？」

**2. 语言信号（中英双写）**

- 中文：执行意图 / 何时何地 / 什么时候做 / 在哪做 / 习惯叠加 / 挂到……后面 / 在我……之后我会…… / 锚点 / 叠加不起来 / 总忘 / 线索不具体 / 频率对不上。
- English: implementation intention / when and where / at what time / habit stacking / after I…, I will… / attach to an existing habit / cue is too vague / frequency mismatch.

**3. 与相邻能力怎么区分**

- 福格 `prompt-types`（跨书，见分流句）：它先决定「用**哪一类**提示（人物 / 情境 / 行动）」；本卡给的是把线索**写下来的格式**（时间地点 / 既有习惯）。
- 福格 `anchor-matching`（跨书，见分流句）：它做「**锚点配不配**」的三轴匹配；本卡用 `After I …` 公式给出「挂到哪个既有习惯后面」。
- 福格 `tiny-habit-design`（跨书）：它给「从零养成」**全流程**（选行为、缩小、庆祝、维持）；本卡只管线索这一步。
- environment-design（组合 / 对比）：本卡摆**时间 / 锚点**线索；它摆**空间**线索（看得见什么）。
- two-minute-rule（对比 + 链接）：`f50`/`f51` 给「缩到两分钟 / 门户习惯」的阈值；本卡给「何时何地 / 挂到哪」的线索格式，二者同一「起不来」簇，常配套。
- friction-prime（对比）：行为**做不到**（太难 / 太麻烦）走它；本卡处理「做得到、只是不知何时何地做」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「我该用**人物提示、情境提示还是行动提示**？」→ 不触发本卡，走福格 **`prompt-types`**（尚未锁定线索类别）。
- 「我已经决定用某个锚点，**它配不配**？」→ 走福格 **`anchor-matching`**（三轴匹配）。
- 「帮我把这个新习惯**从零整体设计**出来（含选行为、缩小、庆祝、维持）」→ 走福格 **`tiny-habit-design`**。
- 「这个行为**本身太难 / 步骤太多**，怎么让它省事？」→ 走 **`friction-prime`**（或福格 `make-it-easy`）。
- 「环境里**看不见 / 摆错位置**，怎么挪？」→ 走 **`environment-design`**。
- 「先帮我判断这个行为**为什么没发生**」→ 走 **`four-step-diagnosis`**（或福格 `bmap-diagnosis`）。

**分流句（本卡 ↔ 福格 `prompt-types` / `anchor-matching` / `tiny-habit-design`，同一「把新习惯落地 / 别老忘」簇）**：问「**什么时候、在哪里**做」（执行意图）或「**挂到哪个既有习惯后面**」（习惯叠加），要一句可执行的线索格式 → cue-design；问「该拿**哪一类提示**提醒自己（人物 / 情境 / 行动）」→ 福格 `prompt-types`；问「我已经选了锚点，**它配不配**」→ 福格 `anchor-matching`；要「从零**整体**养成一个新习惯」→ 福格 `tiny-habit-design`。

## E — Execution

### 输入契约

- **必需**：一个**具体的、想反复发生的行为 / 新习惯**（「每天写日记」「每天冥想一分钟」）。若给的是愿望 / 成果（「变健康」「更自律」），先拆到一个此刻可做的具体行为。
- **可选**：该行为发生的**时间 / 地点**、可用于挂靠的**既有习惯**（每天必做、不落空的）、期望**频率**（每天一次 / 每天多次）。
- **适用条件**：本卡只解决「何时何地做 / 挂到哪个既有习惯后面」。若行为本身**做不到** → 按 B 段分流到 friction-prime / 福格 `make-it-easy`。
- 缺具体行为 → **先问**，不许静默替用户猜。

### 输出契约

**产出类型**：`patch`（给已有计划换零件：加一条线索格式 / 锚点配方）

一条（或一串）**线索配方**：

- **执行意图**：一句「我会在【时间】于【地点】做【行为】」（或「当【情境 X】出现，我就【执行 Y】」）；
- **习惯叠加**：一句 `After I [既有习惯], I will [新习惯]`；若要串链，给出有序的多条；
- 附**排障注**：所写线索是否「高度具体、立刻可执行」、锚点**频率**是否等于目标频率、锚点是否落在混乱时段。

**完成标准**：配方里指名了**具体的时间/地点**或**具体的既有习惯锚点**（不是一个模糊词），且可当天就被触发执行。

### 步骤与完成标准

1. **锁定目标行为**：写下一个具体行为，并标注期望频率（每天一次 / 多次）。
   - 完成标准：有一个此刻可做的具体行为。
   - 判停：若给的是愿望 / 成果 → 回输入契约先拆分；若行为做不到 → 转 friction-prime / 福格 `make-it-easy`。
2. **选线索格式**：优先**习惯叠加**（若有一个每天必做、不落空的既有习惯可挂）；无合适锚点、或用户要固定时刻 → 用**执行意图**（时间 + 地点）。
   - 完成标准：明确用哪一种格式，并锁定时间/地点或既有习惯锚点。
   - 判停：若用户还需先决定「用哪一类提示」→ 转福格 `prompt-types`；若已锁定锚点只问「配不配」→ 转福格 `anchor-matching`。
3. **写出配方句**：按所选格式填出「我会在【时间】于【地点】做【行为】」或 `After I [既有习惯], I will [新习惯]`；要串链就给出有序多条。
   - 完成标准：配方句填满、无空槽、无「午休时」这类模糊词。
4. **排障（f19）**：检查线索是否**高度具体、立刻可执行**；锚点**频率**是否 = 目标频率；锚点是否落在混乱 / 不稳定的时段。
   - 完成标准：≥1 处具体化（如把「午休时」改到「合上电脑时」）或确认频率已对齐。
5. **线索陷阱检查（p44）**：确认新引入的线索不会反过来诱发别的坏行为（如用羞辱 / 恐吓做线索）。
   - 完成标准：给出「新线索不会反噬」的一句确认，或指出需改设计。

### 判停点

- 第 1 步后发现行为**做不到**（能力 / 摩擦）→ 转 friction-prime（或福格 `make-it-easy`）。
- 第 2 步前用户要「选提示类别」→ 转福格 `prompt-types`；只问「锚点配不配」→ 转福格 `anchor-matching`。
- 用户其实要「从零整体养成」→ 转福格 `tiny-habit-design`。
- 用户其实要「改造环境里看得见的线索」→ 转 environment-design。

## B — Boundary

### 不要用（反场景，按分流）

- 要**从零整体养成**一个新习惯（含选行为 / 缩小 / 庆祝 / 维持） → 福格 `tiny-habit-design`。
- 要决定用**哪一类提示** → 福格 `prompt-types`；只做**锚点匹配** → 福格 `anchor-matching`。
- 行为**做不到 / 太难 / 步骤太多** → friction-prime（或福格 `make-it-easy`）。
- 要改「环境里**看得见什么**」（挪线索 / 一室一用 / 换场景） → environment-design。
- 要把行为**缩到两分钟 / 门户习惯** → two-minute-rule。
- 要先**归因**「这个行为为什么没发生」 → four-step-diagnosis（/ 福格 `bmap-diagnosis`）。
- 只想了解整套模型 → 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式（反例素材）

- **线索太模糊 / 频率不匹配 → 叠加失败**（x04，作者亲历）：作者自己的俯卧撑叠加用了「当我午休时」，线索含糊（饭前饭后 / 在哪做）导致执行不稳；改到「合上笔记本电脑时」后歧义消失。作者还提示**锚点频率要与目标习惯一致**。
- **用线索反而诱发想制止的行为**（p44 / x03）：用羞辱式宣讲刺激肥胖者、给吸烟者看黑肺照片，会引发更高的焦虑，反而诱发原来的应对行为 → 处理线索时要避免自己**制造出新的触发线索**。本卡第 5 步专门检查此点。
- **把提示交给运气**（x22）：不主动设计线索、指望环境或记性「碰巧」触发，等于没有线索——本卡的存在就是为了主动写出线索。

### 作者盲点与待核查

- **习惯叠加的来源：明说取自 BJ Fogg**。**本卡如实标注这是跨书同源**（福格 `tiny-habit-design` / `anchor-matching`），不作为本书原创。
- **f19 判据是定性，原文未给量化门槛**：原书只说线索要「高度具体、可立即执行」，**「具体到何种粒度才算够」原文未给判据**，执行不因缺门槛受阻。
- **p44 涉肥胖 / 吸烟，原书只给 backfire 提醒，未给成瘾 / 精神病理的分诊判据**（p44 `notes` 即「必核项 4」）。→ 若底层问题其实是成瘾 / 物质依赖，本卡不适用；照录本书自限（成瘾自限句唯一出处在第 12 章，大意是这类技巧难以遏制真正的成瘾），并提示转介专业人士。**本书没有「何时放弃 / 转介」的分诊判据。**
- **f17 的合并条行号有串位瑕疵**：f17 合并条的行号指针有轻微串位，但不影响本条成立。

### 相邻易混

- **福格 `prompt-types`**：提示**选型**（人物 / 情境 / 行动）vs 本卡**写线索格式**。
- **福格 `anchor-matching`**：锚点**匹配**（位置 / 频率 / 主题三轴）vs 本卡**给锚点公式并排障**。
- **福格 `tiny-habit-design`**：养成**全流程** vs 本卡只管线索这一步。
- **`environment-design`**：空间线索（它）vs 时间 / 锚点线索（本卡）。
- **`two-minute-rule`**：缩小行为本身（它）vs 落实线索格式（本卡）。

## 相关能力

- **environment-design**（组合）：本卡摆时间 / 锚点线索；它摆空间线索。
- **two-minute-rule**（对比）：同一「起不来」簇——本卡给「何时何地 / 挂到哪」的线索格式，它给「缩到两分钟 / 门户习惯」的阈值；常配套。
- **decisive-moments**（对比）：本卡给「何时何地做」的线索格式；它处理「一天里几个岔路口怎么预设选择」。

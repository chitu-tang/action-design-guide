# 金发姑娘法则与爱上无聊（难度调到能力边缘 · 守日程）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 19 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f77`、`f79`），不随公开版分发。

## I — Interpretation

本卡管**已经养起来的习惯如何维持动机**，由两条并成：

1. **f77 金发姑娘法则（调难度）**：动机峰值出现在「任务难度**刚好在当前能力的边缘**」——**不太难**（太难会失去动机）、**不太易**（太易会无聊）。做法：习惯建立后，**逐步小幅加难**，让行为保持 `novel`（Steve Martin 每年只把节目加长一两分钟）。若难度刚好卡在边缘，可能进入**心流**。它是**调难度动作**：形式是「把难度调回 / 调向能力边缘」。
2. **f79 爱上无聊（守日程）**：作者点明，**挡住成功的往往不是失败，而是无聊**。当习惯变得例行、不再带来惊喜，人就追新奇而偏离（一个接一个换项目 / 换饮食 / 换点子）。出路是「**爱上无聊**」：**不论心情如何都照常出现**——专业者按日程照做，业余者则随生活起伏。

两条的关系：f77 解决「难度不对」（无聊 = 太易、焦虑 = 太难）→ **调难度**；f79 解决「难度对了但就是不想做」（情绪不在）→ **守日程、不换方法**。**关键划线**：f79 本质是**「守日程」的心态规则**（无步骤、无阈值），**不是量化门槛**；它只产出「不论心情照常出现」的执行策略。

一句话：**习惯已在、动机开始衰减时——先看是不是难度偏离能力边缘（f77），是就小幅调难；若难度没问题只是无聊，就守日程、爱上无聊（f79）。**

## A1 — Application Example

**主例 · Steve Martin 的喜剧生涯**（`nature: 作者转述`，c105）

- **输入/问题**：一个十岁在迪士尼卖导游册的男孩，少年起在洛杉矶小俱乐部演出、逐月打磨节目。
- **怎么执行**：每年把喜剧节目**延长「一两分钟」**——既加新料，又保留几个保证逗笑的老梗（难度一直停在「刚能应付」的边缘）。
- **结论/输出**：刚好有胜利保持动力、也刚好有失误逼他继续用功。
- **原书交代的结果**：历经近 15 年成名。

**辅例 · 作者与举重教练谈「谁能忍受无聊」**（`nature: 作者亲历 + 转述教练话`，c106）

- **输入/问题**：作者问一位带过奥运选手的教练，「顶尖运动员与别人差在哪？」
- **教练答**：基因、运气、天赋之外，最终看谁能忍受日复一日重复同样训练的那种无聊。
- **结果**：原文即引教练此答案；教练匿名（一位顶尖教练），**无对照样本量**。
- **注**：这是 f79「爱上无聊」的原始素材。

**合成演练（明确标记：原书未给「把难度精确调高到某档」的成案，以下按 f77/f79 规则复算）**

- **输入/问题**：一个人说「我健身半年后觉得无聊、想放弃。」
- **怎么执行**：用 f77 判难度——「无聊」= 难度偏低 → 把重量 / 组数**小幅上调**到「略超出当前能力」的档位（保持 novelty）；若某天心情不在，用 f79 不论心情照常训练、不换项目。
- **结论/输出**：一条难度调整动作 + 一条「情绪不在也照做」的规则。
- **注**：此演练来自 f77 的验收演练，属**合成**，不是书中案例；**不加精确百分比门槛**（4% 不可引用，见 B 段）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 一个习惯做久了觉得**无聊、提不起劲**，想放弃或换项目。
- 想知道怎么在**稳定期继续推进、保持动机**。
- 已经自动化、却没有新挑战，感觉**停滞 / 没劲**。
- 情绪 / 状态不在，纠结「今天还要不要做」。
- 想判断自己该「**加难**」还是「**守住日程照做**」。

**2. 语言信号（中英双写）**

- 中文：金发姑娘 / 难度刚好 / 无聊想放弃 / 动机衰减 / 怎么保持动力 / 逐步加难 / 爱上无聊 / 守日程 / 专业者 vs 业余者 / 状态不好要不要做 / 想换项目。
- English: Goldilocks Rule / just manageable difficulty / on the edge of my ability / stay motivated / boredom / fall in love with boredom / stick to the schedule / professionals vs amateurs。

**3. 与相邻能力怎么区分**

- **簇内**：f77（调难度，核心）+ f79（守日程 / 爱上无聊，并列项）；二者是第 19 章「维持动机」这一簇的两条，f79 是 f77 动机维持的判断依据。
- find-your-field（对比）：本卡**沿现有习惯调难度**；它**选 / 换方向、找赛场**。
- habit-mastery（对比）：本卡维持动机（调难度 / 守日程）；它处理**自动化后回费力区突破**。
- habit-tracking-reflection（对比）：本卡管调难度 / 守日程；它管**记录与复盘**。
- four-laws-framework（对比）：本卡调难度；它轮换四律找瓶颈。
- 来源路由入口 `atomic-habits`：只回答「这套模型是什么、怎么系统性用」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「我该选哪个方向 / 该深耕还是换赛道」→ 不触发本卡，走 **`find-your-field`**。
- 「我已经自动化了，想突破到卓越 / 感觉停在舒适区」→ 不触发本卡，走 **`habit-mastery`**。
- 「帮我建个打卡表 / 做年度复盘」→ 不触发本卡，走 **`habit-tracking-reflection`**。
- 「帮我把新习惯缩到两分钟起步」→ 不触发本卡，走 **`two-minute-rule`**。
- 「我为什么总做不到 X」→ 不触发本卡，走 **`four-step-diagnosis`**。
- 「帮我改环境」→ 不触发本卡，走 **`environment-design`**。

**分流句（本卡 ↔ `find-your-field` ↔ `habit-mastery`）**：**沿现有习惯调难度、让动机不掉** → 本卡；**换 / 选方向** → find-your-field；**自动化后要突破瓶颈** → habit-mastery。

## E — Execution

### 输入契约

- **必需**：一个**已建立、在做的习惯**；**当前能力水平**与**当前难度**；**动机状态**（无聊 / 焦虑 / 无所谓 / 想放弃）。
- **可选**：该习惯已稳定多久；是否已自动化；用户已试过的加难方式。
- **适用条件**：习惯**已经在**（稳定 / 熟练期），用户要维持动机或调难度。习惯**还没建起来** → 走养成线（two-minute-rule / cue-design），不在本卡执行。
- 缺「当前能力 / 难度 / 动机状态」时**先问**，不许静默替用户定难度。

### 输出契约

**产出类型**：`patch`（给已有计划的难度字段换零件）+ `diagnosis`（判动机衰减是难度偏离还是单纯无聊）

- ① 一个**难度调整动作**（f77）：太久无聊 → **小幅加难**到能力边缘（保持 `novel`，如每年只加一两分钟）；太难 / 焦虑 → **降到能力边缘**。
- ② 一条**「对无聊」的执行规则**（f79）：不论心情照常**按日程出现**，别因无聊换方法。
- ③ 一条**口径说明**：把难度调到「刚能应付」即可，**不做精确量化**（4% 不可引用，见 B 段）。

**完成标准**：给出一条可执行的难度调整动作 + 一条「情绪不在也照做」的动作。

### 步骤

1. **判断相位**（f77）：当前难度相对能力，是**偏难**（焦虑 / 失去动机）、**偏易**（无聊）还是**刚好**？
   - 完成标准：给出「偏难 / 偏易 / 刚好」判断 + 依据。
   - 判停：若用户其实要「**选 / 换方向**」→ 转 find-your-field；若是「**已熟练要突破**」→ 转 habit-mastery。
2. **小幅调难度**（f77）：偏离则调回能力边缘；无聊则**逐步小幅加难**（保持 novelty，如 Steve Martin 每年只加一两分钟）。
   - 完成标准：一条具体难度调整动作（加量幅度 / 降档）。
   - 注：**不加精确百分比门槛**——f77 的量化支点（心流 4%）已判「需复核」，本卡**不得引用该数字**（见 B 段）。
3. **对无聊守日程**（f79）：当习惯变得例行、不再惊喜时，**识别「追新奇」的冲动**；不换方法，不论心情照常出现（专业者守日程）。
   - 完成标准：一条「情绪不在也照做」的规则 + 一个「想换方法」时的自检点。

### 判停点

- 第 1 步是**方向问题** → 转 find-your-field。
- 第 1 步是**突破问题** → 转 habit-mastery。
- 第 1 步涉**临床成瘾 / 病理** → 按停手线处理，停止并提示转介。

## B — Boundary

### 不要用（反场景，按分流）

- 要**选 / 换方向、找赛场** → find-your-field。
- 已熟练、要**突破瓶颈到卓越** → habit-mastery。
- 要**记录 / 复盘** → habit-tracking-reflection。
- 要**从零养成 / 把习惯缩到两分钟** → two-minute-rule（及养成线）。
- 要**定位某行为卡在四步哪一步** → four-step-diagnosis。
- 要**改环境里的线索** → environment-design。
- 只想了解这套模型 → 来源路由入口 `atomic-habits`。
- **涉临床成瘾 / 病理 → 不跑本卡**（见下）。

### 作者警告过的失败模式（反例素材）

- **只追新鲜、动机一跌就换方法**：习惯变例行使我们开始偏离、去追新奇，「一个接一个换项目 / 换饮食 / 换点子」；本书的解药是「爱上无聊 / 守日程」，不是换方法。
- **变量奖赏不是万能**：作者自限——**并非**所有习惯都该加不确定性（Google 搜索结果、Uber 接单、刷牙都不是变量奖赏）；别为了「有意思」把本该确定的习惯改坏。

### 作者盲点与待核查（不许当规律用）

- **⚠️ 心流 4% 绝对不可引用（硬性，写死）**：f77 的量化支点「心流约高于现有能力 **4%**」已判「需复核」：正文以「科学家……他们发现」的口吻给出，**无内联出处**；其**端注出处**是英文版注释（Steven Kotler, *The Rise of Superman*, 2014），而该端注同时显示 Kotler 所引 Csikszentmihalyi 的原始比率为 **1:96（约 1%）**，与正文「约 4%」**自相矛盾**。故此数字既**成色弱**、又**来源内部冲突**，**只能整体丢弃**——本卡（及任何卡）**不得引用这个数字**，只能保留其核心「刚能应付的难度」。
- **f79 是「守日程」的心态规则、非量化门槛**：f79 本质是**心态规则**（无步骤、无阈值），只能产出「不论心情照常出现」的执行策略，**不得当量化判据**，也不得声称它给了「加难多少 / 多久加一级」的阈值。
- **f77 证据强度 medium**：核心句可逐字核对，但同章关联的量化支点 4% 已坏，故整条按 **medium** 记、能力卡不得引用该数字（见上）。
- **原文未给「加难多少」的量化门槛**：f77 只说「**小幅**加难 / 保持 novelty」，只给了 Steve Martin「每年一两分钟」的**个例**；**未给**「每级加多少、每级停留多久」的通用阈值——不得补造。
- **第五组（作者前后不一致，原样保留、不替作者调和）**：作者一边承认**运气重要**（正文与引言注里都这么说）；一边又强调**别拿运气替不努力开脱 / 基因只决定机会区**。两造并存，作者**未调和**；本卡**原样照录，不替作者选边**（本卡引用第 19 章「教练提到基因 / 运气 / 天赋」时同样照录、不裁决）。
- **无临床 / 分诊判据（存量风险）**：全书**没有**「何时放弃本方法、转介专业人士」的判据（已 grep `professional / therapist / clinical / treatment / mental health / psychiatr`，零结果）；涉成瘾的唯一自限说明是「这类技巧约束不了真正的成瘾」（第 12 章）。若用户要维持 / 调难度的习惯涉及**临床成瘾、进食障碍、自伤等严重心理病理**，不跑本卡、提示转介专业人士——**这是流程补的，不是原书给的判据**。

### 相邻易混

- **`find-your-field`**：调难度（本卡）vs 选 / 换方向（它）。
- **`habit-mastery`**：维持动机（本卡）vs 突破瓶颈（它）。
- **`habit-tracking-reflection`**：调难度 / 守日程（本卡）vs 记录 / 复盘（它）。
- **`two-minute-rule`**：把习惯缩到最小起步（它）vs 已建立后调难度 / 维持（本卡）。

## 相关能力

- **find-your-field**（对比）：本卡调难度；它选 / 换方向、找赛场。

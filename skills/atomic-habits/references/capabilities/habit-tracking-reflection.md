# 习惯追踪与复盘（觉察 · 追踪 · 恢复 · 复盘）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 4、16、20 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f13`、`f63`、`f65`、`f81` 等），不随公开版分发。

## I — Interpretation

这一卡管的是习惯的「维持与回头」这一段，不是「从零建起来」，也不是「把它拆掉」。它把四个动作串成一条线：**当刻觉察 → 逐日追踪 → 断档恢复 → 定期复盘**。前三个是「盯着它」，最后一个是「回头看它」。

1. **觉察（先看清，不改）**：列你每天的日常习惯，逐条判好 / 坏 / 中性，标 + / − / =；难题用一句判据裁定——这个行为到底是在帮我成为想成为的那种人，还是在替相反的身份投票？全程只观察、不改变、不带评判。它的作用是把你「其实在做什么」变成一张可见的清单。
2. **追踪（让进度可见）**：用日历打叉、回形针法、或各种日志记录你是否做了。它同时借用多条定律——记录本身制造线索（显而易见）、看见连续链条让人不想断（有吸引力）、完成即回报（令人满足）。三条要则：能自动化的计量尽量自动化；手动只追**最重要的少数**；完成后**立刻**记录。
3. **恢复（断档是常态）**：它的规则是「绝不错过两次」。真正毁掉习惯的通常不是第一次失误，而是紧接着的第二次；一旦断链，越快恢复越好，宁可做**最小值**也要出现，避免全有全无。
4. **复盘（定期校准）**：每 12 月做年度复盘（清点这一年，答三问），半年后再做诚信报告（答另外三问），用来对抗习惯钝化和身份僵化；也可用 CBE 式把「最佳努力」算成一个可比较、可复盘的量化指标。
5. **两个护栏**：一是「追踪会反噬」——当测量变成目标它就不再是好测量（古德哈特定律），必要时换一个更能指示目的的指标（非体重胜利）；二是「可测量 ≠ 最重要」，别让可得的数字挤掉不可量化的目的。

## A1 — Application Example

**主例 · Trent Dyrsmid 的回形针策略**（`nature: 作者转述（作者邮件采访）`，c87）

- **输入/问题**：1993 年，加拿大 Abbotsford 一家银行雇了一个 23 岁的股票经纪人 Trent Dyrsmid；Abbotsford 是小城，大生意都在温哥华，没人对他期望高。
- **怎么执行**：他每天早上在桌上摆两个罐子，一个装满 120 枚回形针、一个空着；每打完一个销售电话，就从满罐挪一枚到空罐，直到挪完 120 枚（作者的「Paper Clip Strategy」）。
- **结论/输出**：原书交代结果——**18 个月内他为公司带来 500 万美元**；24 岁年薪 7.5 万美元（约合今天 12.5 万），随后拿到另一家公司的六位数薪资。
- **注**：这是「视觉化计量制造即时满足」的原始案例，用来说明追踪的动机机理；它不是「不中断链条」或「绝不错过两次」的案例。

**辅例（各方向的原书素材）**

| 方向 | 原书案例 | nature | 原书交代的结果 |
|---|---|---|---|
| 觉察 | 日本铁路的指差确认 | 转述（历史/安全系统） | 错误降低多达 85%、事故降低 30%；纽约地铁改「只指不念」后两年内错停事故降 57% |
| 觉察 | 作者的习惯记分卡练习 | 作者工具（非人物案例） | 产出一份带 + / − / = 的日常习惯清单，先觉察、不改变 |
| 追踪 | Jerry Seinfeld 的「不要中断链条」 | 转述（原文标「据报道」，英文版注释查无出处） | **未说明** |
| 恢复 | 作者自述「绝不错过两次」 | 作者亲历（自述规则） | 只给规则与复利算例（$100 涨 50% 到 $150，只要亏 33% 就回到 $100） |
| 复盘 | 作者的年度复盘与诚信报告（c115） | 作者亲历 | 原文给出两套各三问的清单；作者称每年只花几小时，却是关键调整期 |

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**
- 已经在做一件想长期坚持的事，想要一套「打卡 / 记录」系统，并把「断了一天怎么办」的规则一起定好。
- 手里有（或没有）记录，想定期（年度 / 半年）回头盘一盘，用固定问题清点一段时间、校准方向与身份。
- 追着某个数字（步数、体重、营收、发文数）却感觉走偏了，想知道追踪是不是反噬、要不要换指标。
- 想先看清自己一天到底在做什么、哪些是好 / 坏习惯，明确说「先不改，只盘点」。
- 已经有个习惯，但用硬指标衡量后动机下滑（体重秤不动、数字不涨），想要别的进展信号。

**2. 语言信号（中英双写）**
- 中文：打卡 / 记录 / 追踪 / 追踪表 / 习惯追踪 / 不要中断链条 / 断了怎么办 / 绝不错过两次 / 年度复盘 / 半年复盘 / 诚信报告 / 盘一盘这一年 / 习惯记分卡 / 看清我一天在做什么 / 数字不涨 / 换指标。
- English: habit tracker / tracking / streak / don't break the chain / never miss twice / get back on track after missing / annual review / reflection and review / integrity report / habits scorecard / nonscale victory / the measure became the target。

**3. 与相邻能力怎么区分**
- **卡内三向**（同一工作流的三段，见下 §4）：觉察 = 当刻盘点、先觉察不改；追踪 = 逐日打卡、维持、断档恢复、防反噬；复盘 = 定期（年度 / 半年）校准。
- 与另外三张晋级卡：identity-design 只回答「要成为谁」；commitment-accountability 是用契约 / 自动化 / 问责把**未来锁死**（靠约束，不靠记录）；environment-design 是改环境里的**线索**。本卡只在「已经有一个习惯、要记录与回看」时触发。
- 与 four-step-diagnosis（本书）/ 福格 `bmap-diagnosis`：那是「某个行为**该发生却没发生**」的要素级归因诊断；本卡的复盘是「定期回看一段时间、校准方向」。复盘若把一个具体行为定位成「没发生」，转诊断卡。
- 与 reinforcement（本书）/ 福格 `celebration`：那是「完成时加即时奖赏 / 庆祝」，产物是一个奖赏动作；本卡的追踪**也**提供满足，但产物是记录与链条。
- 与 two-minute-rule（本书）/ 福格 `tiny-habit-design`：那是「从零把习惯缩小建起来」；本卡假设习惯已经在。
- 与来源路由入口「原子习惯」：入口回答「这套模型是什么、怎么系统性用」。

**4. 近邻负例（什么样的请求不该触发本卡）**

*卡内三条分支的分工（避免重复触发）：*
- 「先帮我看清我一天都做了什么、哪些是好坏习惯，**先不改**」→ 走**觉察**分支（当刻盘点），不当成逐日打卡或年度复盘。
- 「给这个习惯建个打卡表、断了一天怎么办」→ 走**追踪 + 恢复**分支；不是当刻盘点（不是「看清现状」），也不是定期复盘。
- 「帮我做**年度 / 半年复盘**、盘点这一年并校准方向」→ 走**复盘**分支（定期、跨一段时间的校准），不是逐日打卡，也不是当刻盘点。

*与其他能力、跨书入口的分工：*
- 「帮我养成 / 开始一个每天 X 的习惯」→ 不触发本卡，走养成线（cue-design 等；跨书福格 `tiny-habit-design`）。
- 「帮我戒掉 / 改掉一个坏习惯」→ 不触发本卡，走 four-laws-inversion 或跨书 `change-bad-habit-system`。
- 「我为什么总做不到 X，卡在动机 / 能力 / 提示哪一环？」→ 不触发本卡，走 four-step-diagnosis / `bmap-diagnosis`。
- 「我想成为更健康 / 更自律的人，从哪开始」→ 不触发本卡，走 identity-design。
- 「帮我签个契约 / 找人监督，让自己不做也得做」→ 不触发本卡，走 commitment-accountability。
- 「把家里环境改一改，让好行为自然发生」→ 不触发本卡，走 environment-design。
- 「原子习惯这本书讲了什么」→ 不触发本卡，走来源路由入口。

## E — Execution

### 输入契约
- **必需**：一个**已确定、想维持**的具体习惯（或一小撮要追的习惯）；和 / 或 一段**已有记录**（用于复盘）。
- **可选**：历史断档记录、可自动化的计量源（手环 / 账单 / 日历）、复盘周期偏好、用户已用的量化指标。
- **适用条件**：习惯已存在或已选定，用户要「记录 + 维持 + 定期回看」。
- 缺什么要先问、**不许静默猜值**：若用户还没有任何要维持的习惯（要新建）→ 不代跑，分流到养成线；若输入是「某个行为没发生」→ 分流到诊断卡；要追踪哪个习惯 / 复盘哪一段时间不明确时先问。

### 输出契约

**产出类型**：`design`（建追踪表）+ `diagnosis`（复盘校准）

按触发方向给可检查产物：
1. **[design]（追踪 + 恢复）**：一张追踪表（日历打叉 / 回形针法 / 日志任一）＋「不中断链条」＋「绝不错过两次」的恢复规则（含断档时的「最小值」动作）。
   - **表只给空表，或显式标注「示例模板 · 请替换为你自己的记录」的样表**。用户没有提供的完成记录、打叉、连续天数、起止日期、当前进度**一律留空**，**不许替他填**——预填等于把编造的进度当成他的真实记录。用户只说「已坚持两个月」这类粗略说法时，也不据此推算出具体天数写进表里。
2. **[diagnosis]（复盘校准）**：一份复盘记录——年度复盘三问（今年什么做得好 / 什么不顺 / 学到什么）＋诚信报告三问（驱动我生活与工作的核心价值观 / 我现在如何诚信地生活工作 / 未来如何设更高标准），两套均作答并给出方向调整。若用 CBE 式量化，写明公式、基线与目标增幅，并注明「**1% 增幅与『无名英雄』加分项须主体按自己场景自定**」。

**完成标准**：追踪侧——能显示连续与断档，且断档时有一条明确的恢复动作；复盘侧——两套三问均作答并产出方向调整（或给出可复算的 CBE 指标）。

### 步骤

**第 0 步 · 判向（分流）**
- 动作：判断用户要的是哪条——当刻觉察（→第 1 步）/ 逐日追踪与恢复（→第 2 步）/ 定期复盘（→第 5 步）。
- 完成标准：明确落到至少一个方向，并说清选它的理由。
- 判停：若用户其实要「新建一个习惯」「改掉一个习惯」，或问「某行为为什么没发生」，则**不跑本卡**，按 B 段分流。

**第 1 步 · 当刻觉察（f13 / f14，可选前置）**
- 动作：列出你每天的日常习惯（f13）；逐条问「好 / 坏 / 中性」，标 +（净正向）/ −（净负向）/ =（中性）；疑难项用「这个行为帮我成为想成为的人吗？它为我的身份投票还是反对？」裁定。全程**只觉察、不改变、不带评判**。可加「指差确认」（f14）：把即将做的动作眼看、手点、口念、耳听说出口，把自动行为拉回意识层。
- 完成标准：得到一份带 + / − / = 评分的日常习惯清单，且未做任何改变。
- 判停：若用户接着要「改」，转入相应改法卡，改动不在本卡执行。

**第 2 步 · 建追踪表（f63，design）**
- 动作：选格式——日历打叉、回形针法、食物 / 锻炼日志等视觉计量（f63）；三条要则：①能自动化的计量尽量自动化；②手动只追**最重要的少数**习惯；③完成后**立刻**记录。可配追踪叠加公式 `After I [CURRENT HABIT], I will [TRACK MY HABIT]`。
- 完成标准：一张能显示连续 / 断档的追踪表 ＋ 一条明确的「完成后立刻记录」动作；且**表中不含任何用户未提供的记录**（要么是空表，要么每一处示例都已标注为示例）。
- 判停：若「要追的习惯」还没定，回第 0 步判向。

**第 3 步 · 定恢复规则（f65）**
- 动作：为追踪表配「**绝不错过两次**」规则（f65）：毁掉你的是连续失误而非第一次；一旦断链，尽快恢复，宁可做**最小值**也要出现，避免全有全无。
- 完成标准：恢复规则写明，且给出一个「断档当天可做的最小动作」。
- 判停：无（本步与第 2 步绑定，随追踪表一起给）。

**第 4 步 · 防反噬自检（f66 / f67）**
- 动作：自检「是不是为了数字而做」——当测量变成目标，它就不再是好测量（古德哈特定律，f66）。若已反客为主：把测量放回「大图景中的一条反馈」的位置，或换一个更能指示目的的指标（非体重胜利，f67：皮肤、睡眠、精力、衣服松紧）。并记住「可测量 ≠ 最重要、不可测量 ≠ 不重要」（`x34`）。
- 完成标准：给出一条「换指标 / 降低数字地位」的具体动作。
- 判停：若指标已反客为主且用户愿意 → 进换指标分支；否则保留原指标，但明确标注它只是反馈之一。

**第 5 步 · 定期复盘（f81 / f82，diagnosis）**
- 动作：**年度复盘**（每年 12 月，f81）——先清点这一年（发文数 / 锻炼次数 / 到访新地点……），再答三问「今年什么做得好 / 什么不顺 / 学到什么」；**诚信报告**（半年后，f81）——答三问「驱动我生活与工作的核心价值观是什么 / 我现在如何诚信地生活工作 / 未来如何设更高标准」。可选 CBE 式量化（f82）：正项相加 − 失误，再除以出场时间，得一个可比指标，要求每个赛季提升至少 **1%**（**该 1% 与「无名英雄」加分项须主体自定**），并与自身过往和同类对手比较。
- 完成标准：两套三问均作答并产出方向调整；若用 CBE，给出公式、基线与目标增幅（自定）。
- 判停：若复盘发现某个具体行为「该发生却没发生」→ 转 four-step-diagnosis（本书）/ `bmap-diagnosis`（福格）做要素级归因；本卡只做周期校准。

**回流汇总**：第 0 步分流；第 4 步自检失败 → 进换指标分支；第 5 步发现卡点 → 转诊断卡。

## B — Boundary

### 不要用（反场景）
- 要新建 / 养成一个还不存在的习惯 → 养成线（cue-design / two-minute-rule 等；跨书 `tiny-habit-design`）。
- 要戒掉 / 改掉一个坏习惯 → four-laws-inversion（本书）/ `change-bad-habit-system`（福格）。
- 问「某个行为为什么没发生」 → four-step-diagnosis（本书）/ `bmap-diagnosis`（福格）。
- 要「成为谁」、改身份句 → identity-design。
- 要契约 / 监督 / 自动化把未来锁死 → commitment-accountability。
- 要改环境里的线索 → environment-design。
- 只想了解模型 → 来源路由入口「原子习惯」。

### 作者警告过的失败模式（反例素材）
- **`x34`（作者原话）**：可测量的不等于最重要的，不可测量的不等于不重要——别让可量化指标（收入 / 体重 / 步数）挤掉不可量化的目的。
- **`x33`（作者原话）**：习惯对精通是**必要而非充分**条件，还必须叠加刻意练习；别以为养成 / 自动化习惯就等于掌握（自动化降低反馈敏感度，需不断回到费力区打磨下一个子技能）。
- **古德哈特反噬（f66）**：为数字而做，测量反噬目的。
- **全有或全无（f65）**：断了一次就彻底放弃；本书的解药是「绝不错过两次」。
- **追踪自身的代价（f63）**：追踪要花力气，所以能自动化就自动化、只追少数；追踪是手段不是目的。

### 作者盲点与待核查
- **f82 的 CBE 是单支球队的叙事案例（n=1）**：1% 增幅与「unsung hero」加分项都来自湖人队示例，**换到用户自己的领域时必须主体自定**，不能照抄 1% 和「拼抢」这类篮球动作；它是「把最佳努力量化」的一个示范，不是已证实的通用方法。
- **f67 成色弱**：单句概念型，产物薄（一个替代指标），只能作「测量反噬」的配套，不是独立方法。
- **f14 是场景数据外推**：85% / 30% / 57% 是日本铁路与纽约地铁的**场景数据**，作者未给个人生活场景的量化效果；把它推广到个人属作者的推断。
- **本册另有「正文无内联出处、端注成色弱」的通俗化数字**（如「40%–50% 的日常行为出于习惯」）；本卡在追踪 / 复盘环节**不依赖任何此类数字**。
- **f13 的身份投票判据借用了身份视角**：记分卡拿「是否为想成为的人投票」当疑难项的评分启发，这只是一个觉察用的判断口径，**不等于本卡主张「必须先定身份再行动」**。身份优先 vs 习惯造身份的作者张力，照录见 identity-design 的 B 段，本卡不代作者调和。
- **无临床 / 分诊判据（跨分区备注）**：已对全书 grep `professional / therapist / clinical / treatment / mental health / psychiatr`，**没有**任何「何时放弃本方法、转介专业人士」的判据；最接近的只有一句自限说明「这类技巧约束不了真正的成瘾」（第 12 章）。若用户要追踪 / 复盘的习惯涉及**临床成瘾、进食障碍、自伤等严重心理病理**，不跑本卡、提示转介专业人士——**这不是原书给的判据，是流程补的**。
- **无量化门槛**：f63 只说「手动只追最重要的少数」，原文**未给**「该追几个习惯」的具体数目；也**未给**「追踪多久才见效」的门槛。

### 相邻易混
- **觉察 ⇄ 追踪 ⇄ 复盘（卡内三向）**：都是「回看自己」，但时机与产物不同——觉察 = 当刻盘点（先觉察不改）、追踪 = 逐日打卡（维持 + 恢复）、复盘 = 定期校准（年度 / 半年）。三向近邻负例见 A2 §4。
- **`four-step-diagnosis` / `bmap-diagnosis`**：归因诊断「往回看为什么没发生」 vs 本卡的周期复盘「回看一段时间的走向」；复盘定位到具体行为没发生时要转诊断卡。
- **`reinforcement` / `celebration`**：即时奖赏 / 庆祝（完成时加好感觉）vs 本卡的记录与链条（进度可见）；机制相邻（f63 也说追踪提供满足），但产物不同。
- **`identity-design`**：f13 借用身份视角做评分、f81 复盘会重访身份，但本卡不出身份句、不做身份重定义。
- **`two-minute-rule` / `tiny-habit-design`**：把习惯缩小 / 从零建起来 vs 已有习惯后的维持与回看。

## 相关能力

- **four-step-diagnosis**（对比）：它做一次性要素级归因；本卡做周期性回看（觉察 / 追踪 / 复盘）。复盘定位到具体行为没发生转它。
- **identity-design**（组合）：追踪会重访身份视角、印证身份句，但本卡不出身份句、不做身份重定义。
- **commitment-accountability**（对比）：记录与复盘（看见自己）vs 约束与见证（让做不到有即时代价）。防双触发。
- **environment-design**（对比）：本卡追踪表虽也制造线索，但产物是记录；它改造环境线索。
- **reinforcement**（对比）：完成时加即时奖赏（它）vs 记录与链条让进度可见（本卡）；机制相邻、产物不同。

# 四步模型行为诊断（把「养不成 / 做不到」定位到 提示·渴望·反应·奖赏 的最短板）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 3 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f01`、`f02`），不随公开版分发。

## I — Interpretation

**四步模型**（`f01`）：任何习惯都按 **提示 → 渴望 → 反应 → 奖赏** 这个固定顺序运行。提示是一截「预测奖赏」的信息，触发大脑启动；渴望是动机之力（你渴求的不是习惯本身，而是它带来的状态改变）；反应是你实际做出的行为；奖赏满足渴望，并教会大脑「这个动作值得记住」。

**诊断的动作**（`p19`）不是问「你够不够自律」，而是把「想做却做不到 / 养不成」固定成一个具体行为，沿四步逐项判定「足 / 不足」，找出**最短的那块板**：

- 提示不足 → 行为永远不启动；
- 渴望不足 → 没有足够的动机去做；
- 反应太难 → 做不到；
- 奖赏不满足 → 将来不会重复。

**先把范围砍一半**（`f02`）：按两阶段粗分，先判卡在**问题阶段**（提示＋渴望：没被触发 / 没动机）还是**解决阶段**（反应＋奖赏：做不到 / 没回报），再进四步细查。粗分能降低诊断负担。

**诊断与改法分工**：本卡只负责「定位到四步中的哪一步」；具体改法落到四定律（建立侧 `f03` → four-laws-framework、反向侧 `f04` → four-laws-inversion）——四步的每一步恰好对应一条定律。

**与福格 B=MAP 的区别**：两套模型都是「排查缺了哪一环」，但**记法不同**——福格按「提示 → 能力 → 动机」补要素，本书按「提示 → 渴望 → 反应 → 奖赏」找最短板（分流句见 A2）。这一对争的是同一个「诊断」请求。

## A1 — Application Example

**主例 · 甜甜圈店习惯回路例题**（c15，**作者假想例题**）

- **输入/问题**：走过办公室附近的甜甜圈店。
- **怎么执行**：作者把它逐字拆成四步——1. Cue：你闻到甜甜圈店的香味；2. Craving：你开始渴望甜甜圈；3. Response：你买下并吃掉；4. Reward：你满足了吃甜甜圈的渴望。
- **结论/输出**：一个行为被干净地拆到四步；原文还在 cue+craving 之后标 **Problem phase**、在 response+reward 之前标 **Solution phase**，演示了 `f02` 的两阶段二分。
- **原书交代的结果**：例题本身即结局（假想演示），原文未给后续实际结果。

**补充例题 · 走进暗室开灯**（c14，**作者假想例题**）：作者用「已经做过无数次、瞬间完成」的开灯动作演示四步在一瞬间跑完（Cue 走进暗室 / Craving 想看清 / Response 开灯 / Reward 看见的渴望被满足）。

**合成演练（明确标记：原书未提供针对「养不成」的完整诊断案例）**

- **输入/问题**：「我想每天读书，但总在刷手机，说不清卡在哪。」
- **固定行为**：每晚睡前读一页书。
- **按四步排查**：提示=没有固定线索（书收在书架上、手机在枕边）→ 不足；渴望=不明显（刷手机更即时）→ 弱；反应=启动难（手机就在手边）→ 不足；奖赏=无即时回报 → 弱。
- **结论/输出**：最短板在**提示**与**反应**两步，改法落到第一定律（显而易见）与第三定律（简便易行）。此演练按 `f01` 的验收走查复算，不补造原书未给的条件。

## A2 — Future Trigger ★

**1）用户会在什么情境下遇到这类问题（3–5 条）**

- 一个具体行为「想做却做不到 / 总是忘记 / 养不成」，想知道到底卡在哪一步。
- 计划崩了要复盘：是没被触发、没动机、做不到，还是没有回报。
- 同一件事做了却坚持不下来，怀疑是「这一次」还是「下一次」出了问题。
- 手里有一堆四定律技巧（显而易见 / 有吸引力 / 简便易行 / 令人满足），却不知道该先动哪一条。
- 评估一个已经做过却没起作用的方案，想归因到四步里的哪一环。

**2）语言信号（中英双写关键 trigger）**

- 中文：为什么我养不成 / 就是做不到 / 总是忘记 / 卡在哪一步 / 问题出在哪 / 是没提示、没动机、太难，还是没回报 / 该先改哪一条定律。
- English: why can't I build this habit / where exactly is it stuck / which of the four steps is the weak link / is it cue, craving, response, or reward / why didn't it stick.

**3）与相邻能力怎么区分**

- four-laws-framework（建立侧落地）：本卡只产出「四步级定位」，改法清单在它。
- four-laws-inversion（反向侧落地）：目标是「已经发生、想让它停 / 换」的坏习惯，走它。
- 福格 `bmap-diagnosis`（跨书，同一「诊断」请求）：见下方分流句。
- 来源路由入口 `atomic-habits`：只想了解整书 / 问「书里某段怎么说」时走它。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs 福格 `bmap-diagnosis`】**「我不知道该多提醒、还是降低难度、还是加点激励」——用户已在用「提示 / 能力 / 动机」的要素语言归因，走 **`bmap-diagnosis`**。
- **【vs `four-laws-framework`】**「别诊断了，直接教我把好习惯建起来 / 给我一套建习惯的做法」——要的是**落地清单**而非定位，走 **`four-laws-framework`**。
- **【vs `four-laws-inversion`】**「帮我戒掉睡前刷手机 / 让这个坏习惯停下」——目标行为**已经发生、用户想让它停 / 换**，走 **`four-laws-inversion`**。
- **【vs 来源路由入口】**「原子习惯讲了什么 / 那个四步模型是什么」——只问来源、没有具体行为要诊断，走**来源路由入口 `atomic-habits`**。

**分流句（本卡 ↔ 福格 `bmap-diagnosis`）**：两套模型争同一个「这个行为为什么没发生」的请求。**福格 `bmap-diagnosis` 按「提示 → 能力 → 动机」补要素**（问的是「缺了 M / A / P 哪一个」）；**本书按「提示 → 渴望 → 反应 → 奖赏」找最短板**（问的是四步里哪一步不足）。用户用「动机 / 能力 / 提示」说事，走福格；用户用「渴望 / 反应 / 奖赏」说事，或要四步级定位，走本卡。

## E — Execution

### 输入契约

- **必需**：一个**具体行为** + 「它本应发生却没发生 / 养不成」这一事实（自己或他人均可）。
- 若用户只给概括型（「我太懒」「想更自律」）→ 先拆成具体行为（判据：一个在某一时刻能做 / 没做的动作）；**拆不出来就不要往下走**，先问清是哪个动作、发生在什么时刻。
- **可选**：用户已观察到的现象（总是忘记 / 启动难 / 做了不重复）。
- **适用条件**：目标行为是「想让它发生」的正向行为。若目标相反（已发生、想停），按判停点转出。

### 输出契约

**产出类型**：`diagnosis`（定位四步中最短板）`＋ patch`（可附：把改法落到对应定律）

- 固定结构：`{最短板：提示 / 渴望 / 反应 / 奖赏（可 1–2 项）}` ＋ `{下一步改哪条定律、具体做什么}`。
- 完成标准：给出一个（或两个）明确的待改步骤，且**排查顺序为 提示 → 渴望 → 反应 → 奖赏**；给出的改法指回对应定律（显而易见 / 有吸引力 / 简便易行 / 令人满足，或其反向）。

### 步骤与完成标准

1. **固定行为 + 分诊。** 写成一句话：某人在【具体时刻 / 情境】做【具体动作】。
   - 完成标准：这句话可判真假（「睡前读一页」可判；「变得更爱读书」不可判）。
   - 判停：目标是「一个还不存在的新习惯」→ 转 four-laws-framework；目标是「已发生、想让它停 / 换的坏习惯」→ 转 four-laws-inversion；只问模型是什么 → 转来源路由入口。
2. **两阶段粗分（`f02`）。** 先判卡在问题阶段（提示 / 渴望）还是解决阶段（反应 / 奖赏）。
   - 完成标准：给出「问题阶段 / 解决阶段」的初判。
3. **四步逐项排查（`f01` / `p19`）。** 沿 提示 → 渴望 → 反应 → 奖赏 逐项判「足 / 不足」，找最短板。
   - 完成标准：对每一步给出明确的「足 / 不足」判定，并点名最短板（1–2 项）。
4. **输出定位 + 改法落点。** 把最短板映射到对应定律，给出下一步动作。
   - 完成标准：最短板与建议动作一一对应，且动作落在对应定律上，不是泛泛的「加意志力」。

### 判停点

- 第 1 步若「拆不出可判断的具体行为」→ 回到输入契约先具体化，不进入第 3 步。
- 第 1 步分诊命中 → 按上表转出（four-laws-framework / four-laws-inversion / 来源路由入口 / 福格 `bmap-diagnosis`）。
- 第 3 步若涉及成瘾 / 病理行为 → 见 B 段，照录自限句，不硬套诊断。

## B — Boundary

### 不要用（反场景，按分流）

- 要**从零建一个好习惯 / 要落地清单** → four-laws-framework。
- 要**停下 / 换掉一个已经发生的坏习惯** → four-laws-inversion。
- 用户用「动机 / 能力 / 提示」说事，或在做「缺哪一要素」的归因 → 福格 `bmap-diagnosis`。
- 只想了解整书 / 问书里某段怎么说 → 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式

- **把四步当成穷尽的完整理论**（`x29`，作者原话、硬边界）：作者说，宣称这四条定律是改变任何人类行为的**穷尽框架**，是不负责任的。诊断遇到四步解释不了的行为（非「习惯性」行为、结构性约束下的行为），**不要硬套四步**。
- **把「做不到」归因于意志力**：诊断要先把归因从品格移到四步（哪一步不足），而不是停在「我不够自律」。四步与四定律的用意正是用**设计**替代硬扛。

### 作者盲点与待核查（存量风险）

- **`f01` 的自限句 / 四步非穷尽**（第二组）：作者同章既称四步是「每个习惯的骨干」，又自认四定律非穷尽（即 `x29`）。**两条都收，不替作者调和**：本卡操作层有效（能把一个具体行为拆成四步并定位短板），但不为其「覆盖一切行为」的普遍性背书。
- **第四组「忘掉目标 ↔ 目标定方向」**（小节标题「忘掉目标、专注系统」 ↔ 正文「目标用来定方向，系统用来推进」）：作者一边喊「忘掉目标、专注系统」，一边明说「目标用来定方向，不是全盘否定目标」。**原样保留**：诊断时不要把「设目标」一并否定掉——目标可用来定方向，系统（四步 / 四定律）用来推进。
- **身份因果张力（简述）**：作者同时主张「身份先行」与「习惯造身份」，优先次序含混，**不替作者调和**（详见 identity-design 的 B 段）。
- **成瘾 / 病理无分诊判据**：全书 grep `professional / therapist / clinical / treatment / mental health / psychiatr` 零结果；涉成瘾只有一句自限句在第 12 章，大意是这类技巧难以遏制真正的成瘾。**本卡只能照录「四步 / 四定律技巧不适用于临床成瘾 / 病理」**；转介判停线属流程自补，非原书依据。
- **「某一步不足到什么程度算不足」原文未给量化门槛**，只给方向性判断（有 / 无、强 / 弱），不得当作量表使用。

### 相邻易混

- **福格 `bmap-diagnosis`**：同一「诊断」请求的另一套记法（提示 → 能力 → 动机）；见 A2 分流句。
- **`four-laws-framework`**（建立侧）：本卡产出「四步级定位」，它承载「改法清单」。
- **`four-laws-inversion`**（反向侧）：目标行为方向相反（已发生、要停）走它。
- **`identity-design`**：要「想成为谁 / 角色丧失后重构」走它；本卡不做身份层诊断。

## 相关能力

- **four-laws-framework**（对比）：本卡只做「卡在提示 / 渴望 / 反应 / 奖赏哪一步」的定位；建立侧改法清单在它（壳 ↔ 落地，`f01` ⇄ `f03`）。要落地走它。
- **four-laws-inversion**（对比）：目标行为「已经发生、想让它停 / 换」时，反向四律清单在它。
- **identity-design**（对比）：要「想成为谁 / 角色丧失后重构」走它；本卡不做身份层诊断。
- **habit-tracking-reflection**（对比）：本卡是一次性归因；它是周期性回看。复盘定位到具体行为没发生转本卡。

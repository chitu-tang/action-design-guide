# 诱惑捆绑（把想做的绑到需做的上，给必做行为加吸引力）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 8 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f31`、`f32`），不随公开版分发。

## I — Interpretation

本卡是**第二定律（让它有吸引力）**里给「必做之事」加吸引力的一条工具，只做一件事：**把你想做的动作，挂到你需要做的动作之后**，让需做的事被想做的事牵引。

- **底层机制**：作者把它归到 **Premack 原理**——更喜欢、更常做的行为会强化不太想做的行为。所以在「需做」之后紧接一个「想做」，需做的事就带上了吸引力。
- **两层配方**：它可与 `f17`（习惯叠加）合成一条规则，先用既有习惯触发「需做」，再用「需做」触发「想做」——`After [CURRENT HABIT], I will [HABIT I NEED].` / `After [HABIT I NEED], I will [HABIT I WANT].`
- **一个区分**：本卡给的是「**加吸引力**」的**零件**——改变已有目标行为的吸引力，而不是设计整个习惯、也不是锁死未来。它产出**一份捆绑配方**：一个「需做」+ 一个「想做」→ 一条「先需做、后想做」的规则。

一句话：**用一件真想做的事，给一件必须做的事当奖赏。**

## A1 — Application Example

**主例 · Ronan Byrne 把 Netflix 绑上动感单车**（c45，**作者转述的第三人案例**）

- **输入/问题**：爱尔兰都柏林电子工程学生 Ronan Byrne 爱看 Netflix，但知道自己该多运动。
- **怎么执行**：他把动感单车改装接上电脑与电视，写程序让**只有踩到一定速度，Netflix 才继续播放**；减速太久节目就暂停，直到他继续踩踏。这把「想看 Netflix（want）」绑在「骑动感单车（need）」上。
- **结论/输出**：一份「想做 ↔ 需做」的捆绑配方；作者用它说明诱惑捆绑能让运动习惯变得有吸引力。
- **原书交代的结果**：粉丝评价他是一集一集地看 Netflix、一点点甩掉肥胖；原文**未给**体重 / 时长的量化结果。

**辅例 · ABC 的「TGIT」周四档**（c46，**作者转述**）：电视台把 Shonda Rhimes 的三部剧排在周四、并鼓励观众看剧时吃爆米花喝红酒，把「需要观众做的事（看剧）」与「观众本来就想做的事（放松、喝酒、吃爆米花）」绑在一起。原文交代的结果：观众逐渐把「周四晚 8 点」与放松、娱乐联系起来，看剧习惯变得更有吸引力；**未给收视率数据**。

**书中另给的自用配方**（作者举例）：想听八卦就**只在健身房**看小报 / 真人秀；想做美甲就**只在处理积压邮件时**做美甲。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 「有件事我必须做但总拖（健身、处理邮件、打销售电话），能不能把我想做的事和它绑在一起，让它没那么难受？」
- 「我想看的剧 / 想刷的节目停不下来，能不能拿它当奖励，逼自己去运动 / 学习？」
- 「我知道要养成这个习惯，但这件事太没劲，有没有办法给它加点吸引力？」
- 「怎么设计一条『做完必须做的事，才允许做想做的事』的规则？」
- 「习惯叠加 + 诱惑捆绑具体怎么写成一条配方？」

**2. 语言信号（中英双写）**

- 中文：诱惑捆绑 / 把想做的绑在需做的上 / 给这件事加吸引力 / 做完 A 才允许做 B / 用喜欢的当奖励 / 太没劲 / 提不起劲。
- English: temptation bundling / link a want with a need / make it attractive / only do X while doing Y / reward with something I like / Premack.

**3. 与相邻能力怎么区分**

- **`deep-motive`**（对比，见分流句）：本卡问「怎么给这个行为**加**吸引力」，它问「这个渴望**背后**要满足什么深层动机」。
- **`social-norms`**（对比，见分流句）：本卡靠**自己配的奖赏**（want）给需做之事加吸引力；它靠**亲近者 / 多数人 / 权势者**（外部群体）加吸引力。
- **`reframe`**（对比）：那条是「不得不 → 我可以」的**心态重述**（`f39`/`f40`）；本卡是**行为配对**，不改对行为的描述。
- **`cue-design`**（组合）：`f17` 习惯叠加给「挂到既有线索上」的配方格式；本卡把「想做」接在「需做」之后，二者合成叠加 + 捆绑的双层公式。
- **`commitment-accountability`**（对比）：要「一次性锁死 / 自动化 / 契约 / 罚则」走它（`f54`）；本卡是**给行为加吸引力**，不削减未来选项。
- 福格 `tiny-habit-design`（跨书对比）：从零养成一个习惯走它；本卡只管给已定的需做行为加吸引力。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我从零养成每天跑步的习惯，给我一套方案」→ 不触发本卡，走福格 `tiny-habit-design`。
- 「这帮我想戒掉它 / 让它变得没吸引力」→ 不触发本卡，走 four-laws-inversion（/ 福格 `change-bad-habit-system`）。
- 「帮我改对这件事的心态（不得不 → 我可以）」→ 不触发本卡，走 **`reframe`**（`f39`）。
- 「我想借身边人 / 圈子 / 榜样来带动自己」→ 不触发本卡，走 **`social-norms`**。
- 「我压力大就想做这件事，背后的真实需求是什么？」→ 不触发本卡，走 **`deep-motive`**。
- 「帮我把这件事设成自动 / 一次性锁死」→ 不触发本卡，走 **`commitment-accountability`**（`f54` 锁定而非捆绑）。

**分流句（本卡 ↔ `social-norms` ↔ `deep-motive`）**：想让**一件必须做的事**变得有吸引力、靠**自己配一件真想做的事**去牵引它 → temptation-bundling；想让**某个行为**因为「我这圈子 / 大多数人 / 我佩服的人都在做」而变有吸引力 → social-norms；想知道**一个表层渴望背后**要满足什么深层需求、好换个方式满足 → deep-motive。

## E — Execution

### 输入契约

- **必需**：① 一个**必须做但缺乏吸引力 / 总在拖**的具体动作；② 一个**自己真心想做、能带来愉悦**的具体动作。缺任一者**先问**，不许静默替用户挑一个「想做的」。
- **可选**：已有的线索 / 既有习惯（用于套 `f17` 叠加）；这个「想做」是否已能方便地在同一时间 / 场景发生。
- **适用条件**：只解决「给已定的需做行为加吸引力」。若用户其实要「从头设计一个习惯」「改心态」「锁死未来」「找社会群体」→ 按 B 段分流。

### 输出契约

**产出类型**：`patch`（给已有计划补一条「吸引力」零件：把「想做」挂到「需做」之后）

一份**捆绑配方**，至少含：

- ① 一个明确的「**需做**」动作；
- ② 一个明确的「**想做**」动作（且已确认是真心想做的）；
- ③ 一条可照着执行的规则句：`After [需做]，I will [想做]`；若还需先落地「何时做需做的事」，再加一层 `After [当前习惯]，I will [需做]`（`f17` 叠加）。

**完成标准**：配方能当天照着用，且「需做的事」与「想做的事」在同一时间 / 场景内可先后相接（不是晚上才兑现的延后奖励）。

### 步骤

1. **确认两个动作的对子**：写出一个「需做」与一个「想做」；核对「想做」是当事人真心想做的（凭此产生吸引力）。
   - 完成标准：得到一对明确的 need/want。
   - 判停：若当事人其实要「从头养成一个习惯」→ 转福格 `tiny-habit-design`；要「改心态」→ 转 `f39` reframe。
2. **按 Premack 顺序排序**：把「想做」放在「需做」**之后**（需做在前、奖赏在后），写成 `After [需做]，I will [想做]`。
   - 完成标准：一条可执行规则句，顺序为「先需做、后想做」。
3. **（可选）套上习惯叠加**：若「需做」还缺触发时机，用 `f17` 给它挂一个既有习惯，形成 `After [当前习惯]，I will [需做]` + `After [需做]，I will [想做]` 双层。
   - 完成标准：配方落到一个明确的既有线索上。
4. **可及性自检**：「想做」与「需做」能在同一场景 / 同一时段完成（否则奖赏落空）。
   - 完成标准：确认二者能先后相接；若不能，调整动作或场景。

### 判停点

- 第 1 步要「从头设计一个习惯」→ 转福格 `tiny-habit-design`。
- 第 1 步要「改心态 / 重述」→ 转 `f39` reframe。
- 第 1 步要「一次性锁死 / 自动化 / 契约」→ 转 commitment-accountability。
- 第 1 步要「借群体 / 身边人带动」→ 转 social-norms。
- 第 1 步问「渴望背后的真实需求」→ 转 deep-motive。

## B — Boundary

### 不要用（反场景，按分流）

- 从零养成一个新习惯 / 设计「该做什么、怎么缩小」→ 福格 `tiny-habit-design`。
- 要打破坏习惯 / 让它变得没吸引力 → four-laws-inversion（/ 福格 `change-bad-habit-system`）。
- 要把「不得不」重述成「我可以」→ **`reframe`**（`f39`，心态重述，非行为配对）。
- 要借亲近者 / 多数人 / 权势者带动 → **`social-norms`**。
- 要问渴望背后的深层需求 → **`deep-motive`**。
- 要一次性锁死 / 自动化 / 契约 / 罚则 → **`commitment-accountability`**（`f54`）。
- 纯信息查询（「诱惑捆绑是什么意思」）→ 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式（反例素材）

- **本章没有针对「诱惑捆绑」本身的反向警告**；作者对第二定律「吸引力」的自我限制落在邻卡：x03（用羞辱 / 恐吓推行为会反噬）、x07（过度便利 / 自动化的副作用）。本卡不引用与自己无关的警告。
- **配对顺序不能反**：公式把「想做」放在「需做」**之后**；若把奖赏放在需做之前，吸引力不会牵引需做的事。

### 作者盲点与待核查（写进卡、不许越界宣称）

- **原文未给「吸引力强度 / 绑定次数」的量化门槛**：f31/f32 只给定义与公式，未说绑多久、多紧才算奏效。
- **原文未给「想做的那件事本身是你想戒掉的坏习惯」时的处置**：把想戒的坏习惯当作奖赏去强化需做之事，会与「削弱该坏习惯」的目标相冲；本书**未讨论这一冲突**（**这是本书未覆盖处**）。→ 遇此情形按分工分流（削弱坏习惯走 four-laws-inversion / 福格 `change-bad-habit-system`）。
- **让位记录**：f31 五判据全过、证据充分、福格无竞品，本可晋级；但在整书入口预算（1 路由 + 4 晋级）下裁定其**让位**。

### 相邻易混

- **`social-norms`**：自己配的奖赏（本卡）vs 外部群体（它）。
- **`deep-motive`**：给行为加吸引力（本卡）vs 追问渴望背后的需求（它）。
- **`reframe`**：行为配对（本卡）vs 心态重述（它，`f39`/`f40`）。
- **`cue-design`**：本卡是它的组合件（叠加 + 捆绑双层公式）。
- 福格 `tiny-habit-design`：全流程养成（它）vs 给已定行为加吸引力的单点（本卡）。

## 相关能力

- **social-norms**（对比）：给行为加吸引力的两条不同来源——自己配奖赏（本卡）vs 借亲近者 / 多数 / 权势者（它）。
- **deep-motive**（对比）：本卡给行为「加」吸引力；它追问「这个渴望背后要什么」。
- **reframe**（对比）：行为配对（本卡：把想做的绑到需做的）vs 心态重述 / 动机仪式（它）。

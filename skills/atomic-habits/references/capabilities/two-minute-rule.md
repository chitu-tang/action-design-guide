# 两分钟法则（the two-minute rule：门户习惯 · 先标准化再优化 · habit shaping 逐级升级）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 13 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f50`、`f51`、`f52`），不随公开版分发。

## I — Interpretation

本卡解决一件事：**一个新习惯「起不来」时，把它的起始版本缩到足够小，让它先发生。**

三层内容：

1. **两分钟法则（阈值）**：新习惯的起始版应**用不到两分钟就能完成**。作者给的缩放示范：`Read before bed each night` → 「读一页」；`Do thirty minutes of yoga` → 「拿出瑜伽垫」；`Study for class` → 「打开笔记」；`Run three miles` → 「系上跑鞋带」。配套原则是「**先标准化，再优化**」——习惯先要存在，才谈得上改进。
   还有一条加强版：**做两分钟就停**（作者同章说明其用意——先「掌握出现的习惯（showing up）」，每次做两分钟都是在「为你想成为的那种人投票」）。原文强调：**不是靠它开始，而是把它当成整个习惯**。
2. **门户习惯（入口动作）**（`f51`）：比两分钟版更进一步，找那个**能自然引向目标行为的最小起始动作**。求法是把目标按「very easy → very hard」摊成一把刻度——跑马拉松（very hard）／跑 5K（hard）／走一万步（moderately difficult）／走十分钟（easy）／**穿上跑鞋（very easy）**——取最易那一端当门户。
3. **habit shaping（逐级升级）**（`f52`）：等习惯稳定、每天都出现之后，**把目标拆成若干级，每一级都先掌握该级的「前两分钟」**，再往下一级走，直到回到最初的目标。作者给了三组 5 阶段示例（早起 / 成为素食者 / 开始锻炼）。

一句话：**入口先放到最小（两分钟 / 门户习惯）→ 让它先存在（先标准化）→ 稳定后再逐级放大（habit shaping）。**

## A1 — Application Example

**主例 · 读者用「健身房只待五分钟」减重 100 磅以上**（`c71`，**原书转述**）

- **输入/问题**：一位读者想健身 / 减重。
- **怎么执行**：他每天去健身房，但**规定自己最多只待五分钟**——到时立刻离开（两分钟法则的变体：把起始版压到远低于「完整健身」的量）。
- **结论/输出（原文交代的结果）**：几周后他逐渐延长了停留时间；几年后体重消失、减重逾 100 磅。
- **成色**：转述案例，无对照样本量。

**辅例 · Greg McKeown 刻意「少写一点」的日记习惯**（`c72`，**原书转述**）

- 英国领导力顾问 Greg McKeown 建立每日日志习惯的方式，是**刻意少写**——总是在「写起来开始像负担之前」就停下（呼应海明威的做法：总在写得顺手时收笔）。
- **结论/输出**：原文**未给** McKeown 日志习惯的具体后续量化结果（**未说明**）。
- **成色**：转述案例（英文版注释记为 McKeown, *Essentialism*, 2014, p.78）；海明威引语在正文同段、**注释未单列出处**。

**habit shaping 的示例表（作者构造的演示例题，非真人计划）**（`c73`）

- 「开始锻炼」5 阶段：Phase 1 换上运动服 → Phase 2 出门走 → Phase 3 开车去健身房、练 5 分钟就离开 → Phase 4 每周至少一次练 15 分钟 → Phase 5 每周三次。
- **结论/输出**：原文**未交代执行结果**（例题本身即演示，**未说明**）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 想开始一个新习惯（读书 / 运动 / 写作 / 冥想）但**总起不来**。
- 一上来就定太大（每天 30 分钟），几天后筋疲力尽、放弃。
- 想给一个**宏大目标**找一个小小的**入口动作**。
- 想让习惯**先存在**、稳定下来再谈优化（「先标准化再优化」）。
- 已经能稳定做两分钟版了，想**逐级加量**到目标版。

**2. 语言信号（中英双写）**

- 中文：两分钟法则 / 起不来 / 从小处开始 / 缩到最小 / 起个头 / 门户习惯 / 先开始再说 / 先做五分钟 / 逐级升级 / 习惯塑造 / 先标准化再优化。
- English: two-minute rule / can't get started / start small / shrink the habit / gateway habit / habit shaping / just show up / standardize before you optimize.

**3. 与相邻能力怎么区分**

- **福格 `tiny-habit-design`（跨书，同一「把行为缩小到立刻能做」请求）**：福格那条是「**缩小规模 + 找锚点 + 庆祝**」的**完整养成流程**（明确愿望 → 发散行为选项 → 筛黄金行为 → 缩成微行为 → 接锚点 → 庆祝 → 扩展维持）；本卡是「**门户习惯 + 两分钟门槛 + habit shaping 逐级升级**」这一套，**不包含锚点匹配与庆祝**。
- cue-design：本卡给**阈值 / 入口**；它给「**何时何地做**」的线索格式（执行意图 / 习惯叠加）。
- friction-prime：本卡缩小**行为本身**；它改**环境步骤 / 难度**。
- motion-vs-action：本卡解决「**起不来**」；它判定「在**准备**还是在**行动**」。
- decisive-moments：本卡是**入口门槛**；它是**一天里的岔路口选择**。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我从零跑完整套习惯养成方案（选行为 + 接锚点 + 庆祝 + 维持扩展）」→ 走福格 **`tiny-habit-design`**（全流程，不是只缩入口）。
- 「我想把这个习惯接到『刷完牙之后』」→ 走 **`cue-design`**（锚点 / 习惯叠加）。
- 「这件事本身太麻烦、步骤太多」→ 走 **`friction-prime`**（改环境难度）。
- 「我一直在准备、研究，迟迟不开始，怎么判断」→ 走 **`motion-vs-action`**。
- 「我每天下午那点总是不知不觉刷手机」→ 走 **`decisive-moments`**（岔路口）。
- 「这套模型是什么」→ 走来源路由入口 `atomic-habits`。

**分流句（本卡 ↔ 相邻三卡）**：**入口门槛太高、根本起不来** → **`two-minute-rule`**；分不清自己是在「**准备**」还是在「**行动**」→ **`motion-vs-action`**；每天几个**岔路口式的小选择** → **`decisive-moments`**。
**分流句（本卡 ↔ 福格 `tiny-habit-design`，同一「缩小行为」请求）**：要「**缩小规模 + 锚点 + 庆祝**」的**完整养成流程**（还要选黄金行为、配锚点、做庆祝、长期扩展）→ 福格 **`tiny-habit-design`**；只要「**门户习惯 + 两分钟门槛 + habit shaping 逐级升级**」这一套——把新习惯缩到两分钟内、先标准化再优化、稳定后逐级加量 → 本卡 **`two-minute-rule`**。

## E — Execution

### 输入契约

- **必需**：①一个**想开始的新习惯**（如「每天读书」）；**或**一个**想达成的目标**（如「跑马拉松」——若给的是目标，需先转成门户习惯）。缺习惯 / 目标时**先问**，不许静默替用户猜。
- **可选**：用户以往「起不来」的经历、能投入的时间、想升级到的目标版。
- **适用条件**：用户的问题是「**入口太大 / 起不来**」。若要的是**完整养成流程**（含锚点、庆祝）→ 按 B 段分流到福格 `tiny-habit-design`；若「何时何地做」→ cue-design。

### 输出契约

**产出类型**：`patch`（给已有计划换零件：把习惯的起始版缩到两分钟 / 门户习惯；稳定后加一条升级路径）

- ① 一个 **≤2 分钟**的起始版动作（两分钟法则）；
- ② 若输入是**大目标**：一把「very easy → very hard」的刻度，并把**最易那一端**定为门户习惯；
- ③ 可选：一条「**做两分钟就停**」的加强版（用于建立「出现」的身份）；
- ④ 可选（习惯已稳定时）：一条 **habit shaping 分阶段升级路径表**，每级写明「该级的前两分钟」是什么。

**完成标准**：起始版能用「用不到两分钟 / 穿跑鞋 / 打开书」这类动作说清，且用户明白先让它**存在**、稳定后再升级；升级路径每一级都有可执行的「前两分钟」动作。

### 步骤与完成标准

1. **取一个想开始的新习惯 / 目标**：确认输入是「习惯」还是「大目标」。
   - 完成标准：得到一句「我想开始做 X」或「我想达成 Y」。
2. **缩到两分钟版（或门户习惯）**：直接给该习惯一个 ≤2 分钟的起始版；若给的是大目标，先把目标摊成「very easy → very hard」的刻度、取最易端作门户（如马拉松 → 穿上跑鞋）。
   - 完成标准：产出一条 **≤2 分钟**、可当天执行的动作；若是大目标，附上刻度并指明门户。
3. **写清「先标准化再优化」（+ 可选加强版）**：说明这个起始版先让习惯**存在**，稳定后再优化；可选加「做两分钟就停」的加强版。
   - 完成标准：用户能说出「先让它存在，再谈改进」；起始版与目标版的关系明确。
4. **（习惯稳定后）habit shaping 逐级升级**：把目标拆成若干级，每级先掌握该级的「前两分钟」，逐级提高。
   - 完成标准：产出一条**分阶段升级路径表**，每级有可执行的「前两分钟」动作；并**明确告知**每级停留多久 / 增幅多大原文未给，需主体自定。
   - 判停：若用户其实要「**完整养成流程（含锚点 / 庆祝 / 扩展）**」→ 转福格 **`tiny-habit-design`**；若「**何时何地做**」→ 转 **`cue-design`**。

### 判停点

- 用户要完整养成流程（选行为 + 接锚点 + 庆祝 + 维持）→ 转福格 **`tiny-habit-design`**。
- 用户要「把新习惯接到某既有行为后面」→ 转 **`cue-design`**。
- 用户的问题是「这件事本身太麻烦、步骤太多」→ 转 **`friction-prime`**。
- 用户其实卡在「准备 vs 行动」→ 转 **`motion-vs-action`**；卡在「一天里的岔路口」→ 转 **`decisive-moments`**。

## B — Boundary

### 不要用（反场景，按分流）

- 要「**缩小规模 + 锚点 + 庆祝**」的完整养成流程 → 福格 `tiny-habit-design`。
- 要「把新习惯接到某既有行为后面（何时何地做的线索格式）」→ cue-design。
- 问题是「这件事本身太麻烦、步骤太多」→ friction-prime。
- 问题是「一直在准备 / 研究，迟迟不开始」→ motion-vs-action。
- 要处理「一天里几个岔路口式的小选择」→ decisive-moments。
- 只想了解这套模型本身 → 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式（反例素材）

- **一上来做得太大 / 太早**（`x06`）：即便知道该从小处起，兴奋也会让人一上来就做得太大、太多太快，很快耗尽、放弃。→ 正解就是两分钟法则把起始版压到两分钟以内。
- **全有或全无**（`x08`，**相邻概念的反例**）：「做不到完美就干脆不做」会毁掉习惯。→ 「做两分钟就停」的加强版**不能被误读**成「做不到完整版就白做」。（该反例的原绑定对象是习惯追踪，此处作相邻参照、须标明。）

### 作者盲点与待核查（缺口）

- **habit shaping 的「每级停留多久、增幅多大」原文未给**：`f52` 只给了「每级先掌握该级前两分钟」的方法与三组示例（早起 / 素食 / 锻炼各 5 阶段），**没有**规定「每级要停留多少天 / 几周」「每级增幅多大」「何时可以升级」。路径**可仿制，但升级节奏无量化门槛**。
- **「两分钟」是作者的操作性阈值，非实验得出的常量**：`f50` 给的是一条操作性规则——「两分钟」不是被实证测定的界限。
- **门户习惯的求法只在示例里**：`f51` 给了「把目标摊成 very easy → very hard、取最易端」的示范（马拉松 → 5K → 走一万步 → 走十分钟 → 穿上跑鞋），但**未给**「摊几级、粒度多细」的规则。
- **涉戒断 / 成瘾不在本卡职责内**：若用户实际是在「戒某物」，本书涉成瘾只有一句自限说明——「这类技巧约束不了真正的成瘾」（第 12 章），且全书无分诊判据；本卡只处理「开始 / 起不来」，**不得**把它讲成戒断工具。

### 相邻易混

- 福格 `tiny-habit-design`：全流程（缩规模 + 锚点 + 庆祝 + 扩展）vs 本卡（门户习惯 + 两分钟门槛 + habit shaping）。
- cue-design：本卡给阈值 / 入口，它给「何时何地做」的线索格式。
- friction-prime：本卡缩小行为本身，它改环境步骤 / 难度。
- motion-vs-action：本卡解决「起不来」，它判定「准备 / 行动」。
- decisive-moments：本卡是入口门槛，它是一天里的岔路口选择。

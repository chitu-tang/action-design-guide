# 行为改变四定律框架与章末操作集（建立侧：显而易见 · 有吸引力 · 简便易行 · 令人满足）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 3 章（2018；中译《原子习惯》），四张章末操作集分见第 7、10、14、17 章。原文依据保存在私有工作区（溯源条目 `f03`、`f15`、`f34`、`f48`、`f62` 等），不随公开版分发。

## I — Interpretation

本卡是**建立侧四律总纲**：把四步模型（`f01`）的四步，各转成一根可拨动的**杠杆**，用来**建立好习惯**：

| 步 | 定律 | 正向做法 | 对应章末操作集 |
|---|---|---|---|
| 提示 | 第 1 定律 | 让它**显而易见** | `f15` 1.1–1.4 |
| 渴望 | 第 2 定律 | 让它**有吸引力** | `f34` 2.1–2.3 |
| 反应 | 第 3 定律 | 让它**简便易行** | `f48` 3.1–3.5 |
| 奖赏 | 第 4 定律 | 让它**令人满足** | `f62` 4.1–4.4 |

四张章末整合表把每条定律落成**可执行的操作清单**（并非另一套理论，是同一张速查表逐章累加）：

- **第一定律**：1.1 记分卡（觉察）→ 1.2 执行意图（when/where）→ 1.3 习惯叠加（挂到既有习惯）→ 1.4 环境设计（让好线索显眼）。
- **第二定律**：2.1 诱惑捆绑 → 2.2 加入「期望行为即常态」的文化 → 2.3 动机仪式。
- **第三定律**：3.1 减摩擦 → 3.2 预备环境 → 3.3 决定性时刻 → 3.4 两分钟法则 → 3.5 自动化。
- **第四定律**：4.1 强化（完成即奖赏）→ 4.2 让「什么都不做」也满足 → 4.3 追踪器不中断链条 → 4.4 绝不错过两次。

三个收口工具：

- **四问自检**（`p22`）：最轻量的入口——每当要改一个行为，就问「怎么让它显而易见 / 有吸引力 / 简便易行 / 令人满足？」，找出能撬动的那根杠杆。
- **分工口径**（`p86`）：前三条定律管「**这一次**」发生，第四条定律管「**下一次**」重复。行为做了却不重复 → 优先查第四定律。
- **轮换循环**（`f85`）：改进没有终点——依次轮换四律，找到当前瓶颈、优化，再进入下一轮（round and round）。

**与诊断/反向的分工**：诊断「卡在哪一步」由 four-step-diagnosis（`f01`/`p19`）负责；**打破坏习惯**的反向清单由 four-laws-inversion（`f04`）承载——本卡只装**建立侧**正向四律与其操作集。

## A1 — Application Example

**合成演练（明确标记：原书未提供把四条定律一次跑完的单一完整案例）**

- **输入/问题**：想建立「每天早起」。
- **怎么执行**（依次问四句，各产出一条动作）：显而易见=前夜把闹钟放到房间另一头；有吸引力=起床后先喝一杯喜欢的咖啡；简便易行=前一晚备好衣物；令人满足=打卡记录连续天数。
- **结论/输出**：一次四问产出四条具体动作，分别落在 `f15`/`f34`/`f48`/`f62` 四条定律的清单上。此演练按 `f03` 的验收走查复算，不补造原书未给的条件。

**补充真实案例（说明四律「适用于几乎每个领域」的用意）**

- **英国自行车队与 Dave Brailsford 的「边际收益聚合」**（c04，**作者转述**）：作者转述 2003 年 Brailsford 任英国自行车队绩效总监，把骑车涉及的**每一件事拆开、各改善 1%**（边际收益聚合），作为「对小改善的系统化设计」的范例。**原书交代的结果**：2008 北京奥运拿下公路与场地自行车 60% 金牌；2012 伦敦创 9 项奥运纪录、7 项世界纪录；2007 至 2017 年英国选手夺 178 个世界冠军、66 枚奥运/残奥金牌、5 个环法冠军（成绩数字见英文版注释，作者转述、非本书统计口径）。
- **作者把手机留在另一房间**（c67，**原书亲历**）：作者自述尽可能把手机放到另一间屋到午饭时间，用增高摩擦来减少无意识查看，属于第 3 定律（给坏习惯加摩擦）的落地；同一动作也可读作第 1 定律的反向（让坏线索隐而不见）。**原书交代的结果**：他因此每早获得三到四小时不被打断的工作时间。

## A2 — Future Trigger ★

**1）用户会在什么情境下遇到这类问题（3–5 条）**

- 要从零把一个好习惯「设计出来」，想先拿到一套系统做法。
- 手里有许多习惯技巧，想弄清它们各归哪条定律、该按什么顺序用。
- 行为做了却不重复，想知道该查哪条定律（这一次 / 下一次）。
- 已建立的习惯想继续变好，要找「下一个瓶颈」。
- 想用「怎么让它显而易见 / 有吸引力 / 简便易行 / 令人满足」四句做最轻量自检。

**2）语言信号（中英双写关键 trigger）**

- 中文：怎么建立这个好习惯 / 给我一套建习惯的做法 / 四定律怎么用 / 让它显而易见 / 有吸引力 / 简便易行 / 令人满足 / 做了不重复该查哪条 / 找下一个瓶颈。
- English: how do I build this habit / the four laws of behavior change / make it obvious-attractive-easy-satisfying / which law should I work on / find the next bottleneck / why did it not stick.

**3）与相邻能力怎么区分**

- four-step-diagnosis（前置诊断）：只做「卡在四步哪一步」的定位，走它；本卡承载改法清单。
- four-laws-inversion（反向侧）：目标是「停下 / 换掉坏习惯」，走它。
- 来源路由入口 `atomic-habits`：只想了解整书 / 问书里某段怎么说，走它。
- 各单点手段卡（cue-design / environment-design / two-minute-rule 等）：只想要某一根杠杆的细做法，走对应单点卡。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs `four-laws-inversion`】**「帮我戒掉睡前刷手机、让这个坏习惯停下」——要的是**反向四律**（隐而不见 / 缺乏吸引力 / 难以实行 / 令人不满），走 **`four-laws-inversion`**。
- **【vs `four-step-diagnosis`】**「先别给做法，我只想知道到底卡在提示还是反应」——要的是**定位**而非落地清单，走 **`four-step-diagnosis`**。
- **【vs 各单点手段卡】**「就想把一个行为缩到两分钟 / 只想改环境里看得到的东西 / 只想做执行意图」——只动**一根杠杆**，走对应单点卡（two-minute-rule / environment-design / cue-design）。
- **【vs 来源路由入口】**「原子习惯讲了什么 / 那四定律是什么」——只问来源、没有具体行为要设计，走**来源路由入口 `atomic-habits`**。

**分流句（本卡 ↔ `four-step-diagnosis`）**：要「**定位**卡在提示 / 渴望 / 反应 / 奖赏哪一步」走 four-step-diagnosis；要「**改法清单**、把好习惯按四律设计出来」走本卡。二者是「壳 ↔ 落地清单」的关系（`f01` ⇄ `f03`/`f04`）。

## E — Execution

### 输入契约

- **必需**：一个想**建立**的具体好习惯（一句话：某人 / 我在某时刻做某动作）。
- 若用户只给抽象愿望（「想更健康」「想更自律」）→ 先拆成具体行为；**拆不出就不要往下走**。
- **可选**：当前已有的做法、可用空间 / 工具、能否提前布置、偏好的杠杆。
- **适用条件**：目标方向是**建立**好习惯。若方向相反（停止 / 换掉坏习惯），按判停点转出。

### 输出契约

**产出类型**：`diagnosis`（定位哪条定律是瓶颈）`＋ patch`（把改法落到具体的章末操作项）

- 固定结构：`{瓶颈定律 / 子项}` ＋ `{每条定律各 ≥1 条可执行动作}` ＋ `{这次 / 下一次的判断}`。
- 完成标准：四条定律各至少给出一条动作（可引用 `f15`/`f34`/`f48`/`f62` 的具体条目），并说明本次瓶颈落在哪条、下一步改哪条。

### 步骤与完成标准

1. **固定行为 + 分诊。** 写成一句可判真假的话。
   - 判停：方向是「停下 / 换掉坏习惯」→ 转 four-laws-inversion；只想要「卡在哪一步」的定位 → 转 four-step-diagnosis；只问模型是什么 → 转来源路由入口。
2. **四问自检（`p22`）。** 依次问「怎么让它显而易见 / 有吸引力 / 简便易行 / 令人满足？」。
   - 完成标准：四问各得出至少一个候选动作或明确「已满足」。
3. **按章末操作集落手段。** 用四张整合表（`f15` 1.1–1.4 / `f34` 2.1–2.3 / `f48` 3.1–3.5 / `f62` 4.1–4.4）把候选落成具体操作。
   - 完成标准：每条定律的动作指回一个具体条目（如 1.2 执行意图、3.4 两分钟法则）。
4. **判「这次 / 下一次」（`p86`）。** 行为做了却不重复 → 优先查第四定律（是否即时令人满足）。
   - 完成标准：给出「这次 / 下一次」的判断结论。
5. **轮换找下一个瓶颈（`f85`）。** 把系统推向「显而易见 / 有吸引力 / 简便易行 / 令人满足」一端，找当前瓶颈，再进入下一轮。
   - 完成标准：给出「下一个瓶颈」与下一轮要动的定律。

### 判停点

- 第 1 步若方向是「打破坏习惯」→ 转 four-laws-inversion。
- 第 1 步若只要「卡在四步哪一步」的定位，不要改法 → 转 four-step-diagnosis。
- 若只涉及某一根杠杆的细做法 → 转对应单点卡（cue-design / environment-design / two-minute-rule / reinforcement 等）。
- 若涉及成瘾 / 病理行为 → 见 B 段，照录自限句，不硬套。

## B — Boundary

### 不要用（反场景，按分流）

- 要**打破 / 换掉坏习惯** → four-laws-inversion（反向四律）。
- 只要**定位**「卡在四步哪一步」→ four-step-diagnosis。
- 只要**某一根杠杆**的细做法 → 对应单点卡（cue-design / environment-design / two-minute-rule / reinforcement / social-norms 等）。
- 只想了解整书 / 问书里某段怎么说 → 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式

- **把四定律当成穷尽的完整理论**（`x29`，作者原话、硬边界）：作者说，宣称这四条定律是改变任何人类行为的**穷尽框架**，是不负责任的。遇到四律解释不了的行为（非「习惯性」行为、结构性约束下的行为），**不要硬套**。
- **把四律当成「每一条都必须用满」的清单**：四张整合表是**可选菜单**，不是每次都要全部执行；按瓶颈选杠杆。

### 作者盲点与待核查（存量风险）

- **`f03` 与 `f04` 互为正反，不许合并。** 作者原话即「我们可以把这些定律倒过来用」（正向四条 ↔ 反向四条，第一律反向即让它隐而不见）。反向四律是**一等公民**、与正向对称，**不许互相吸收**——合并会丢掉「建好习惯 / 打破坏习惯」两套对称清单。反向侧与本卡**互设链接（contrasts）、不合并**，反向清单归 four-laws-inversion。
- **第一组 · 引言「科学支持我写的一切 ↔ 这不是学术研究、是操作手册」**（同一句，即 `x28`）：作者在同句内既宣称「科学支持我写的一切」，又声明本书不是学术研究、是操作手册。**原样保留，不替作者调和**：本卡的四律是**操作框架**，不是经同行评审的理论；引用其规律时按「操作手册」而非「已证实科学定律」对待。
- **第二组 · 「四步是每个习惯的骨干 ↔ 宣称四定律穷尽是不负责任的」**：作者同章既称四步是「每个习惯的骨干」，又自认四定律非穷尽（即 `x29`）。**两条都收，不替作者调和**：本卡操作层有效，但不为其「覆盖一切行为」的普遍性背书。
- **身份因果张力（简述）**：作者同时主张「身份先行」与「习惯造身份」，优先次序含混；这是与《福格行为模型》融合时的核心冲突点（Fogg：先做小、先感受成功，身份是结果）。**不替作者调和**（详见 identity-design 的 B 段）。
- **成瘾 / 病理无分诊判据**：全书 grep `professional / therapist / clinical / treatment / mental health / psychiatr` 零结果；涉成瘾只有一句自限句在第 12 章，大意是这类技巧难以遏制真正的成瘾。**本卡只能照录「四律技巧不适用于临床成瘾 / 病理」**；转介判停线属流程自补。

### 相邻易混

- **`four-laws-inversion`**：同一框架的反向清单（打破坏习惯）；`f03`/`f04` 互为正反、不许合并。
- **`four-step-diagnosis`**：做「卡在哪一步」的定位；本卡承载改法清单（壳 ↔ 落地）。
- **各单点手段卡**：本卡是归口骨架，细做法在 cue-design / environment-design / two-minute-rule / reinforcement 等。
- **来源路由入口 `atomic-habits`**：只想了解整书走它。

## 相关能力

- **four-step-diagnosis**（对比）：它做「卡在哪一步」的定位；本卡承载建立侧改法清单（壳 ↔ 落地）。要先定位走它。
- **four-laws-inversion**（对比）：同一套四定律的反向清单（打破坏习惯）；`f03`/`f04` 互为正反、不许合并。
- **identity-design**（对比）：它出身份句与小胜；本卡出四条动作清单。身份张力是与福格融合的核心冲突点。

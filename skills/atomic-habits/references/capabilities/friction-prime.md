# 摩擦管理与预备环境（摩擦侧：给好习惯减摩擦 · 给坏习惯加摩擦 · 提前预备环境）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 12 章与第 14 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f46`、`f47`、`p81`），不随公开版分发。

## I — Interpretation

本卡是**摩擦侧**的环境工具：它问的不是「环境里看得到什么」（那是线索侧，归 environment-design），而是「这件事**本身多难做**」。

核心是**最省力法则**：人会自然扑向最省事的那条路。所以改行为有两条对称的杠杆：

1. **给好习惯减摩擦**：拆掉好习惯路径上的步骤与阻力，让它省力到「不想做时也做得动」。作者的命名是 **addition by subtraction**（减法式加法）——减去路径上的废动作，反而增加产出。
2. **给坏习惯加摩擦**：在坏习惯与你之间多塞步骤与阻力，一路加到它「不切实际」、甚至「根本没得选」。作者把它定为打破坏习惯的最优解——不是靠每次忍住，而是让这条路走不通。

再加一个**预备**动作：**预备环境**（prime the environment）。提前把空间布置成「下一步很容易」的状态——睡前摆好装备、把贺卡按场合预分类、收尾时顺手为下一步做准备（resetting the room）。它是把「每次都要临时准备」前移成「一次性布置」，让好习惯成为阻力最小的路径。

一句话：本卡管「把好习惯的路修平、把坏习惯的路堵上」，并且**只动难度，不动线索**（线索侧归 environment-design）。

## A1 — Application Example

**主例 · 作者妻子按场合预分类的贺卡盒（预备环境）**（c66，**原书亲历**）

- **输入/问题**：一件事（及时寄贺卡）总被拖延——作者常因「还没买卡」而错过时机。
- **怎么执行**：妻子把贺卡**按场合预分类**放进一个盒子（生日、慰问、婚礼、毕业……），要用时随手抽一张就能寄出——**预备环境**：把「做这件事」的摩擦降到最低。
- **结论/输出**：寄卡这件事的阻力被移除。
- **原书交代的结果**：妻子很擅长记得寄卡；作者则相反，常因摩擦太高而忘记。

**补充案例（加摩擦 / 预备）**

- c67（**原书亲历**）：作者尽可能把手机放到**另一间屋**到午饭时间，减少无意义查看。**原书交代的结果**：他因此每早获得三到四小时不被打断的工作时间。
- c65（**作者转述**）：密西西比州 IT 开发者 Oswald Nuckols 的「**重置房间**」——看完电视把遥控器归位、离车顺手扔垃圾、洗澡前擦一下马桶，每一步都在为下一步做准备。**原书引其自述**：别人以为他工作很拼，其实他很懒，只是「有前瞻性地懒」。

（c66/c67 为作者自述经验，无对照样本量。）

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 「这个好习惯做起来太麻烦、步骤太多，怎么让它顺手一点？」
- 「坏习惯随手就能做，怎么让它难到我不想做 / 根本做不了？」
- 「想提前把环境布置好，让下一步动作很容易（睡前备好装备、收尾即预备）。」
- 「总靠忍，越忍越破功，有没有让它『干脆不是个选项』的办法？」
- 「健身房来回太远 / 工具总在柜子最里面，做这件事的阻力太大。」

**2. 语言信号（中英双写）**

- 中文：减少摩擦 / 加摩擦 / 太麻烦 / 步骤太多 / 顺手 / 省事 / 预备环境 / 提前布置 / 让坏习惯做不了 / 难到没得选 / 减法式加法。
- English: reduce friction / increase friction / friction / prime the environment / make it impractical / least effort / too much trouble.

**3. 与相邻能力怎么区分**

- environment-design（对比，见分流句）：本卡问「这件事**本身多难做**」，它问「环境里**看得到什么**」。
- two-minute-rule（对比）：要「把行为缩到两分钟 / 微行为」走它；本卡是改**环境步骤**，不缩小行为本身的规模。
- commitment-accountability（对比 + 配套）：要「一次性锁死 / 契约 / 罚则 / 自动化」走它；p81（加摩擦到没得选）与承诺机制 `f54` 配套使用。
- cue-design（对比）：行为做得到、只是老忘（线索缺失）→ 走它。
- 福格 `make-it-easy`（跨书，同轴）：能力侧「让行为更容易做」走它——见 B 段「同轴记录」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「环境里该看到什么 / 线索怎么摆 / 把坏线索藏起来」→ 不触发本卡，走 **`environment-design`**（线索侧）。
- 「把它缩小到两分钟 / 先做出一个最小的开始动作」→ 走 **`two-minute-rule`**。
- 「想用契约 / 罚金 / 自动化一次性锁死未来」→ 走 **`commitment-accountability`**。
- 「我做得到、只是不知道何时何地做」→ 走 **`cue-design`**。
- 「太难做了、能力不够（时间 / 钱 / 体力 / 脑力）」→ 走福格 **`make-it-easy`**（能力侧）。
- 「先帮我判断这个行为到底卡在哪一环」→ 走 **`four-step-diagnosis`**。

**分流句（本卡 ↔ `environment-design`）**：问「这件事**本身多难做**」（步骤多少、能不能提前预备、坏习惯能不能变得不切实际），走 **`friction-prime`**；问「环境里**看得到什么**」（好线索是否显眼、坏线索是否被移除），走 **`environment-design`**。

## E — Execution

### 输入契约

- **必需**：一个想促成的好习惯**或**想削弱的坏习惯，加上它当前的**操作路径**（做一次要几步、卡在哪）。缺路径信息**先问**，不许静默替用户猜。
- **可选**：可用空间 / 工具、能否提前布置、愿意加几重阻力。
- **适用条件**：只解决「这件事本身多难做」。若用户真正的问题是「环境里看得到什么」→ 按 B 段分流到 environment-design。

### 输出契约

**产出类型**：`patch`（给已有计划换零件：调摩擦 / 预备环境）

一份**双向摩擦方案**，至少含：

- ① ≥1 条「**给好习惯减摩擦**」动作（削减步骤 / 移除阻力）；
- ② ≥1 条「**给坏习惯加摩擦**」动作（增加步骤 / 阻力，尽量加到「不切实际」）；
- ③ 可选：≥1 条「**预备环境**」动作（收尾即预备下一步 / 提前摆好）。

**完成标准**：每条落成「少做 X 步 / 把 Y 收起来 / 提前摆好 Z」式可执行动作；坏习惯那条要说明加了几步 / 几重阻力。

### 步骤与完成标准

1. **定位行为与其当前步骤数**：数出做该行为当前要几步 / 有哪些阻力点（工具在哪、要不要出门、要不要登录等）。
   - 完成标准：给出该行为的**步骤清单或阻力点**。
2. **好习惯减摩擦 + 预备**：削减步骤、移除阻力；或用「预备环境」把临时准备前移成一次性布置。
   - 完成标准：≥1 条减摩擦（或预备）动作，且**指名被移除的步骤 / 被预置的空间**。
3. **坏习惯加摩擦**：在坏习惯与你之间增加步骤 / 阻力，加到「不想做 / 不切实际」。
   - 完成标准：≥1 条加摩擦动作，并说明**加了几步 / 几重阻力**。

### 判停点

- 第 1 步后发现真正问题是「环境里看得到什么（线索）」→ 转 **`environment-design`**。
- 用户想「一次性锁死 / 订契约 / 设罚则」→ 转 **`commitment-accountability`**（p81 与 `f54` 承诺机制配套）。
- 用户想把行为缩到「两分钟」→ 转 **`two-minute-rule`**。

## B — Boundary

### 不要用（反场景，按分流）

- 要改「环境里看得到什么」（线索显眼 / 移除坏线索 / 一室一用 / 换场景）→ environment-design。
- 要一次性锁死 / 契约 / 罚则 / 自动化 → commitment-accountability。
- 要把行为缩小到两分钟 / 微行为 → two-minute-rule。
- 行为做得到、只是老忘（线索缺失）→ cue-design。
- 要完整归因「卡在哪一环」 → four-step-diagnosis（/ 福格 `bmap-diagnosis`）。

### 作者警告过的失败模式（反例素材）

- **过度自动化 / 便利的副作用**（x07）：当行动门槛降到近零，人会被当下最小的冲动牵着走，一直在简单任务间打转、回避更难但更有价值的工作。作者自陈他常发现自己不由自主地滑向社交媒体。→ 「减摩擦」不能减到失去约束：它既能锁住好习惯，也能让人沉迷于轻松行为。

### 作者盲点与待核查（无分诊判据，p81 涉成瘾）

- **成瘾 / 病理无分诊判据**：`p81`（让坏习惯难到没得选）在原文紧邻的自限句在第 12 章，大意是这些小技巧难以戒掉真正的成瘾；全书无「何时放弃本方法、转介专业人士」的判据（grep `professional / therapist / clinical / treatment / mental health / psychiatr` 零结果）。**本卡只能照录「加摩擦技巧不适用于临床成瘾 / 病理」**；转介判停线属流程自补，非原书依据。
- **「加摩擦到没得选」的强度未给阈值**：p81 只说把摩擦加到「你根本没得选」，但加多少步 / 多重的阻力才算够，原文未量化。

### 同轴记录（同一根轴上的原则）

- **与福格 `make-it-easy` 同轴**：本卡「减少好习惯的摩擦」与福格能力侧的「让行为更容易做」落在**同一根轴**上。同一根轴上的重复——「Fogg 的 ability / Clear 的环境设计（**仅摩擦侧**）/ Nordgren 的 effort / Nudge 的 sludge 说的是同一件事」。**二者同属一条原则**（同一根轴上只保留一处），但两者**出招不同**——福格走「补能力因素 / 缩小行为 / 入门步骤」，本卡走「改环境步骤 / 预置空间 / 加阻力」——故仍需互设近邻负例。（线索侧不与它们同轴，见 environment-design。）

### 相邻易混

- **`environment-design`**：摩擦侧（本卡，问「多难做」）vs 线索侧（它，问「看得到什么」）。
- **`four-laws-inversion`**：本卡与 `f53`（第三定律反向 3.6/3.7：加摩擦 + 用承诺机制）同族——f53 是反向侧框架锚点，本卡是其实现手段；两卡**互设链接、不合并**。
- **`commitment-accountability`**：p81 与承诺机制 `f54` / p80 配套；「锁死未来选择」走它。
- 福格 `make-it-easy`：能力侧摩擦（它）vs 环境侧摩擦（本卡），同一轴、不同出招。

## 相关能力

- **environment-design**（对比）：摩擦侧（本卡，问「多难做」）vs 线索侧（它，问「看得到什么」）；互设近邻负例。
- **motion-vs-action**（对比）：本卡改「这件事本身多难做」；它判「在准备还是在行动」。
- **two-minute-rule**（对比）：本卡改环境步骤 / 难度；它缩小行为本身（门槛）。

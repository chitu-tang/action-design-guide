# 承诺与问责（承诺机制 · 自动化 · 契约 · 问责）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 14 章与第 17 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f54`、`f55`、`f56`、`f68`、`f69`、`f71`），不随公开版分发。

## I — Interpretation

这套方法不解决「该做什么」，而是解决「**怎么让已经决定要做的事不依赖当时的意志力**」。它把「未来的自我控制」换成「当下的结构安排」，用三条腿落地：**锁死未来**（第三定律侧）、**让代价即时且有见证**（第四定律侧）、以及一条**惩罚强度匹配判据**。

1. **锁定未来（第三定律侧，第 14 章）**——在当下做一个「削减未来选项」的决定，而不是许一个未来的愿。三种手段同属一层：
   - **承诺机制（commitment device）**：当下做出的、控制未来行为的选择。设计准则只有一句——**让退出一个好习惯比开始它更费劲**；例：只带现金、主动加入赌场黑名单、赛前把钱包留在家里、点餐前先让服务员把一半打包。
   - **一次性行动（onetime actions）**：一次布置、长期自动生效的选择（换好床垫、装净水器、退订邮件、设自动储蓄、用更小的盘子）。共性是前置一点努力、之后持续复利。
   - **自动化（automation）**：第三定律最强手段——用技术把行为自动化（自动续药、自动储蓄、定时断网、网站屏蔽器），尤其适用那些**频率太低、不足以练成习惯**的事（如每年再平衡投资组合）；也可用来**让坏习惯变得不可能**（每周重置社媒密码）。
2. **让代价即时且有见证（第四定律侧，第 17 章）**——让不执行的代价**公开且即时**：
   - **习惯契约（habit contract）**：口头或书面约定，写明承诺 + 违约惩罚，再由一两个**问责伙伴**签字（签名是「认真对待」的标志）。
   - **问责伙伴（accountability partner）**：契约的轻量版——哪怕只是有人旁观，也会产生即时社会成本（怕被视为懒惰 / 不可靠）。
3. **惩罚强度匹配判据（f71）**——凡靠惩罚 / 代价的机制，痛苦必须**即时**（不能有行为与后果的间隙）、**具体近身**（越局部、越具体越有效；越笼统、越遥远越无效），且**强度匹配**行为（惩罚的痛苦须大于行为带来的好处），并**可靠执行**；否则无效（惩罚的强度须匹配它要纠正的行为的强度）。

一句话骨架：**能让行为不靠意志力的，不是更硬的决心，而是更硬的当下结构**——把未来选项锁死、把代价变即时、把执行交给系统或他人。产出是一组约束 / 契约 / 自动化方案，不是一次性的决心。

## A1 — Application Example

**主例 · Bryan Harris 的习惯契约**（c95，作者转述的第三人案例）

- **输入/问题**：纳什维尔的创业者 Bryan Harris，儿子出生后想减掉几磅体重。
- **怎么执行**：他写了一份**习惯契约**，缔约方是他自己、妻子和私人教练；契约定明目标与达成路径的阶段，列出每日习惯，并写明违约后果（示例：漏记一天饮食就给教练 $200；未达标则要穿正装 / 戴对手球帽）。签约时三方签名（签名是「认真对待」的标志）。
- **结论/输出**：原书交代他三个月后达成季度目标，并把目标与惩罚一起升级，最终把体重减了下来。
- **注**：罚则金额（$100/$200/$500）是个案，不是可迁移的强度标定。

**辅例 · 锁定未来（第三定律侧，均作者转述）**
- **Nir Eyal 的插座定时器**（c75）：他买了一个插座定时器接在路由器和电源之间，每晚 10 点自动切断网络，逼全家睡觉。原书**未给效果数据**，只说断网后全家知道该睡了。
- **Victor Hugo 锁衣赶稿**（c74）：为赶稿让助手把衣服锁进大箱、只留披肩，无法外出而专心写作。原书**明示这是传说**；结局（1831-01-14 提前出版）在同章交代。

**辅例 · 轻量问责与自动化问责**（作者转述，原书均未给效果）
- **Margaret Cho 的「每天一首歌」**（c96）：与朋友做「每天一首歌 / 一个笑话」的共享挑战，互相督促。用于说明「有人看着」的问责效应。
- **Thomas Frank 的自动惩罚推文**（c97）：预设自动推文，若没在 5:55 起床就发推承认懒惰并承诺给回复者 $5（限 5 人）。原书**未给该机制的实际效果**。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**
- 已经知道自己该做什么，但一到关键时刻就靠意志力硬撑、反复失守，想要「不靠自控也能做到」：「我不想每次都靠自控，能不能提前把路堵死」。
- 想给某个好习惯或要戒的坏习惯**加一道外部约束 / 押注 / 契约**：「帮我写个习惯契约」「找个人监督我」「没做到就罚钱 / 发红包」。
- 想把系统**一次性布置好**、减少重复决策：「有没有一次设置、长期自动生效的做法」「怎么自动储蓄 / 自动续药 / 定时断网」。
- 想用技术让坏习惯**变得不可能**：「怎么让刷手机 / 赌博 / 乱花钱变得做不到」。
- 已有惩罚或契约但没用，想改强度或改成立即生效：「我签了目标但没人执行 / 罚得太轻，还是破戒」。

**2. 语言信号（中英双写）**
- 中文：承诺机制 / 承诺装置 / 一次性行动 / 一次性布置 / 自动化 / 用技术自动化 / 习惯契约 / 问责伙伴 / 找人监督 / 被人盯着 / 押金 / 罚金 / 违约代价 / 加约束 / 锁死 / 让坏习惯不可能 / 不靠意志力 / 不想每次靠自控。
- English: commitment device / lock in future behavior / onetime actions / automate my habits / habit contract / accountability partner / someone to watch me / punishment / penalty / stake / make it impossible / without willpower / self-control.

**3. 与相邻能力怎么区分**
- 与 friction-prime（本书，摩擦侧）：那条改「这件事本身多难做」——加 / 减的是**步骤数与即时摩擦**（少走一步、把零食藏起来、手机放另一个房间），产出是对已有计划的零件修补；本卡改「**未来的选项与代价**」——用当下决策 / 契约 / 技术把选项锁死，关键是「退出比开始更费劲」+ 惩罚 / 见证，产出是一套约束 / 协议 / 自动化方案。问「把这件事变简单 / 变难一点」→ friction-prime；问「怎么让我不做也得做 / 一次设置长期生效 / 有人盯着我」→ 本卡。
- 与福格 `tiny-habit-design`（跨书）：那条是**从零把一个新习惯养出来**（发散→黄金行为→缩微→锚点→庆祝）；本卡**不设计要养成哪一个习惯、也不缩小规模**，只给「锁死 / 约束 / 见证」的手段。用户说「帮我养成 / 设计一个习惯」→ 福格；用户说「习惯已经知道要做，但我需要外部约束 / 契约 / 自动化」→ 本卡。
- 与 habit-tracking-reflection（本书）：那条产出**记录与复盘机制**（追踪打卡、不中断链条、年度复盘、诚信报告），靠「看见自己」维持；本卡产出**约束与见证机制**（承诺 / 契约 / 罚则 / 自动化），靠「让做不到有即时代价、让行为不可能反转」维持。问「怎么记录 / 复盘」→ 追踪卡；问「怎么加约束 / 押注 / 找人盯」→ 本卡。
- 与 reinforcement（本书，奖赏侧）：那条给**好习惯加即时奖赏**（做对就爽）；本卡给**坏习惯加即时代价**（做错就疼）+ 给好行为加约束——奖赏侧与代价侧对称，互设。
- 与 four-laws-inversion（本书）：反向四律框架卡收录 f70（4.5/4.6 反向锚点），回答「打破坏习惯的四步改造」；本卡是**执行级**的契约 / 问责 / 自动化怎么做。要整体改造走前者，要具体写契约 / 加约束 / 自动化走本卡。
- 与来源路由入口「原子习惯」：入口回答「这套模型是什么、怎么系统性用」。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「我想养成每天读书的习惯，帮我设计一下」→ 不触发本卡，走福格 `tiny-habit-design`（从零建习惯）；本卡只管给已有目标加约束 / 见证。
- 「怎么把这件事变得容易一点 / 少走一步 / 把零食藏起来」→ 不触发本卡，走 friction-prime（摩擦侧）。
- 「帮我做个习惯追踪表 / 年度复盘」→ 不触发本卡，走 habit-tracking-reflection。
- 「怎么奖励自己坚持下来」→ 不触发本卡，走 reinforcement。
- 「承诺机制是什么意思」这类纯信息查询、且没有落地请求 → 不触发本卡，走来源路由入口 / 参考。

## E — Execution

### 输入契约
- **必需**：一个**具体、可观察的目标行为**（要养成的 or 要戒掉的）。若只给愿望（「变健康」「别乱花钱」），先要求拆到一个具体行为，再进流程。
- **必需**（至少其一可落定）：约束的**执行方**（谁监督 / 谁执行）与**代价形式**（罚什么 / 押什么）。缺则先问，**不许静默替用户猜罚则金额或对象**。
- **可选**：偏好的手段（承诺机制 / 一次性行动 / 自动化 / 契约 / 问责伙伴）、可承受的代价、已有的伙伴或工具。
- **适用条件**：用户想要「**让行为不靠意志力**」——即已知道该做什么，需要外部约束 / 自动化 / 见证。若其实是想「从零设计一个新习惯」「只加 / 减摩擦」「只要记录复盘」，按 B 段分流。
- **硬停线**：请求涉及临床成瘾 / 戒断 / 进食障碍 / 自伤等严重心理病理 → 不跑本流程（见下）。

### 输出契约

**产出类型**：`design`（新建一套约束 / 自动化方案；+ 视情况 `patch`：往用户已有计划里补约束 / 罚则字段）

一套可执行的「锁定未来」方案，含四类可检查产物（按输入取用其一或组合）：
1. **≥1 条承诺机制或一次性行动**：一条当下做出、锁死未来的选择，并写明「退出为什么比开始更费劲」；
2. **（可选）1 条自动化方案**：用技术把目标行为自动化，并给出「这条是否频率太低、值得自动化」的判断；
3. **1 份契约或问责关系**：习惯契约（承诺 + 罚则 + 一两个问责伙伴签名）或轻量问责伙伴；罚则须写明即时、具体近身、可靠执行；
4. **1 条强度自检**：说明该惩罚 / 约束的强度如何匹配目标行为。**作者未给数值阈值**，须由当事人自定一个「痛苦略大于回报」的可执行标定，并注明这是**自定约定**。

**完成标准**：用户能说出「何时、由谁、以什么即时代价」保证执行，并能指出「若执行方不在 / 罚得太轻」时如何调整。

### 步骤

**第 1 步 · 锁定目标行为与失守点**
- 动作：把请求收敛成一个具体可观察的行为（养成 X / 戒掉 Y），并问清「过去失守发生在哪一步」。
- 完成标准：写出一个具体行为 + 一个明确的失守场景。
- 判停：给的是愿望而非行为 → 退回要求拆成具体行为，不给具体行为不进流程。涉及临床成瘾 / 戒断 → 按停手线处理，停止并提示转介。

**第 2 步 · 先判定用哪条线**
- 动作：按请求分流——要「让好行为近乎默认 / 让坏行为不可能」（第三定律侧 f54/f55/f56）vs 要「给不执行加即时、公开的代价」（第四定律侧 f68/f69/f71）。两条可并用。
- 完成标准：明确主用哪条线。
- 判停：若用户其实只要「把这件事变简单 / 变难一点」（摩擦），跳 friction-prime，不在本卡执行。

**第 3 步 · 出「锁定未来」手段（第三定律侧，按需）**
- 动作：给一条当下的约束（承诺机制：把未来选项锁死；准则「退出比开始更费劲」），或一条一次性行动（一次布置、长期生效），或一条自动化（用技术把行为自动化；对频率太低、练不成习惯的事尤其适用）。
- 完成标准：≥1 条具体手段，且能说明它为什么让「退出」变难 / 让行为近乎自动。
- 判停：要「让坏习惯不可能」可用自动化（f56，如每周重置密码）；若只是「少看一眼」这类低摩擦手段 → 归 friction-prime。

**第 4 步 · 出「契约 / 问责」方案（第四定律侧，按需）**
- 动作：写习惯契约（承诺 + 违约惩罚 + 一两个问责伙伴签字）或设定轻量问责伙伴；用 f71 自检罚则：即时（无延迟）、具体近身、强度大于行为回报、可靠执行。
- 完成标准：得到一份带罚则与执行方的契约或问责关系，且四要素齐。
- 判停：罚则强度原文未给阈值 → 让当事人自定「痛苦略大于回报」的可执行标定，并标明是**自定约定**，不得声称有统一门槛。

**第 5 步 · 强度匹配自检（f71）**
- 动作：核对「惩罚 / 约束是否即时、是否可靠执行、是否强度匹配」；不匹配则回第 3 / 4 步调。
- 完成标准：能指出「若不执行会立刻发生什么」，且当事人认为该代价足以压过行为回报。
- 判停：若发现「惩罚太轻 / 太迟 / 太泛」（x10）→ 视为无效设计，回第 4 步重设。

**回流汇总**：第 1 步愿望未拆 → 停并要求具体行为；涉成瘾 → 按停手线转介；第 2 步只求摩擦 → friction-prime；第 4 / 5 步强度不足或不可靠 → 回第 4 步重设。

## B — Boundary

### 不要用（反场景）
- 从零养成一个新习惯 / 设计「该做什么、怎么缩小」 → 福格 `tiny-habit-design`（本卡只管加约束 / 见证 / 自动化，不设计行为本身）。
- 只加 / 减即时摩擦（少一步、藏起来、放远） → friction-prime（摩擦侧零件）。
- 只要记录 / 复盘 → habit-tracking-reflection。
- 给好习惯加即时奖赏 → reinforcement。
- 打破坏习惯的整体四步改造 → four-laws-inversion（本卡是执行级手段）。
- 纯信息查询（「承诺机制是什么」）→ 来源路由入口 / 参考。
- **涉临床成瘾 / 戒断 / 严重心理病理 → 不跑本流程**（见下）。

### 作者警告过的失败模式（反例素材）
- **自动化的副作用**（x07）：当行动所需努力降到近乎零，人会在「简单任务间来回跳」，不去做更难但更有回报的事——自动化不是越多越好。
- **惩罚太轻 / 太迟 / 太泛则无效**（x10）：惩罚只有足够痛苦、且被可靠执行，行为才会改变；惩罚强度须匹配行为强度（f71）。
- **羞辱 / 恐吓会反噬**（x03）：用羞辱推行为改变会把人推回旧的应对策略——设计「公开」代价时须防把「公开」做成「羞辱」。
- **自控是短期策略**（x02）：这正是本卡的前提——用当下结构替代未来意志力，而不是叫用户「更自律一点」。
- **传说材料**（c74）：Victor Hugo 锁衣赶稿在原书里明示为传说，别当史实引用。
- **未交代结局**（c97）：Thomas Frank 的自动惩罚推文，原书**未给该机制的实际效果**，不得补结局。

### 作者盲点与待核查
- **罚则强度阈值原文未给（task-15 缺口）**：f69 只给个案金额（Bryan Harris 的 $100/$200/$500）与形式罚，f71 只说「强度必须匹配行为」——**全书没有可迁移的强度标定原则或数值门槛**。实现时必须由当事人自定，并标明是自定约定。
- **伙伴的选择与结构方法原文未给**：f68 只断言「有伙伴即有用」，未给「怎么选伙伴 / 伙伴该做什么 / 找不到怎么办」（正式版在 f69 的习惯契约）。
- **频率阈值缺口（微）**：f56 说自动化那些「频率太低、不足以成为习惯」的事，但未给「低到何种程度就该自动化」的量化门槛。
- **成瘾无分诊判据**：见下。
- **素材成色**：Bryan Harris 案例来源为英文版注释（作者的邮件往来，二手）；Margaret Cho（英文版注释，报纸）、Nir Eyal（英文版注释，访谈）、Thomas Frank（英文版注释，博客）均为转述，非同行评审。

### 涉成瘾 / 结构性约束（存量风险，必写）
- **本书没有「何时放弃这套方法、转介专业人士」的分诊判据**（全项目已 grep `professional / therapist / clinical / treatment / mental health / psychiatr`，零结果）。涉及成瘾，原文唯一的自限句在**第 12 章**，大意是这些技巧难以遏制真正的成瘾——**只此一句、没有分诊判据**。
- 因此：**凡请求涉及临床成瘾、戒断、进食障碍、自伤等严重心理病理，或用户其实是想戒断依赖，本卡不跑流程**，照录「这类技巧不适用于临床成瘾 / 病理，请寻求专业帮助」，不把承诺机制 / 契约 / 自动化当治疗方案（f56 的 notes 亦已注明本条不主张能治成瘾）。
- **结构性约束（基因 / 天赋 / 运气）**本书同样只给「机会范围、非命运」，不给分诊判据；若用户把「我天生做不到」当理由来要约束方案，先指出这是结构性限制、不是意志力问题，约束机制解决不了。

### 相邻易混
- friction-prime：改「这件事本身多难做」（摩擦 / 步骤） vs 本卡改「未来的选项与代价」（约束 / 契约 / 自动化）。
- 福格 `tiny-habit-design`：从零「造」一个新习惯 vs 本卡给已有目标「加约束 / 见证」。
- habit-tracking-reflection：记录与复盘（看见自己） vs 约束与见证（有人盯着 / 有代价）。
- reinforcement：即时奖赏（做对就爽） vs 本卡即时代价（做错就疼）+ 约束。
- four-laws-inversion：反向四律的整体框架 / 速查表 vs 本卡执行级的契约 / 问责 / 自动化。

## 相关能力

- **identity-design**（组合）：身份定了之后，「让它发生且不靠意志力」的约束 / 见证层。
- **habit-tracking-reflection**（对比）：本卡靠约束 / 见证；它靠记录 / 复盘（看见自己）。
- **environment-design**（对比）：本卡靠「一次性锁死 / 契约 / 罚则」；它靠「挪环境线索」。
- **four-laws-inversion**（组合）：反向侧框架 `f70`（问责 + 契约）的实现手段在本卡。
- **reinforcement**（对比）：`p87` 的对称两侧——本卡给坏习惯加即时代价 + 约束，它给好习惯加即时奖赏。

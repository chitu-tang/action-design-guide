# 环境设计（线索侧：好线索显眼 · 移除坏线索 · 让最优选项最明显）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 6 章与第 7 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f20`、`f23`、`f24`、`f25`），不随公开版分发。

## I — Interpretation

本卡是**线索侧**的环境设计：不靠意志力，而是改「环境里**看得到什么**」。

核心主张：行为由环境触发——环境是塑造行为的「无形之手」；但人不必做环境的受害者，可以做它的**建筑师**。凡是「想做却总没发生」或「不该做却总做」的问题，先看线索摆在哪里，而不是先问自己够不够自律。

三个线索侧手段（全部只动线索，不改变行为本身的难度）：

1. **让好线索显眼**：把要促成的行为的线索放到看得见、够得着、最显眼的位置；作者的说法是让「**最好的选择成为最明显的选择**」。散在视线外的好习惯线索等于没有线索。
2. **移除坏线索**：把坏习惯的线索藏起、挪走、退订、移出首屏。作者的观察是，**移除单个线索常使整个习惯消散**，比每次硬抗诱惑可靠——这也意味着策略重心从「忍住」转到「看不见」。
3. **换场景 / 一室一用**：当现有线索无法移动时，换一个新环境（新咖啡馆、公园长椅、房间一个不常用的角落）甩掉旧线索；或把空间与数字空间按用途切分，让每种习惯有专属的线索场——「一室一用」。

本卡**只覆盖线索侧**：只回答「环境里看得到什么」。它**不**处理「这件事本身多难做」——减少步骤、预备环境、一次性决策、让坏习惯不可能——那是摩擦侧，归 friction-prime（本书）与福格 `make-it-easy`（能力侧摩擦）。

## A1 — Application Example

**主例 · 作者把苹果从保鲜柜移到台面**（c32，**原书亲历**）

- **输入/问题**：作者想把「多吃水果」变成日常行为。
- **怎么执行**：把苹果从冰箱保鲜柜（看不见）挪到厨房台面的大果盘（最显眼处）——纯线索侧改造，不改变「吃苹果」这件事本身的难度。
- **结论/输出**：苹果变得显眼、伸手可及。
- **原书交代的结果**：他开始**几乎每天**吃几个苹果，只因它们变得显眼。

**补充案例（一室一用 / 换场景）**

- c34（**原书亲历**）：作者早期在沙发、餐桌上工作，工作与生活界限模糊、晚上难收工；搬进带独立办公室的家后，工作「在里面」、生活「在外面」，更容易切换。**原书交代的结果**：界限变得清晰。
- c35（**作者转述**）：作者说认识一位作家，用电脑只写作、平板只阅读、手机只社交与短信，把数字空间也做成「一用一区」。**原书未交代该作家的结果**，仅作示例。

（c32/c34 为作者自述经验，无对照样本量。）

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 「我知道该做什么，可就是老看不见、老忘，怎么让好习惯更容易被触发？」
- 「我想减少 / 戒掉某个坏习惯，可它总在我眼前、手边，怎么把它挪出视线？」
- 「换了新家 / 新工位 / 新城市，想顺势建立新的习惯。」
- 「工作和生活混在同一张桌子、同一个房间，切换不过来，怎么用空间分开？」
- 「我总靠意志力硬扛，有没有不动意志力、从环境下手的办法？」

**2. 语言信号（中英双写）**

- 中文：改造环境 / 环境设计 / 让线索显眼 / 把 X 放到看得见的地方 / 移除坏习惯线索 / 让它看不见 / 一室一用 / 换个环境 / 环境里看得到什么 / 无形之手 / 做环境的建筑师。
- English: environment design / make it obvious / visible cues / remove cues / make it invisible / one space one use / new environment / architect of your environment.

**3. 与相邻能力怎么区分**

- friction-prime（对比，见分流句）：本卡问「环境里**看得到什么**」，它问「这件事**本身多难做**」。
- cue-design（组合/对比）：cue-design 把新习惯挂到既有线索上（执行意图 / 习惯叠加的**时间与锚点**格式）；本卡则在物理 / 数字**空间**里摆线索。两者常配套使用。
- four-step-diagnosis（对比）：先归因「这个行为为什么没发生」时走它；本卡用于**已知要改、直接动环境线索**。
- commitment-accountability（对比）：一次性锁死 / 契约 / 罚则 / 自动化走它。
- 福格 `make-it-easy`（跨书对比）：能力侧「让行为变容易」走它，不是本卡。
- four-laws-inversion（对比 + 链接）：本卡是建立侧的线索手段；`f25`（1.5 隐而不见）字面属反向第一律，但它是空间线索侧手段、与 f20 同族，故落本卡；与 four-laws-inversion **互设链接、不合并**（反向侧框架条 `f04` 仍在彼卡）。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「这个好习惯做起来太麻烦、步骤太多，怎么让它更省事？」→ 不触发本卡，走 **`friction-prime`**（摩擦侧）。
- 「坏习惯随手就能做，怎么让它难到我不想做 / 根本做不了？」→ 不触发本卡，走 **`friction-prime`**（或 commitment-accountability）。
- 「把行为落成『什么时候、在哪做』的计划句 / 挂到某个既有习惯上」→ 走 **`cue-design`**。
- 「用契约 / 罚金 / 自动化一次性锁死」→ 走 **`commitment-accountability`**。
- 「先帮我判断这个行为到底卡在哪一环」→ 走 **`four-step-diagnosis`**（或福格 `bmap-diagnosis`）。

**分流句（本卡 ↔ `friction-prime`）**：问「环境里**看得到什么**」（好线索是否显眼、坏线索是否被移除），走 **`environment-design`**；问「这件事**本身多难做**」（步骤多少、能不能预备、坏习惯能不能变得不切实际），走 **`friction-prime`**。

## E — Execution

### 输入契约

- **必需**：一个想促成（或想削弱）的**具体行为**，加上该行为发生的**物理 / 数字环境**（在哪个空间、身边有什么、桌面和手机首屏有什么）。缺环境描述**先问**，不许静默替用户猜。
- **可选**：该行为当前的线索是什么、坏习惯的触发物、有没有可能换场景。
- **适用条件**：只解决「环境里看得到什么」。若用户真正的问题是「这件事多难做」→ 按 B 段分流到 friction-prime。

### 输出契约

**产出类型**：`patch`（给已有计划换零件：改造线索环境）

一份**线索侧环境改造清单**，每条落成「把 X 从 A 挪到 B / 藏起 / 收进柜子 / 退订 / 移出首屏」式可执行动作，至少含：

- ① ≥1 条「让**好习惯线索显眼** / 让最优选项最明显」；
- ② ≥1 条「**移除或掩盖坏习惯线索**」；
- ③ 可选：1 条「**换新场景**」或「**一室一用 / 活动区切分**」方案。

**完成标准**：每条改造成都能落到一个具体位置，且改造后可观察行为频次变化。

### 步骤与完成标准

1. **定位行为与其线索**：问清目标行为在什么情境 / 地点发生、当前依赖或缺失什么线索。
   - 完成标准：指名该行为的**关键线索**（或明确「无固定线索」）。
2. **线索侧正向改造**：把好习惯线索放到显眼、够得着的位置，让最优选项最明显。
   - 完成标准：≥1 条**位置级**动作（如「把水壶放到桌面正前方」）。
3. **线索侧反向改造**：移除 / 掩盖坏习惯线索（移出视线、收进柜子、退订、移出首屏）。
   - 完成标准：≥1 条「移除 / 掩盖」动作，且**指名被移除的那条线索**。
4. **（可选）场景侧加固**：线索无法移动时，换新环境甩掉旧线索（`f24`），或按用途切分空间 / 数字空间（`f23`）。
   - 完成标准：给出换场景或空间切分方案。

### 判停点

- 第 1 步后发现真正问题是「这件事太难做 / 步骤太多」→ 转 **`friction-prime`**。
- 第 1 步后发现真正问题是「不知道何时何地做」→ 转 **`cue-design`**。
- 用户想用契约 / 惩罚锁死 → 转 **`commitment-accountability`**。

## B — Boundary

### 不要用（反场景，按分流）

- 要减少**步骤 / 让行为本身更省事 / 让坏习惯不切实际** → friction-prime（摩擦侧）。
- 要把行为落成 when/where 或锚点配方 → cue-design。
- 要用承诺机制 / 契约 / 罚则 / 自动化锁死 → commitment-accountability。
- 要先归因「这个行为为什么没发生」 → four-step-diagnosis（/ 福格 `bmap-diagnosis`）。
- 只想了解整套模型 → 来源路由入口 `atomic-habits`。

### 范围约束（硬，编译 Skill 时作边界说明）

**本卡只覆盖「线索侧」**：好线索显眼、移除坏线索、让最优选项最明显，外加由其派生的「换场景 / 一室一用」（二者仍是**线索隔离**手段）。**明确不含摩擦侧**——减少步骤、预备环境、一次性决策、让坏习惯不可能——那是 friction-prime（本书 `f46`/`f47`）与福格 `make-it-easy`（能力侧摩擦）的地盘。依据：本册分层口径把「环境层」拆成**线索侧（原子习惯）**与**默认值 / 摩擦侧（Nudge 作原则来源，不单独出卡）**，并裁定「一问『环境里看得到什么』、一问『这件事本身多难做』」。

### 作者警告过的失败模式（反例素材）

- **用羞辱 / 恐吓去「推动」会反噬**（x03）：把坏习惯的负面后果直接摆到人面前（羞辱式减重宣讲、给吸烟者看黑肺照片），会因引发压力 / 焦虑反而触发原来的应对行为。处理坏习惯线索时要避免自己**制造出新的触发线索**。（注：提取时曾把此点外推到「第四定律反向」，原文只落在**第一定律 / 线索管理**；本卡按原文归位。）
- **靠意志力硬扛不是长期解**（x02）：自控只是短期策略，能量更该花在优化环境上。本卡正是这条的出口；但**不能把「改环境」讲成万能**——见下。

### 作者盲点与待核查（写进卡、不许越界宣称）

- **成瘾 / 病理无分诊判据（存量风险，f25 涉成瘾）**：原书唯一自限句在第 12 章，大意是这些小技巧难以戒掉真正的成瘾。全书 grep `professional / therapist / clinical / treatment / mental health / psychiatr` **零结果**，没有「何时放弃本方法、转介专业人士」的判据。**本卡只能照录「技巧不适用于临床成瘾 / 病理」**；实操中的转介判停线属流程自补，非原书依据。
- **「移除单个线索习惯就消散」是作者经验主张**，未给对照证据；配合上一条，只适用于普通习惯，不适用于成瘾。
- **无「线索强度」的量化阈值**：线索多久、多显眼才算够，原文未给。

### 相邻易混

- **`friction-prime`**：线索侧（本卡）vs 摩擦侧（它）——见 A2 分流句。
- **`four-laws-inversion`**：`f25` 与 `f04` 的关系——f25 是反向第一律的**空间线索侧**实现，落本卡；与 four-laws-inversion **互设链接、不合并**，两卡各自保留完整契约。
- **`cue-design`**：空间环境线索（本卡）vs 时间 / 锚点格式线索（它）。
- 福格 `make-it-easy`：能力侧摩擦（它）vs 线索侧（本卡）。

## 相关能力

- **friction-prime**（对比）：同一「改造环境让行为发生」请求的两半——本卡问「看得到什么」（线索侧），它问「多难做」（摩擦侧）；互设近邻负例。
- **cue-design**（组合）：本卡摆空间线索；它摆时间 / 锚点线索（执行意图 / 习惯叠加）。
- **identity-design**（组合）：身份定了之后，用本卡让身份相关行为最显眼。
- **habit-tracking-reflection**（对比）：本卡改造环境线索；它的追踪表产物是记录。
- **commitment-accountability**（对比）：本卡靠「挪线索」；它靠「一次性锁死 / 契约 / 罚则」。
- **four-laws-inversion**（组合）：反向第一律「隐而不见」的 `f25`（移除坏线索）落在本卡（空间线索侧）。

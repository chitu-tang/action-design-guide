# 找赛场与差异化（探索/利用 · 找赛场四问 · 自创游戏 · 与个性匹配）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 18 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f73`、`f74`、`f75`、`f76`），不随公开版分发。

## I — Interpretation

本卡是「从好到卓越」延伸层的**选赛场**簇：它不回答「怎么把某个习惯做得更好」，而回答「**哪个方向 / 赛场**对你最有利」。全簇以 f74（找赛场四问）为骨，其余三条是围绕它的判断依据：

- **f74 找赛场四问（核心）**：探索阶段用一串自问，把一堆候选方向收敛到「最能让你满足」的那个。四问是：①**什么对我像玩、对别人像工作**（判「是否天生适合」看的不是喜不喜欢，而是能否比多数人更轻松地承受其痛苦）；②**什么让我忘记时间**（心流）；③**在哪里我的回报高于常人**（与周围人比较时占优）；④**什么对我自然而然**（抛开社会期待，什么感觉真实、有活力）。产出是**候选方向的打分与排序**。
- **f73 探索/利用权衡**：先探索（广撒网），再聚焦最佳解，但偶尔仍要试验。赢时多利用、输时多探索；时间多时偏探索、时间紧时先落地已有最佳解。长期建议 80–90% 精力用于最佳策略、10–20% 继续探索——**这是启发式（源自 Google 80/20），不是硬阈值**。
- **f75 自创游戏/专业化**：找不到对自己有利的赛场时，就**自创一个**——组合多项技能降低竞争（Scott Adams：会画 + 会写笑话 + 有商业背景），或**专业化**、把某技能练到极窄的顶尖。它是**策略型**建议（非分步流程）。
- **f76 与个性匹配**：选与你个性、兴趣相合的行为，在对你容易的事上努力（爱攀岩就不必举铁）。**Big Five 只是背景**，可操作处只有「按兴趣/性格选行为」；尽责性低的人更依赖环境设计。

一句话：**先判相位（该利用还是该探索），再用四问给方向排序；没有有利赛场就自创/专精，并让选择贴合你的个性。** 它管「选哪条赛道」，不管「这条赛道上的难度该调多少」（那是 goldilocks），也不管「自动化后如何突破」（那是 habit-mastery）。

## A1 — Application Example

**主例 · 作者自创「生物力学」专业**（c103，作者亲历）

- **输入/问题**：作者在大学里发现自己不够强，无法在物理或生物专业的顶尖学生里冒头。
- **怎么执行**：**自创一个专业**——`biomechanics`，把物理 + 化学 + 生物 + 解剖组合起来（f75 自创游戏：组合技能、降低竞争、绕开基因劣势）。
- **结论/输出**：一个为自己量身定制的赛场。
- **原书交代的结果**：因为课程都是自己感兴趣的，学习不再像苦差，也更易避开与人比较的陷阱。

**辅例**

| 对照的四问 / 手段 | 原书案例 | nature | 原书交代的结果 |
|---|---|---|---|
| 四问之③「回报高于常人」 | 作者写 jamesclear.com 时邮件列表增长比部分同行快，因而更有动力继续写（c104） | 作者亲历 | 原文**此处未给具体订阅数字**，只说增长很快 |
| 自创游戏（技能组合） | Scott Adams：多项「前 25%」（会画、会写笑话、有商业背景）组合成稀缺优势（c102） | 作者转述（二手，来源见英文版注释） | 原文引其自述：会画又会写笑话的组合使他独特 |
| 专业化 | 掰手腕冠军靠「非常特定的力量」可胜过更强的健美者 | 作者举例（无人物） | **未说明**（说明性举例，非案例） |

**合成演练（明确标记：原书未提供「用四问给候选方向打分排序」的完整成案，以下按 f73/f74 规则复算）**

- **输入/问题**：一个人说「我在『写作 vs 编程』之间难以取舍。」
- **怎么执行**：先用 f73 判相位——眼下哪边在「赢」（有正反馈）就多利用，另一边留作探索；再用 f74 四问逐问给「写作」「编程」各打分（像玩 / 忘时间 / 回报高于平均 / 自然而然），汇总排序。
- **结论/输出**：一份方向排序（收敛到得分更高的一方）+ 一条「主攻哪边、留多少精力探索另一边」的精力配比。
- **注**：此演练属**合成**，不是书中案例；配比只能按 B 段口径作**启发式**（80–90/10–20 非硬阈值）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 在几个方向 / 机会之间取舍，不知道该深耕哪个。
- 现在做的事越做越苦、总在同一层卡住，怀疑自己选错了赛场。
- 在主赛场挤不进前列，想找 / 造一个对自己更有利的赛道。
- 想按自己的性格 / 兴趣选行为，而不是照搬「最流行」的做法。
- 想知道该继续「利用」现有最优解，还是该再「探索」新方向。

**2. 语言信号（中英双写）**

- 中文：找赛场 / 选方向 / 该深耕还是换方向 / 探索还是利用 / 我在哪件事上更容易成 / 组合技能 / 自创游戏 / 差异化 / 专业化 / 按性格选习惯 / 我是不是不适合这个。
- English: find your field / explore vs exploit / which direction / double down or pivot / play to your strengths / create your own game / specialization / different not better / habits that fit your personality。

**3. 与相邻能力怎么区分**

- **簇内**：f74 是核心（四问）；f73（相位/配比）、f75（自创/专精）、f76（性格匹配）都是围绕它的判断依据，不再单开入口。
- goldilocks（对比）：本卡选 / 换**方向**；它调**已有习惯的难度**（能力边缘、逐步加难）。
- habit-mastery（对比）：本卡在**选定赛场之前**；它处理**已熟练之后的突破**。
- four-step-diagnosis（对比）：本卡做**方向取舍**；它把「某行为没发生」定位到四步中最短板。
- identity-design（对比）：本卡挑**外在赛场**；它定**内在身份**（想成为谁）。
- four-laws-inversion（对比）：本卡选方向；它是「改掉一个坏习惯」的整套反向四律。
- 来源路由入口 `atomic-habits`：只回答「这套模型是什么、怎么系统性用」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「我做的这件事最近很无聊，想加点难度 / 保持动力」→ 不触发本卡，走 **`goldilocks`**。
- 「我已经很熟练了却感觉停在原地，怎么突破到卓越」→ 不触发本卡，走 **`habit-mastery`**。
- 「我为什么总做不到早起 / 这个行为卡在哪一步」→ 不触发本卡，走 **`four-step-diagnosis`**。
- 「帮我改环境，让好行为自然发生」→ 不触发本卡，走 **`environment-design`**。
- 「我想成为更自律 / 更健康的人」→ 不触发本卡，走 **`identity-design`**。
- 「帮我戒掉睡前刷手机」→ 不触发本卡，走 **`four-laws-inversion`**。

**分流句（本卡 ↔ `goldilocks` ↔ `habit-mastery`）**：要**选 / 换一个方向或赛场** → 本卡；习惯已定、只是**难度不对**（无聊或太难） → goldilocks；习惯已**自动化、想突破到更高水平** → habit-mastery。

## E — Execution

### 输入契约

- **必需**：一组**候选方向 / 机会**（≥2），或一个「该深耕还是要换」的既有方向；用户当前的**输赢 / 正反馈状况**（用于 f73 相位判断）；以及**可投入时间**。
- **可选**：用户自评的兴趣 / 性格（用于 f76）；已经试过哪些方向。
- **适用条件**：用户要在「方向 / 赛场」层做取舍。若其实是要**调某个已有习惯的难度**、或**突破瓶颈** → 按 B 段分流，不在本卡执行。
- 缺候选方向或「输赢」信息时**先问**，不许静默替用户造选项。

### 输出契约

**产出类型**：`candidates`（对候选方向产排序）+ `patch`（把选定方向落回已有计划的方向字段）

- ① 一个**相位判断**（f73）：当前该多利用还是多探索，并给一个精力配比口径（**启发式，非硬阈值**）。
- ② 一份**四问打分与方向排序**（f74）：对每个候选方向逐问打分，收敛到得分更高的一方。
- ③（若四问后仍无明显有利赛场）一条**自创游戏 / 专业化动作**（f75）：明确组合哪几项技能，或专攻哪个窄域。
- ④（可选）一条**按性格 / 兴趣校正**的选择（f76）。

**完成标准**：给出一份候选方向的排序 + 一条明确的下一步（深耕哪边 / 换到哪边 / 自创哪个组合），且用户能据此选一个方向。

### 步骤

1. **判相位**（f73）：这个方向现在在「赢」还是「输」？可用时间多还是少？
   - 完成标准：给出「利用 / 探索」标签 + 一个精力配比口径。
   - 判停：若用户其实要「调某个已有习惯的难度」→ 转 goldilocks。
2. **四问打分排序**（f74）：对每个候选，逐问打分——①像玩对别人像工作 / ②让我忘时间 / ③回报高于平均 / ④自然而然。
   - 完成标准：一份方向排序，并说明依据。
3. **无有利赛场则自创**（f75）：若四问后没有一个明显占优，就给「组合技能」或「窄域专精」的差异化动作。
   - 完成标准：一条可执行的定位动作（写明组合哪几项技能 / 专攻哪个窄域）。
   - 判停：若用户其实已经选定方向、要的是**突破瓶颈** → 转 habit-mastery。
4. **性格校正**（f76，可选）：按兴趣 / 性格选行为，别照搬最流行的做法；尽责性低者更依赖环境设计。
   - 完成标准：一条「按自己性格 / 兴趣」的选择动作。

### 判停点

- 第 1 步要「调难度 / 保持动力」→ 转 goldilocks。
- 第 3 步要「已熟练后的突破」→ 转 habit-mastery。
- 第 1 步若是「某行为为什么没发生」→ 转 four-step-diagnosis。

## B — Boundary

### 不要用（反场景，按分流）

- 要**调某个已有习惯的难度 / 觉得无聊想加难** → goldilocks。
- 已**熟练、想突破瓶颈到卓越** → habit-mastery。
- 要**定位某行为卡在四步哪一步** → four-step-diagnosis。
- 要**改环境里的线索** → environment-design。
- 要定「**想成为谁**」/ 改身份句 → identity-design。
- 要**改掉一个坏习惯** → four-laws-inversion。
- 只想了解这套模型 → 来源路由入口 `atomic-habits`。
- **涉临床成瘾 / 病理 → 不跑本卡**（见下）。

### 作者警告过的失败模式（反例素材）

- **`x14`（作者原话）**：把别人的成功解释为「基因好 / 运气好」，用来替自己的不努力开脱——在没投入同等努力前，无法判断自己手上的牌更好还是更差。
- **`x15`**：选错习惯 / 赛场时，继续用同一套方法会越来越吃力；有时问题只是选的习惯太难或与自身不匹配，需换赛场或自创游戏。**注**：原文是一句动机论、且**立刻给了补救**（把习惯改易）；提取时把它放大成硬边界，属**外推**——本卡只把它作「选错赛场」的提醒，不宣称作者划了硬门槛。
- **自创游戏不是万能**：f75 是**策略型**建议（非分步流程），只给方向（组合 / 专精），**没有**「该组合哪几项技能、专攻多窄」的判据。

### 作者盲点与待核查（不许当规律用）

- **f73 的配比是启发式、非硬阈值**：80–90% / 10–20% 来自作者对 Google 80/20 的转述，是**启发式**，不是可测的硬阈值；**不得当精确门槛用**。
- **f76 的 Big Five 仅背景**：人格有生物学基础的说法只是**背景**；可操作处只有「按兴趣 / 性格选行为」。**不得把 Big Five 当测评工具**，也不得声称它决定成败。
- **f75 是策略型、非分步流程**：原文只给「赢不了就换游戏 / 专业化」的策略与例子，**没有步骤清单**。
- **结构性约束无分诊判据（存量风险）**：本书涉**基因 / 天赋 / 运气**等结构性约束时，原文只给「基因设定机会范围、非命运」；全书**没有**「何时放弃这个方法、转介专业人士」的判据（已 grep `professional / therapist / clinical / treatment / mental health / psychiatr`，零结果）；涉成瘾的唯一自限句在第 12 章，大意是这类技巧难以遏制真正的成瘾。**本卡只能照录「选赛场的技巧不适用于临床成瘾 / 病理，对结构性约束也只是『机会范围、非命运』」。**
- **第五组（作者前后不一致，原样保留、不替作者调和）**：作者一边承认**运气重要**（在书里说这个过程有一部分只是运气，并在引言注释里说运气确实重要）；一边又强调**别拿运气替不努力开脱 / 基因只决定机会区**（原话说，在你和所佩服的人付出同等努力之前，不要用运气来解释他们的成功；又说基因只决定机会范围、非命运）。两造并存，作者**未调和**；本卡**原样照录，不替作者选边**。
- **无出处数字（关联提醒）**：本卡**不引用**任何「正文无内联出处」的通俗化数字；若他卡引用（心流 4%、40–50% 等），须标「通俗化转述、来源成色弱」。f77 的心流 4% 已标「需复核」，**本卡与 `goldilocks` 卡均不引用**。

### 相邻易混

- **`goldilocks`**：选 / 换**方向**（本卡）vs 调**已有习惯的难度**（它）。
- **`habit-mastery`**：选**赛场**（本卡）vs **自动化后回费力区突破**（它）。
- **`four-step-diagnosis`**：**方向取舍**（本卡）vs **要素级归因诊断**（它）。
- **`identity-design`**：**外在赛场**（本卡）vs **内在身份**（它）。
- **`four-laws-inversion`**：**选方向**（本卡）vs **改掉坏习惯**（它）。

## 相关能力

- **goldilocks**（对比）：本卡选 / 换方向（找赛场）；它调已有习惯的难度。两卡都属「从好到卓越」延伸层。
- **habit-mastery**（对比）：本卡选赛场（方向）；它讲选定方向之后「自动化再回费力区突破」。
- **identity-design**（对比）：本卡挑外在赛场；它定内在身份（想成为谁）。

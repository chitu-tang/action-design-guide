# 社会规范（模仿亲近者·多数人·权势者，加入「期望行为即常态」的文化）

## R — 出处（Reference）

本节方法论出自 James Clear《Atomic Habits》第 9 章（2018；中译《原子习惯》）。原文依据保存在私有工作区（溯源条目 `f35`、`f36`），不随公开版分发。

## I — Interpretation

本卡讲**社会规范**怎样给行为加吸引力：我们不是自己挑出最早的习惯，而是**模仿**周围人——作者把模仿对象归为三类（f35，**分类清单**）：

1. **亲近者（the close）**——家人、朋友、同事。**物理与社会距离越近，越容易模仿**；好友变胖，你变胖的概率上升 57%。
2. **多数人（the many）**——群体。不确定怎么做时，我们会看「别人都怎么做」；从众实验里近 75% 的人会附和明显错误的群体答案。
3. **有权势者（the powerful）**——有地位、受尊敬、成功的人。我们模仿成功者，因为想获得认可、尊重与地位。

**这三类是「为什么某个行为对你有吸引力」的分析镜片，本身不产出动作**（f35 的落地在 f36）。真正落地的操作在 f36：

> **加入一个文化：在那里，你期望的行为是常态，且你与该群体本就有共同点。**

两条判据缺一不可：**常态**让改变从「我要做」变成「像我们这种人会做的事」；**共同点**让群体归属先于行为改变（如 Nerd Fitness 服务「极客、不合群者、变异人」，成员先因共同爱好归属，再谈健身）。作者的判断是：把个人追求变成共享身份后，动机更持久。

一句话：**改「我」很难，改「我所在的圈子和圈子里的常态」更容易——加入一个「该行为是常态」、且你本就属于其中的群体。**

## A1 — Application Example

**主例 · Steve Kamb 的 Nerd Fitness**（c52，**作者转述**）

- **输入/问题**：想健身 / 减肥的人，第一次去健身房或尝试改饮食时常觉得格格不入。
- **怎么执行**：加入 Nerd Fitness——一个服务「极客（nerds）、不合群者（misfits）、变异人（mutants）」的群体；成员先因**已有的共同点**（如都爱《星球大战》）归属，而**健身在那里是常态**。两条判据都满足。
- **结论/输出**：一个满足（1）常态行为、（2）共同点的群体选择。
- **原书交代的结果**：作者称改变因此「更像我们这种人本来就会做的事」；**原文未给该公司业绩数字**。

**补充例（三类模仿）**

- c50（**研究**）：追踪 12,000 人、32 年发现「朋友变胖，本人变胖概率 +57%」；伴侣一方减重，另一方约三分之一概率也瘦。**相关≠因果**。
- c51（**作者转述**）：宇航员 Mike Massimino 在 MIT 一门十人的机器人课上，四人后来成为宇航员。原文交代该班结果，未给样本设计。
- c53（**研究**）：Asch 从众实验，随「演员」增至三至八人，最终**近 75%** 受试者附和明显错误的群体答案。原文未给总样本量与统计（见英文版注释）。
- c54/x23（**研究 + 反例**）：黑猩猩转入使用较差砸坚果法的群体后，会弃用更优方法以求合群。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 「我身边的圈子 / 朋友都在做 X，我不知不觉也跟着做，怎么借着这点改变自己？」
- 「我想养成 / 戒掉某个行为，感觉靠一个人很难，能不能换个圈子 / 找一群人一起？」
- 「怎么找一个『做这件事是常态』的群体，让我不再觉得自己是异类？」
- 「我想知道某个行为为什么对我这么有吸引力（身边人都在做）。」
- 「怎么让家里 / 团队里大家都把某件事当常态？」

**2. 语言信号（中英双写）**

- 中文：社会规范 / 身边的人 / 圈子 / 找一群人 / 加入社群 / 大家一起 / 随大流 / 从众 / 亲友影响 / 榜样 / 有地位的人 / 归属感 / 合群 / 我这种人也会做。
- English: social norms / the people around me / join a group / a tribe / fit in / peer pressure / imitation / the close, the many, the powerful / role model / belonging / common ground.

**3. 与相邻能力怎么区分**

- **`temptation-bundling`**（对比，见分流句）：那条靠**自己配的奖赏**给行为加吸引力；本卡靠**外部群体**。
- **`deep-motive`**（对比，见分流句）：本卡解释「这个行为为什么在**社会层面**有吸引力」；它解释「这个渴望在**生理 / 心理层面**要满足什么」。
- **`environment-design`**（对比）：那条改**物理 / 数字空间**里看得到什么；本卡改**社会圈层**（你会靠近、模仿谁）。
- **`commitment-accountability`**（对比）：那条用**契约 / 问责伙伴 / 罚则**；本卡的问责伙伴（`f68`）只作其轻量版，社会规范本身不靠惩罚。
- **f36 ⇄ f35 内部关系**：f35 是分类镜片（为什么有吸引力），f36 是落地判据（选 / 加入哪个群体）；两条件同处「社会规范」一卡，不可只取其一。
- 福格 `group-behavior-design`（跨书相邻）：那条是**为群体设计行为**；本卡是**个人借群体改变自己**。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我设计一个群体的行为规范 / 让团队都养成某习惯」→ 不触发本卡，走福格 `group-behavior-design`（本卡是个人借群体，不是给群体做设计）。
- 「把我想做的绑到需做的上」→ 不触发本卡，走 **`temptation-bundling`**。
- 「我这个渴望背后的真实需求是什么」→ 不触发本卡，走 **`deep-motive`**。
- 「改房间 / 摆线索 / 把坏习惯的东西收起来」→ 不触发本卡，走 **`environment-design`**。
- 「用契约 / 罚金 / 找人签合同盯着我」→ 不触发本卡，走 **`commitment-accountability`**。
- 「先帮我判断这个行为到底卡在哪一环」→ 不触发本卡，走 **`four-step-diagnosis`**。

**分流句（本卡 ↔ `temptation-bundling` ↔ `deep-motive`）**：想让**某个行为**因为「我这圈子 / 大多数人 / 我佩服的人都在做」而变有吸引力，或想**借一个群体 / 圈子**带动自己的习惯 → social-norms；想用**自己配的一件真想做的事**去牵引一件必须做的事 → temptation-bundling；想追问**一个表层渴望背后的深层需求**、换个方式满足 → deep-motive。

## E — Execution

### 输入契约

- **必需**：① 一个想促成（或想削弱）的**具体行为**；② 当事人当前**所属 / 常接触的群体**（家人、朋友、同事、常去的社群）中，谁在做、谁不做该行为。缺群体信息**先问**，不许静默替用户挑一个圈子。
- **可选**：能接触到的候选群体；当事人与潜在群体的**共同点**（兴趣、身份、经历）。
- **适用条件**：只解决「借社会规范 / 群体给行为加吸引力」。若用户其实要「给群体本身做行为设计」→ 转福格 `group-behavior-design`；要「自己配奖赏」→ temptation-bundling。

### 输出契约

**产出类型**：`patch`（给已有计划换零件：把行为嵌进「该行为是常态」的群体，或调整接触的圈层）

一份**社会规范方案**，至少含：

- ① 用三类模仿（**亲近者 / 多数人 / 权势者**，f35）**诊断**该行为当前的吸引力来源（被谁带动）；
- ② 一个满足两判据（f36）的**目标群体**：该行为在那里是**常态** + 当事人与该群体**已有共同点**；
- ③ 一条**接触 / 远离**动作：靠近想模仿的群体，或拉开与在拖后腿的圈子的距离。

**完成标准**：能指出「加入 / 靠近哪个群体、为什么它满足两条件」，以及该动作如何改变该行为的吸引力。

### 步骤

1. **用三类模仿定位吸引力来源**：把该行为当前的带动者归到「亲近者 / 多数人 / 权势者」（f35）。
   - 完成标准：指名该行为被哪一类（哪些人）带动。
   - 判停：若用户其实要「给一个群体做行为设计」→ 转福格 `group-behavior-design`。
2. **（正向）选一个满足两判据的群体**（f36）：该行为是常态 + 已有共同点。
   - 完成标准：给出一个具体群体，并逐条说明它如何满足两条判据；两者缺一即不合格。
   - 判停：若**找不到**满足条件的群体 → 见 B 段「缺口」——原文未给「如何找 / 找不到怎么办」，只能在此如实标注并**由当事人自行搜索 / 现造**。
3. **（反向）拉开与拖后腿圈子的距离**：对在带动坏行为的「亲近者 / 多数人」，减少接触。
   - 完成标准：≥1 条具体「减少接触 / 换圈」动作。
4. **（可选）把个人追求转成共享身份**：加入后把「我在做」讲成「我们在做」。
   - 完成标准：一句共享身份的表述（如「我们是跑者」）。

### 判停点

- 第 1 步要「给群体做设计」→ 转福格 `group-behavior-design`。
- 第 1 步要「自己配奖赏 / 捆绑」→ 转 temptation-bundling。
- 第 2 步找不到满足条件的群体 → 按 B 段缺口标注（原书无「如何找 / 找不到」方法），不得编造判据。
- 第 2 步发现用户其实想改「物理 / 数字空间」→ 转 environment-design。

## B — Boundary

### 不要用（反场景，按分流）

- 要给**群体本身**设计行为 / 让一个团队都养成某习惯 → 福格 `group-behavior-design`（本卡是个人借群体）。
- 要自己配奖赏给行为加吸引力 → temptation-bundling。
- 要追问渴望背后的深层需求 → deep-motive。
- 要改物理 / 数字空间里的线索 → environment-design。
- 要用契约 / 罚金 / 正式问责锁死 → commitment-accountability（本卡不含惩罚机制）。
- 要先归因「行为卡在哪一环」→ four-step-diagnosis。
- 纯信息查询（「社会规范是什么意思」）→ 来源路由入口 `atomic-habits`。

### 作者警告过的失败模式（反例素材）

- **群体的常态会压过个人的最优**（x23/c54）：黑猩猩宁可弃用更高效的砸坚果法，也要随新群体。作者的意思是：群体的常态常常压过个人的期望行为。
- **改变若意味着挑战群体，就会失去吸引力**：当改变习惯意味着与群体作对时，改变就没了吸引力——所以本卡对「坏圈子」的正向做法是**远离 / 换圈**，而不是硬扛。
- **从众会压过亲眼所见**（c53/Asch）：近 75% 的人附和明显错误的群体答案；多数时候，人宁可跟着人群一起错，也不愿独自正确——提醒「多数人都在做」不等于「值得做」。
- **相关≠因果**（c50）：朋友肥胖与本人肥胖 +57% 是**相关**，不是因果；不得当因果机制宣传。

### 作者盲点与待核查（写进卡、不许越界宣称）

- **f36 的缺口（必写）**：原文只给「**选择判据**」（期望行为是常态 + 有共同点），**没有给「怎么找这样的群体」「找不到怎么办」的方法**（f36 仅勉强达标）。写卡 / 编译时**不得补造一套「寻找群体」的步骤**——实操里只能如实标注「由当事人自行搜索 / 现造」，或先建一个最小群体。这是原文未给的缺口。
- **f35 是分类清单，不产动作**：三类模仿是**分析镜片**，落地动作在 f36（f35 判据 2/3 不过，作 f36 判断依据）。**不得把「the close/many/powerful」当成一条可独立执行的流程**。
- **三类模仿的证据成色**：c50（12,000 人 / 57%）、c53（Asch 75%）、c51（Massimino 一课十人四宇航员）均为**作者转述或引用**，原文多未给样本设计；c52（Nerd Fitness）**未给业绩数字**。引用须标来源类型，不得当作者亲历或已证实因果。
- **涉成瘾 / 病理无分诊判据（存量风险，按内容涉及即写）**：社会规范会放大喝酒、成瘾类行为（f35 的验收演练即「我为什么越来越爱喝酒」），但全书**没有**「何时放弃本方法、转介专业人士」的判据（全项目 grep `professional / therapist / clinical / treatment / mental health / psychiatr` 零结果）；涉成瘾的唯一自限说明是「这类技巧约束不了真正的成瘾」（第 12 章）。**本卡只能照录「技巧不适用于临床成瘾 / 病理」。**

### 相邻易混

- **`temptation-bundling`**：外部群体（本卡）vs 自己配的奖赏（它）。
- **`deep-motive`**：社会来源（本卡）vs 内在需求（它）。
- **`environment-design`**：社会圈层（本卡）vs 物理 / 数字空间（它）。
- 福格 `group-behavior-design`：为群体做设计（它）vs 个人借群体改变自己（本卡）。

## 相关能力

- **temptation-bundling**（对比）：本卡借群体 / 社会来源；它是自己配奖赏。
- **deep-motive**（对比）：本卡看「社会层面」为何有吸引力；它找「内在（生理 / 心理）深层需求」。

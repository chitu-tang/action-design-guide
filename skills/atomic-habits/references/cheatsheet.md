# 决策规则速查 — 原子习惯

| 能力 | 一句话规则 |
|---|---|
| 身份设计（身份型习惯与身份重定义） | 想「从根上」改变、或角色变化后要重构自我时，走身份设计——三层定位 → 定一句能被行为印证的身份句 → 落第一个小胜 → （涉及角色丧失时）把角色型身份改写成特质型身份。 |
| 习惯追踪与复盘（觉察 · 追踪 · 恢复 · 复盘） | 已经有一个想长期维持的习惯时，走「觉察 → 追踪 → 恢复 → 复盘」——先当刻盘点，再建一张打叉式追踪表并配 「不中断链条」与「绝不错过两次」恢复规则，定期（年度 / 半年）用固定问题复盘校准，同时防追踪反噬。 |
| 承诺与问责（承诺机制 · 自动化 · 契约 · 问责） | 已知道该做什么、但不想再靠意志力硬撑时，走承诺与问责——在当下把未来选项锁死（承诺机制 / 一次性行动 / 自动化），再给不执行加即时、公开、可靠执行的代价（习惯契约 / 问责伙伴），并用「即时 + 强度匹配」自检罚则。 |
| 环境设计（线索侧） | 一个行为要改、又不想靠意志力时：把好习惯的线索放到最显眼处、把坏习惯的线索移除，让最优选项成为最明显的选择（只动「看得到什么」，不动「多难做」）。 |
| 四步模型行为诊断 | 一个行为养不成或没发生，就沿「提示→渴望→反应→奖赏」逐项排查找最短板；与福格 B=MAP 分流——福格补「提示/能力/动机」，本书找「提示/渴望/反应/奖赏」的最短板。 |
| 行为改变四定律框架与章末操作集（建立侧） | 建立好习惯，就把行为按「显而易见 / 有吸引力 / 简便易行 / 令人满足」四条定律逐条设计，用章末操作集落手段，轮换四律找下一个瓶颈（反向侧另立 four-laws-inversion）。 |
| 反向四律（打破坏习惯） | 对一个具体坏习惯，按「隐而不见 / 缺乏吸引力 / 难以实行 / 令人不满」四反向定律逐条产出动作，并指明各条落哪张实现卡。 |
| 线索设计（执行意图 · 习惯叠加 · 线索陷阱） | 把新习惯落到既有线索上——用「I will [行为] at [时间] in [地点]」（执行意图）或「After I [既有习惯], I will [新习惯]」（习惯叠加）写出配方，并排障（线索要具体、频率要对齐）、防反噬。 |
| 诱惑捆绑（把想做的绑到需做的上） | 一件必须做但缺吸引力的事：把一件你真心想做的事挂在它后面（After [需做]，I will [想做]）；借群体走 social-norms，追根源走 deep-motive。 |
| 社会规范（三种模仿 · 加入「期望行为即常态」的文化） | 想让某个行为因「我这圈子 / 大多数人 / 我佩服的人都在做」而变有吸引力：加入一个「期望行为是常态」且你已有共同点的文化（用亲近者 / 多数人 / 权势者诊断吸引来源）；自己配奖赏走 temptation-bundling。 |
| 渴望的深层动机（表层渴望 vs 深层动机） | 某个行为「就是控制不住 / 戒不掉」时：问它背后要满足什么深层动机（节省能量 / 食物水 / 爱与繁衍 / 连接归属 / 社会认可 / 减少不确定 / 地位声望），再自行配对替代行为；加吸引力走 temptation-bundling，重述走 reframe。 |
| 心态重构与动机仪式（把「不得不」换成「我可以」 · 难习惯前先做件喜欢的事） | 一想到某件事就烦 / 进入不了状态时：换个说法（「不得不」→「我可以」）或给难习惯前面接一个喜欢的动作当开机线索；把想做之事绑在需做之事后面当奖赏走 temptation-bundling，追渴望根源走 deep-motive。 |
| 运动 vs 行动（motion vs. action：从「准备」转入「练习」） | 分不清自己在「准备」还是在「行动」时：用「有没有产出可交付结果」判定运动态还是行动态，再把准备项换成一条今天就能做、会产出结果的最小行动。 |
| 摩擦管理与预备环境（摩擦侧） | 一个行为「本身多难做」时：给好习惯减摩擦（减步骤 / 提前预备）、给坏习惯加摩擦（加步骤直到不切实际）；不动「看得到什么」（那是 environment-design）。 |
| 决定性时刻（识别一天里的岔路口并预设选择） | 一天里真正决定走向的只是少数几个「岔路口」式小选择：先把它们认出来，再给关键岔口预设选择（可配一个仪式化的第一步）。 |
| 两分钟法则（门户习惯 · 先标准化再优化 · habit shaping 逐级升级） | 新习惯起不来时，把起始版压到两分钟内（门户习惯），先标准化再优化，稳定后再用 habit shaping 逐级升级。 |
| 强化与即时奖赏（完成加即时奖赏 · 让「什么都不做」也满足 · 奖赏须与身份一致） | 习惯做完却毫无满足、坚持不住时：给行为结尾挂一个即时奖赏/回馈（回避型则把「忍住」变可见），并检查这个奖赏是否与你的身份一致；纯情绪庆祝走福格 celebration，即时代价走 commitment-accountability。 |
| 找赛场与差异化（探索/利用 · 找赛场四问 · 自创游戏 · 与个性匹配） | 在几个方向 / 机会间取舍、或越做越苦怀疑选错赛场时：先用探索/利用判断相位（赢时多利用、输时多探索），再用四问（像玩对别人像工作 / 让我忘时间 / 回报高于平均 / 自然而然）给候选方向打分排序；没有有利赛场就自创游戏或窄域专精，并按性格/兴趣选行为。 |
| 金发姑娘法则与爱上无聊（难度调到能力边缘 · 守日程） | 习惯已养起来、动机开始衰减（无聊或焦虑）时：把任务难度调到「刚好在当前能力边缘」——太易就逐步小幅加难（保持 novelty），太难就降档；若难度没问题只是无聊，就「爱上无聊」、不论心情照常按日程出现，别因无聊换方法。 |
| 习惯 + 刻意练习 = 精通（自动化后的突破路径） | 一个已经自动化、变得熟练的技能却停步不前时：别指望「养成习惯就等于掌握」——习惯只是必要不充分条件；要回到费力区，挑一个还不够好的子技能刻意打磨、把它练成新习惯，再叠加下一个，循环不止（原文为公式式口号，成色弱，只作方向性解释）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

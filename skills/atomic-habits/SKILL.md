# 原子习惯 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 临床成瘾、物质依赖或需要躯体戒断处理的成瘾问题：原书只在正文里用一句话声明这类方法不适用于真正的成瘾，全书未给「何时放弃这套方法、何时转介专业」的分诊判据——本工具不处理成瘾治疗，应转介专业人士；不得假装本书给了判据。
- 精神疾病／心理病理导致的执行不能：原书对「习惯问题」与「需要专业干预的问题」并未划线，本入口据此一律划出本工具范围、直接转介；这是本入口的硬停线，不是原书给的判据。
- 结构性约束（贫困、制度性障碍、人身安全风险）：原书默认用户「有选择的余地」，对基因／天赋／运气只给「设定机会范围、非命运」的说法（第 18 章），同样未给分诊判据，不得把结构性困境当成「系统设计问题」处理。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 系统优于目标：目标只给方向、系统才产生结果；小习惯靠 1% 的复利放大，且成果常延迟出现在「潜能积蓄期」之后，所以要看轨迹而非当下结果。
2. 改变分结果／过程／身份三层，身份最深；本书主张从「想成为谁」出发的身份型习惯——但身份与习惯谁是起点，作者同时持有「身份优先」与「习惯造身份」两个方向，本入口照录这层张力、不替作者调和。
3. 任何习惯都可拆成提示→渴望→反应→奖赏四步，四步缺一不成；这四步对应四条可操作的定律，正用建立好习惯、反用打破坏习惯，两条清单互为正反、不合并。
4. 第一定律「让它显而易见」：改变始于觉察，再用执行意图、习惯叠加与环境线索把好习惯的提示摆到显眼处；坏习惯则移除线索——自控的秘诀是环境，不是硬抗诱惑。
5. 第二定律「让它有吸引力」：渴望由预测与多巴胺驱动，用诱惑捆绑、社会规范与心态重构让好习惯有吸引力，反过来让坏习惯显得没意思。
6. 第三定律「让它简便易行」：人遵守最省力法则，减摩擦、预备环境、两分钟法则、承诺机制与自动化让好习惯易行、坏习惯难行；反过来加摩擦、把选择提前锁死。
7. 第四定律「让它令人满足」：立即被奖赏的才会被重复，用即时奖赏、习惯追踪（不中断链条／绝不错过两次）与问责／契约为好习惯制造即时回报、为坏习惯制造即时代价；习惯靠重复次数（频率）而非天数固化。

## 边界与判停

- 完成一次四步诊断或一个单点设计、给出下一步路由后即停，不要把整条流水线（诊断→设计→追踪→复盘）一次跑完。
- 对话中出现临床成瘾、物质戒断风险、自伤意念、进食障碍等信号时，立即停止习惯设计并转为建议寻求专业帮助；原书只给一句自限、未给分诊判据，不得据本书判断「能不能用」。
- 用户没有给出可操作的具体行为时，先停下要求具体化（哪个行为、什么场景、想要的结果），不静默猜值；具体化后再路由到对应能力卡。
- 用户要的是「未经验证的结论」时停——本书正文有三条数字无内联出处、端注成色弱，把这类数字或作者推测当既定事实用时，停下并注明「通俗化转述、来源成色弱」。特别是「心流高于现有能力约 4%」这个数字：端注给出的出处与数字本身冲突，任何产物都不得引用。
- 同一句里既命中某张卡的触发面、又命中任一停手条件（成瘾／物质依赖／躯体戒断风险／自伤意念／进食障碍）时，判停优先：不加载能力卡，直接转介。
- 用户要求作者未给的阈值（如「重复多少次才算固化」「罚则强度多大」）或把「身份优先」「习惯形成靠频率」当成已被证明的定论时，停下并说明这属作者主张或原书缺口，不替作者补值。

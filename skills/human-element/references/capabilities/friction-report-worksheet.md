# 摩擦报告工作表

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》结语（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f45`），不随公开版分发。

## I — Interpretation

本卡是 four-frictions-diagnosis 的**填表交付版**：同一套「四种心理摩擦力（惯性 / 惰性 / 情感 / 抵触）」诊断，换成**一张可填的 2×2 工作表**。做法是——挑一个案例或一个变革计划，在表里**逐格**记录观察、给出该格摩擦的**影响力（低 / 中 / 高）**、写一句针对这个案例的分析；四格填完，就能看出这个计划最该先处理哪一根摩擦。

作者反复强调一件事：**填表的意义不在那张表本身，而在于逼协作的人把判断讲出来、被反驳、再修正**。也就是说，这张表的价值一半在「填」，一半在「填的过程逼人把判断讲出来、被反驳、再修正」。

**自我版（本卡的主用法）**：一个人把**一件事**按四格过一遍。它保留了「四格逐项对照、找出最大摩擦」这个可执行内核，但**丢掉了作者强调的「协作辩论」环节**——没有别人来反驳你的打分，判断的自证偏弱。这一点要在用时明说，不把它讲成「原书讲了一个人填表」。

它的产物是**一张填好的四格表 + 一条最大摩擦**（诊断），**不产出任何行动方案**——出招仍在三张轴卡里。

## A1 — Application Example

**主例 · 迪拜创业计划摩擦报告**（结语引出，对应「结语摩擦报告表（图）」表 A）——**这是对外场景（政府推国民创业），不是自对己案例。**

- **输入/问题**：迪拜未来基金会想在全国掀起年轻人创业的浪潮，但推力资源齐备却只换来「涓涓细流」。
- **怎么执行（按四格填表）**：把「目标＝鼓励迪拜年轻公民成为企业家、对象＝优秀大学生」写在表头，再逐格写观察与影响力。四格影响力为**惯性高 / 惰性高 / 抵触低 / 情感高**（结语摩擦报告表（图）表 A；**图转录，非正文引文**）。正文里对应的诊断是：惯性（创业对当地学生是陌生概念）、惰性（流程复杂、耗时长、成本高，路径模糊）、情感（高失败率与家人难堪带来的焦虑）、抵触（政府没有强制，故抵触可能性很低）。
- **结论/输出**：一张四格都填好的表，最大摩擦判在惯性 / 惰性 / 情感三格，据此把重点放在结构调整。
- **注**：案例与表格里的数字（石油占 GDP 24%、12 个月、10 万美元、90% 失败率等）**原文未给出处**（c112 备注）。**Flyhomes 一案的正文讨论只讲了情感与努力两格，这是正文表达上的侧重，不是表缺格**——结语摩擦报告表（图）表 B 四格都填了。

**合成演练（自我场景）· 一个人把「每周复盘」按四格过一遍**——**原书未提供自对己案例，以下为按原书规则设计的演练（机制同源推断）**：
- **表头**：目标＝让「每周复盘」落地；对象＝**我自己**（把原表的「受众」换成自己）。
- **逐格填**：惯性（把下班后的时间改成复盘，改变大不大？）、惰性（坐下来要花多少力气？「复盘写什么」是否模糊？）、情感（一想到复盘是否发怵？）、抵触（是否用「必须写满」在压自己？）；各给一句分析 + 低 / 中 / 高。
- **结论/输出（预期）**：最大摩擦落在**惰性（不知写什么）+ 抵触（像被考核）**，据此给一份 3 行模板、去掉「必须写满」的硬要求。
- **注**：这一演练**能按原书四格复算**，但原书**未提供**该自我场景的结果，结局属预期、非书证；且它按本卡 I 段说明**丢失了「协作辩论」环节**。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 想照着「四种心理摩擦力」给一个计划**做一张诊断表**、逐格过一遍。
- 有一份方案 / 变革计划，想系统地把四种摩擦都盘一遍、看哪个最重。
- 需要一份**可交付的格式**（表），而不只是一句判断。
- 想把一件事发出来给别人（或未来的自己）看，用表格固定复盘口径。
- 已经把四摩擦记成一句话，想落成一个稳定模板、每次都能复用。

**2. 语言信号（中英双写）**
- 中文：摩擦报告 / 摩擦报告工作表 / 四格表 / 按四种摩擦填一张表 / 给这个计划盘一遍摩擦 / 做个诊断表 / 哪个摩擦最重。
- English: friction report / friction report worksheet / fill the four-friction table / score the four frictions / a diagnostic sheet for this plan / which friction dominates.

**3. 与相邻能力怎么区分**
- 与 four-frictions-diagnosis：**同一「四摩擦诊断」契约、交付物不同**——那条给**判断**（主摩擦 + 分流去向），本卡给**一张填好的四格表**。要「告诉我卡在哪」走那条；要「给我一张表」走本卡。
- 与 fuel-friction-framing：那条是方向前导（别只加推力）；本卡是四格诊断的填表形态。
- 与来源路由入口「人性阻力」：入口答「整套模型是什么」。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「这件推不动的事到底卡在哪、下一步该走哪张卡」→ 走 four-frictions-diagnosis（要判断，不是要表）。
- 「帮我把这个习惯拆小 / 降难度」→ 走福格 `tiny-habit-design` / `make-it-easy`。
- 「这本书的四种摩擦是什么 / 整套模型怎么用」→ 走来源路由入口「人性阻力」。

## E — Execution

### 输入契约
- **必需**：一个要盘的**案例 / 变革计划**，并写清**目标**与**对象**（自我版对象＝我自己）。
- **可选**：已经掌握的该计划背景（谁在推、推给谁、卡了多久）。
- **适用条件**：用户要**一张四格诊断表**（交付格式）。若实际是「要一句卡在哪的判断」「要降难度」，按 B 段分流。
- 缺「要盘的是哪个计划 / 目标对象是谁」时**先问**，不许静默替用户编一个案例。

### 输出契约

**产出类型**：`diagnosis`（一张填好的四格诊断表；不产出行动方案）

可检查产物：
1. **一张四格都填了的表**：惯性 / 惰性 / 情感 / 抵触各给「影响力（低 / 中 / 高）+ 一句针对该案例的分析」。
2. **一条最大摩擦**：圈出影响力最高的格，并说明理由。

**完成标准**：四格都有影响力与分析（**不留空格**），且给出唯一一条最大摩擦。

### 步骤

**第 1 步 · 立表头**
- 动作：写下这件事的**目标**与**对象**（自我版对象写「我自己」）。
- 完成标准：目标、对象两栏都有具体内容。

**第 2 步 · 逐格填（四格）**
- 动作：对惯性 / 惰性 / 情感 / 抵触四格，各给一个**影响力（低 / 中 / 高）** 与一句**针对这个案例的**分析。格内诊断问句见「结语摩擦报告表（图）」（图转录，**非正文引文**）。
- 完成标准：四格全部有影响力与分析，无空格。
- 判停：若某一格判断不出来，先回 four-frictions-diagnosis 做四格判断，再回来填表。

**第 3 步 · 找最大摩擦**
- 动作：比较四格影响力，圈出最高的一格作为最大摩擦。
- 完成标准：给出唯一一条最大摩擦。
- 判停：**若四格影响力并列或打分的判据不清（原书未给「影响力怎么打分」的量尺）**，如实标明「作者未给判分判据」，允许并列、不硬凑一个。

**第 4 步 · （自我版）替代协作辩论**
- 动作：原书要你与团队成员协作填表、目的是「讨论与辩论」；一个人填时，用「**反方会怎么反驳我这格的打分**」自问自答一次，尽量补回被丢掉的这一环。
- 完成标准：对至少一格写出了「反方会怎么反驳」并给了回应（或明说本卡已失去协作辩论这一环）。

## B — Boundary

### 不要用（反场景）
- 只要一句「卡在哪 / 下一步走哪张卡」的判断 → four-frictions-diagnosis（不同交付物）。
- 要方向前导「别只加推力」→ fuel-friction-framing。
- 要把习惯建起来 / 降难度 / 加提示 → 福格 `tiny-habit-design` / `make-it-easy` / `prompt-types`。
- 只想了解整套模型 → 来源路由入口「人性阻力」。
- 对外说服术 / 销售话术 → 本书不做。

### 作者警告过的失败模式（反例素材）
- **把填表本身当目的**：作者明说，填表的意义不在那张表本身，而在于让协作的人把判断讲出来、被修正；只交一张漂亮表、跳过讨论，就丢掉了这张表一半的价值。
- **一个人填表而不设「反方」**（本卡 I 段说明）：自我版天然缺「协作辩论」，判断缺少外部反驳，自证偏弱——须明标，不假装有。

### 作者盲点与待核查（写进卡、不许假装有）
- **引用级别红线（硬约束）**：结语两张摩擦报告表的**格内文字是图转录，不是原文**，**不得当正文引文**；要引用四个格的具体问句 / 影响力勾选，须标为「结语摩擦报告表（图）」，**不得写成正文引文**。
- **x69 已核销（硬约束）**：原判「Flyhomes 案例只填两格、内部不一致」**不成立**——结语摩擦报告表（图）表 B 四格都填了（惯性低 / 惰性高 / 抵触低 / 情感高），正文只讲情感与努力两格是**叙述侧重**。**不得再把 x69 当「内部不一致」提上来**。
- **f45 判「需改造」**：原书是对外技巧（与团队协作填表），自我版要**重写**为「一人把一件事按四格过一遍」，且**丢失了作者强调的「协作辩论」价值**——不当原样搬。
- **缺判据（原书未给，不许假装有）**：作者**未给**「某一格的影响力该判低 / 中 / 高的量尺或分界」。占位勾选框存在，但**打分判据没有**；用时如实标「原文未给判分判据」。
- **全书无出处体系**：凡引数字一律「原文未给出处」；迪拜 / Flyhomes 两案数字极多且全无出处（c112 / c113 备注）。
- **证据档四档具名**：f45 ＝ `author_firsthand`（结语的方法载体）。**不写 `strong` / `medium` / `weak`**。
- **全书无一处「自己对自己改变」的案例或声明**：原书主语一律是「你和团队成员 / 你的受众」（x65）；本卡 A1 的自我场景是**明确标记的合成演练**，属**机制同源推断**，不是作者原意。

### 相邻易混
- four-frictions-diagnosis（同一契约、不同交付物）：那条给**判断**（主摩擦 + 分流），本卡给**一张表**。
- fuel-friction-framing（方向前导）：讲「别只加推力」；本卡是四格诊断的填表形态。
- friction-effort-diagnosis / negative-emotion-source / resistance-self-persuasion（三轴出招）：本卡只盘出最大摩擦，出招在它们。

## 相关能力

- **four-frictions-diagnosis**（对比）：同一「四摩擦诊断」契约；本卡是它的**填表交付版**，它给**判断**、本卡给**一张表**。
- **fuel-friction-framing**（对比）：它是方向前导；本卡是四格诊断落成一张可填的表（经来源路由入口访问）。
- **注**：盘出最大摩擦后，出招在对应轴卡（惰性 / 情感 / 抵触三张）；这条「出招去向」由总诊断卡统一承载，本卡不另列边。

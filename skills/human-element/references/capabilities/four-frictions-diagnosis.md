# 阻力四格诊断

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 1 章与第 2 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f02`、`f08`），不随公开版分发。

## I — Interpretation

本卡是**诊断**，不是出招。它只回答一个问题：**我推动的这件事，为什么推不动？**（把主语换成自己时：我为什么执行不下去自己定下的改变？）它给的不是「怎么改」，而是一张把阻力来源分成四格的定位图，用来指认「主要卡在哪一格」，再把后续定位与出招交给对应的轴卡。

四要素与四种摩擦一格对一格：

1. **变化程度**（对现状的落差是大是小）→ **惯性摩擦**（Inertia）：落差越大、越陌生，越推不动。
2. **实施成本**（要花多少力气、路径清不清楚）→ **惰性**（Effort）：成本越高越不动；反身时还叠加「不知道怎么做」的模糊性。
3. **对预期变化的反应**（感觉被威胁到什么）→ **情感摩擦**（Emotion）：威胁感带来焦虑、害怕，让人做不成本来想做的事。
4. **创造变革的方式**（是不是在施压）→ **抵触摩擦**（Reactance）：被推着走时的反弹。

进入四格之前有一个**归因纠偏**前置步（f08）：人习惯把「不动」解释成内部原因（对方冷漠 / 我懒、没毅力），看不见当时情境里的摩擦。不先纠偏，四格就会问偏。

一个口径要点：「心理摩擦力 / 摩擦」（`friction`）是**这四种摩擦的统称，不是第五个要素**。四格之间是并列关系。

限定：本卡**只到「指认主摩擦 + 一条分流去向」为止**，不做每个轴的解法——惰性怎么降、情感从哪来、抵触怎么化解，各在对应轴卡里。

## A1 — Application Example

**主例 · 迪拜把年轻人变成创业者**（`nature: 作者转述的第三方长案例`，c112）——**这是对外场景（政府推国民），不是自对己案例。**

- **输入/问题**：迪拜想培育本土创业文化。政府先上了一整套「推力」——崭新的联合办公空间、加速器、营销活动，结果只换来「涓涓细流」：很少有年轻人迈出创业第一步。
- **怎么执行（把四格过一遍）**：
  - **惯性**：成为一名企业家对当地年轻人还是陌生概念，毕业后的热门选择是当公务员。
  - **惰性**：创业流程复杂、耗时长、成本高，注册费可高达 10 万美元，启动可能耗时 12 个月以上，且路径「令人迷茫」。
  - **情感**：约 90% 的初创会失败，在当地「失败」还会让家人难堪，对失败的恐惧成为主要障碍。
  - **抵触**：政府这边并没有逼着他们走这条路，所以抵触的可能性很低。
- **结论/输出**：主摩擦判在惯性 / 惰性 / 情感三格（抵触一格判低），据此把重点放在结构调整上。
- **注**：案例里的数字（石油占 GDP 24%、12 个月、10 万美元、90% 失败率等）**原文未给出处**（c112 备注）。

**合成演练（自我场景）· 半年没动起来的「每周复盘」**——**原书未提供自对己案例，以下为按原书规则设计的演练（机制同源推断）**。把主语从「受众」换成「我自己」，逐格问：
- 变化程度：把下班后的时间改成「复盘」，算大改动还是小调整？（惯性）
- 实施成本：坐下来要花多少力气？「复盘到底写什么」是不是含糊？（惰性）
- 威胁感：一想到「复盘」是否发怵、怕看见自己没进展？（情感）
- 我是否在强迫自己：是不是用「必须每天写满」在压自己？（抵触）
- 预期输出：主摩擦落在惰性（不知写什么）+ 抵触（像被考核）。这一演练**能按原书四问复算**，但原书**未提供**该自我场景的结果，结局属预期、非书证。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 一件事推了几个月推不动，来问「到底卡在哪」。
- 对别人推一个改变（孩子 / 同事 / 客户 / 团队 / 选民）没反应，想找原因而不是加把劲。
- 自己定的计划执行不下去，第一反应是「我就是懒 / 没毅力」。
- 要改一个行为，却不知道该往哪个方向使劲（减摩擦？降难度？化解反弹？）。
- 手上有个「什么都试过就是不动」的事，想先分类再对症。

**2. 语言信号（中英双写）**
- 中文：到底卡在哪 / 为什么推不动 / 是不是我懒 / 阻力在哪 / 哪种摩擦 / 是惯性还是惰性还是情感还是抵触 / 别扭着不动 / 归因。
- English: what's really blocking this / why won't this move / is it inertia, effort, emotion or reactance / four frictions diagnosis / trace it to friction not to laziness / diagnose the resistance.

**3. 与相邻能力怎么区分**
- 与福格 `bmap-diagnosis`：都答「卡在哪」，但一个从**行为的三个前提**切（动机 / 能力 / 提示，问「行为为什么没发生」），一个从**阻碍的四个来源**切（惯性 / 惰性 / 情感 / 抵触，问「我推动的事为什么推不动」）。输出不同；双触发写进近邻负例。
- 与 fuel-friction-framing：那条是**方向前导 / 燃料侧总纲**（推力 vs 摩擦力、两类推力），只讲「别只加推力」；本卡给出四格并落到「主摩擦是哪一格」。
- 与 friction-report-worksheet：本卡给**判断**，那张卡给**一张填好的四格表**（同一契约的交付变体）。
- 与三张轴卡（friction-effort-diagnosis / negative-emotion-source / resistance-self-persuasion）：本卡**指认主摩擦后就分流**，后续定位与出招在对应轴卡。
- 与来源路由入口「人性阻力」：入口答「这套模型是什么、怎么系统性地用」。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「帮我养成每天读书的习惯 / 把它拆到多小」→ 不触发本卡，走福格 `tiny-habit-design`（往前建）。
- 「只想把这件事变简单 / 加个提示」→ 不触发本卡，走福格 `make-it-easy` / `prompt-types`。
- 「按四种摩擦填一张表给我」→ 走 friction-report-worksheet，不是本卡的诊断动作。
- 「我觉得这事跟我这个人不符」→ 不触发本卡，四要素**不含身份层**，走身份层（原子习惯）。
- 「教我一套说服别人的销售话术」→ 不触发本卡，本书不做说服术。

## E — Execution

### 输入契约
- **必需**：一件推不动的事（对自己的执行 / 对别人的推动均可），并说清**谁在推、推给谁、卡了多久**。
- **可选**：已经试过的措施（用于判断是不是一直在「加推力」）。
- **适用条件**：用户要「为一件具体推不动的事找归因」。若其实是「把某习惯建起来」「把它变简单」「按四格填表」，按 B 段分流。
- 缺「推不动的是哪件事」时**先问**，不许静默替用户编一件事。

### 输出契约

**产出类型**：`diagnosis`（一份四格诊断 + 一条分流去向；不产出行动方案）

可检查产物：
1. **一张四格过表**：对每格给出「命中 / 未命中 + 一句依据」。
2. **一条主摩擦判断**：指名落在惯性 / 惰性 / 情感 / 抵触中的哪一格。
3. **一条分流去向**：把主摩擦交给对应轴卡（见步骤 4）。

**完成标准**：四格都过了一遍、给出一条主摩擦、并指明下一步走哪张卡。

### 步骤

**第 1 步 · 归因纠偏（f08，前置步）**
- 动作：先检查用户的说法是不是把「不动」归成内部原因（「他就是不配合」/「我就是懒、没毅力」）。若是，改问情境：当时的时间、地点、启动成本、别人怎么做的。
- 完成标准：能说出至少一个情境侧的摩擦线索，而不是停在「懒 / 冷漠」。
- 判停：若线索全指向**技能不足或资源缺失**（不是摩擦），转福格 `make-it-easy`，本卡停。

**第 2 步 · 四格逐问**
- 动作：逐格过四问，每格留一句依据——
  ① 变化程度：这个改变是对现状动大手术，还是只做小调整？（惯性强弱）
  ② 实施成本：要付出多少体力 / 精力？实现路径是否模糊？（惰性强弱）
  ③ 威胁感：它威胁到了什么（功能 / 社会 / 情感层面的需要）？（情感强弱）
  ④ 是否在施压：这件事是不是被「逼」着做的（命令、死线、惩罚、被排除在设计外）？（抵触强弱）
- 完成标准：四格每格都有「命中 / 未命中 + 一句依据」。

**第 3 步 · 指认主摩擦**
- 动作：从命中格里挑一个**最能解释当下为什么不动**的，作为主摩擦。
- 完成标准：给出唯一一条主摩擦，并说明「为什么是它先」。
- 判停：**若四格同时命中，原书未给优先级（不得编）**——如实标明「作者未给四种摩擦同时命中时的优先级」，允许并列，选一条「最能解释现在的不动」的先行项，或直接进第 4 步做多轴分流。

**第 4 步 · 分流**
- 动作：按主摩擦指路——惯性 → familiarization / referent-management；惰性 → friction-effort-diagnosis；情感 → negative-emotion-source；抵触 → resistance-self-persuasion。若线索指向「跟我是谁冲突」，额外提示转身份层（原子习惯）。
- 完成标准：产出一条明确的分流去向。

## B — Boundary

### 不要用（反场景）
- 要把一个还不存在的习惯建起来 / 拆多小 → 福格 `tiny-habit-design`。
- **提示 / 能力 / 动机三样还没排过** → 先走福格 `bmap-diagnosis`。本卡是**第二遍诊断**：B=MAP 三要素都齐了、行为仍然不动，才轮到四要素（惯性 / 惰性 / 情感 / 抵触）。
- 只要降低难度 / 加提示 → 福格 `make-it-easy` / `prompt-types`。
- 要**一张填好的四格表** → friction-report-worksheet（同一契约的交付变体）。
- 冲突落在**身份层**（「这不像我 / 我跟你不是一类人」）→ 本书四要素不含身份，转原子习惯的身份层能力。
- 纯情绪管理 / 心理治疗 → 转介；本书不是临床工具。
- 对外说服术 / 销售话术 → 本书不做。

### 作者警告过的失败模式（反例素材）
- **默认只加推力、不减摩擦**（x01）：跟着直觉「再加点好处、再多讲一遍价值」，反而在无意中给创新添了阻力；价值再高也不减摩擦——给子弹镀金能抬高它的价值，却减不掉它受的阻力。
- **归因偏差掩盖摩擦**（f08）：把不行动归成对方的内部特质（冷漠 / 懒），于是继续加推力；摩擦还有「双重掩盖」——既藏在表象下，当事人自己也说不清（f08 说明）。
- **用命令式施压招抵触**（f47 / p86）：施压本身就是一条摩擦，越是「必须 / 绝对不许」，反弹越强。

### 作者盲点与待核查（写进卡、不许假装有）
- **本条不含身份层（硬标识）**：作者自认四要素有漏项——除了这四种摩擦，还牵涉到身份的问题（x64）。身份类摩擦**不在**四要素类型学内；遇到「这事跟我是谁冲突」，本卡**不硬塞进四格**，明标越界并转身份层（原子习惯），**不替作者收口**。
- **四摩擦同时命中时的优先级作者未给（硬标识）**：f02 的 `notes` 确认四者并列、作者未给优先级，**卡里不得编一个先后顺序**。
- **四摩擦的英文原词不在中文正文（硬标识）**：Inertia / Effort / Emotion / Reactance 是从**英文原著侧**核得的，**中文正文里并没有这四个英文词**（f02 notes）；「心理摩擦力 / 摩擦」（`friction`）是四摩擦的**统称**，**不是第五个要素**。转述时不得说成「中文正文里的英文原词」。
- **全书无出处体系**：凡引数字一律「原文未给出处」。f08 的课堂实验（直接给文件约 70% 给反馈 vs 需点链接约 40%）**原文未给出处**。
- **证据档四档具名**：f02 ＝ `author_firsthand`（本书自有中心框架）；f08 ＝ `cited_third_party`（基本归因错误是点名引用的心理学概念）。**不写 `strong` / `medium` / `weak`**。
- **全书无一处「自己对自己改变」的案例或声明**：原书主语一律是「你的受众 / 人们 / 球员 / 选民」（x65）；本卡 A1 的自我场景是**明确标记的合成演练**，属**机制同源推断**，不是作者原意。

### 相邻易混
- fuel-friction-framing（方向前导 / 燃料侧总纲）：讲「别只加推力」；本卡出四格并指认主摩擦。
- friction-report-worksheet（同一契约的填表交付版）：本卡给判断，它给一张表。
- friction-effort-diagnosis / negative-emotion-source / resistance-self-persuasion（三轴卡）：本卡指认后分流，具体定位与出招在它们。
- 福格 `bmap-diagnosis`（跨书对比）：行为三前提 vs 阻碍四来源。

## 相关能力

- **fuel-friction-framing**（对比）：它是「推力 vs 摩擦力」的方向前导（别只加推力）；本卡是四格诊断的落点。先有方向感，再落到四格。
- **friction-report-worksheet**（组合）：同一「四摩擦诊断」契约；本卡产**判断**（主摩擦 + 分流去向），它产**一张可填的四格表**。
- **friction-effort-diagnosis**（组合）：主摩擦判在**惰性**时的下游——把「不想做」细分成消耗 / 模糊性。
- **negative-emotion-source**（组合）：主摩擦判在**情感**时的下游——挖负情绪来源。
- **resistance-self-persuasion**（组合）：主摩擦判在**抵触**时的下游——把自我命令改造成自我结论。
- **familiarization**（组合）：主摩擦判在**惯性**时的下游之一——把陌生变熟悉（惯性轴无晋级主卡，经来源路由入口访问）。
- **referent-management**（组合）：主摩擦判在**惯性**时的下游之二——参考点管理 / 把唯一死命令扩成多方案（经来源路由入口访问）。
- **福格 bmap-diagnosis**（对比·跨书）：同一「卡在哪」请求的两套记法（福格＝动机 / 能力 / 提示；本卡＝惯性 / 惰性 / 情感 / 抵触），输出不同，**双触发写进近邻负例**。**预判：若四摩擦与福格 B=MAP 分不开，本卡降为能力卡。**

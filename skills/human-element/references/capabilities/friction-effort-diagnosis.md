# 惰性诊断：消耗还是模糊（Effort 二维 · 摩擦类型学）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 5 章与第 6 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f18`、`f22`、`f27`），不随公开版分发。

## I — Interpretation

本卡是「Effort／惰性」这根轴的**定位总入口**：把「我坐下来就是不动」这个笼统的抱怨，拆成**两个可分辨的维度**，从而不再用错药。

1. **消耗（投入的能量）**——做这件事要花多少力气。写 50 页比写 5 页更费；把垫子从柜子里翻出来再铺开，比直接躺上去更费。消耗高，表现为「我知道怎么做，就是嫌麻烦／太累／步骤太多」。
2. **模糊性（知不知道怎么做）**——你**是否清楚怎么实现目标**。不认识路就得自己探路、反复试错、撞「死胡同」。模糊性高，表现为「我想做，但不知道先做哪一步／从哪下手／算不算做对」。

作者的关键判断：**两维要用不同方法治**——模糊性靠「创建路线图」（把事拆成何时／怎么做），消耗靠「流线化行为」（消障碍、找捷径）；而且，围绕任务的困惑往往比实际工作本身更碍事。本卡再加两个**可选零件**：给行为定一个固定时机（机会窗口 f22），以及把自己的流程当产品再设计一遍（UX 四原则 f27：减步骤／去选项／加进度反馈）。

一句话：**先判「是嫌费力，还是不知道怎么做」，再选药。**

**分工说明（写死）**：本书只做**定位**（给你消耗／模糊性这把尺子与摩擦类型学），**出招（具体降难度、拆小步、让行为变简单）走福格 `make-it-easy`**。本书不抢降难度动作。

## A1 — Application Example

**⚠ 本书全书没有一处「自己对自己改变」的案例或声明，原书主语一律是「你的受众／人们／村民／球员／选民」。** 下列原书案例**均为对外场景**（作者讲的是怎么推动别人）：作者讲销售、球员、选民、村民，不是自对己案例。凡要落到自己身上，只能写成**明确标记的合成演练**，并注明「**机制同源推断**」，不得冒充作者经历。

**主例 · 肯尼亚公共氯气分配器**（c61，原书案例，`nature: third_party`，**对外场景**）

- 输入／问题：肯尼亚西部村民用氯瓶净化水的人很少。作者归因：不是村民不在意，而是净化流程带摩擦——要**等 20 分钟**、要**量准氯量**（消耗＋模糊性并存）。
- 怎么执行：把加氯挪到取水时（公共分配器），一次手柄出准确剂量，并把分配器涂成亮色便于记住。
- 结论／输出：作者交代独立氯瓶组只有约 10% 家庭坚持净水，公共分配器组升至 61%（**原文未给出处**；点名 Michael Kremer 但无文献）。**这是作者的对外干预案例，不是自对己案例。**

**辅例 · 学校审批新课程**（原书假想例，**对外场景**）：作者用它说明同一件事里消耗与模糊并存——消耗是「为获批要做的工作量」，模糊是「审批流程摸不摸得清、该找谁问、拿到的答复是否一致」；他点出，人如果不知道到哪儿取信息，就很难开工。

**合成演练（自对己；原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- 输入／问题：「我想开始写论文，坐下来却总刷手机。」
- 怎么执行（按 f18 二维判）：先问——是**不愿花力气**（消耗），还是**不知道下一步做什么**（模糊性）？本例实测为后者：不知道先写哪一部分，于是用刷手机回避。判为**模糊性**，故不用「逼自己坐更久」（那是治消耗的药），改先列一份到章节的路线图（模糊性走清晰化）。
- 结论／预期输出：主维度＝模糊性；下一步方向＝把「写论文」拆成何时／怎么做的清晰路径。**此为按原书规则可复算的演练，不是作者原案例；机制同源推断，不写成「作者要你对自己这么用」。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 坐下来面对某件事就是不动，分不清是「懒得花力气」还是「不知道从哪下手」。
- 事情太多、做不完，想找出到底卡在哪一块，好对症下药。
- 已经知道要做，却「嫌麻烦／步骤太多／太累」——想确认这是不是消耗问题。
- 想做却「不知道先做哪一步／算不算做对」——想确认这是不是模糊性问题。
- 想把自己的流程当产品再设计一遍，但先不确定该减负担还是该把路径讲清楚（定位后再改）。

**2. 语言信号（中英双写）**

- 中文：惰性／努力／消耗／模糊性／懒得花力气／不知道从哪下手／太麻烦／步骤太多／做不完／坐下来就是不动／摩擦类型。
- English: effort / inertia / friction diagnosis / consumption vs ambiguity / I can't get started / too much friction / don't know where to start / streamline my process.

**3. 与相邻能力怎么区分**

- **`roadmap-clarity`**（同轴·模糊性侧）：本卡只**判维度**；那条**出招**把「多做 X」改成「何时／何地／怎么做」。
- **`streamlining`**（同轴·消耗侧）：本卡判到消耗后**指方向**；那条**盘出最摩擦的那一步**（步骤盘点、搬走旁边的障碍、找捷径）。
- **`effort-troubleshooting`**（同轴·排障／观察端）：本卡是**静态二维定位**；那条给两问排障与「欲望之路」自我观察。
- **福格 `make-it-easy`**（跨书·见分工说明）：本书**定位**，福格**降难度**；本书不抢「把行为变简单」的动作。
- **福格 `prompt-types`／原子执行意图**：那是「何时做／靠什么触发」，本卡不处理时点（时点由 roadmap-clarity 承接，且该项让位）。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「我就是**没动力／不想做**，提不起劲」→ 不触发本卡，走福格动机诊断（`motivation-diagnosis`）；本卡前提是「想做但卡住」。
- 「帮我把这件事**变简单／拆到最小步**」→ 不触发本卡，走福格 `make-it-easy`（出招侧）。
- 「我**总忘了做**，不是不想」→ 不触发本卡，走 roadmap-clarity 的提醒／触发面（撞福格 `prompt-types`）。
- 「这件事到底**卡在哪一类阻力**（惯性／惰性／情感／抵触）」→ 走 four-frictions-diagnosis，本卡只接已聚焦在惰性轴的情形。
- 纯信息查询（「Effort 二维是什么」）→ 走来源路由入口 human-element。

## E — Execution

### 输入契约

- **必需**：① 一件「坐下来就卡住／推不动」的**具体事**；② 它的**卡住表现**（一句话：是「嫌费力」还是「不知道怎么做」，或说不清）。
- **可选**：该行为当前有没有固定时机（用于第 3 步）；目前采用的流程／步骤清单（用于第 4 步）。
- **缺**①或②时先问那件事和卡住的样子，**不许静默假设**维度。
- **适用条件**：惰性轴内的**定位**；纯「没动力」不适用（见 B 段分流）。

### 输出契约

**产出类型**：`diagnosis` ＋ `patch`（先给主维度定位，再给一条对应方向的补丁）

- **诊断输出**：主维度判断（**消耗**／**模糊性**／两者兼有及孰主）＋ 一句依据。
- **补丁输出**：对应下一步方向（模糊 → 清晰化／路线图；消耗 → 流线化／减步骤）；可选：一个固定时机（f22）、一份流程再设计（f27）。
- **完成标准**：指对维度、选对药（不拿治消耗的药去治模糊性），且给出可执行的下一步方向。

### 步骤

1. **分辨主维度**（f18）：把它读成两个问句——「做它要付出多少**能量**？」（消耗）／「我**知不知道**怎么做？」（模糊性）。用自陈＋具体事实（要不要翻箱倒柜？有没有明确的下一步？）判孰主。
   - 完成标准：给出主维度（消耗／模糊性／兼有＋孰主）。
   - 判停点：若判定为「纯没动力／不想做」→ 停，按 B 段分流（走福格动机诊断）。
2. **选药**（f18）：模糊性 → 清晰化／把事拆成「何时／怎么做」（转 roadmap-clarity）；消耗 → 转 streamlining **盘出最摩擦的那一步**（要具体降难度动作仍走福格 `make-it-easy`）。
   - 完成标准：主维度与药**方向一致**（模糊配路线图、消耗配流线化）。
   - 判停点：若要的是**具体降难度动作**（拆小步、让行为变简单）→ 转福格 `make-it-easy`，本卡不代做。
3. **（可选）定时机**（f22 机会窗口）：给该行为指定一个固定时间段（「每天早饭后 10 分钟」式），让行为有可发生的时间场合。
   - 完成标准：得到一条明确的时间窗（若用户不问时机，可跳过）。
4. **（可选）流程再设计**（f27）：把用户自己的流程当产品过一遍四条——**减步骤**（步骤越多越易跳票）／**去选项**（选择越多决策越费力）／**加进度反馈**（终点不明确时给进度）／**简单设计**（别堆功能）。
   - 完成标准：至少落一条可照做的改动，且能指出改的是哪条原则。
5. **边界自检（必做）**：确认该事不落在「**太省力也不行**」的 4 种情形里（见 B 段）；若落在，明标「原书未给判据」，不硬套降本。
   - 完成标准：卡内／答复明确标注该边界是否命中。

### 失败处理与回流

- 第 1 步判不出维度 → 退回让用户举一个具体障碍（要不要费力？知不知道下一步？），别硬猜。
- 第 1 步判为「没动力」→ 按 B 段分流福格动机诊断。
- 第 2 步用户要的其实是「变简单」→ 转福格 `make-it-easy`。
- 落在「太省力也不行」情形 → 见 B 段，停并不假装有判据。

## B — Boundary

### 不要用（反场景）

- **纯「没动力／不想做」**（提不起劲）→ 走福格动机诊断（`motivation-diagnosis`），本卡前提是「想做但卡住」。
- **要具体降难度／拆小步／让行为变简单** → 走福格 `make-it-easy`（出招侧）。
- **「总忘了做」的非模糊性遗忘** → 走 roadmap-clarity／福格 `prompt-types`。
- **要判「卡在哪一类阻力」（惯性／惰性／情感／抵触）** → 走 four-frictions-diagnosis。
- **「这事跟我是谁冲突」** → 身份层（本书四要素不含身份，见 four-frictions-diagnosis）。
- 纯信息查询 → 来源路由入口 human-element。
- **真实产品／界面的 UX 设计（对外商业）** → 本卡只借 UX 原则做自我流程再设计，不做对外 UI 设计。

### 分工说明（**写死，编译 Socket 时必须落进边界**）

**惰性轴：定位走本书（消耗／模糊性二维、摩擦类型学），出招走福格 `make-it-easy`（降难度）。** 本书与福格 `make-it-easy`／福格 `prompt-types`／福格 `anchor-matching`、原子执行力意图与环境摩擦侧、以及 **Nudge 的 sludge（只作术语与原则来源）** 撞在同一片地：f18 f19 f20 f21 f22 f23 f28 p53 全在这片地上。裁定：**本书只给类型学与边界，不抢降难度动作**；粒度不同（类型学 vs 干预阶梯），不构成替代。双触发写进近邻负例。

### 作者警告过的失败模式（反例素材）

- **「忽略努力的盲点」**（p40）：作者自研 1/5/20 问题问卷实验（实际同意率 84%/56%/11%，对照组预测 59%/32%，**原文未给出处**）——人**明知努力重要却系统性低估**其幅度，规划时会把成本算得太低。
- **越笃信「只要想做就能做到」，越会忽视会坏事的摩擦**（x26）：对行动信念越强，越不排查障碍、越没预案（原文未给出处）。
- **「太省力也不行」的 4 种情形**（x58/x59 ＋ p43/p44/p45/p46）：①把体验本身当目的（性、电子游戏）；②拿努力当美德信号（志愿时长）；③努力与质量挂钩（画作）；④拿努力解闷。此四情形下「**让努力变得值得**」比「降低努力」更有效。**⚠ 原书对这四类情形没有给任何判定尺子**——用时须**明标为本书边界、非判据**，不得硬套「降本」。
- **把「不主动」当态度问题**（x25）：拒绝提供路径，行为因模糊而持续不发生（原书说，路径不清楚时行为就很少发生）。

### 作者盲点与待核查

- **全书无一处「自己对自己改变」的案例或声明**（原书主语一律是受众／人们／村民／球员／选民）：本卡的二维是**机制同源推断**到自对己，不是作者给的自我场景。
- **「太省力也不行」无判据**：原书只列 4 情形、**未给**何时算「太省力」的尺子——**不许假装有**；归本卡 Boundary，**不单开卡**。
- **数字未给出处**：f22 的「乳房自检 70% 女性称遗忘」、Atlassian「联邦快递日」每季度 24 小时均**原文未给出处**。
- **模型边界**：本书自称与福格 ability「同轴不同粒度」，但**粒度差是否足以避免双触发，作者未论证**。

### 相邻易混

- roadmap-clarity：本卡判「是模糊性」／那条出招「把事拆成何时／怎么做」。
- streamlining：本卡判「是消耗」／那条**定位到哪一步**并搬走旁边的障碍。
- effort-troubleshooting：本卡是静态二维定位／那条给两问排障与自我观察。
- 福格 `make-it-easy`：本书定位（类型学）／它出招（降难度）。

## 相关能力

- **four-frictions-diagnosis**（组合）：先由它判主摩擦；惰性轴落到本卡，本卡做消耗 / 模糊性的**静态二维定位**。
- **roadmap-clarity**（组合）：本卡判到**模糊性**后转它出招（把「多做 X」改成「何时 / 何地 / 怎么做」）。

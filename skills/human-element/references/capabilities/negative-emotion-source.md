# 情感摩擦诊断：找出负情绪来源（连问为什么 / 三类提问 / JTBD 定名 / 三种补救）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 7 章与第 8 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f29`、`f31`、`f32`、`f34`），不随公开版分发。

## I — Interpretation

本卡是**情感轴（Emotion，四摩擦之一）的诊断方法学**：当一件事「你/你的受众明明知道该做，却莫名不想做、隐隐不安」时，把那股**非预期的负面情绪**当作一种可定位的摩擦来查，而不是当成「懒」「不自律」或「嘴上说没事」。

情感摩擦的核心判断是：**阻力不来自行为多难，而来自这件事触发了某种负面情绪**（焦虑、怀疑、怕做错、怕丢脸、失去感）。本卡给的是**一条找来源、再对因下药的工作流**，四步：

1. **定名威胁面**（f29，JTBD 三价值）——问「这个改变威胁了我/受众的哪一类价值」：功能价值（省时之类）、社会价值（会不会丢面子/影响身份观感）、情感价值（带来的是不是负面感受）。负面情绪往往不是对功能不满，而是劫持了社会/情感价值。
2. **挖真因**（f31，5 个为什么）——对表层理由**连问同一句「为什么」5 次**，一层层剥到根因（如「太贵」→「怕董事会审批煎熬」）。作者说四种摩擦里它**尤其擅长挖情感摩擦**。
3. **换一种问法**（f32，三类提问）——不往下问「为什么」时，改用**三个不同特点的问句**：开放式（不能用一个词答）、探究性（引导多说）、启发性（指出新想法与个人需求/目标的冲突）。
4. **对因补救**（f34，三种补救）——按查到的来源选一味：可试用（先小规模试）、可回退（留反悔余地）、加支持（配一个服务/陪伴元素）。作者强调「要根据潜在原因选择」，**不能乱用**。

一句话：**别对着「太贵/没时间/不感兴趣」这些症状使劲，先挖到负面情绪的来源，再按来源下药。**

**与相近动作划清（见 B 段分流）**：福格 `celebration` 是行为**做完后加正情绪**；原子 `reframe` 是行为**前换说法改感觉**；本书这一步是**找负情绪来源**的诊断 + 减手段——三者不在同一动作位。

## A1 — Application Example

**主例 · 软件销售从「太贵」挖到「怕董事会审批」（f31，作者构造的五轮「为什么」对话示例，nature: hypothetical／worked_example）**

> ⚠ **这是作者讲的销售场景，不是自对己案例**（原书主语一律是「客户／受众」）。本卡把它当**对外场景的机制示范**用，不冒充自对己经历。

- **输入/问题**：客户说「这个软件……对我们来说太贵了」。
- **怎么执行**：连问五次「为什么」——①为什么贵？→②担心时机/投资 →③要董事会批准，上次审批很难熬 →④董事会有人对数据隐私有负面经历 →⑤靠别家公司的推荐信与参考资料才安心。
- **结论/输出**：真因不是价格，而是**「怕董事会审批的挫败感与数据隐私担忧」**（作者称为「一种预期的挫折感」）。
- **原书交代的结果**：挖到真因后，可提供知名组织的客户评价/结果数据，或请第三方做数据隐私审计来消除摩擦（原书交代此后续动作）。

**辅例 · 蛋糕粉与「太省事反而不用心」**（c76，转引，作者自标「据传」）：蛋糕粉上市 25 年不流行，原因不是口感/价格，而是「用蛋糕粉不显得用心」——**情感价值被威胁**。作者建议去掉鸡蛋粉、让用户自己打蛋，恢复亲手感，销量上升。**⚠ 这是对外产品案例；且作者本人用了「据传」二字、同段把 Dichter 误写成「迪克特」，作史实很薄，只能作机制隐喻。**

**辅例 · Tinder 消除「被拒绝」的焦虑**（c77，第三方案例）：Match.com 要建档、搜索、写邮件并冒被拒绝风险；Tinder 用「双向右滑」在受伤前先确认双方兴趣。**对外产品竞争案例，反身价值弱。**

**合成演练 · 早睡卡点（原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- **输入/问题**：「我总说要早睡，但每晚又拖到一点。」
- **怎么执行**：定名威胁面（f29）→ 挖真因（f32 三问，或 f31 连问五次）→ 对因补救（f34）。
- **复算**：开放地问「拖到一点时我在做什么」→ 刷手机；探究地「刷的是什么、为什么不放下」→「白天没有属于自己的时间」；启发性「早睡和哪个需求冲突」→ 与「想要一点属于自己的时间」冲突；据此把「自己的时间」挪到白天，并给自己「先只试两周」的可回退安排。
- **结论/输出**：负情绪来源＝「失去对自己时间的掌控」，被威胁的是情感价值；补救＝可试用 + 留回退。**注意：这是机制同源推断（作者从未写过「对自己用」），完成标准是演练能按原书问句复算，不是「作者背书有效」。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 一件事「该做却莫名不想做」，嘴上给的理由（太贵/没时间/不感兴趣）自己也觉得不像真话。
- 反复卡在同一个点，症状一样而理由每次换：到底是怕失败、怕被评判、还是失去感。
- 知道自己「情绪上过不去」，但说不清到底哪一类情绪、被威胁的是什么。
- 想找一件「怕投入白费 / 怕做错」的事的启动办法，需要先看清焦虑来源再对症。
- 已经反复对自己讲「这件事多重要」却没用，想换一条挖根源的路。

**2. 语言信号（中英双写）**

- 中文：找负情绪来源 / 负面情绪从哪来 / 情感摩擦 / 莫名不想做 / 说不上来的不安 / 表面理由是「没时间太贵不感兴趣」 / 连问为什么 / 挖真因 / 这改变威胁我哪类价值 / 怕做错怕白费。
- English: emotional friction / find the source of the negative emotion / five whys / 5 whys / root cause / JTBD / functional social emotional value / why do I keep avoiding this / I say "no time" but that's not it.

**3. 与相邻能力怎么区分**

- **福格 `celebration`**（对比，**见分流句**）：那条在行为**做完后加即时正向情绪**以固化；本卡在**动手前**找**负**情绪来源。一个是「加正情绪」，一个是「找负情绪来源」，动作位不同。
- **原子 `reframe`**（对比，**见分流句**）：那条在行为**前换一个说法 / 措辞**来改感觉（「不得不」→「我可以」）；本卡不改措辞，而是**先诊断来源**（连问为什么 / 三类提问 / 定名价值面）再**对因下药**。
- **`emotion-diagnosis-checklist`**（同轴卫星，related）：本卡是**诊断主线（含完整工作流）**；那张是第 8 章章末的**清单版 / 另一种观察作法**（评估 2 问 + 方法一/方法二 3 问），是同一工作流的自检与观察变体，不抢本卡入口。
- **`four-frictions-diagnosis`**（总诊断，related）：那条判「卡在哪根摩擦（惯性/惰性/情感/抵触）」；本卡在**已锁定是情感摩擦**后，往里挖来源。
- **`resistance-self-assessment`**（对比·防双触发）：两卡共享「莫名不想做 / 发怵」信号，但**怕的内容说得清**（怕做错 / 怕白忙）→ 本卡（定名价值面 + 对因下一条补救，需要内容才做得了）；**说不清在怕什么、要的是一次把它问出来的访谈** → 那张（抵触自评三问 + 自问自答式深度访谈，正是用来造内容的）。作者未给情感与抵触的划线（x73），此系本书按「手里已有什么」自划。
- **抵触轴各卡**（对比）：情感是「对这件事有负面情绪」，抵触是「反感被推着走 / 被迫改变」；对策不同（清情绪 vs 去压力）——见下方负例与 B 段。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 【vs 福格 `celebration`】「做完之后我想立刻做个庆祝动作来固化习惯」→ 不触发本卡，走 `celebration`（那是加正情绪）。
- 【vs 原子 `reframe`】「帮我把『不得不做』换个说法 / 改改心态就行」→ 不触发本卡，走 `reframe`（那是换措辞改感觉）。
- 【vs four-frictions-diagnosis】「我说不清自己卡在哪根摩擦，帮我先归因」→ 不触发本卡，走 four-frictions-diagnosis（先判轴）。
- 【vs emotion-diagnosis-checklist】「给我一份情感摩擦的自检清单 / 章末那组问题」→ 走同轴清单卡。
- 【vs resistance-self-assessment】「我说不清自己到底在怕什么，帮我把它问出来」→ 不触发本卡，走 `resistance-self-assessment`（那是把内容问出来的访谈）。
- 【vs 抵触轴】「我一被逼着做就反弹、越推越不动」→ 不触发本卡，走抵触轴（去压力、把命令改提问/实验）。
- 【vs 路由入口】「情感摩擦是什么 / 讲讲这本书的情感轴」→ 走来源路由入口 human-element。
- **涉临床**：抑郁 / 焦虑症 / 进食障碍等严重心理病理、或成瘾戒断 → 本卡不跑。

**分流句（本卡 ↔ 福格 `celebration` ↔ 原子 `reframe`）**：行为**做完后加正情绪** → `celebration`；行为**前换说法改感觉** → `reframe`；**先找负情绪来源、再按来源下药** → 本卡。三者不在同一动作位，**不得互抢**。

## E — Execution

### 输入契约

- **必需**：① 一件「想做却卡住 / 莫名不想做」的具体事，**或** 一句当事人给出的表层理由（「太贵」「没时间」「不感兴趣」「怕白费」）。② 面向自己还是面向某个受众（原书主语句式是受众；自用须改主语，见 B 段）。
- **可选**：当事人对「被威胁的价值类型」的猜测、近期同类症状的重复记录。
- **缺①时先问是**哪件事 / 哪句话；**不许静默替用户猜「真因」**。若请求其实是「加正情绪 / 改措辞 / 先判轴 / 要清单」→ 按 B 段分流，不跑本流程。

### 输出契约

**产出类型**：`diagnosis`

一份**情感摩擦诊断结论**，三段式（`reviews.md` 一条）：
1. **负情绪来源**（一句，用「挖真因」得到；链到具体问句：哪个「为什么」或哪类提问挖出的）；
2. **被威胁的价值类型**（功能 / 社会 / 情感，选一或数项，来自 f29）；
3. **一条补救动作**（可试用 / 可回退 / 加支持，来自 f34，须与来源对应，**不罗列全部三味**）。

**完成标准**：来源不是表层理由（如「太贵」「没时间」）；价值类型有明示；补救与来源对得上；自评「照这条补救做，那股情绪会小一些」。

### 步骤

1. **分流**：先确认是「找负情绪来源」才跑本卡（否则按 B 段改走 `celebration` / `reframe` / four-frictions-diagnosis / emotion-diagnosis-checklist / 抵触轴）。
   - 完成标准：明确本卡是正确入口。
2. **定名威胁面**（f29）：问「这个改变威胁了我/受众的哪一类价值」——功能 / 社会 / 情感。
   - 完成标准：指名 ≥1 类被威胁的价值；若三类都答「没有」，多半不是情感摩擦，回第 1 步或转 four-frictions-diagnosis。
3. **挖真因**（二选一，**判停点**）：
   - **f31 5 个为什么**：对表层理由连问**同一句**「为什么」直到根因浮现（作者示范为 5 次）。
   - **f32 三类提问**：不往下问「为什么」时，依次用开放式 → 探究性 → 启发性三个**不同**特点的问句。
   - 完成标准：得到一个**情感层**根因（如「怕再失败」「失去掌控」「怕被评判」），且它不等于开头那句表层理由。
   - **判停**：若连问后落到的是「不知道该怎么做」→ 那是惰性轴的模糊性，转 roadmap-clarity / friction-effort-diagnosis；若落到的是「被要求这么做、反感」→ 转抵触轴。
4. **对因补救**（f34）：按来源选**一味**——怕做错 → 可回退（留反悔余地）；怕首次尝试 → 可试用（先小规模试）；怕孤军/失误无人管 → 加支持（配服务/陪伴）。
   - 完成标准：补救与第 2、3 步的来源对应，且只给对症那一味（作者要求「根据潜在原因选择」）。
5. **交回落地（可选）**：把补救写进已有计划（落 `patch`）或交给对应执行卡。
   - 完成标准：指明交给哪条线落地。

### 失败处理与回流

- 第 3 步挖不到情感层根因、越挖越像「怎么做不清楚」或「被逼着做」→ 按判停分流，**不硬贴情感标签**。
- 第 4 步补救做完情绪仍强、且涉及严重心理病理 → 见 B 段，停并提示转介专业人士。

## B — Boundary

### 不要用（反场景）

- 要在**做完后加即时正向情绪**（固化）→ 福格 `celebration`。
- 要在**行为前换措辞 / 改心态** → 原子 `reframe`。
- 还没判「卡在哪根摩擦」→ four-frictions-diagnosis。
- 只要**情感摩擦的自检清单 / 章末那组问题**→ emotion-diagnosis-checklist。
- 真正的问题是「**被推着走**、越推越反弹」→ 抵触轴（去压力、命令改提问/实验）。
- 负面情绪已经**越出「这件事」、变成对自我价值的怀疑**（「我是不是就是这种人」「做不好说明我不行」）→ 原子 `identity-design`（身份层）。本卡只管这件事带来的情绪（烦、累、怕），一旦指向「我是什么人」就走身份层。
- 纯信息查询（「情感摩擦 / 情感轴是什么」）→ 来源路由入口 human-element。
- **临床**：抑郁 / 焦虑症 / 进食障碍等严重心理病理、成瘾戒断 → 不跑本流程。

### 作者警告过的失败模式（反例素材）

- **把症状当真因**（x34）：客户「焦虑」表现为「不感兴趣」、同事「愤怒」表现为「冷漠」；成本异议常是结束对话的最快方式，是全面怀疑的包装，不是根本原因。**若只回预算/价值/付款计划，就打偏了。**
- **双重掩盖**（x12）：摩擦既藏在表象下，**当事人自己也说不清**。直接问一句「你有什么顾虑」得到的答案很可能不是真因 → 所以要**连问/换着问**，不能问一句就收工。
- **同理心剧场**（x35）：用表演式共情（「我理解你」）替代真实理解，反而制造新摩擦；对照做法是先问「你需要什么帮助」。
- **越推越打偏**：负面情绪被隐藏为可接受的表面理由（x34 warning_signs：对方给的理由过于笼统「太贵、没时间」、同类症状反复、解决表层后问题照旧）——出现这些信号就要往下挖，而不是加推力。

### 作者盲点与待核查（不许假装有）

- **全书无一处「自己对自己改变」的案例或声明**：原书主语一律是「受众 / 人们 / 客户 / 选民」，只有一处偏读者自己的计划。本卡 A1 已把原书案例标为「对外场景」，自我场景一律写成**明确标记的合成演练 + 机制同源推断**；**不得写成「作者要你对自己这么用」**。
- **全书无出处体系**：本卡所引条目（f31/f29/f32/f34）原文均**未给具体数字**，无「原文未给出处」的数字须标；作者示范的 5 次「为什么」是做法，不是统计结论。
- **情感与抵触没划线**（x73）：第 7 章讲情感摩擦时直接说受众会有截然相反的情绪反应，把抵制与负面情绪都算进情感摩擦，**而这正是「抵触」的地盘**。作者**未收口**；本卡只在「非预期负面情绪」的本书定位内出招，遇「反感被推着走」转抵触轴，**不替作者把两轴合并或裁定**。
- **情感摩擦定义域被撑到「身份 / 价值威胁」**（x74；对应清单卡 p67 的 Q2）：作者把情感摩擦扩问为是否伤及人们更广泛的需求，又用老年人一连串「失去」举例，已越出「情绪」进入**身份与价值威胁**。**本卡不把它塞进情感摩擦**（p67 的 Q2 不归本卡）；自我场景下这块很可能该归**身份层**，用时须**明标越界、不替作者收口**。
- **情感摩擦没有「何时是情感、何时是抵触/惰性」的判据**：作者只给了「尤其擅长挖情感摩擦」，**未给**判别清单；本卡按第 3 步判停分流，**不假装存在判据**。

### 相邻易混

- 福格 `celebration`：**做完后加正情绪**（它）vs **做前找负情绪来源**（本卡）。
- 原子 `reframe`：**换措辞改感觉**（它）vs **改措辞前先诊断来源、再对因下药**（本卡）。
- emotion-diagnosis-checklist：诊断主线 / 完整工作流（本卡）vs 章末清单与观察变体（它）。
- four-frictions-diagnosis：判「卡在哪根摩擦」（它）vs 已锁定情感后挖来源（本卡）。
- resistance-self-assessment：怕的内容说得清 → 定名价值 + 对因下药（本卡）vs 说不清、要一次把它问出来的访谈（它）。
- 抵触轴：对这件事有负面情绪（本卡）vs 反感被推着走 / 被迫（抵触轴）。

## 相关能力

- **four-frictions-diagnosis**（组合）：先由总诊断判轴；主摩擦判在情感时进本卡，本卡往里挖负情绪来源。
- **emotion-diagnosis-checklist**（组合）：本卡是**主线诊断**（连问 5 个为什么 / 三类提问 / 对因补救），它是**章末清单版 + 「观察行为而非说法」变体**（`p67` `p69` `p70`）。
- **friction-effort-diagnosis**（对比·防双触发）：本卡挖到「不知道该怎么做」时转惰性轴；两轴（情感 vs 惰性）在「莫名不想做」处易混，互设近邻负例。
- **resistance-self-persuasion**（对比·防双触发）：本卡找「对这件事的负面情绪来源」，它处理「反感被推着走」；作者未给情感与抵触的划线（x73），挖到「被逼着做」转抵触轴，二者互设近邻负例。
- **resistance-self-assessment**（对比·防双触发）：**怕的内容说得清**（怕做错 / 怕白忙）→ 本卡定名价值、对因下药；**说不清在怕什么、要一次把它问出来的访谈** → 它。两者共享「莫名不想做 / 发怵」信号，按「手里已有什么内容」分界，互设近邻负例。
- **福格 celebration**（对比·跨书）：本卡在**动手前**找**负**情绪来源；福格在**做完后加正情绪**（固化）——一个「找负来源」，一个「加正情绪」，动作位不同。
- **原子 reframe**（对比·跨书）：本卡先**诊断来源**再对因下药；原子在**行为前换说法 / 措辞**改感觉。改措辞前先诊断走本卡。

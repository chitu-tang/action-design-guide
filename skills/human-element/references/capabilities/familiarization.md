# 把陌生变熟悉（惯性轴的熟悉化 · 自我场景 4 招）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 4 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f10`、`f11`、`f15`、`p33`），不随公开版分发。

## I — Interpretation

本卡处理**惯性摩擦**：新事物之所以被拒，常不是因为不好，而是因为**陌生**——人天生偏爱已知、回避未知。惯性摩擦最大的两种情况：①改变是对现状的**重大突破**；②**没时间适应**。本卡的思路是**先把陌生变熟悉，再要求决定**。

把「陌生」变熟悉的做法，自我场景下保留 4 招（原书 5 招里删掉「借他人信誉」的那一招）：

1. **重复 / 播种想法**（f10 技巧 1）——在被要求承诺之前，先让这个想法**频繁出现**，别藏到「完善了」再宣布；重复会让它更有说服力（作者引真相错觉效应）。
2. **从小处逐渐渗透**（f10 技巧 2 + f11）——重大改变从最小一步起步（机制＝渐进式暴露疗法：对蛇恐惧者从隔镜看到放膝上，数小时即可适应）。
3. **贴既有原型**（f10 技巧 4）——让新做法**尽量像已有的东西**（合规原型更易被接受）；先出「普通的 Model S」，成熟后再打破常规。
4. **用熟悉的东西做类比**（f10 技巧 5）——把新事物对照已知领域（乔布斯把文件/文件夹/桌面搬进电脑）。

再配两张自检清单：**评估惯性摩擦 3 问**（f15：是重大突破还是微调 / 有没有时间适应 / 是渐进还是一步到位）与**「帮助人们适应改变」7 问**（p33，自我场景版删 Q5/Q6 剩 5 问）。

**分流（见 B 段）**：福格 `anchor-matching` 是**时间上的挂钩**、原子 `environment-design` 是**让线索显眼**；本书这一面是**感知 / 语义上的熟悉化**（怎么把陌生感降下来），机制不同——本卡只保留「熟悉感怎么建立」这一面，**不抢**前两本的做法。

## A1 — Application Example

> ⚠ **原书未提供「自己对自己改变」的案例**；以下原书案例均为**对外场景**，自我场景一律写成**明确标记的合成演练 + 机制同源推断**。

**辅例 · 洛兰的作业截止日实验**（c33，作者自研实验，**原文未给出处**）：推迟到期日的选项，周二班说完即投，约 **30%** 反对；周三班说完隔 3 小时再投，只有 **5%** 反对——多出来的熟悉时间降低了反对。**对外（学生群体）场景；数字原文未给出处。**

**辅例 · 渐进式暴露疗法（蛇恐惧）**（引用第三方临床做法）：从隔着单面镜看蛇 → 站门口 → 坐近 → 放膝上，数小时之内即可缓解严重的恐蛇。**这是临床/对外场景，作者用它支撑「从小处渗透」。**

**辅例 · 特斯拉 Model S 的「熟悉外观」**（c38）：首发款刻意保持普通汽车外观，打破常规的车型留到品牌成熟后再出。**对外商业案例。**

**辅例 · 乔布斯用「文件/文件夹/桌面」做类比**（c39，转引自约翰·波拉克《创新的本能》）：用实体办公室类比虚拟办公室，让大众接受个人电脑。**对外商业案例；是本书唯三可核线索之一（有书名）。**

**合成演练 · 养成「每天写 300 字」（原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- **输入/问题**：「我想让自己养成每天写 300 字的习惯，可一直没动。」
- **怎么执行**：按自我版 4 招（删掉「找熟人代言」）把这件事变熟悉。
- **复算**：播种（把「每天写 300 字」写便签贴屏幕边，天天见）→ 从最小一步（先写 50 字）→ 贴原型（接在既有「早上喝咖啡」之后）→ 类比（「像刷牙一样，固定时段做」）。
- **结论/输出**：新做法进入日常、不再陌生。**注意：这是机制同源推断，作者从未写过「对自己这么用」；完成标准是演练能按原书规则复算。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 决心开始一个新做法，可它太陌生，一上来就迈不动。
- 想换掉旧习惯/旧流程，但新的东西「不像自己会做的」，本能地退回去。
- 重大改变总想一步到位，结果被陌生感劝退。
- 想给自己一个缓冲：先接触、先适应、再真做。
- 已经知道「陌生」是阻力源，来要「怎么把新做法变熟悉」的做法。

**2. 语言信号（中英双写）**

- 中文：陌生 / 不熟悉 / 太新了 / 迈不动 / 想先适应一下 / 一步步来 / 从小处开始 / 先试试水 / 找个熟悉的类比 / 让它像老朋友一样 / 惯性摩擦 / 熟悉化。
- English: unfamiliar / too new / ease into it / build familiarity / start small / get used to it / repeated exposure / familiar analogy / inertia friction / make it feel familiar.

**3. 与相邻能力怎么区分**

- **福格 `anchor-matching`**（跨书对比，**见分工说明**）：那是把新行为**挂到已有的时间/情境锚点上**（时间挂钩），解决「什么时候做」；本卡是**降低陌生感**（反复接触、从小渗透、贴原型、类比），解决「太陌生不敢开始」。
- **原子 `environment-design`**（跨书对比）：那是让**线索显眼**、把提示放到眼前；本卡是让**内容本身变熟悉**——机制不同。
- **`referent-management`**（同轴 sibling，related）：那是**参考点管理 / 多选项**（把唯一死命令扩成多方案）；本卡是**熟悉化**（把陌生变熟悉）。惯性轴两个侧面，产物不同。
- **`friction-effort-diagnosis`**（惰性轴对比）：那是「消耗 / 模糊性」太难；本卡是「陌生 / 不确定」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 【vs 福格 `anchor-matching`】「帮我给新习惯找个固定时间/锚点」→ 不触发本卡，走 `anchor-matching`。
- 【vs 原子 `environment-design`】「帮我把提示弄得显眼一点」→ 不触发本卡，走 `environment-design`。
- 【vs referent-management】「别只给我一条死命令，给我几个都能接受的方案」→ 走 referent-management。
- 【vs friction-effort-diagnosis】「这件事步骤太多/太模糊所以做不动」→ 走惰性轴诊断。
- 【vs 抵触轴】「我一被要求做就反弹」→ 走抵触轴。
- 【vs 路由入口】「惯性摩擦是什么 / 讲讲这本书的惯性轴」→ 走来源路由入口 human-element。

**分工说明（本卡 ↔ 福格 `anchor-matching` ↔ 原子 `environment-design`）**：**降低陌生感（反复接触 / 从小渗透 / 贴原型 / 类比）** → 本卡；**把行为挂到时间/情境锚点** → `anchor-matching`；**让线索显眼** → `environment-design`。三者机制不同，本卡只保留「熟悉感怎么建立」这一面。

## E — Execution

### 输入契约

- **必需**：一个**新做法 / 新改变**，且当事人感到它「陌生、不像自己会做的」。
- **可选**：已有的日常动作（用于「贴原型 / 类比」）、可安排的接触频率与时间。
- **缺「新做法」时先问**是哪件事；**不许静默替用户挑「熟悉原型」**。若请求其实是「找时间锚点 / 让线索显眼 / 扩多方案」→ 按 B 段分流。

### 输出契约

**产出类型**：`patch`（给已有计划补「熟悉化」零件）

一份**熟悉化方案**，含：
1. **自我版 4 招**里选用的动作（播种怎么播 / 最小一步是什么 / 贴哪个既有原型 / 用什么类比）；
2. **一组适配动作**（f15/p33 清单，自我版删 Q5/Q6）：是否重大突破→要不要拆步、有没有留适应时间、是渐进还是一步到位。

**完成标准**：给出可照做的熟悉化动作（每招能落到具体动作），且自评「这件事没那么陌生、能开工」。

### 步骤

1. **先量惯性摩擦**（f15）：Q1 对现状是重大突破还是微调；Q2 有没有留适应时间；Q3 是一步到位还是渐进。**判停**：若三问指向「摩擦很大」，先走第 2 步的「拆步 / 播种」。
   - 完成标准：得到摩擦大小判断与节奏决定。
2. **选自我版 4 招落地**（f10 改后 4 招 + f11）：①播种/重复；②最小一步（渐进暴露）；③贴既有原型；④熟悉类比。**不得使用被剔的「找熟人代言」（见 B 段）。**
   - 完成标准：产出一组具体动作（各招有明确落法）。
3. **过一遍适应清单**（p33 自我版 5 问）：延长「了解→决定」的时间 / 提高接触频率 / 渐进而非颠覆 / 与已有事物相似 / 一个熟悉类比。**跳过 Q5/Q6**。
   - 完成标准：5 问各有答案，遗漏项补上动作。
4. **交回落地（可选）**：把熟悉化动作写进已有计划（`patch`）。
   - 完成标准：指明写进哪个计划的哪个环节。

### 失败处理与回流

- 第 1 步若发现真正的卡点是「太难/太啰嗦」→ 转惰性轴（friction-effort-diagnosis / streamlining）。
- 若发现卡点是「被要求做、反感」→ 转抵触轴。
- 若发现卡点是「找不到何时做的提示」→ 转福格 `anchor-matching` / `prompt-types` 或原子 `cue-design`。

## B — Boundary

### 不要用（反场景）

- 要找**时间锚点 / 触发时机** → 福格 `anchor-matching` / `prompt-types`。
- 要**让线索显眼** → 原子 `environment-design`。
- 要**把单死命令扩成多方案** → referent-management。
- 卡点是「太难 / 太模糊」 → 惰性轴（friction-effort-diagnosis / roadmap-clarity / streamlining）。
- 卡点是「反感被推着走」 → 抵触轴。
- 纯信息查询（「惯性摩擦是什么」）→ 来源路由入口 human-element。

### 作者警告过的失败模式（反例素材）

- **领导者把想法藏到「准备好」才公布**（x17）：公布之时往往就是要人表态之时，没给适应时间；应对是提前「播种想法」。**自我版：别等「想清楚了」才启动，否则第一天就要自己立刻切换。**
- **一次性抛出完全陌生的方案并要求当场决定**：触发最大惯性摩擦（原书点的两种最大情况之一）。
- **忽略「熟悉需要时间与机会」**：原书反复强调重复需要时间；把改变做成「一步到位」是常见错误。

### 作者盲点与待核查（不许假装有）

- **文本残损，逐字引用须避开**：原书某处排版残损——一处是与上文脱节的编者注，另一处的句子在中途被图版占位截断，直到后文才接回（x71）。**本卡不在这段取任何引文，也禁止把断裂两侧拼成一句。**
- **数字原文未给出处**：洛兰截止日实验的 **30%/5%**、镜像掉笔的「约 **3 倍**」原文**均未给出处**；不得当已证实的统计结论。（镜像/代言人那条已随技法 3 剔除，仅作剔因说明。）
- **全书无一处「自己对自己改变」的案例或声明**：原书主语一律是「你的受众 / 人们 / 学生」。本卡 A1 已把原书案例标为**对外场景**，自我场景一律写成**明确标记的合成演练 + 机制同源推断**，**不得写成「作者要你对自己这么用」**。
- **不可能有「基于机制同源」之外的自我依据**：本书对自我场景的唯一依据是机制同源，不是原书背书（x65）。

### 相邻易混

- 福格 `anchor-matching`：**时间挂钩**（它）vs **熟悉化**（本卡）。
- 原子 `environment-design`：**线索显眼**（它）vs **内容变熟悉**（本卡）。
- referent-management：**参考点管理 / 多选项**（它，同轴另一侧面）vs **把陌生变熟悉**（本卡）。
- friction-effort-diagnosis：**太难/太模糊（惰性）**（它）vs **太陌生（惯性）**（本卡）。

### 本卡的两处硬剔除（写卡时已执行，非原文缺失）

- **「找代言人」构件一次剔干净**：f10 技法 3「找熟人代言」与 p33 的 Q5「谁是变革的代言人」、Q6「产品外观与手感是否贴合用户」是**同一个只对别人的构件**散在两处。本卡从 f10、p33 **两处同时剔除**：核心是借他人信誉、自我场景无「代言人」，且 Q6 产品外观同样是只对别人的面。这是**有意的剔（按设计不进自我场景）**，不是遗漏。

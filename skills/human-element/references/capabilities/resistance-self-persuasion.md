# 抵触自解（把自我命令改造成自我结论）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 9 章与第 10 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f36`、`f37`、`f41`、`f42`、`f47`、`f48`），不随公开版分发。

## I — Interpretation

抵触（英文原词 Reactance）是四摩擦之一：当人被推着走、自由感受到威胁时，会本能地反弹——你越推，他越不动。本书给的解法不是加大推力，而是**停止强制**：不告诉对方该怎么想，而用提问或让他参与设计，引导他自己得出结论；当论据从内部长出来时，改变才真正发生，这叫「自我说服」（f36）。

掉头用在自己身上，就是本卡的骨架：**把自我命令改造成自我结论**。总法配两条实现路径：

1. **问，但不说**——用提问引自己发现，而不是告诉自己该怎么做。最直接的一招是成瘾咨询的「1 到 10 分」自评加一句追问「我为什么不干脆给自己打 1 分」（f37），逼出自己支持改变的理由。
2. **共同设计**——让「现在的我」参与计划的设计（f42）；若计划由「过去的我」或外部权威单方写好、现时的我只被执行，就会触发「被排除」的抵触。

两条判别件配套使用：**抵触三情形**（f47）——信念被威胁、感到改变的压力、被排除在设计外，三者同时命中时抵触最强，可当自检；**越推越反弹**（f48）——一旦加证据、加鼓励已经引发抵触，继续加推力只会让反对更烈，这是该踩刹车的信号。

当自我说服走不通时（时间压力大、决定来自上级只能传递），把单边命令**改造成有期限的实验**：试行 N 周，无效就重估（f41）。

注意：作者明说**自我说服并非每种情况都适用**，但**没有给判别清单**；且全书没有一处「自己对自己改变」的案例或声明，自我版一律是机制同源推断。

## A1 — Application Example

原书主语一律是「你的受众 / 人们 / 球员 / 选民」，**全书没有一处「自己对自己改变」的案例或声明**。下面先给两个对外的原书案例（均标明对外场景），再给一条明确标记的自我合成演练。

**主例（对外场景）· 戒毒咨询师的「1 到 10 分」提问**（c104，`cited_third_party` / `reported_case`）

- 输入/问题：咨询师要帮一个对药物成瘾的人寻求治疗。此处「你」是咨询师、对象是成瘾者——**这是对外场景，不是作者教人对自己用**。
- 怎么执行：不解释成瘾风险（那是「告诉对方该怎么做」），而是抛出一个意想不到的问题：在 1 到 10 分之间（10＝毫无保留地致力于清醒），你会给自己打几分？成瘾者通常打 2 到 4 分，随即追问「你为什么不干脆给自己打 1 分？」。
- 结论/输出：成瘾者自己说出支持戒瘾的论据（不打 1 分，说明他看到了清醒的好处），论点由当事人内部生成。原书交代了这个机制；原文未给出处。

**辅例（对外场景）· 吸烟者朗读实验**（c103，`cited_third_party`）：同一篇文章，被要求**大声朗读**的吸烟者，比只听的吸烟者更被说服、更有动力戒烟——信息来源不同，说服力不同。原文未给出处。

**合成演练（自我场景 · 明确标记）**

> 原书未提供自对己案例，以下为按原书规则设计的演练；**机制同源推断**，不是作者要你对自己这么用。

- 输入/问题：我想戒掉熬夜刷手机，反复对自己下命令「必须 11 点睡」，越下越抵触、干脆摆烂。
- 怎么执行（照原书规则复算）：① 用抵触三情形自检（f47）：这件事威胁我哪条核心认同？我在给自己施压吗（死线＋命令语气）？计划有没有「现在的我」参与？→ 命中「施压」与「被排除」（计划由「过去的我」定死）。② 用 1 到 10 分自问（f37）：我想 11 点睡的承诺打几分？→ 4 分；追问「我为什么不干脆给自己打 1 分」→ 答「其实我想有清醒的上午」。③ 把命令改成实验（f41）：「试 5 周 11 点躺下，不行再重新评估」。④ 让现在的我参与重定时段（f42）。
- 结论/预期输出：得到一句改写成自我结论的指令（如「为了想要清醒的上午，这周先试 11 点半躺下」），而不是「必须 11 点睡」。**原书写的是对受众；自我版属机制同源推断，无作者给的自我场景完成标准。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**

- 给自己下了硬命令（「必须」「绝对不许」），结果越逼越不想做，甚至反着来。
- 一份计划是「过去的我 / 别人」定好的，现在的我一看就抵触，不想执行。
- 明知该做一件事，反复讲道理、打鸡血、看励志内容逼自己，越逼越僵。
- 想改变一个触及自我认同的做法（如「我不是那种早起的人」），一提就反弹。
- 想给自己建立改变的动机，但不想走施压、说教的路子。

**2. 语言信号（中英双写）**

- 中文：越逼越不想做 / 自己给自己下命令 / 硬逼自己 / 怎么让自己不反弹 / 抵触自己定的计划 / 把命令改成问自己 / 自我说服 / 逼自己没用 / 一被要求就烦。
- English: self-persuasion, reactance / the more I push myself the less I do / self-command vs asking myself / soften my own demands / "why don't I rate myself a 1?" / convert a command into an experiment / stop forcing it / I resist my own plan.

**3. 与相邻能力怎么区分**

- 与 resistance-mechanism-rules（抵触机制与规则）：那条是**识别**面（命令式内部语言长什么样、规则口径），本卡是**改写 / 落地**面（把命令实际改造成提问、实验、共同设计）。
- 与 resistance-self-assessment（抵触自我访谈与自评）：那条输出**抵触来源定位**（是哪一种情形、强度多大），本卡输出**改写后的指令 / 做法**。要诊断走它，要动手改写走本卡。
- 与 commitment-public-pledge（承诺仪式与公开承诺）：那条给计划加**承诺 / 公开字段**，本卡去**卸掉命令**。
- 与 four-frictions-diagnosis（阻力四格诊断）：那条判主摩擦并**分流**；本卡只在已确定卡在抵触轴时执行。
- 与福格 `make-it-easy`：那条**降低行为难度**（能力侧）；本卡不改难度，只卸掉「被命令」引起的反弹。
- 与福格 `change-bad-habit-system`（戒除坏习惯整体方案）：要一套戒除方案走它；本卡只处理「命令式自我对话招来的反弹」这一件事。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我整体戒掉熬夜 / 刷手机」→ 不触发本卡，走福格 `change-bad-habit-system`（本卡只卸命令，不出整体戒除方案）。
- 「我想对自己多点动机 / 打打鸡血」→ 不触发本卡（那是加推力，本书明示反效）。
- 「给这个目标加个截止日 / 更严的考核」→ 不触发本卡（加压力反而触发抵触，见 B 段）。
- 「我不知道自己为什么抵触这件事」→ 先走 resistance-self-assessment（定位来源），再回本卡改写。
- 「帮我看看我的计划有没有冲突」→ 走 four-frictions-diagnosis。

## E — Execution

### 输入契约

- **必需**：①一句「自我命令 / 硬要求」原话（如「必须…」「绝对不许…」）**或**一个「越逼越不想做」的具体行为；②该命令 / 计划是由谁定的（是不是「过去的我 / 外部」单方定死）。
- **可选**：这件事是否触及核心认同（用于判 f47 第一情形）。
- **缺**①时先问是哪句命令 / 哪件事；**不许**静默替用户编一个目标。
- **适用条件**：请求是「卸掉自我命令引起的反弹」。若请求其实是「整体戒除」「加推力」「加截止日」「诊断主摩擦」，按 B 段分流。
- **临床红线**：涉成瘾 / 戒断 / 严重心理病理 → 不跑本流程，见 B 段。

### 输出契约

**产出类型**：`patch`（把已有自我指令 / 计划改写成自我结论式：改写后的提问、实验或共同设计）

可检查产物（三者按情形取一或组合）：

1. **一句改写后的指令 / 提问**：把「必须 X」改写成自问句或带重估条款的实验句（f37 / f41）。
2. **一份「现在的我」参与的重设要点**：至少一处由现时的我重新选择的内容（时段 / 强度 / 口径）（f42）。
3. **一条刹车信号**：明确「再加证据 / 鼓励已经无效，停」的判据（f48）。

**完成标准**：当事人能复述改写后的说法（不再是命令语气），并说得出「这是我自己得出来的结论」，且能指出该用哪个行为印证。

### 步骤

**第 1 步 · 判别再分路径**
- 动作：把请求归到「用提问引结论（1–10＋追问 / 自问句）」「把命令改实验」「共同设计重定计划」三条实现路径之一或组合。若其实是「诊断来源 / 整体戒除 / 加推力」，按 B 段分流后停。
- 完成标准：明确走哪条（哪几条）路径。

**第 2 步 · 抵触三情形自检（f47）**
- 动作：对这件事过三问——威胁我哪条核心认同？我是否在给自己施压（死线 / 命令语气）？计划有没有「现在的我」参与？
- 完成标准：定位到抵触落在哪一条（或几条）；三者同时命中＝抵触最强，优先处理。
- 判停：若命中「被排除」→ 重点走第 4 步共同设计。

**第 3 步 · 把命令改写成自我结论**
- 动作（走 f37 或 f41）：用 1–10 自评＋追问「我为什么不干脆给自己打 1 分」逼出内部论据；或把「必须 X」改写为「试行 N 周，无效就重新评估」的实验句。
- 完成标准：产出一句不再是命令语气、且带内部理由的表述。
- 判停：若逼出的理由为空、写不成实验句 → 回第 2 步看是否卡在「目标不一致」（可能根本不想做这件事，见 B 段），停并按现状告知。

**第 4 步 · 让「现在的我」参与重设（f42）**
- 动作：让现时的我重新选择计划里的时段 / 强度 / 口径，把「过去定死」的部分改回可选。
- 完成标准：计划里至少有一处是现时的我选的。

**第 5 步 · 装刹车信号（f48）**
- 动作：约定「一旦发现自己在加证据、加鼓励、刷励志依旧不动，就停止加推力，改去减摩擦或改提问」。
- 完成标准：说得出这条信号。

**失败处理与回流**：第 3 步产不出内部论据 → 第 2 步查是否「目标不一致 / 涉临床」；第 4 步改不动 → 回到第 1 步改走实验路径（f41）。

## B — Boundary

### 不要用（反场景）

- **临床成瘾 / 戒断 / 严重心理病理 → 不跑本流程。** 作者自承抵触技巧对成瘾者不成立：对成瘾者用情感恳求、恐惧威胁、数据引用都不起作用，甚至让他们离清醒更远（x47）。本卡只做机制说明，**红线是转介专业人士**。
- 要一套整体戒除坏习惯的方案 → 福格 `change-bad-habit-system`。
- 想给自己加动机 / 打鸡血 / 加截止日 → 不触发本卡（加推力、加压力反而触发抵触，见下）。
- 只想诊断抵触来源 / 主摩擦 → resistance-self-assessment / four-frictions-diagnosis。

### 作者警告过的失败模式（反例素材）

- **越推越反弹（f48）**：一旦加证据、加鼓励已引发抵触，继续加推力只会让反对更烈（死刑证据实验 c97＝读到反证者反而更坚定；费斯廷格「追寻者」邪教 c98＝预言落空后不改信念反而造新证据；格兰特校友捐赠邮件 c99＝叠加利他＋利己两套说服反而降捐款；均 `cited_third_party`，原文未给出处）。
- **「问 Yes 问题」有适用前提**：不是所有问题都能问出 Yes，问孩子想不想吃蔬菜、问老板愿不愿加薪只会得到 No（x49）；必须从双方一致处起手，不能套模板（`cited_third_party`）。
- **空洞的参与邀请＝意见箱，基本无效**：只发一句「欢迎反馈」、让参与完全靠对方主动，大概率不发生；要给自己结构化的参与和承诺（x52）。
- **共同设计的「有意义」没有判据**：作者反复强调参与要有意义，但没给「多有意义才算数」的尺子（x76）；自我参与若只是形式记下想法而不真改变计划，等于伪参与（哈伍德「通过代表参与」组 c109，`cited_third_party`）。
- **自我说服有前提：目标得一致**：拉杜瑟承诺卡作者自加限定——球员和教练打第一天起目标就一致，球员本就想要（c105）。**若我根本不想要这件事，提问也变不出动机**。

### 作者盲点与待核查

- **适用边界无判别清单（必写）**：作者承认自我说服并非每种情况都适用，只举了「紧张的时间压力」「决定来自上级、只能传递」两种情况，**全书未给判别清单**。本卡**不假装有**这条线。
- **全书无「自己对自己改变」的案例或声明**：原书主语一律是「你的受众 / 人们 / 球员 / 选民」。本卡所有自我场景均为**机制同源推断**，无作者给的自我场景完成标准。
- **情感与抵触没划线**：（x73）把受众的相反情绪反应与抵制都当情感摩擦讲，而抵制本是第四要素的地盘。对己用时须分清：我是「对这件事有负情绪」（走情感轴）还是「抵触被要求这么做」（走本卡）。
- **费斯廷格案例日期存疑（不进正文）**：（x72）记「1953 年」与「1956 年 12 月 21 日」并存，与通说（1954–1955）冲突，无注释无参考文献。**用时只取机制（失败后重写解释），不引年份**。
- **证据档（四档具名）**：f36 / f41 / f47＝`author_firsthand`（作者自述 / 自设框架）；f42 / f48＝`cited_third_party`；f37＝`retold`（转述成瘾咨询做法）。凡引数字 / 实验一律「原文未给出处」，不写 strong/medium/weak。

### 相邻易混

- resistance-mechanism-rules：识别命令式内部语言 / 给规则口径（它）vs 实际改写（本卡）。
- resistance-self-assessment：定位抵触来源（它）vs 改写指令（本卡）。
- commitment-public-pledge：加承诺 / 公开字段（它）vs 卸掉命令（本卡）。
- four-frictions-diagnosis：判主摩擦并分流（它）vs 已锁定抵触轴后的执行（本卡）。
- 福格 `make-it-easy`：降难度（它）vs 卸掉「被命令」的反弹（本卡）。
- 福格 `change-bad-habit-system`：整体戒除方案（它）vs 只处理命令招来的反弹（本卡）。

## 相关能力

- **four-frictions-diagnosis**（组合·前置）：先用它判主摩擦；主摩擦为抵触时进本卡执行改写。
- **resistance-mechanism-rules**（组合）：它给「命令是抵触生成器」的识别面与本轴规则口径，本卡据此执行改写。
- **resistance-self-assessment**（依赖）：先用它定位抵触落在哪一情形，再回本卡改写。
- **commitment-public-pledge**（组合）：本卡卸掉命令后，可用它给计划加承诺 / 公开字段。
- **friction-effort-diagnosis**（对比·防双触发）：它减摩擦 / 清路径，本卡卸「被命令」的反弹，动作位不同。
- **negative-emotion-source**（对比·防双触发）：它找「对这件事的负面情绪来源」，本卡处理「反感被推着走」；作者未划线（`x73`），互设近邻负例。
- **福格 make-it-easy**（对比·跨书）：它降行为难度，本卡卸「被命令」的反弹，动作位不同。
- **福格 change-bad-habit-system**（对比·跨书）：整体戒除走它，本卡只卸命令。
- **福格 celebration / 原子 reframe**（对比·跨书）：那是「加正情绪」「改措辞」，不在「卸命令、引自我结论」这个动作位。

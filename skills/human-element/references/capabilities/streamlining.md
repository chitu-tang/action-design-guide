# 流线化：减消耗（消障碍 · 找捷径 · 降低实施成本）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 5 章与第 6 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f20`、`f21`、`p41`、`p53`），不随公开版分发。

## I — Interpretation

本卡治 Effort 二维中的**消耗**那一维：行为太费力、步骤太多、启动成本太高，于是人走阻力最小的路（去刷手机、点外卖）。

- **流线化**（f20）：让想法更顺滑、阻力更小——**消除障碍**、**寻找捷径**。先找摩擦点（有的明显、有的隐蔽），再逐一消除。
- **体验时间线**（f21）：流线化的**第一步工具**。把完成一个行动的所有步骤**逐个时刻**画出来，标出积极与消极体验，**找出最摩擦的一步**。
- **流线化两步**（p53）：**第一步像侦探**（用体验时间线找摩擦点），**第二步像工程师**（重建环境、消除消极时刻）。关键是**诊断出哪个具体步骤摩擦最大**，把资源集中在最重要的时刻。
- **降低实施成本**（p41）：最小努力法则的行动含义——**降本即提升接受度**。世界银行创业难易度、糖果盘距离实验都说明：微小的成本变化会带来很大的行为差异。

一句话：**先侦探式找出最费力的那一步，再工程师式把它搬走。**

**⚠ 操纵性子面必须剔除**：f20 章末 4 问中的 **Q3（让拒绝变得更费力）** 与 **Q4（把努力从执行中抹掉，即默认选项）** 是**操纵性技术**，与「不做说服术」「不碰 Nudge 的地盘」冲突，**不得进自我场景**。本卡只保留 Q1（盘点步骤）与 Q2（让创新更易实施）两问。

**分流句（让位，须写明）**：本卡**只判能力卡、不单开入口**。「减步骤 / 消障碍 / 降成本」正是福格 `make-it-easy` 的动作位，与原子环境摩擦侧、Nudge 的 sludge **同一请求**——故经来源路由入口 human-element 访问，**出招仍走福格 `make-it-easy`**。本书只给摩擦类型与手法清单，不抢降难度动作。

**本卡不认领的触发面**：「**砍步骤／去多余选项／加进度反馈／拆到最小步／让行为本身变简单**」这类**纯出招的降难度字面整体让给福格 `make-it-easy`**，已列进本卡路由意图的「不适用」行。分界是**粒度**：

| | 福格 `make-it-easy` | 本卡 |
|---|---|---|
| 对象 | **一个行为**（把行为缩小规模、拆小步、降六类成本） | **一整条流程 / 整件事**（从想起到做完的旅程） |
| 动作 | 出招：把行为变简单 | 定位后再搬障碍：逐时刻盘点、指出最摩擦的一步、搬走旁边挡路的障碍、找捷径 |

同一句「这套流程太臃肿、帮我砍步骤去选项」，按粒度分：**要「把行为砍小」去福格，要「先盘清哪一步最卡」才进本卡**。

## A1 — Application Example

**⚠ 本书全书没有一处「自己对自己改变」的案例或声明，原书主语一律是「你的受众／人们／顾客／企业家」。** 下列原书案例**均为对外场景**。凡要落到自己身上，只能写成**明确标记的合成演练**，并注明「**机制同源推断**」，不得冒充作者经历。

**主例 · 海滨别墅代拆旧沙发**（c01，原书案例，`nature: author_personal`，**对外场景**）

- 输入／问题：定制沙发公司的顾客花几小时共同设计，却在签约前「神秘消失」；公司以为是价格、交货期，全猜错。
- 怎么执行：戴维发现真因是顾客**不知道如何处理家里的旧沙发**（一道与产品无关的摩擦）；建议公司**主动代拆旧沙发并捐赠**——即消除最摩擦的一步。
- 结论／输出：作者交代转化率显著提升（**具体数字未给**）。**这是作者给公司的对外建议案例，不是自对己案例。**

**辅例 · 肯尼亚氯气分配器（第二步＝工程师式消除）**（亦见 friction-effort-diagnosis 卡，**对外场景**）：作者交代，整体体验里成本最高的两个摩擦是「带水回程」与「等 20 分钟」；他们不能消除前者，但**重新设计流程**让加氯发生在取水时，从而**省掉 20 分钟**——把净化过程塞进已有路径（顺路完成）。

**合成演练（自对己；原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- 输入／问题：「我想每天做 20 个俯卧撑，可总不做。」
- 怎么执行（按 f20，**仅用 Q1/Q2**）：盘点步骤（找垫子→腾地方→换衣服→做）；消除障碍（垫子就铺床边、穿着睡衣做）。**Q3「让拒绝更难」、Q4「默认选项」只对别人成立，不进本演练，剔除。**
- 结论／预期输出：步骤数减少、可立即开始。**此为按原书规则可复算的演练，不是作者原案例；机制同源推断，不写成「作者要你对自己这么用」。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 一整条流程／整件事**步骤太多、太费劲**，迟迟不开始——想先盘清它到底卡在哪一步。
- 想找出「做这件事最卡的是哪一步」，好集中精力改那一步。
- 想把完成这件事的步骤**逐个时刻摊开看一遍**（体验时间线），标出哪一步最烦、哪一步最顺。
- 想知道为什么「微小的便利改动」能带来行为大变化。
- 想把某个新行为**塞进已有路径**里（顺路完成）。

**2. 语言信号（中英双写）**

- 中文：流线化／减消耗／消障碍／找捷径／步骤太多／太费力／哪一步最卡／盘一遍步骤／体验时间线／降低实施成本／让它更省力／顺路做。
- English: streamline / reduce effort / remove friction / barrier / shortcut / lower the cost / too many steps / make it easier.

**3. 与相邻能力怎么区分**

- **`friction-effort-diagnosis`**（上位·惰性总诊断）：那条**判维度**（嫌花力气还是不知道怎么做）；本卡接「已判为消耗」后**定位到具体哪一步**（逐时刻盘点、指认最摩擦一步、搬走旁边的障碍）——**一个判维度，一个判步骤**。
- **`roadmap-clarity`**（同轴·模糊性侧）：本卡治「太费力」（消耗）；那条治「不知道怎么做」（模糊）。
- **`effort-troubleshooting`**（同轴·排障）：本卡是**成步骤的消障碍做法**；那条给两问排障与自我观察。
- **福格 `make-it-easy`**（跨书·见分流句）：本书给手法清单与摩擦定位，福格给「把行为变简单」的干预阶梯；**把一个行为砍步骤 / 去多余选项 / 加进度反馈 / 拆到最小步一律走福格**，本卡只接「盘一条流程、找最摩擦一步」。
- **Nudge sludge**：默认值设计 / sludge 清理面向机构与政策，本书只做个人侧。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我把这件事**砍步骤／去多余选项／加进度反馈／拆到最小步**，让行为本身变简单」→ 不触发本卡，走福格 `make-it-easy`（纯出招的降难度）。分界：**对象是「一个行为」还是「一整条流程」**——把行为砍小去福格，盘一条流程的步骤、找最摩擦那一步才是本卡。
- 「我不知道这件事**该不该做 / 值不值得**」→ 走动机侧，不是本卡。
- 「我想**用默认值 / 让拒绝更难**改变别人的行为」→ 不触发本卡；这是操纵性技术，见 B 段（不做说服术）。
- 「我不知道**怎么做**、路径模糊」→ 走 roadmap-clarity（模糊性侧）。
- 纯信息查询（「流线化是什么」）→ 走来源路由入口 human-element。

## E — Execution

### 输入契约

- **必需**：① 一件「太费力 / 步骤太多」的具体事；② 它当前的**步骤序列**（哪怕是粗略的）。
- **可选**：最近的完整执行经历（用于做体验时间线）；已有的环境布置。
- **缺**②时先让用户把步骤说一遍，**不许静默替用户编步骤**。
- **适用条件**：消耗侧（太费力 / 步骤多 / 成本高）；模糊性 / 纯动机问题不适用（见 B 段分流）。
- **红线**：输入若涉及「让拒绝变难 / 设默认值」等**操纵性**诉求 → 停（见 B 段）。

### 输出契约

**产出类型**：`patch`（给已有做法补一份「减消耗」改造：步骤盘点 → 定位最摩擦一步 → 消除 / 简化）

- **输出**：① 一份步骤清单；② 被定位的**最摩擦一步**；③ 至少一条**消除 / 简化**动作（可含「塞进已有路径」的捷径）。
- **完成标准**：最摩擦的一步被搬走或找到捷径（顺路完成），且当事人能**立即开始**、不再卡在启动。
- **边界**：本卡的「改」是**搬走流程里挡路的障碍**，不是「把这个行为拆小 / 砍到最小」——后者是福格 `make-it-easy`。

### 步骤

1. **建体验时间线（侦探）**（f21）：把完成该行动的步骤**逐个时刻**写出来；标出哪一步是积极体验、哪一步是消极体验。
   - 完成标准：得到一张逐时刻的步骤表，并标出至少一个消极时刻。
   - 说明：作者原法要访谈**多人**（完成 7–10 个时间线才显模式）；**自我使用时改成多次记录 / 复盘自己最近一次的执行过程**（f21 判「需改造」，见 B 段）。
2. **定位最摩擦一步**（p53）：在消极时刻里找出**成本最高的那一步**（作者强调把资源集中在最重要的时刻）。
   - 完成标准：明确指出「最摩擦的一步」是哪一步。
   - 判停点：若卡点其实是「不知道怎么做」→ 转 roadmap-clarity；若其实是「没动力」→ 转福格动机诊断。
3. **工程师式消除**（p53/f20）：针对最摩擦一步做改造——消障碍、找捷径、把动作**塞进已有路径**（顺路完成）、或降低实施成本（p41）。
   - 完成标准：产出至少一条可照做的消除 / 简化动作。
4. **步骤盘点与简化**（f20，**仅 Q1/Q2**）：通读步骤清单，问「必须采取哪些步骤（含看似无关紧要的）」与「如何让它更容易实施」；砍掉或合并步骤。
   - 完成标准：步骤数减少，且指出改的是哪一步。
   - **红线**：**不得**引入 Q3（让拒绝更难）/ Q4（默认选项）——见 B 段。
5. **边界自检**：确认该事不落在「**太省力也不行**」的 4 种情形（见 B 段 / 亦见 friction-effort-diagnosis 卡）；若落在，明标原书无判据，不硬套降本。
   - 完成标准：卡内 / 答复明确标注边界是否命中。

### 失败处理与回流

- 第 1 步做不出时间线 → 退一步做「步骤盘点」（第 4 步），先拿一个粗略清单。
- 第 3 步改造后仍不动 → 回到 friction-effort-diagnosis 重判维度（可能是模糊性，不是消耗）。
- 用户要「砍步骤 / 去多余选项 / 加进度反馈 / 变简单 / 拆小步」→ 转福格 `make-it-easy`（本卡不代做降难度阶梯，也不认这些字面）。
- 用户要「用默认值 / 让拒绝更难」→ 停：操纵性技术，不做说服术。

## B — Boundary

### 不要用（反场景）

- **要具体降难度 / 拆小步 / 砍步骤 / 去多余选项 / 加进度反馈 / 让行为本身变简单** → 福格 `make-it-easy`（纯出招侧；本卡在 R1 后不再认领这些字面）。
- **模糊性 / 不知道怎么做** → roadmap-clarity。
- **没动力 / 不想做** → 福格动机诊断。
- **判「卡在哪一类阻力」** → four-frictions-diagnosis。
- **对外 UI / 产品设计** → 本卡只做自我流程减负，不做商业 UI 设计。
- 纯信息查询 → 来源路由入口 human-element。

### 分流句（**本卡只判能力卡、不单开入口**）

「减步骤 / 消障碍 / 降成本」正是福格 `make-it-easy` 的动作位，与原子环境摩擦侧、**Nudge 的 sludge** 撞同一片地（f20 f21 p53 p41 全在此）。裁定：**本卡判能力卡，不单开可发现入口，经来源路由入口 `human-element` 访问；出招（具体降难度）仍走福格 `make-it-easy`。** 本书只给摩擦类型与手法清单，不抢降难度动作。另有一条口径：「砍步骤 / 去多余选项 / 加进度反馈 / 拆到最小步」这类纯出招字面整体让给福格，本卡不再认领（见 I 段粒度表）；双触发写进近邻负例。

### 作者警告过的失败模式（反例素材）

- **操纵性子面（硬标识，必须剔）**：f20 的 Q3（让拒绝变难）/ Q4（默认选项）是**操纵性技术**，**不得进自我场景**。作者全书**未讨论其伦理边界**（x28）。
- **「太省力也不行」的方向反例**（x58/x59）：当体验本身是目的、努力是美德信号、努力与质量挂钩、努力是无聊解药时，人**主动求难**；此时一味降摩擦会削掉用户真正想要的东西（蛋糕粉 1929 年上市即失败，嫌「不用心」）。
- **「挤掉价值」的失败**：成本一旦压倒一切，价值判断失效（p39，作者自研 5/20 分钟问卷对照，「狗 vs 青蛙」价值不起作用）——**原文未给出处**。

### 作者盲点与待核查

- **f21 判「需改造」**：作者原法要**访谈多人**（7–10 个时间线才显模式，数字**原文未给出处**）；自我版须改成**复盘自己最近一次的执行过程**，不得原样搬用「访谈他人」这一环。
- **图转录不进 R 段 / 依据栏**：f21 涉及的图 6-1、图 6-2、图 6-3**图内文字是图转录，不是原文**，不得填进引文或依据。
- **数字未给出处**：p41 的全部数字——世行创业难易度「新西兰约 4 小时 / 印度约 17 天 / 乍得约 62 天」、「创业数量约 4 倍」、糖果盘「0.8 米 vs 0.25 米、摄取量 2 倍」——**原文均未给出处**。
- **芝大案例内部数字冲突**：作者讲「芝加哥大学改用通用申请」时，申请量前后两处数字冲突——一处说不到 4 000 份，另一处说从 5 000 增加到 33 000（c60 已标待核）。**两条都不许当事实**，本卡不据其立论。
- **全书无一处「自己对自己改变」的案例或声明**：本卡的自我场景是**机制同源推断**到自对己，不是作者给的自我场景。

### 相邻易混

- roadmap-clarity：本卡治消耗（太费力）/ 那条治模糊（不知道怎么做）。
- friction-effort-diagnosis：本卡是消耗侧的**步骤级定位与搬障碍** / 那条是**维度级二选一**。
- effort-troubleshooting：本卡是成步骤的消障碍做法 / 那条给排障两问与观察。
- 福格 `make-it-easy`：本书给手法清单 / 它给「变简单」的干预阶梯（砍步骤、去选项、拆小步一律走它）。

## 相关能力

- **friction-effort-diagnosis**（组合）：它**判维度**（消耗还是模糊）；本卡接「已判为消耗」后**定位到哪一步**（盘点步骤、搬障碍、找捷径）。
- **roadmap-clarity**（对比）：本卡治**消耗**（太费力），它治**模糊**（不知道怎么做）。
- **effort-troubleshooting**（对比）：本卡盘一条流程的步骤并搬走旁边的障碍；它只读出摩擦点（欲望之路）再交回。
- **福格 make-it-easy**（对比·跨书，分流句）：本书只给摩擦类型与手法清单，**把一个行为砍步骤 / 去多余选项 / 加进度反馈 / 拆到最小步走福格 make-it-easy**；本卡判能力卡、不单开入口。
- **Nudge sludge**（对比·跨书）：默认值设计 / sludge 清理面向机构与政策，本书只做个人侧；且 `f20` 的操纵性子面（让拒绝变难 / 默认选项）已剔出，不进自我场景。

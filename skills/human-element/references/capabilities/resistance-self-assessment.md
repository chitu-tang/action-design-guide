# 抵触自我访谈与自评（深度访谈 · 抵触自评 3 问）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 10 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f38`、`f43`、`p99`），不随公开版分发。

## I — Interpretation

本卡是抵触轴的**自我访谈 / 自评清单层**——把「我为什么抵触这件事」摊成可回答的问题，输出**抵触来源定位**（不是改写动作）。三件：

1. **深度访谈（f38，改造用）**：原著是**与选民对话的两方技巧**（问对问题，不用灌输）。掉头用在自己身上，要**删掉「拉票员」一方**，改成自问自答式深度访谈：① 说出我的立场；② 问自己对这件事的感受以了解信念；③ 回想相关个人经历；④（原「拉票员分享故事」→改为）与自己的最初立场共鸣；⑤ 再问自己现在的看法。核心是让持抵触态度的一方自己松动。
2. **抵触程度自评 3 问（f43）**：① 这件事威胁我哪条核心信念？② 我是否在给自己施压（惩罚 / 时间压力 / 严苛命令）？③ 这个计划有「现在的我」参与吗？——三问同时命中时抵触最强。它是抵触三情形（f47，在能力卡内）的章末自评版。
3. **「问 Yes 问题」自评 3 问（p99，须删 Q2）**：① 我是在问还是在告知？② 你问的是能回答「Yes」的问题吗？（**此问依赖「Yes 阶梯」，只对劝别人成立，自我场景须删**）③ 我有没有机会给自己立个公开承诺？

三件的共同产物是**抵触来源与强度的定位**，供 resistance-self-persuasion 据此改写。

## A1 — Application Example

**主例（对外场景）· 领导力实验室的深度拉票**（c106，`cited_third_party` / `reported_case`）

- 输入/问题：一个减少对性少数群体歧视的非营利组织，想改变选民对变性人权利的反对态度。
- 怎么执行：用深度拉票五步——提出正确的问题（而非告诉选民该怎么想），让持反对意见者自己说出立场、感受与经历，最后重估看法。
- 结论/输出：原作者报告，几乎 500 名佛州选民的访谈效果，比 1998–2012 年同性恋权利态度转变更明显；同一批研究者比较的其他 49 项传统拉票实验无一被证明有效。**注意：这是面向选民（他人）的游说技巧，原文本就是两方对话，不是自对己案例。** 原文未给出处。

**合成演练（自我场景 · 明确标记）**

> 原书未提供自对己案例，以下为按原书规则设计的演练；**机制同源推断**，不是作者要你对自己这么用。演练已按要求删掉「拉票员」一方。

- 输入/问题：我很抵触「公开写作」这件事。
- 怎么执行（照改造后的 f38 复算）：① 说出立场（我不想公开写）；② 问自己感受（怕被评判、被暴露）；③ 分享经历（大学时被当众批过作文）；④ 与最初意见共鸣（理解自己为什么怕）；⑤ 重估看法（或先小范围发）。再用 f43 三问定位：命中的是「威胁核心信念」（怕被看见 vs「低调」认同）。
- 结论/预期输出：得到抵触来源（信念威胁 + 被暴露），立场发生一点松动。**原书写的是对选民；自我版属机制同源推断，无作者给的自我场景完成标准。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**

- 知道自己在抵触某件事，但说不清是**怕什么 / 抗拒哪一点**。
- 想给自己做一次「深度访谈」：把立场、感受、经历摊开来，看看抵触从哪来。
- 想判断一个自我改变会招来多大抵触（信念威胁 / 压力 / 被排除）。
- 想核对：我是在问自己，还是在命令自己？我有没有给自己留公开承诺的口子？
- 计划反复推不动，想先定位抵触来源再决定怎么办。

**2. 语言信号（中英双写）**

- 中文：我到底为什么抵触 / 抵触来自哪里 / 抵触有多大 / 深度访谈自己 / 说不出怕什么 / 是在问还是在命令自己。
- English: why do I resist this / where is my resistance coming from / how strong is my reactance / self-interview / deep canvassing / am I asking or telling myself.

**3. 与相邻能力怎么区分**

- 与 resistance-self-persuasion（抵触自解）：那条是**改写动作**（把命令改造成结论 / 实验），本卡是**定位来源**（访谈 + 自评三问）。先诊断走本卡，要改写走它。
- 与 resistance-mechanism-rules：那条给**语言机制 / 规则口径**（命令招反弹），本卡给**来源与强度定位**。
- 与 commitment-public-pledge：本卡 p99 第 3 问只是**问你有没有承诺机会**，真正加承诺字段走那条。
- 与 negative-emotion-source（情感轴诊断卡）：两卡共享「莫名不想做 / 发怵」信号。**说不清在怕什么、要一次把它问出来的访谈** → 本卡；**怕的内容说得清**（怕做错 / 怕白忙）→ 它。作者未给情感与抵触的划线（x73），此系本书按「手里已有什么」自划。
- 与 four-frictions-diagnosis：那条判**主摩擦是哪一根轴**并分流；本卡只在确定卡在抵触轴时定位来源。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我把『必须』改成一句能执行的话」→ 不触发本卡，走 resistance-self-persuasion。
- 「帮我看我的计划卡在哪根轴」→ 走 four-frictions-diagnosis。
- 「帮我给自己加个公开承诺」→ 走 commitment-public-pledge。
- 「命令为什么会招反弹」→ 走 resistance-mechanism-rules。
- 「我特别怕做错、怕白忙一场，就想治一下这种启动前的焦虑」→ 不触发本卡，走 negative-emotion-source（怕的内容已说得清、要的是定名价值 + 对因下药）。
- 「帮我整体戒掉熬夜」→ 走福格 `change-bad-habit-system`。

## E — Execution

### 输入契约

- **必需**：一件「知道自己在抵触、但说不清来源」的具体事（一句话即可）。
- **可选**：这件事是否触及自我认同（用于 f43 第 1 问）。
- **缺**具体事时先问是哪件事；不许静默编一个。
- **适用条件**：请求是「定位抵触来源 / 强度」。若要改写或整体戒除，按 B 段分流。
- **临床红线**：涉成瘾 / 戒断 / 严重心理病理 → 不跑本流程，转介。

### 输出契约

**产出类型**：`diagnosis`（抵触来源定位：命中哪一种情形、强度如何）

可检查产物：

1. **一次自问自答式深度访谈记录**（f38 改造版，五步、无「拉票员」一方）。
2. **抵触自评三问的结论**（f43）：命中「信念威胁 / 压力 / 被排除」中的哪几条；几条同时命中＝抵触最强。
3. **（可选）问 Yes 三问结论**（p99，删 Q2 后）：我是在问还是在命令；有没有给自己留承诺机会。

**完成标准**：当事人能说出抵触主要来自哪一条（或几条），并据此判断「要不要先降抵触再谈执行」。

### 步骤

**第 1 步 · 分诊确认在抵触轴**
- 动作：确认这件事是不是「被推着走时反弹」型抵触（而非「累 / 不会做 / 有负情绪」）。
- 完成标准：确认属抵触轴；否则按 B 段分流。

**第 2 步 · 抵触自评三问（f43）**
- 动作：过三问——威胁我哪条核心信念？我在给自己施压吗？计划有「现在的我」参与吗？
- 完成标准：定位到命中哪几条；三者同时命中＝最强，优先处理。

**第 3 步 · 自问自答式深度访谈（f38 改造版）**
- 动作：按五步走，**删掉「拉票员」一方**，第 4 步改成与自己的最初立场共鸣。
- 完成标准：走完五步，立场是否有一点松动可记录。
- 判停：若第 2 步三问全未命中且第 3 步立场零松动 → 说明不是抵触轴，回第 1 步重判。

**第 4 步 · （可选）问 Yes 三问（p99，删 Q2）**
- 动作：只保留 Q1（问还是告知）与 Q3（有无承诺机会）；**Q2「Yes 阶梯」只对别人，自我场景删除**。
- 完成标准：产出「我是在问 / 在命令」与「有无承诺机会」两项结论，并注明 Q2 已按自我场景删除。

**失败处理与回流**：定位出抵触来源后，若用户要动手卸抵触 → 交 resistance-self-persuasion；若要加承诺 → commitment-public-pledge。

## B — Boundary

### 不要用（反场景）

- 要**把命令实际改写成结论 / 实验** → resistance-self-persuasion（本卡只定位）。
- 要判**主摩擦是哪一根轴** → four-frictions-diagnosis。
- **临床成瘾 / 戒断 / 严重心理病理** → 不跑本流程；对成瘾者劝说无效（x47），红线是转介。
- 整体戒除坏习惯 → 福格 `change-bad-habit-system`。

### 作者警告过的失败模式（反例素材）

- **传统灌输式拉票普遍无效（f38 的对照）**：几乎 500 名选民研究里，其他 49 项传统拉票实验无一被证明有效（x48，`cited_third_party`）；向意见相左者讲道理只会适得其反。
- **「Yes 阶梯」不是万能**：不是所有问题都能问出 Yes，问孩子想不想吃蔬菜、问老板愿不愿加薪只会得到 No（x49）——**此技巧只对劝别人成立、且须从一致处起手；自我场景整条删除**。
- **深度访谈的前提是目标一致**：拉杜瑟承诺卡的作者自加限定——双方从第一天起目标一致（c105）；若我根本不想要这件事，访谈也问不出动机。

### 作者盲点与待核查

- **f38 改造重（本卡最需标注处）**：原著是**与选民对话的两方技巧**，第 4 步（拉票员分享自己的故事）在独处时不存在，须换成自述自省；改造后与 resistance-self-persuasion 的 f37 自我提问有部分重合，本卡只保留其**五步结构 + 定位产物**。
- **p99 的 Q2 只对别人**：Q2 依赖「Yes 阶梯」（x49），自我场景须删；Q1≈「问 vs 告知」（与 f41 同口径）、Q3≈公开承诺（与 f39/f44 同族），独立增益偏低，故 p99 靠「清单形式」保留，不单开入口。
- **f43 与能力卡 f47 同内容**：f43（自评 3 问）是 f47（三情形）的章末自评版，母条已在 resistance-self-persuasion 内；本卡只承载「把母条固化成自检问句」这一形态增量。
- **全书无「自己对自己改变」的案例或声明**：原书主语一律是「你的受众 / 人们 / 选民」，自我场景均为机制同源推断。
- **证据档（四档具名）**：f38＝`cited_third_party`（佛州选民研究，点名创始人 David Fleischer，无文献，原文未给出处；皮尤 2017 为全书少见可核线索）；f43 / p99＝`author_firsthand`（作者自设的章末清单）。不写 strong/medium/weak。

### 相邻易混

- resistance-self-persuasion：定位来源（本卡）vs 改写动作（它）。
- resistance-mechanism-rules：来源与强度定位（本卡）vs 语言机制 / 规则口径（它）。
- commitment-public-pledge：p99 第 3 问只是问你有没有承诺机会（本卡）vs 真正加承诺字段（它）。
- negative-emotion-source：说不清、要一次把它问出来的访谈（本卡）vs 怕的内容说得清、定名价值 + 对因下药（它）。
- four-frictions-diagnosis：抵触轴内定位（本卡）vs 判主摩擦并分流（它）。

## 相关能力

- **resistance-self-persuasion**（依赖·下游主卡）：本卡定位出抵触来源后，由它执行改写（`f43` 是其内部 `f47` 的清单版）。
- **resistance-mechanism-rules**（对比）：它给命令语言机制，本卡给来源与强度定位。
- **commitment-public-pledge**（组合）：本卡 `p99` 第 3 问指向它，真正加承诺走它。
- **negative-emotion-source**（对比·防双触发）：**说不清在怕什么、要一次把它问出来的访谈** → 本卡；**怕的内容说得清**（怕做错 / 怕白忙）→ 它。两者共享「莫名不想做 / 发怵」信号，按「手里已有什么内容」分界，互设近邻负例。
- **福格 change-bad-habit-system**（对比·跨书）：整体戒除走它。

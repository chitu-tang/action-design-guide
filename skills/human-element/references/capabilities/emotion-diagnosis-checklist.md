# 情感摩擦诊断清单（评估 2 问 · 多问为什么 3 问 · 观察 3 问）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 8 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `p67`、`p69`、`p70`），不随公开版分发。

## I — Interpretation

本卡是情感轴的**章末诊断清单 / 观察作法**，是「找负情绪来源」那条工作流（母条 f31 在能力卡 negative-emotion-source 内）的**清单版与另一种观察入口**。它把同一件事拆成三组可照抄的问句：

1. **评估 2 问**（p67）——先量情感摩擦的**强度**与**威胁面**：①受众（或自己）对这个改变感到被威胁或焦虑到什么程度；②它是否破坏了更广泛的**功能/社会/情感价值**。第 2 问是把功能价值与社会/情感价值分开看的入口（蛋糕粉式：功能上「更省事」，情感上「不算我做的」）。
2. **方法一 · 多问「为什么」3 问**（p69）——①为什么要接受（校准三类价值）；②我是在治**症状**（「不」「太贵」）还是在治**病因**（用 f31 的 5 个为什么去挖）；③我到底在做**什么**（进步导向：产品只是达成更大目标的手段，摩擦就藏在那个更广的背景里）。
3. **方法二 · 观察 3 问**（p70）——①观察行为，而不是只听话（「说一套做一套」）；②对背景了解多少（行为发生在具体的社会/情感/物理环境里）；③对方自创了什么**变通办法**（变通办法是摩擦的线索）。

**它和母条的分工**：f31（在那张能力卡内）是**连问同一句「为什么」5 次**；p69 是**3 个不同的「为什么」**——两者都是挖真因，但一个靠重复下钻、一个靠换维度。本卡不抢那张卡的入口，只提供**自检清单 + 「观察行为而非说法」这一变体**。

**自我场景的主语要换**（见 B 段）：原书主语是「受众/人们」，p70 的「观察别人」反身时只能**弱化成「记录自己的真实行为（不是说法）」**。

## A1 — Application Example

> ⚠ **原书未提供「自己对自己改变」的案例**；以下原书案例均为**对外场景**，自我场景一律写成**明确标记的合成演练 + 机制同源推断**。

**辅例 · 蛋糕粉「功能更省事、情感不算我做的」**（c76，转引，作者自标「据传」）：对应 p67 Q2——功能价值增加（更省事）反而威胁了情感与社会价值（「不用心」）。**⚠ 对外产品案例；作者用了「据传」，史实成色薄，只作机制隐喻。**

**辅例 · 「支付与分期」的自创变通**（c88，第三方案例）：对应 p70 Q3——人们为绕开情感摩擦会自创变通办法（改付款/分期安排）。**对外商业案例。**

**合成演练 · 冥想卡点（原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- **输入/问题**：「我想开始每天冥想。」
- **怎么执行**：用评估 2 问 → 方法一 3 问。
- **复算**：评估 Q1——这改变让我感到被威胁/焦虑吗？→ 怕「浪费时间」、怕做不到；评估 Q2——它破坏我更广泛的需求吗？→ 与「我是高效的人」的自我认同冲突（**⚠ 此处已踩到 p67 Q2 的越界，见 B 段**）；方法一 Q2——我在治症状还是病因？→ 症状是「没做」，病因是怕做不到；方法一 Q3——我真正要取得的进步是什么？→ 有一点稳定的安静时间。
- **结论/输出**：情感摩擦强度＝中，来源＝怕做不到与效率观冲突；**输出是诊断，不是治疗**（补救走 negative-emotion-source 的 f34）。**注意：这是机制同源推断，不是作者背书。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 想系统过一遍「情感摩擦」的诊断问句，而不是只挖一次根因。
- 想知道某个改变/创新的情感摩擦**有多强**、威胁到了哪类价值。
- 想用一组固定的章末自检问题，把情感摩擦的强度与来源查全。
- 想从「我实际做了什么」而不是「我说了什么」里反推摩擦点。
- 已经知道是情感摩擦，但想要清单 / 换一种观察作法。

**2. 语言信号（中英双写）**

- 中文：情感摩擦清单 / 评估情感摩擦几问 / 情感摩擦强度 / 章末自检 / 多问为什么 / 找情感摩擦的方法 / 观察自己的行为 / 说一套做一套 / 我的改变威胁了哪类价值。
- English: emotion friction checklist / how strong is the emotional friction / assess emotional friction / observe behavior not words / what value does this change threaten / why checklist.

**3. 与相邻能力怎么区分**

- **`negative-emotion-source`**（同轴主线，**不适用改走它**）：那条是**完整诊断工作流**（连问 5 个为什么 / 三类提问 / 对因补救，输出负情绪来源 + 价值类型 + 一条补救）；本卡是**章末清单 + 「多问为什么 3 问 / 观察 3 问」的清单版**。要动手挖一个具体卡点 → 走主线；要一份自检 / 评估清单 → 走本卡。
- **`four-frictions-diagnosis`**（跨轴，**不适用**）：那条判「卡在哪根摩擦（惯性/惰性/情感/抵触）」；本卡**只在情感轴内部**评估强度与来源。
- **`resistance-self-assessment`**（抵触轴，对比）：那是抵触轴的自我访谈 / 自评清单（我是否在自我施压、被排除）；本卡是情感轴（对这件事的负面情绪）。
- 福格 `celebration` / 原子 `reframe`（对比）：加正情绪 / 换措辞，均不在「评估负情绪来源」这个动作位。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 【vs negative-emotion-source】「帮我把某句『没时间』挖到真正的根因」→ 不触发本卡，走主线诊断。
- 【vs four-frictions-diagnosis】「我说不清卡在哪根摩擦」→ 不触发本卡，先走四格诊断。
- 【vs 抵触轴 resistance-self-assessment】「我是不是在给自己施压、越推越反弹」→ 走抵触轴自评卡。
- 【vs 福格 `celebration` / 原子 `reframe`】「想加正情绪 / 想换说法」→ 走那两张。
- 【vs 路由入口】「情感摩擦是什么」→ 走来源路由入口 human-element。

**分流句（本卡 ↔ `negative-emotion-source` ↔ `four-frictions-diagnosis`）**：要**一份情感摩擦自检清单 / 评估强度** → 本卡；要**动手挖一个具体卡点的负情绪来源并下药** → negative-emotion-source；**还没判卡在哪根摩擦** → four-frictions-diagnosis。

## E — Execution

### 输入契约

- **必需**：① 一个具体的改变 / 创新（自用或对外），或一句当事人给出的表层理由。② 面向自己还是面向受众（原书主语是受众；自用须改主语，见 B 段）。
- **可选**：近期同类症状的重复记录、可观察到的「说 vs 做」不一致处。
- **缺①时先问是**哪件事；**不许静默替用户猜**。若请求其实是「动手挖一个卡点并要补救」→ 转向 negative-emotion-source。

### 输出契约

**产出类型**：`diagnosis`

一份**情感摩擦评估结论**（`reviews.md` 一条），三段式：
1. **强度**（低/中/高，来自 p67 Q1）；
2. **被威胁的价值面**（功能 / 社会 / 情感，来自 p67 Q2 与 p69 Q1，**Q2 的越界部分须明标**，见 B 段）；
3. **来源线索**（来自 p69 Q2「症状 vs 病因」与 p70 三问观察到的变通办法）。

**完成标准**：强度有判断、价值面有明示、来源线索可追溯到具体观察或问句；**输出是评估，不含补救动作**（补救走 negative-emotion-source）。

### 步骤

1. **评估 2 问**（p67）：Q1 量强度；Q2 判是否破坏更广泛的价值（**判停点**：若 Q2 的答案落到「这事跟我是不是这种人冲突」，那是**身份/价值威胁**，按 B 段明标越界、转身份层，不塞回情感摩擦）。
   - 完成标准：得到强度 + 价值面的初步判断。
2. **方法一 3 问**（p69）：Q1 三类价值校准动机；Q2 分清症状与病因（**判停**：若确认在治表层症状，转 negative-emotion-source 用 f31 挖真因）；Q3 进步导向（我在达成什么更大目标）。
   - 完成标准：说清动机三维价值、并判出是症状还是病因。
3. **方法二 3 问**（p70，**须改主语**）：把「观察别人」改成「记录自己」——①看实际做了什么而非说了什么；②补背景（时、地、情境）；③记下自己自创的变通办法（它就是摩擦线索）。
   - 完成标准：从自己的行为数据里反推 ≥1 条来源线索。
4. **汇总**：按输出契约写成三段式评估，落 `reviews.md`。
   - 完成标准：三段齐全，且第 2 段标清 Q2 越界与否。

### 失败处理与回流

- 第 1 步 Q2 命中身份/价值威胁 → 明标越界（见 B 段），把该条交给身份层处理，**不塞回情感摩擦**。
- 第 2 步确认「在治症状」且想要对策 → 转 negative-emotion-source（挖真因 + 下药）。
- 第 3 步若当事人无法稳定记录自己行为（偏弱，见 B 段）→ 只用前两组问句，如实说明第三组的局限，**不假装观察数据存在**。

## B — Boundary

### 不要用（反场景）

- 要动手**挖一个具体卡点的负情绪来源并要补救**→ negative-emotion-source（本卡只评估、不下药）。
- 还没判「卡在哪根摩擦」→ four-frictions-diagnosis。
- 是抵触（被推着走、越推越反弹）→ 抵触轴各卡（尤其 resistance-self-assessment）。
- 要加正情绪 / 换措辞 → 福格 `celebration` / 原子 `reframe`。
- 纯信息查询（「情感摩擦 / 情感轴是什么」）→ 来源路由入口 human-element。
- **临床**：严重心理病理 / 成瘾戒断 → 不跑本流程。

### 作者警告过的失败模式（反例素材）

- **把症状当真因**（x34）：负面情绪被隐藏、转化为可接受的表面理由（「太贵」「没兴趣」「冷漠」）；成本异议常是「结束对话的最快方式」。**p69 Q2 专门用来防这个陷阱，别跳过。**
- **双重掩盖**（x12）：摩擦既藏在表象下、当事人自己也说不清 → 所以 p70 要**看行为而不是听话**。
- **同理心剧场**（x35）：用表演式共情替代真实理解，反而制造新摩擦。

### 作者盲点与待核查（不许假装有）

- **p67 的 Q2 越界到「身份 / 价值威胁」**（x74）：这处把情感摩擦扩问为「它会不会伤及更广的需要」，又用老年人一连串「失去」举例，已越出「情绪」进入**身份与价值威胁**；Q2 **可能应归身份层**。**用时须明标越界、不替作者收口**（本卡第 1 步已设判停，遇「这事跟我是不是这种人冲突」转身份层）。
- **情感与抵触没划线**（x73）：第 7 章讲情感摩擦时把抵制与负面情绪都算进情感摩擦（原书说受众常会冒出与预期相反的情绪），**而这正是「抵触」的地盘**。作者**未收口**；本卡只在「非预期负面情绪」定位内出招，遇「反感被推着走」转抵触轴。
- **全书无一处「自己对自己改变」的案例或声明**：原书主语一律是「受众 / 人们」。p70 原法「观察别人」反身时**只能弱化成「记录自己的真实行为」**（你无法旁观自己）；本卡 A1 已标对外场景与合成演练 + 机制同源推断，**不得写成作者要你对己这么用**。
- **全书无出处体系**：本卡所引 p67/p69/p70 均**无数字**；c76/c88 属外部案例，原文未给出处（c76 作者自标「据传」）。
- **无「何时是情感、何时是抵触/惰性」的判据**：作者未给判别清单；本卡按第 1/2 步判停分流，**不假装存在判据**。

### 相邻易混

- negative-emotion-source：完整诊断工作流 + 下药（它）vs 章末评估清单 / 观察变体（本卡）。
- four-frictions-diagnosis：判轴（它）vs 情感轴内的强度/来源评估（本卡）。
- resistance-self-assessment：抵触轴自评（它）vs 情感轴评估（本卡）。
- 福格 `celebration` / 原子 `reframe`：加正情绪 / 换措辞（它们）vs 找负情绪来源（本卡）。

## 相关能力

- **negative-emotion-source**（组合·同轴主线）：本卡是它的**章末清单版与观察变体**（`f31` 在主线内）；要动手挖一个具体卡点走主线，要一份评估清单走本卡。
- **福格 celebration**（对比·跨书）：加正情绪（它）vs 评估负情绪来源（本卡）。
- **原子 reframe**（对比·跨书）：换措辞（它）vs 找负情绪来源（本卡）。

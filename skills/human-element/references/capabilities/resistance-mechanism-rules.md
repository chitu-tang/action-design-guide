# 抵触机制与规则（命令招反弹 · 问而不说）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 9 章与第 10 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `p86`、`p89`），不随公开版分发。

## I — Interpretation

本卡是抵触轴的**机制与规则层**——回答「为什么命令会招来反弹」「不招反弹的原则口径是什么」，不含具体改写动作（改写落在能力卡 resistance-self-persuasion）。两条：

1. **命令是强大的抵触生成器（p86）**：抵触根植于保护自主权的欲望，人一旦觉得自由被剥夺，就会反击。信息只要**像是命令**（尤其空洞命令），反作用力最大——推力越大，反作用力越强。掉头到自己身上：我对自己说「必须 / 绝对不许 / 一定要」，等于自己给自己下命令，同样招来自己的抵触。
2. **问，但不说（p89）**：自我说服的头一条规则。不告诉（自己或对方）该怎么想，而用提问引导对方自行发现——论据从内部生成才有效。

两条合起来是抵触轴的**辨识 + 口径**：先认出「这是命令式语言」，再守住「提问而非灌输」的原则。具体把哪句话改成哪个问句、哪次实验，不在本卡，在 resistance-self-persuasion。

## A1 — Application Example

**主例（对外场景）· 男浴室涂鸦实验**（c96，`cited_third_party` / `reported_case`）

- 输入/问题：一所大学想减少男浴室里的涂鸦。
- 怎么执行：测试两种标识——一条措辞最强（绝对禁止），一条措辞普通（一般劝阻）。
- 结论/输出：两条都适得其反，招来更多涂鸦；其中**最强措辞**那条所在的浴室，新增涂鸦最多。作者由此得「推力越大，反作用力越强」。**注意：这是对别人的标识实验，不是自对己案例。** 原文未给出处。

**合成演练（自我场景 · 明确标记）**

> 原书未提供自对己案例，以下为按原书规则设计的演练；**机制同源推断**，不是作者要你对自己这么用。

- 输入/问题：我每天对自己说「绝对不许再熬夜」，结果越来越晚睡。
- 怎么执行（照原书规则复算）：① 认出「绝对不许」属命令式（＝自己给自己下命令）；② 按 p89「问，但不说」，把它换成非命令的表述 / 自问句（如「如果 11 点前躺下，第二天会清爽，这周先试几晚？」）。
- 结论/预期输出：产出一句改写后的内部语言。**原书写的是对受众；自我版属机制同源推断，无作者给的自我场景完成标准。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**

- 想搞清楚「为什么我越逼自己越反着来」——要的是机制解释，不是立刻改写。
- 用「必须 / 绝对不许 / 一定要」这类词对自己说话，直觉上觉得不对劲。
- 帮别人把关语言：一份通知 / 一份要求里全是命令口吻，想知道怎么改口径。
- 想知道抵触轴的「总原则」是什么（不施压、用提问引结论）。
- 在「命令」这个词上打转，问「命令为什么会招人烦」。

**2. 语言信号（中英双写）**

- 中文：命令语气 / 为什么越逼越反弹 / 绝对不许反而更做 / 命令是抵触生成器 / 问还是说 / 问而不说 / 别用命令口气。
- English: commands trigger reactance / why pushing backfires / "don't ever" backfiring / ask don't tell / questioning vs telling / commanding language.

**3. 与相邻能力怎么区分**

- 与 resistance-self-persuasion（抵触自解）：本卡是**辨识 + 口径**（认出命令式语言、守住「问而不说」），那条是**把命令实际改写成结论**（1–10 追问、实验句、共同设计）。要机制解释 / 规则口径走本卡；要动手改写走它。
- 与 resistance-self-assessment：那条定位**抵触来源与强度**（三情形），本卡给**语言机制**。
- 与 commitment-public-pledge：那条加公开承诺字段，本卡谈命令语言。
- 与 four-frictions-diagnosis：那条判主摩擦并分流，本卡只讲抵触轴的语言机制。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我把自己下的『必须』改写成一句能执行的话」→ 不触发本卡，走 resistance-self-persuasion（本卡只认机制、不改写）。
- 「我不知道自己为什么抵触这件事」→ 走 resistance-self-assessment。
- 「帮我整体戒掉熬夜」→ 走福格 `change-bad-habit-system`。
- 「帮我给目标加个公开承诺」→ 走 commitment-public-pledge。

## E — Execution

### 输入契约

- **必需**：一段**带命令口吻的语言样本**（自我对话原话，或一份对外通知 / 要求）。
- **可选**：该语言是自我对话还是对外文本（决定主语改写方式）。
- **缺**语言样本时先问；不许静默编一句。
- **适用条件**：请求是「认出命令式语言 / 要抵触轴的规则口径」。若要实际改写或整体戒除，按 B 段分流。
- **临床红线**：涉成瘾 / 戒断 / 严重心理病理 → 不跑本流程，转介。

### 输出契约

**产出类型**：`patch`（改写命令式内部语言：把命令口吻换成非命令 / 提问式表述）

可检查产物：

1. **一处「命令式」标注**：指出样本里哪句属命令式（尤其「必须 / 绝对不许」这类空洞命令）。
2. **一句口径改写**：按 p89「问，但不说」，把它改成非命令的表述或自问句。

**完成标准**：当事人在语言样本里指得出命令式句子，并说得出「为什么命令会招反弹」与「改用提问的方向」。

### 步骤

**第 1 步 · 认命令**
- 动作：在样本里标出命令式语言（命令动词、绝对化词、无权力支撑的空洞命令）。
- 完成标准：指得出至少一句命令式原话。
- 判停：若样本里没有命令式语言 → 说明不在焦点，停（别硬套）。

**第 2 步 · 说机制**
- 动作：用 p86 解释为什么会招反弹（威胁自主权 → 反击；推力越大反作用越大）。
- 完成标准：当事人能复述「这是自己给自己下命令 → 招自己的抵触」。

**第 3 步 · 守口径**
- 动作：给出 p89 的方向——不灌输、改用提问引导自行发现；但**不改写成完整动作**，交 resistance-self-persuasion 执行。
- 完成标准：产出一处方向性改写（非命令语气），并指明「要落地完整改写走 resistance-self-persuasion」。

**失败处理与回流**：若用户真正要的是「把命令改写成能执行的东西」或「整体戒除」，第 1 步后直接按 B 段分流。

## B — Boundary

### 不要用（反场景）

- 要**实际把命令改写好、要一套卸抗争方案** → resistance-self-persuasion（本卡只给机制与口径）。
- **临床成瘾 / 戒断 / 严重心理病理** → 不跑本流程；对成瘾者劝说无效（x47），红线是转介。
- 整体戒除坏习惯 → 福格 `change-bad-habit-system`。
- 想加动机 / 打鸡血 / 加截止日 → 不触发本卡（就是本书反对的加推力）。
- 只想定位抵触来源 → resistance-self-assessment。

### 作者警告过的失败模式（反例素材）

- **命令招反弹**：男主浴室涂鸦实验里，最强命令的浴室新增涂鸦最多（c96，`cited_third_party`，原文未给出处）。
- **推力越大反作用越大**：这是 p86 的核心结论，也是「越推越反弹」（f48，`cited_third_party`）的同一侧。
- **空洞命令最糟**：作者明说空泛的命令是最糟的策略；无权力支撑的命令尤其反效（p86）。

### 作者盲点与待核查

- **p86 的改写方向属合理外推**：原文讲的是**对外命令**（作者对受众 / 员工），其「识别面」扎实；但「把命令式内部语言改写掉」这一步**没有作者给的自我场景完成标准**，属机制同源合理外推，不得当成作者教人对自己这么做。
- **p89 产物偏「一句提问」**：本条本身只是一条规则主张（`assertion` 档），无实验、无可核出处；具体提问法（1 到 10 分）在 resistance-self-persuasion 的 f37。
- **全书无「自己对自己改变」的案例或声明**：原书主语一律是「你的受众 / 人们」，自我场景均为机制同源推断。
- **证据档（四档具名）**：p86＝`cited_third_party`（浴室涂鸦实验＋机制规则，未给出处）；p89＝`assertion`（规则主张，具体提问法在别处）。凡引数字 / 实验一律「原文未给出处」，不写 strong/medium/weak。
- **点名但无页码**：西奥迪尼《影响力》在 p86 / p89 一带点名，无页码，不得当已证实。

### 相邻易混

- resistance-self-persuasion：识别命令 / 给口径（本卡）vs 实际改写（它）。
- resistance-self-assessment：语言机制（本卡）vs 来源与强度定位（它）。
- commitment-public-pledge：命令语言（本卡）vs 公开承诺字段（它）。
- four-frictions-diagnosis：抵触轴语言机制（本卡）vs 四摩擦总诊断与分流（它）。

## 相关能力

- **resistance-self-persuasion**（组合·下游主卡）：本卡的机制与口径由它落成具体改写（1–10 追问 / 实验句 / 共同设计）。
- **resistance-self-assessment**（对比）：它定位抵触三情形与强度，本卡只讲命令这一条语言机制。
- **commitment-public-pledge**（对比）：本卡谈命令语言，它谈承诺格式。
- **福格 change-bad-habit-system**（对比·跨书）：整体戒除走它，本卡不出戒除方案。

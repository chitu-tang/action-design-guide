# 承诺仪式与公开承诺（承诺卡周仪式 · 每日三问 · 内部压力）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 10 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f39`、`f44`、`p96`），不随公开版分发。

## I — Interpretation

本卡是抵触轴的**承诺族**：给已有的自我改变计划**加一个承诺 / 自省的格式**，靠「公开」制造责任感来稳住承诺。三件：

1. **承诺卡周仪式（f39）**：每周两两配对，就分阶段各写一个目标，周末分享并自省是否达成、为何没达成、下周如何改进。骨架＝「写分阶段目标 → 每周自省 → 改进」。
2. **每日例会三问（f44）**：每天问——昨天为目标做了什么？今天将做什么？看到什么障碍？给每日自省一个固定格式。**独处时「对团队公开」这一环不存在，须自行替换。**
3. **公开承诺规则（p96）**：一个人公开许下承诺时，自我说服的效力更强，因为「公开」本身带来责任感；**但作者给了一个警告：只有源自内部的压力才管用，一旦变成硬加的外部压力就会反噬，反而把抵触推高。**

本卡落在抵触轴的关键一侧：**公开承诺必须是内部压力**（我自发想晒出来的），一旦变成被人监督、被硬性考核的外部压力，就反过来放大抵触。这一侧是本卡与其他几本书承诺类能力的分界。

## A1 — Application Example

**主例（对外场景）· 拉杜瑟教练的承诺卡**（c105，`cited_third_party` / `reported_case`）

- 输入/问题：一位高中橄榄球教练想稳住队员对赛季目标的承诺。
- 怎么执行：用一张 3 厘米×5 厘米的承诺卡——每周把两名球员配成一组（每周轮换），球员就三个阶段的各写一个目标（调节 / 练习 / 比赛），每周结束时分享目标并自省是否达成、为何没达成、下周怎么改进。
- 结论/输出：作者报告该队领导 35 年、20 个完美赛季、1992 至 2003 年连胜。**注意：这是教练对球员（他人）的公开承诺仪式，不是自对己案例。** 数字 `原文未给出处`。

**辅例（对外场景）· 每日例会三问**（c111，`cited_third_party`）：软件开发团队每天早会用三个问题（昨天为团队目标做了什么 / 今天做什么 / 有什么障碍）制造公开承诺，打破孤岛、维持对目标的承诺。原文未给出处。

**合成演练（自我场景 · 明确标记）**

> 原书未提供自对己案例，以下为按原书规则设计的演练；**机制同源推断**，不是作者要你对自己这么用。演练已按要求把「对团队公开」一环替换掉。

- 输入/问题：我想一年内学会吉他，但总断。
- 怎么执行（照原书规则复算）：① 每周写三个阶段的各一个目标（基础练习 / 技能 / 表演）；② 周末自省是否达成、原因、下周改进；③ 公开对象只落在「内部压力」——只对我信任的一个人说，不上报、不被考核。
- 结论/预期输出：完成每周一轮「写目标—自省—改进」，且公开方式是自发的。**原书写的是教练对球员；自我版属机制同源推断，无作者给的自我场景完成标准。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题**

- 想给一个自我改变加个「逼自己不松懈」的机制，但怕变成压力反而更抵触。
- 想找一个固定的自省格式（每周 / 每天），防止计划漂移。
- 在纠结「要不要公开说出去 / 告诉别人」——想知道公开承诺到底帮不帮、会不会反噬。
- 已经有人在**外部监督 / 硬性考核**我，我却越来越不想做。
- 想要一个「写下分阶段目标 + 定期回看」的承诺仪式。

**2. 语言信号（中英双写）**

- 中文：公开承诺 / 许个承诺 / 写下来分享出去 / 承诺卡 / 每日三问 / 每周自省 / 被人监督反而更不想做 / 承诺会不会变成压力。
- English: public commitment / pledge / share my goal / accountability ritual / commitment card / daily standup questions / weekly reflection / being monitored makes it worse.

**3. 与相邻能力怎么区分**

- 与 resistance-self-persuasion（抵触自解）：那条是**卸掉命令**（把「必须」改造成结论）；本卡是**加承诺**（给计划加公开 / 自省字段）。
- 与 resistance-self-assessment：本卡是行动（加承诺），那条是诊断（定位抵触来源）。
- 与 resistance-mechanism-rules：本卡谈承诺，那条谈命令语言。
- 与 four-frictions-diagnosis：那条判主摩擦，本卡在抵触轴内给承诺格式。
- **与原子 `commitment-accountability`（承诺与问责）/ 原子「追踪与复盘」族（跨书）**：见下方分流句。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我设计一套每日打卡追踪、看数据复盘」→ 走原子「追踪与复盘」族（本卡只加承诺 / 自省字段，不做追踪系统）。
- 「我想靠外部监督 / 打卡群强制自己不偷懒」→ **不触发本卡**（外部硬性考核会放大抵触，本卡只保留内部压力一侧）。
- 「帮我把命令改写成结论」→ 走 resistance-self-persuasion。
- 「我不知道自己为什么抵触」→ 走 resistance-self-assessment。
- 「帮我整体戒掉熬夜」→ 走福格 `change-bad-habit-system`。

**分流句（本卡 ↔ 原子 `commitment-accountability` ↔ 原子「追踪与复盘」族，写死）**：靠**公开承诺制造责任感**这一请求，跨书已由原子的「承诺与问责」入口承接，本书**只保留「须落内部压力、被外部硬性考核会放大抵触」这一侧**——用它做「这个承诺是自发的还是被考核的」的甄别，不抢「怎么搭问责机制」的出招位；需要「追踪数据 / 定期复盘」走原子「追踪与复盘」族。

## E — Execution

### 输入契约

- **必需**：①一个已有的自我改变目标 / 计划；②该承诺打算公开给谁、会被谁监督（用于判「内部压力 vs 外部考核」）。
- **可选**：用周仪式（f39）还是每日三问（f44）。
- **缺**目标时先问；不许静默编一个。
- **适用条件**：请求是「给已有计划加承诺 / 自省格式」。若要整体戒除、要外部强制、要追踪系统，按 B 段分流。
- **临床红线**：涉成瘾 / 戒断 / 严重心理病理 → 不跑本流程，转介。

### 输出契约

**产出类型**：`patch`（给已有计划加承诺 / 公开字段）

可检查产物：

1. **一套承诺仪式格式**：周仪式（写分阶段目标 → 周末自省 → 改进）或每日三问（昨天做了什么 / 今天做什么 / 什么障碍）。
2. **一处「内部压力」标注**：明确公开对象是自发选择、不被考核；若发现是外部硬性考核，标红并改设计。

**完成标准**：当事人得到一份可照着做的承诺 / 自省格式，且能说出「这是内部压力、不是被人盯着考核」。

### 步骤

**第 1 步 · 判内部压力还是外部考核**
- 动作：问清这个公开 / 承诺是自发的，还是被某个外部对象硬性要求、计分、考核的。
- 完成标准：判定属「内部压力」或「外部考核」。
- 判停：**若是外部硬性考核 → 停在甄别，告知「被外部考核会放大抵触」，改设计或直接不做**（见 B 段），不进第 2 步。

**第 2 步 · 选格式**
- 动作：每周用周仪式（f39：三阶段目标 + 周末自省 + 下周改进），或每日用三问（f44）。
- 完成标准：选定一种并写明节奏。
- 判停：若走每日三问且是独处 → 跳到第 3 步替换「对团队公开」环。

**第 3 步 · 替换独处时缺失的环节（仅 f44）**
- 动作：独处时「对团队公开」这一环不存在，须替换——改成只对信任的一个人说、或写进自己的可见处（保持内部压力）。
- 完成标准：给出一个替代动作，且仍是内部压力。

**失败处理与回流**：第 1 步判为外部考核 → 回设计，去掉考核属性；第 3 步替代后仍像被别人盯着 → 收窄公开范围。

## B — Boundary

### 不要用（反场景）

- **想靠外部监督 / 硬性考核逼自己不偷懒** → 不触发本卡；作者明示硬加的外部压力只会反噬，本卡只保留内部压力一侧。
- 要一套**问责机制 / 契约 / 自动化**（锁死未来选项） → 原子 `commitment-accountability`。本卡只做一件事：判这个承诺是内部压力还是外部考核，并给出公开 / 自省的格式。
- 要一套**追踪数据 / 定期复盘系统** → 原子「追踪与复盘」族。
- 要**卸掉命令**（把「必须」改造成结论） → resistance-self-persuasion。
- **临床成瘾 / 戒断 / 严重心理病理** → 不跑本流程；对成瘾者劝说无效（x47），红线是转介。
- 整体戒除坏习惯 → 福格 `change-bad-habit-system`。

### 作者警告过的失败模式（反例素材）

- **外部压力放大抵触（p96 的核心警告）**：公开承诺须是内部压力；硬加的外部压力只会反噬，反而把抵触推高。
- **承诺的前提是目标一致**：拉杜瑟承诺卡的作者自加限定——教练和球员从一开始就目标一致，球员本就想要（c105）；**若我根本不想要这件事，公众承诺也稳不住**。
- **空洞的参与 / 承诺邀请基本无效**：只发一句「欢迎反馈」，让参与完全靠对方主动，大概率不发生（x52，`cited_third_party`）。

### 作者盲点与待核查

- **f39 的赛季 / 连胜数字原文未给出处**：领导 35 年、20 个完美赛季、1992 至 2003 年连胜——**均 `原文未给出处`，不得当可核实事实**。
- **f44 独处时缺一环**：「对团队公开」这一环在独处时不存在，须自行替换（本卡第 3 步）。
- **全书无「自己对自己改变」的案例或声明**：原书主语一律是「球员 / 团队 / 你的受众」，自我场景均为机制同源推断。
- **证据档（四档具名）**：f39＝`cited_third_party`（拉杜瑟承诺卡），f44＝`retold`（每日例会为泛例），p96＝`cited_third_party`（承诺卡规则）。凡引数字 / 实验一律「原文未给出处」，不写 strong/medium/weak。

### 相邻易混

- resistance-self-persuasion：加承诺（本卡）vs 卸掉命令（它）。
- resistance-self-assessment：加承诺动作（本卡）vs 定位抵触来源（它）。
- 原子 `commitment-accountability`（跨书）：同一「公开承诺造责任感」请求；本书只保留「须落内部压力、防被考核」一侧（它给问责机制出招）。
- 原子「追踪与复盘」族（跨书）：数据追踪 / 复盘系统走它，本卡只加承诺 / 自省字段。

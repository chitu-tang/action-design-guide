# 创建路线图：治模糊性（把「多做 X」改成「何时／何地／怎么做」）

## R — 出处（Reference）

本节方法论出自 Loran Nordgren & David Schonthal《The Human Element》第 1 章与第 6 章（2021；中译《人性阻力》）。
原文依据保存在私有工作区（溯源条目 `f19`、`f23`、`p04`），不随公开版分发。

## I — Interpretation

本卡治的是 Effort 二维中的**模糊性**那一维：想做却「不知道怎么做」，因而迟迟不动。

- **创建路线图**（f19）：把笼统的「我要多做 X」改写成一条**清晰路径**——**何时**做、**何地**做、**怎么**做。作者给两个作用：为行为创造「机会窗口」（何时做），并帮助人记住要做（如果—那么）。章末 3 问：能不能告诉人怎么实现？人知不知道什么时候该动手？能不能建一个如果—那么触发器？
- **补「怎么做」而不是再讲「为什么值得做」**（p04）：作者的英雄卡实验说明——讲好处、给报酬几乎无效甚至反作用，**给一份写作模板**才有效。障碍常不在「值不值得做」，而在「不知道怎么做」。
- **如果—那么触发器**（f23）：在记忆里建立「未来某个时刻」与「那一刻该做的正确行为」的清晰联系。它解决的是**忘记做**（不是坚决抵制）——很多不行动只是遗忘，出路是加提醒与触发点，而非加意志。

一句话：**模糊性不是靠更强的理由治好的，是靠「何时／何地／怎么做」与被记住的触发点治好的。**

**分流句（让位，须写明）**：本卡**只判能力卡、不单开入口**。因为扣掉「何时做」（归福格 `prompt-types`／`anchor-matching`／原子执行意图）与「如果—那么」（归 f23／原子执行意图）后，本卡只剩「**怎么做清楚**」这一薄面——它与福格／原子是**同一请求**，故经来源路由入口 human-element 访问，**出招仍走福格／原子**。

## A1 — Application Example

**⚠ 本书全书没有一处「自己对自己改变」的案例或声明，原书主语一律是「你的受众／人们／选民／球员」。** 下列原书案例**均为对外场景**（作者讲的是怎么推动别人）。凡要落到自己身上，只能写成**明确标记的合成演练**，并注明「**机制同源推断**」，不得冒充作者经历。

**主例 · 二战战争债券「何时买」海报**（c62，原书案例，`nature: third_party`，**对外场景**）

- 输入／问题：美国政府大卖战争债券，广告商做了大量激发爱国与恐惧的海报。
- 怎么执行：事实证明煽情与恐惧标语**都不是最有效的**；最有效的一张**不讲「为什么」**，只讲**「何时买」**——大意是在工作场所遇到律师请你签名认购时就买。
- 结论／输出：作者交代债券销售翻了一番（**原文未给出处**）。作者归因：它相当于给人一张**路线图**，消除了「如何捐赠、何时捐赠」的模糊性。**这是作者的对外传播案例，不是自对己案例。**

**辅例 · 破伤风疫苗「地图＋日程」标语**（c63，原书案例，`nature: third_party`，**对外场景**）：讲好处的标语、讲风险的标语都不是最有效的；附**诊所地图**并提示在日程里找时间的路线图标语，接种率从约 3% 升到 28%（**原文未给出处**，「一组心理学家」未点名）。

**辅例 · 英雄卡写作模板**（c02，作者自研实验，`nature: author_personal`，**对外场景**）：基础同意率只有 18%；展示受益儿童、发放报酬两组几乎无效甚至反作用；**给写作模板**的第三组成功率上升 60%（**原文未给出处**，作者自称「测试」）。

**合成演练（自对己；原书未提供自对己案例，以下为按原书规则设计的演练，机制同源推断）**

- 输入／问题：「我想每周写一篇文章，总不动笔。」
- 怎么执行（按 f19）：把「多做 X」改成清晰的**何时／何地／怎么做**——怎么做（选题→列 3 点→写 800 字→发）、何时（周三 20:00）、触发（晚饭后坐下即开，即一条「如果—那么」）。
- 结论／预期输出：得到一条含**时间与触发点**的清晰路径，模糊性下降。**此为按原书规则可复算的演练，不是作者原案例；机制同源推断，不写成「作者要你对自己这么用」。**

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 知道一件事值得做，却总不动笔／不开始，缺的是「第一步怎么做」。
- 反复对自己（或别人）讲这件事多重要，仍然没人动。
- 想做但「不知道具体什么时候做、在哪做、怎么做」。
- 常常不是不想，而是**忘**了——想给行为挂一个触发点。
- 想让某个行为有个清晰的行动计划（而不是又一个理由）。

**2. 语言信号（中英双写）**

- 中文：路线图／不知道怎么做／第一步做什么／何时何地怎么做／给个模板／我总忘了做／加个提醒／如果—那么／说再多理由也没用。
- English: roadmap / how-to / step-by-step / when and how / template / I keep forgetting / if-then / just tell me the first step.

**3. 与相邻能力怎么区分**

- **`friction-effort-diagnosis`**（上位·惰性总诊断）：那条**判维度**（消耗还是模糊性）；本卡接「已判为模糊性」后**出招**（把事说清楚）。
- **`streamlining`**（同轴·消耗侧）：本卡治「不知道怎么做」（模糊）；那条治「太费力」（消耗）。
- **`effort-troubleshooting`**（同轴·排障）：本卡给「怎么做」的路径；那条给两问排障与自我观察。
- **福格 `prompt-types`／`anchor-matching`、原子执行意图**（跨书·见分流句）：那是「何时做／靠什么触发」，本卡只剩「怎么做清楚」薄面，让位。
- **`four-frictions-diagnosis`**：那条判「卡在哪一类阻力」；本卡只在已聚焦模糊性时出场。

**4. 近邻负例（什么样的请求不该触发本卡）**

- 「帮我把这件事**排进日程／记住做**」（纯时点／提醒）→ 不触发本卡，走福格 `prompt-types`／`anchor-matching`／原子执行意图。
- 「帮我把这件事**变简单／拆到最小步**」（降低难度）→ 走福格 `make-it-easy`。
- 「我就是**没动力／不想做**」→ 走福格动机诊断；本卡前提是「想做、只是想不清楚怎么做」。
- 「我**知道了怎么做但还是不做**」→ 走 friction-effort-diagnosis 判消耗侧 / streamlining。
- 纯信息查询（「路线图是什么」）→ 走来源路由入口 human-element。

## E — Execution

### 输入契约

- **必需**：① 一件「想做却不动」的具体事；② 它当前的表述形态（多半是「我要多做 X」这样的**笼统意愿**）。
- **可选**：已有的时间／地点约束、已有的提醒方式。
- **缺**①时先问那件事，**不许静默替用户填步骤**。
- **适用条件**：模糊性侧（不知道怎么做 / 何时做 / 总忘）；纯消耗 / 纯动机问题不适用（见 B 段分流）。

### 输出契约

**产出类型**：`patch`（把「多做 X」改写成含「何时／何地／怎么做」的清晰路径，可附一条「如果—那么」触发）

- **输出**：一条清晰路径，含「怎么做」的步骤（+ 可选「何时／何地」+ 可选「如果 X 就做 Y」触发）。
- **完成标准**：当事人拿到后能说出「下一步我做什么、什么时候做」——模糊性可感地下降。

### 步骤

1. **改述**（f19）：把「我要多做 X」改写成「我在**何时、何地、以什么方式**做 X」。若说不出方式，先答「怎么做」。
   - 完成标准：产出一条含方式（＋可选时间 / 地点）的具体路径。
   - 判停点：若卡点其实是「太费力 / 步骤太多」→ 转 streamlining；若是「没动力」→ 转福格动机诊断。
2. **补 how-to 而非 why**（p04）：确认用户缺的是**做法**还是**理由**；若是前者，只补一份「第一步怎么做」的模板，**不再加一段「为什么重要」**。
   - 完成标准：产出一份可照着开工的首步模板（而非又一段说理）。
3. **挂触发点**（f23）：把行为挂到一个**具体的未来时刻**上，写成一条「如果 X，那么做 Y」（如「如果晚饭后坐下，那么打开文档写 800 字」）。
   - 完成标准：得到一条具体的「如果—那么」链接（若用户不要触发，可跳过）。
4. **边界自检**：确认产出的「何时做 / 如果—那么」部分**不越位承担福格 / 原子的活**——本书只保留「怎么做清楚」这一面，时点 / 触发对标已有卡（见 B 段分流句）。
   - 完成标准：卡内 / 答复标注了该让位，并把「变简单」的请求转出。

### 失败处理与回流

- 第 1 步改写过行仍不动 → 回到 friction-effort-diagnosis 重判维度（可能是消耗，不是模糊）。
- 用户要的其实只是「提醒 / 排日程」→ 转福格 `prompt-types`。
- 用户要「变简单 / 拆小步」→ 转福格 `make-it-easy`。
- 用户要「加理由 / 讲意义」→ 提示这通常无效（p04），改补 how-to。

## B — Boundary

### 不要用（反场景）

- **纯时点 / 提醒需求**（「排进日程 / 记住做」）→ 福格 `prompt-types`／`anchor-matching`／原子执行意图。
- **降低难度**（「变简单 / 拆小步」）→ 福格 `make-it-easy`。
- **没动力 / 不想做** → 福格动机诊断。
- **判「卡在哪一类阻力」** → four-frictions-diagnosis。
- **纯消耗问题**（知道怎么做，就是太费力）→ streamlining。
- 纯信息查询 → 来源路由入口 human-element。

### 分流句（**本卡只判能力卡、不单开入口**）

f19／f23／p04 三条撞的是**同一片请求**：福格 `prompt-types` / `anchor-matching` / 原子执行意图占住「**何时做 + 如果—那么**」，福格 `make-it-easy` 占住「**降难度**」。扣掉这些后，本卡只剩「**怎么做清楚**」这一薄面。裁定：**本卡判能力卡，不单开可发现入口，经来源路由入口 `human-element` 访问；出招仍走福格 / 原子的能力卡。** 本书不抢「何时做 / 降难度」的动作。双触发写进近邻负例。

### 作者警告过的失败模式（反例素材）

- **把「不主动」当态度问题、拒绝给路径**（x25）：领导者以「员工该有主动性」为由拒绝回答「何时、怎么做」，行为因模糊而**持续不发生**（原书强调，路径不清晰，行为就难得发生）。
- **用煽情 / 恐惧 / 讲意义替代路线图**（c62/x23；c63/x24）：战争债券与破伤风疫苗两组案例都表明，激发情绪与讲好处的标语**不是最有效的**，给「何时 / 在哪 / 怎么做」才有效。
- **只加理由不加做法**（p04）：英雄卡实验里，展示受益对象、发放报酬几乎无效甚至反作用，**只有给做法**有效。

### 作者盲点与待核查

- **数字未给出处**：p04 的「成功率上升 60%」、f23 / f22 的「乳房自检 70% 女性称遗忘」、战争债券「花费约 3 000 亿美元」均**原文未给出处**（作者自研实验亦无出处）。
- **全书无一处「自己对自己改变」的案例或声明**：本卡的自我场景是**机制同源推断**到自对己，不是作者给的自我场景。
- **f23 的独立内核很薄**：其独立价值是「忘记 ≠ 抵制」这条判别机制，只是一条机制，不是独立能力；本卡把它作「加触发点」的内部一步收着。
- **f19 第 3 问与 f23 部分重合**：f19 是路线图清单、f23 是「忘记 vs 抵制」的机制条，**不合并**。

### 相邻易混

- streamlining：本卡治模糊（不知道怎么做）/ 那条治消耗（太费力）。
- friction-effort-diagnosis：本卡是模糊侧的**出招** / 那条是**判维度**。
- effort-troubleshooting：本卡给清晰路径 / 那条给排障两问与观察。
- 福格 `prompt-types`／`anchor-matching`：本卡只留「怎么做清楚」/ 时点与触发归它们。

## 相关能力

- **friction-effort-diagnosis**（组合）：它**判维度**（消耗还是模糊性）；本卡接「已判为模糊性」后**出招**，把事说清楚。
- **streamlining**（对比）：本卡治**模糊**（不知道怎么做），它治**消耗**（太费力）。
- **effort-troubleshooting**（对比）：本卡给「怎么做」清晰路径，它给两问排障与「欲望之路」观察。
- **福格 prompt-types / 福格 anchor-matching / 原子执行意图**（对比·跨书，分流句）：那是「何时做 + 如果—那么」，本卡只剩「**怎么做清楚**」这一薄面，**让位**——本卡判能力卡、不单开入口，经来源路由入口访问，出招仍走福格 / 原子。

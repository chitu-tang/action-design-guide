# 决策规则速查 — 人性阻力

| 能力 | 一句话规则 |
|---|---|
| 抵触自解（把自我命令改造成自我结论） | 越逼自己越不动 / 抵触自己定好的计划时，走抵触自解：先按抵触三情形自检，再把自我命令改造成自我结论——用 1–10 自评加「我为什么不给自己打 1 分」逼出内部论据、 把「必须」改成「试行 N 周无效就重估」的实验、或让「现在的我」参与重设计；加推力、加截止日只会更反弹。 |
| 惰性诊断：消耗还是模糊（Effort 二维 · 摩擦类型学） | 一件事坐下来就卡住时，先判它卡在哪一维——「嫌花力气」（消耗）还是「不知道怎么做」（模糊性）；模糊走清晰化／路线图，消耗走流线化／减步骤；本书只定位，具体降难度动作走福格 make-it-easy。 |
| 情感摩擦诊断：找出负情绪来源（连问为什么 / 三类提问 / JTBD 定名 / 三种补救） | 有件事「该做却莫名不想做」、嘴上理由（太贵/没时间/不感兴趣）自己都不信时：先定名被威胁的价值类型（功能/社会/情感）→ 连问同一句「为什么」 或换三类提问挖真因 → 按来源只下一味补救（可试用/可回退/加支持）；要加正情绪走福格 celebration，要换措辞走原子 reframe。 |
| 阻力四格诊断 | 一件推不动的事，别先怪自己懒——先做归因纠偏（找情境摩擦而非内部归因），再按「变化程度 / 实施成本 / 威胁感 / 是否在施压」四问逐格过，指认主摩擦，分流到对应轴卡。 |
| 推动力与摩擦力框架（燃料侧总纲） | 任何「让新想法落地」的努力都同时受两种相反的力——推动力与摩擦力；默认只加推力是错的，先判断这件事卡在 推力侧还是摩擦侧、以及当事人正在用的是哪一类推力（循序渐进式 / 令人反感的）。 |
| 摩擦报告工作表 | 想照「四种心理摩擦力」给一个计划做一张诊断表、逐格过一遍时，走摩擦报告工作表——四格各给影响力（低 / 中 / 高） 与一句分析，圈出最大摩擦；一个人填时用「反方会怎么反驳」补回协作辩论这一环。 |
| 把陌生变熟悉（惯性轴的熟悉化 · 自我场景 4 招） | 一件新做法因「太陌生、不像自己会做的」而迈不动时，用自我版 4 招把陌生变熟悉：播种/重复 → 最小一步渗透 → 贴既有原型 → 熟悉类比 （删掉只对别人的「找熟人代言」）；要找时间锚点走福格 anchor-matching，要让线索显眼走原子 cue-design。 |
| 参考点管理与多选项（把单死命令扩成一组都能接受的方案） | 只用一条「必须……」的死命令时，它是在跟现状比、必输——把唯一选项改写成 ≥2 个都接受的方案，再按四步时间线选一条路径； 要把新做法变熟悉走 familiarization，要找时间锚点/线索显眼走福格/原子。 |
| 创建路线图：治模糊性（把「多做 X」改成「何时／何地／怎么做」） | 想做却不动、缺的是「第一步怎么做」时，把「我要多做 X」改写成「我在何时、何地、以什么方式做 X」，并补一份做法模板（而非再讲为什么值得做）、可选挂一条「如果 X 就做 Y」；时点与触发让位给福格 prompt-types / anchor-matching、原子执行意图。 |
| 流线化：减消耗（消障碍 · 找捷径 · 降低实施成本） | 一整条流程／整件事太费力、步骤太多、迟迟不开始时，把它的步骤逐个时刻摊开（体验时间线）、指认最摩擦的那一步，再搬走旁边挡路的障碍、找捷径、把动作塞进已有路径；本卡只做摩擦审计与定位，把一个行为砍小／拆到最小步这类纯出招走福格 make-it-easy。 |
| 惰性排障与自我观察（两问定位 · 从「自创捷径」读摩擦） | 说不清卡在哪，就问两问——「是什么让这个行为难以执行？」「怎么让它更简单？」；说不清摩擦点，就观察自己在做这件事时总绕开 / 将来哪一步（欲望之路＝人造捷径）；本卡只排障 / 观察，降难度出招走福格 make-it-easy、说清路径走 roadmap-clarity、盘出最摩擦那一步走 streamlining。 |
| 情感摩擦诊断清单（评估 2 问 · 多问为什么 3 问 · 观察 3 问） | 想要一组固定的情感摩擦自检问句时用它：评估 2 问量强度与价值面 → 多问为什么 3 问（症状 vs 病因 / 进步导向）→ 观察 3 问（看行为而非听话）； 要动手挖一个具体卡点并下药走 negative-emotion-source，还没判轴走 four-frictions-diagnosis。 |
| 抵触机制与规则（命令招反弹 · 问而不说） | 想弄清「为什么我越逼自己越反着来 / 命令为什么会招反弹」，或要认出自己嘴里的「必须 / 绝对不许」式命令语言时，走本卡：认出命令式 → 说清机制（威胁自主权）→ 守「问，但不说」的口径； 要实际把命令改写成能执行的东西，走 resistance-self-persuasion。 |
| 抵触自我访谈与自评（深度访谈 · 抵触自评 3 问） | 知道自己抵触某件事、却说不清怕什么时，走本卡给自己做一次深度访谈并把抵触自评三问过一遍：定位抵触来自「信念威胁 / 施压 / 被排除」中的哪一条、强度多大； 要动手把命令改写成结论，走 resistance-self-persuasion。 |
| 承诺仪式与公开承诺（承诺卡周仪式 · 每日三问 · 内部压力） | 想给已有计划加「公开承诺 / 定期自省」来防松懈时，走本卡：选周仪式或每日三问加承诺字段，并守住「公开对象须是自发的内部压力」； 一旦变成被人监督的硬性考核，就停手（外部压力会放大抵触）；要搭追踪 / 问责系统走原子的「承诺与问责」「追踪与复盘」。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》前言（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `p01`、`p06`），不随公开版分发。

（注：中文版首条作「停止自我批评」，英文原文是 `Stop judging yourself`（评判自己），口径更宽；英文正文另在别处有一句把自我批评本身也称作一种习惯，可视作对首条的解释。）

## I — Interpretation

这是一张**入门总纲 / 心态前提**卡，承载全书的**基调**与**粗纲**——它不是一条可执行的工作流，而是「动手之前该持有的姿势 + 这套方法整体长什么样」。由两个互补的半边组成：

1. **心态前提（`p01`）——行为设计成功的三件事：**
   - 停止评判自己（`Stop judging yourself`；作者指出自我批评本身也是一种习惯）；
   - 把你的愿望拆解成微行为（「我要更健康」不是行为，「上完厕所做两个俯卧撑」才是）；
   - 把错误当成「发现」来拥抱，并借它们继续改进。
   它的作用是把「没做到」从**性格问题**转译成**方法问题**——不自责、不追求一步到位。

2. **方法粗纲（`p06`）——微习惯策略一句话骨架：**
   拿一个你想要的行为 → 把它变小 → 找到它在生活中自然嵌入的位置 → 滋养它生长；想做出长期改变，最好从小处着手。

两个半边相互咬合：`p01` 第 2 条≈`p06` 的「make it tiny」，`p01` 第 3 条≈`p06` 的「nurture its growth」；`p01` 第 1 条（不自责）是执行 `p06` 的前提。合起来就是用户翻开这本书时该先接受的两句话：**别自责、从小处做。** 具体怎么做，再转到对应的能力卡（诊断 / 养成 / 改掉）。

## A1 — Application Example

**案例：作者拿自己做实验（原书亲历，`c05`，前言及行为设计相关章节）。**

- **输入/问题**：作者想把自己的行为设计成能长期融入生活的样子。他先试「很合理」的做法——每顿午餐吃一个橙子——结果坚持不下来；反倒是些「很傻」的微行为——如上完厕所做两个俯卧撑——成功了。为什么？
- **怎么执行（用本卡的心态前提 + 方法粗纲）**：
  - 心态①（`p01`）：不因「橙子计划失败」就评判自己，把它当成设计问题，而不是「我不行」。
  - 方法粗纲（`p06`）：不从「合理但太大」的行为起步，而是拿一个想要的行为、把它**变小**、嵌进既有生活情境（例如「上完厕所之后」）。
  - 心态③（`p01`）：把每一次「没坚持住」当成一种**新发现**，回到理论模型反复分析、调整方向。
- **结论/预期输出**：起步姿态＝不自责 + 从小处着手；遇到失败＝当发现并据此**重设设计**，而不是加码意志力。
- **真实结果**：6 个月后作者减重约 9 千克，体能与效率提升，累计养成数十个新习惯（原书亲历，作者自述；幸存者偏差，无对照样本、无量化实验）。

**补充（学员案例，`c02`）**：埃米被「做不到最好就干脆放弃」的心态卡住数月，接触微习惯后只在每天送完女儿后写**一条**待办、且回家立刻能做，最终公司成功开业。它演示的正是 `p01` 要破除的全或无心态。

## A2 — Future Trigger

**1）用户会在什么情境下遇到这类问题（3–5 条具体场景）**

- 准备开始行为改变 / 想用这套福格方法，先想知道「该带什么心态、这套方法整体长什么样」。
- 一失败就自责，把「没做到」当成品格或意志力缺陷。
- 陷入「做不到最好就干脆放弃」的全或无心态。
- 想先弄懂「微习惯」这套策略的骨架是什么、该从多小开始。
- 想给自己的行为设计定个基调：别贪大、别自责、失败了当发现。

**2）语言信号（中英双写关键 trigger）**

- 中文：这套方法到底怎么入手 / 微习惯到底是什么 / 要从多小开始 / 我是不是要求太高了 / 一失败就自责 / 我总想一步到位 / 想把愿望拆成小行为 / 怎么能不苛责自己。
- English: how do I start with tiny habits / what's the essence of tiny habits / how small should I start / stop judging myself / I always aim for perfect or nothing / I beat myself up when I fail / break my goal into tiny behaviors.

**3）与相邻能力怎么区分**

- `tiny-habit-design`（晋级）：**动手设计一个具体习惯**（7 步全流程）。
- `teach-in-2-minutes`（同册相邻）：用 2 分钟脚本**教别人**这套模型。
- `fogg-behavior-model`（来源路由入口）：整书概览 + 各能力卡的路由表。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs `tiny-habit-design`】**「帮我设计每天跑步的微习惯 / design a daily running habit for me」——用户要**动手设计一个具体习惯**，不是要心态和粗纲 → 不触发本卡，走 `tiny-habit-design`。
- **【vs `bmap-diagnosis`】**「我午休后想喝水，两周没做到，卡在哪」——对**一个具体行为**做归因 → 不触发本卡，走 `bmap-diagnosis`。
- **【vs `change-bad-habit-system`】**「帮我戒掉睡前刷手机」——目标行为**已发生、想让它停/换** → 不触发本卡，走 `change-bad-habit-system`。
- **【vs `teach-in-2-minutes`】**「怎么两分钟给别人讲福格行为模型」——诉求是**教别人** → 不触发本卡，走 `teach-in-2-minutes`。
- **【vs 来源路由入口】**「福格行为模型讲了什么 / 书里都有哪些方法」——只在**问来源、问整书** → 不触发本卡，走来源路由入口。

## E — Execution

**输入契约**

- 必需：用户处于「准备开始行为改变」或「想先了解这套方法的基调与骨架」的阶段。
- **判停 1**：要**动手设计一个具体习惯** → 转 `tiny-habit-design`。
- **判停 2**：要**诊断一个具体行为**为什么没发生 → 转 `bmap-diagnosis`。
- **判停 3**：要**终止 / 替换一个已发生的坏习惯** → 转 `change-bad-habit-system`。
- **判停 4**：只是**问来源 / 整书概览** → 转来源路由入口 `fogg-behavior-model`。

**步骤**

1. **给心态前提（`p01` 三件事）。**
   - 讲清：①停止评判自己（自我批评本身是习惯）；②把愿望拆成微行为；③把错误当「发现」并据此改进。
   - 完成标准：用户能复述并接受「不自责 + 把愿望拆小 + 失败当发现」这三条。

2. **给方法粗纲（`p06` 四段骨架）。**
   - 讲清：拿一个你想要的行为 → 把它变小 → 找到它在生活中自然嵌入的位置 → 滋养它生长；从小处着手。
   - 完成标准：用户能复述这条「选行为→变小→嵌入→生长 / 从小处着手」的全貌。

3. **指路（路由到下一步的能力卡）。**
   - 按用户的实际目标给出「下一步去用哪张卡」：诊断 → `bmap-diagnosis`；造新习惯 → `tiny-habit-design`；改掉坏习惯 → `change-bad-habit-system`。
   - 完成标准：用户拿到一个明确的「接下来做什么」的指向。

**输出契约**

**产出类型**：`none`（不产出配方，也不产出诊断）

- 固定结构：`{入门姿态：p01 的三件事}` + `{方法粗纲：p06 的四段}` + `{下一步路由}`。
- 完成标准：交付的是「心态 + 全貌 + 去哪继续」；**不产出**具体习惯配方、也不产出行为诊断结论（那是别的卡）。

## B — Boundary

**反场景（不要用本卡）**

- 要**动手设计一个具体习惯** → `tiny-habit-design`。
- 要**诊断一个具体行为**为什么没发生 → `bmap-diagnosis`。
- 要**终止 / 替换一个已发生的坏习惯** → `change-bad-habit-system`。
- 要**教别人**这套模型 → `teach-in-2-minutes`。
- 只想**问来源 / 看整书讲什么** → 来源路由入口 `fogg-behavior-model`。

**失败模式**

- **把 `p01` 讲成励志口号**：它的定位是「把没做到从性格问题转成方法问题」的**口径**，不是打鸡血。讲成「相信自己就一定能行」就跑偏了。
- **把 `p06` 当成完整流程**：它只是**粗纲**（一句话骨架），真正的分步流程在 `tiny-habit-design`（7 步）。停在这张卡会让用户以为「听懂了」就等于「会做了」。

**作者盲点 / 待核**

- **`p01` 是作者经验主张**：作者称三条基于「20 多年的研究、亲授 4 万余人」的实践验证，属**作者陈述**，非可复核实验；不得当作已证实的普适结论。
- **术语口径**：中文版把 `Stop judging yourself` 译成「停止自我批评」，比英文原文**窄**（英文正文另有一处把自我批评本身也称作一种习惯）；引用时以英文原词 `Stop judging yourself` 为准。
- **粗纲 ≠ 方法成立**：`p06`「从小处着手」是全书的格言式主张，其好处作者另有论证（`f12`，本册 reference），此处只作粗纲呈现，不为其效果背书。

**边界 / 安全**

- 本卡是**心态 / 总纲层**，**不承载任何安全判停**。若用户「想改变」的对象是成瘾 / 物质依赖（药物、酒精等），本册在改坏习惯线上**没有判停规则**（这是原书本身的缺口），不要停在这张入门卡，直接提示**寻求专业帮助（转介）**。
- 涉及「情绪创造习惯」等作者推测（`f26`、`f30`、`p53`）不得当作规律使用（`p53` 仅为 reference）。

**相邻易混**

- `teach-in-2-minutes`：诉求是**教别人**（2 分钟脚本）；本卡是**自己入门定位**（心态 + 全貌）。
- 来源路由入口 `fogg-behavior-model`：给的是**整书概览 + 各能力卡路由表**；本卡只是把「入门姿态 + 方法粗纲」讲清的一张小卡，不含全册路由。
- 本卡与 `tiny-habit-design` 的边界：**想入门/定基调 → 本卡；开始动手设计一个具体习惯 → 主卡。**

## 相关能力

- **teach-in-2-minutes**（对比）：本卡是「自己入门」的心态 + 方法粗纲；要把这套模型讲给别人听走它。
- **tiny-habit-design**（依赖）：本卡只给入门姿态和粗纲（选行为→变小→嵌入→生长）；真要动手设计一个具体习惯，下一步是养成主卡。

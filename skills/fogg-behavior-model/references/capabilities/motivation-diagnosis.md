## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 2 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f09`），不随公开版分发。

## I — Interpretation

本卡是 B=MAP 诊断里 **M（动机）这一格**的细分工具。它**不负责**行为有没有发生，只负责回答一个问题：当提示 P、能力 A 都已满足、行为却仍然没发生时，动机这一格到底出了什么状况、还能不能动它。

三件工具，按顺序用：

1. **动机不可靠的 5 个陷阱（`f09`）** —— 用来「祛魅」。它解释为什么靠动机推动改变会失败：①动机很复杂（可能有相互冲突、还被忽视的动机）；②动机波浪（Motivation Wave）——动机涨到顶峰后会迅速滑落（所以高动机只适合一次性难事，不适合长期习惯）；③动机波动极频繁（一天之内随时间与情境变化，无法被掌控）；④把动机用在「健康、自律」这类抽象概念上没有结果；⑤单靠动机撑不起长期改变。它的作用是把「我没做到」从「性格缺陷」重新解释成「依赖了一个不可靠的要素」。

2. **PAC 三来源（`f10`）** —— 用来定位动机到底从哪来。Person=你自己本就想要的；Action=做这个行为带来的利益或惩罚（胡萝卜与大棒）；Context=情境（周围人、社会氛围）。一个行为的动机可能来自一项或多项，也可能是相互冲突的多股力量。它的作用是判断这个行为为什么在你身上强或弱、哪股力量在推、哪股在拽。

3. **减少去激励因素（`p68`，英文原词 `demotivator`）** —— 这是本卡唯一直接给动作的地方。动机 = 「希望（激励）− 恐惧（去激励）」；所以设计的抓手是**减少或移除去激励因素**（恐惧、社交压力等），让自然的激励因素（通常就是希望）主导，而不是硬加奖励或施压。硬加激励常常同时抬高了压力与恐惧，反而让行为更难维持。

一句话：**动机是被诊断的对象，不是被「加油」的对象。** 你可以看清它的结构，但很少能靠加动机把它修好；真正的动作在「减负」。

## A1 — Application Example

**案例一：朱妮用行为设计戒糖（原书学员案例，`c03`，前言「原因5」+ 第07章）。**

- **输入/问题**：朱妮是芝加哥电台晨间主持人，家人因糖尿病相继去世，她**动机极强**（怕糖尿病、想为家人与自己活得更久），却屡次戒糖失败。问题：动机这么强，为什么还是做不到？
- **怎么执行（用本卡的三件工具）**：
  - **过 5 陷阱（`f09`）**：命中陷阱①「动机很复杂」——她既有「想戒糖」的动机，又有「想念母亲、用甜食应对悲伤」的冲突动机（两股力量方向相反）；命中陷阱⑤「仅凭动机无法长期改变」——靠决心硬撑正是失败模式本身。
  - **落 PAC（`f10`）**：P=想健康、想活下去（Person）；A=（无强利益/惩罚机制）；C=以甜食排解悲伤的生活情境。诊断结论：**问题不在动机不够，而在依赖动机**。
  - **动机侧动作（`p68`）**：不给「加油」，而是减负——清理休息室与冰箱里的甜食（削弱情境里的去激励/诱因）、用低糖零食替代、想母亲时改玩游戏而不是吃甜食（把冲突动机的出口换掉）。
- **结论/预期输出**：诊断＝「依赖动机 + 冲突动机」而非「意志力不足」；动作＝减少/移除去激励因素、替换出口，而非再加压力。
- **真实结果**：前言处只交代她「偶尔也会失控」，但不再自责（心态转变）；第07章完整结局——「毕业 3 个月后……她已靠行为设计与微习惯策略彻底戒掉嗜甜、摆脱糖瘾」。

**案例二：给派对发太阳镜促人跳舞（原书亲历，`c50`，第06章）——演示 `p68` 的「减负」侧。**

- **输入/问题**：作者想让人在「公司假日派对」上跳舞，默认障碍是社交恐惧（去激励因素），而不是缺兴趣。
- **怎么执行**：不硬加诱惑/压力，而是**弱化或移除恐惧**——关灯、先跳集体舞、先鼓励别人跳；在一次康健专业人士会议上，他干脆给每人发一副太阳镜来降低「被人看着」的社交恐惧。
- **结论/预期输出**：动作＝减少去激励因素（恐惧），让希望主导。
- **真实结果**：「这招很管用，还比酒精更健康、更得体。」（原书亲历，作者自述；无对照样本、幸存者偏差。）

## A2 — Future Trigger

**1）用户会在什么情境下遇到这类问题（3–5 条具体场景）**

- 已经排除了提示与能力的问题（提示在、也不难），可就是不想做、拖着不做。
- 想弄清某个行为的动机到底从哪来、为什么忽强忽弱、为什么会互相打架。
- 想「削弱」而不是「硬加」动机——越给自己/别人加压越抵触。
- 复盘「靠打鸡血、靠重新激发动力重启计划」为何反复失败。
- 评估一个「加奖励 / 加惩罚」的方案为什么反而让人更焦虑、更不想做。

**2）语言信号（中英双写关键 trigger）**

- 中文：我就是没动力 / 提不起劲 / 动机忽高忽低 / 一鼓作气再而衰 / 我明明很想做可就是做不到 / 为什么奖励惩罚都没用 / 越逼越不想做 / 想削弱动机该怎么做。
- English: I have no motivation / my motivation comes and goes / why don't rewards or punishments work / the more I push myself the less I want to / how do I weaken motivation / why can't I sustain it even though I really want it.

**3）与相邻能力怎么区分**

- `bmap-diagnosis`（晋级）：对「行为为什么没发生」做 **P→A→M 总排查**；只有 P、A 都满足仍不做，才轮到动机，才转本卡。本卡是它的 M 分支的细分。
- `fogg-behavior-model`（来源路由入口）：了解整书、或问书里某段怎么说。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs `bmap-diagnosis`，最重要的一条】**「我午休后想喝水，两周了就是做不到，卡在哪？」——还没做总排查，卡点完全可能只是**缺提示**。**先做总排查，别一上来就诊断动机** → 不触发本卡，走 `bmap-diagnosis`。
- **【vs `bmap-diagnosis` / 未具体化】**「我就是没动力，什么都不想干」——**没有落到具体行为**（哪个动作、什么时刻）。这既不触发总排查，也不触发本卡；**先把行为具体化**，再决定要不要排查。
- **【vs `tiny-habit-design`】**「帮我养成每天跑步的习惯 / help me build a daily running habit」——要造一个还不存在的新习惯 → 不触发本卡。
- **【vs `change-bad-habit-system`】**「帮我戒掉睡前刷手机 / help me quit scrolling at night」——目标行为已发生、用户想让它停或换 → 不触发本卡。
- **【vs 来源路由入口】**「福格说动机是怎么回事来着 / what does the book say about motivation」——只在**问来源、问书里某段**，没有具体行为要诊断 → 不触发本卡。

## E — Execution

**输入契约**

- 必需：一个**具体时刻的具体行为** + 「它没发生」的事实 + **P、A 已满足仍不做**这一前提（用户已试过补/换提示、降低难度，或能明确说出「提示在、也不难，但就是不做」）。
- **判停 0（前置）**：若还没做过 P/A 排查 → 本卡不启动，先走 `bmap-diagnosis`。**必须确认 P、A 都满足，否则「动机」不是当下的卡点。**
- **判停 1**：行为未具体化（「我太懒」「没动力」）→ 先具体化行为；具体化不了就停在这里，不往下诊断。
- **判停 2**：目标是「造新习惯」→ 转 `tiny-habit-design`；目标是「停/换已发生的坏习惯」→ 转 `change-bad-habit-system`。

**步骤**

1. **确认前提：P、A 已满足，行为仍不发生。**
   - 完成标准：能明确表述「这个时刻有提示、行为也不难，可我就是不做」。
   - 判停：任一不满足 → 停，回到 `bmap-diagnosis` 排查相应要素。

2. **查动机结构（先 5 陷阱，再 PAC）。**
   - **2a 过 5 陷阱（`f09`）**：逐一对照——动机是不是很复杂（有冲突动机 / 被忽视的动机）？是不是正处在「动机波浪」的回落段（高动机只适合一次性难事）？是不是在频繁波动？是不是在追「健康 / 自律」这类抽象概念？是不是把长期改变的支点押在动机上？
   - **2b 落 PAC（`f10`）**：把这个行为的动机拆成 P（你自己想要的）、A（行为带来的利益/惩罚）、C（情境）三来源，标出哪几股在推、哪几股在拽（冲突）。
   - 完成标准：给出「这个行为的动机为何强 / 弱 / 波动 / 冲突」的**定性结论 + 具体来源**（落到 P/A/C 与陷阱编号）。

3. **给动机侧动作：优先「减负」，而非「加压」（`p68`）。**
   - 默认动作：找出并**减少 / 移除去激励因素（demotivator）**——恐惧、社交压力、诱因情境等，让希望主导。
   - 若动机这一格客观改不动（如受外部硬约束）→ 用**替换规则**（`p15`）转去改能力或提示，别在不可控的动机上死磕。
   - 判停：若用户的真实诉求是「加点奖励/压力催一催」→ 先纠正——硬加激励会同时抬升压力，通常不是长效解，仍要落回「减负」或改 P/A。
   - 完成标准：给出**一个具体的「减少去激励因素」动作**；默认路径不是加奖励或施压。

**输出契约**

- 固定结构：`{动机诊断：命中的陷阱 + PAC 来源/冲突}` + `{动机侧动作：优先减少去激励因素（demotivator）}`。
- 完成标准：先给出动机的**结构与来源**判定，再给出一个**减负**动作；且启动前已确认 P、A 均满足（否则不算本卡的输出）。

## B — Boundary

**反场景（不要用本卡）**

- **还没做 P/A 排查**就下「动机问题」的结论 → 先走 `bmap-diagnosis`（这是本卡最要防的误触发）。
- 目标是从零**造一个新习惯** → `tiny-habit-design`。
- 目标是**终止 / 替换一个已发生的坏习惯** → `change-bad-habit-system`。
- 只想**了解模型 / 问书里某段** → 来源路由入口 `fogg-behavior-model`。
- 行为未具体化（「我就是没动力」）→ 先具体化行为，本卡不启动。

**失败模式（作者警告）**

- **从动机入手（`x07`）**：一上来罚款、摆脸色、讲道理——作者点名这是最先错的路径，第一步必须是查提示。
- **把「做不到」归因于意志力（`x09`）**：停在「我意志力不够」，放弃排查提示与能力。
- **高估未来动机（`x10`）**：在动机高涨的一刻（新年、冲动购物、收房当天）规划长期行为，默认未来的自己同样有劲头。
- **仅凭动机实现长期改变（`x11`，动机猴子陷阱）**：相信「想通了就能改变」，反复靠重新激发动力重启。

**作者盲点 / 待核**

- **作者对动机的立场是「立场」而非定论**：作者把动机定性为「善变、冲突、不可靠」，据此主张别把改变的支点放在动机上。这是本册作者的框架（`f09`/`f10` 的 5 陷阱与 PAC 均为作者模型），主流心理学对动机 / 意志力的看法并不一致；本卡按作者口径使用，**不外推为普适规律**。
- **「动机很复杂」的佐证无量化实验**：作者引慧俪轻体等观察，未给量化效果（`f09` summary）。
- **命名碰撞**：PAC 在全书三处复用——动机来源（`f10`）、提示分类（`f18`）、能力三方式（`f15`）——同一命名指不同三分，别混为一条。
- **「情绪创造习惯」等作者推测**（`f26`、`f30`、`p53`）不得当作动机规律使用（`p53` 仅为 reference）。

**边界 / 安全（存量风险，必写）**

- **成瘾 / 自由落体型行为无判停规则**：改坏习惯这条线上遇到药物、酒精等成瘾或自由落体型目标，本册**没有判停规则**（原书未给；作者对「哪些坏习惯不适用本方法」自限，唯一相关的硬边界 `x40` 仍属参考级）。**碰到这类目标，不要硬套「动机诊断 / 削弱动机」，直接提示寻求专业帮助（转介）。**
- **强动机 + 高依赖**（如朱妮的糖瘾，`c03`）虽是本卡的示例，但其可操作解法依赖「行为设计 + 专业训练营」；个人自行削弱动机可能不足，需如实提示边界。

**相邻易混**

- `bmap-diagnosis`：本卡只是它的 **M 分支**；P、A 任一不满足时**不要**走本卡。
- `celebration`：庆祝是把即时情绪接进习惯（第 6 步机制）；本卡说的是「想不想做的欲望」。别把「设计庆祝」当动机调整。

## 相关能力

- **bmap-diagnosis**（依赖）：本卡只是 B=MAP 诊断的 M 分支——必须先做过 P→A→M 总排查、确认提示与能力都满足，才能启动本卡的动机细分。

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》结语（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `p97`），不随公开版分发。

**出处说明（术语，硬错点）**：中文版把这两个过滤器称作「福格**原则**」，**英文原书用的词是 `Fogg Maxim #1 / #2`**（**不是** `Fogg Principle`，原书无此词）。两条的正式英文名见原书第 6 章与第 9 章，合集名作 `Fogg Behavior Maxims`。中文版附录也直写「比如福格原则」，是 Maxim 的对译。

---

## I — Interpretation

这是一张**把两条福格格言当作准入过滤器**的决策规则：当你拿到一个**外界现成的**方案 / 计划 / 工具 / 建议时，用两个问题快速判断「**该不该投入时间**」。

两条过滤器：

1. **`Fogg Maxim #1`**——它是否帮你做**你本来就想做**的事？
2. **`Fogg Maxim #2`**——它是否帮你**感受到成功**？

判定规则很简单：**只要有一个答案是否定的，这套方案就不值得你花时间**（`p97` 原文 `it's not worth your time`）。两个都过，才说明「方向对」，可以进一步考虑。

它的作用对象是「**任何外来的方法论 / 课程 / 工具 / 别人给的建议**」，**不专属《福格》内容**——因此本卡标 `cross_book`（跨书通用）。它与 group-ethics-guardrail **同源、同两条 `Fogg Maxim`**，但**输出契约相反**：本卡是**自己**当决策者去**筛外部方案**；那张卡是**约束自己去影响别人**（别越界成操纵）。二者**只建链接、不合并**。

一句话：**拿到别人的方案，先问「帮我做我想做的吗？帮我感受成功吗？」——两个都过才值得投入。**

## A1 — Application Example

**主例 · 朋友发来一套新运动/饮食计划**（`nature: 原书举例场景`，`p97` 原文，结语）

- **输入/问题**：朋友发来一封邮件，推荐一套**新的运动或饮食计划**；你不知道该不该投入时间去试。
- **怎么执行**：快速扫一遍，只问两个问题——**①它能帮你做你本来就想做的事吗？②它能帮你感受到成功吗？**
- **结论/输出**：原文明确——「答案或肯定或否定，但只要有一个为否，就说明这事不值得花时间」。
- **结果**：**原书未交代该具体计划（或任何一例）的后续实际结果**，标「未说明」——本卡不补结局。

**说明性对照（供识别「过/不过」）**：若某方案要求你做**你本不认同、不想要**的改变（`Maxim #1` 不过），或全程只有压力、从不给你「成功感」（`Maxim #2` 不过）——**任一不过即判「不值得投入」**，与原文判停一致。（原书未展开更多实例。）

## A2 — Future Trigger

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 朋友/教练/博主/导师**推荐了一套现成的方案**（运动计划、饮食法、生产力工具、课程、App），问「**值不值得试 / 该不该采纳**」。
- 公司或团队**推来一套新的改革/管理办法**，你被要求配合，想知道该不该投入。
- 面对一堆**互相打架的自助建议**，想要一个**快速筛子**先把噪声过滤掉。
- 拿到别人给的一份「**为你好**」的计划，直觉不太对，想有个客观标准判断要不要花时间。
- 要评估一个**外界工具/服务**是否真的服务于自己已有的目标。

**2. 语言信号（中英双写）**

- 中文：这套方法该不该采纳 / 值不值得花时间 / 别人推荐的计划靠谱吗 / 这个课程要不要报 / 这个工具值不值 / 怎么过滤外界建议 / 帮我筛一下这个方案。
- English: should I adopt this program / is this worth my time / should I try this plan / how do I filter outside advice / will this help me / worth investing in.

**3. 与相邻能力怎么区分**

- **本卡 vs group-ethics-guardrail（最易混）**：**同源、同两条 `Fogg Maxim`，只建链接不合并**（gate-c §3）。分界——**本卡 = 筛「外部给我的现成方案」要不要采纳**（自己当决策者）；**group-ethics-guardrail = 约束「我自己去影响别人」时有没有越界成操纵**。一句话：**决策者是自己、对象是外来的方案 → 本卡；决策者是「我」、对象是「别人」的行为 → 护栏卡。**
- celebration：那张谈的是「**自己给自己**做即时庆祝、感受成功」（`Fogg Maxim #2` 的个人落地）；本卡只是把 `Maxim #2` 用作**筛外部方案**的一个问题，不负责设计庆祝。
- 来源路由入口 fogg-behavior-model：只在「想了解模型本身」时触发；本卡用在「已有一个外部方案要过滤」时。

**4. 近邻负例（什么样的请求不该触发本卡）**

- **【vs group-ethics-guardrail】**「我想让下属周末加班以『帮』他晋升，这样算不算操纵？」→ **不触发本卡**（对象是**别人**的行为、要判越界），走 group-ethics-guardrail。
- **【vs tiny-habit-design】**「帮我设计一个每天读书的习惯」→ 不触发本卡（这是**自己设计**），走 tiny-habit-design。
- **【vs bmap-diagnosis】**「我为什么坚持不了健身，卡在哪？」→ 不触发本卡（自我诊断），走 bmap-diagnosis。
- **【vs change-bad-habit-system】**「帮我戒掉游戏」→ 不触发本卡，走 change-bad-habit-system。
- **【vs 来源路由入口】**「福格行为模型讲的是什么」→ 走 fogg-behavior-model。
- **【vs 方案评估/尽调】**「帮我做一个完整的竞品/健康方案评估报告」→ 本卡只是**两问快速过滤**，不替代对方案本身证据、成本、风险的深入评估；超出两问范围的部分不回本卡。

## E — Execution

### 输入契约
- **必需**：① 一个**外界现成的**方案 / 计划 / 工具 / 建议（不是用户自己设计的东西）；② 它**声称帮你达成什么**（要能说清「它帮你做什么」）。
- **可选**：用户**本来就想做的事**是什么（判断 `Maxim #1` 需要）——缺此项时先问，**不许替用户假定他的目标**。
- **判停**：若对象其实是「**我要去影响别人**」→ 转 group-ethics-guardrail；若用户要的是**自己设计**一个习惯 → 转 tiny-habit-design。

### 输出契约
一份过滤结论 = `{Maxim #1：是 / 否}` + `{Maxim #2：是 / 否}` + `{结论：值得投入 / 不值得花时间}`。
- **完成标准**：对两个问题都给出明确「是/否」，并据「任一为否 → 不值得投入」得出可执行结论；能说清每个判定依据什么。

### 步骤

1. **过 `Fogg Maxim #1`。** 问：**它帮你做你本来就想做的事吗？** 先写下「你本来就想做的是什么」，再看该方案是否服务于它。
   - 完成标准：给出明确「是 / 否」，且「你想做的」有据（是用户自己说的，不是你替他假设的）。
2. **过 `Fogg Maxim #2`。** 问：**它帮你感受到成功吗？**（注意是「**感受到**」成功，不只是「最终可能成功」。）指出方案里哪一步会给人成功感。
   - **「成功感」不是外部奖励**：徽章、积分、排行榜、连续打卡天数、排名/落后提醒——这些是**外部奖励或外部反馈**，不能据此把 `Maxim #2` 判为「是」。参照本册 `celebration` 卡的分野：成功感是**当下自己产生的那种感觉**（即时、内在）；靠外部排名与断签惩罚驱动的方案，实际是在让人**躲失败**，不是感受成功。外部奖励可作辅助，但不能充抵这一问。
   - 反过来说：若方案里**根本没有**让人当下感到「我做到了」的环节，只有要求、压力或「最终会成功」的许诺 → 判「否」。
   - 完成标准：给出明确「是 / 否」，并指明依据。
3. **出结论（判停点）。** 两条都「是」→ **值得投入**（仍需你自己做进一步评估）；**任一「否」→ 不值得花时间**（`p97` 原文 `it's not worth your time`），到此结束，不再替它找理由。
   - 完成标准：产出 `{Maxim#1, Maxim#2, 结论}` 三元组；判定为「不值得」时不再往下推进该方案。

### 失败处理
- 第 1 步用户说不出「自己本来想做什么」→ 先明确愿望，再回来过滤（`p97` 假定你已知道自己想要什么）。
- 第 2 步方案「最终会成功」但**过程中无成功感** → 判 `Maxim #2` 为「否」（原文强调「感受成功」，如庆祝侧的即时反馈）。

## B — Boundary

### cross_book 定位（元数据说明——给本册维护者，不是给使用者）
- 本卡在清单里标 `cross_book`：它服务的是「**拿到一个外界提出的现成方案，要不要投入**」这一**跨书通用**决策，作用对象是「**任何外部方法论**」，**不专属《福格》本册内容**。因此它的长远归属是**多书产品层**（该层在本册单册包里**不存在**，本册也不依赖它），**不占《福格》本册的晋级名额**（本册晋级 Skill 恰为 3 个：bmap-diagnosis / tiny-habit-design / change-bad-habit-system）。
- **在《福格》单册内怎么用它**：就当一张普通的能力卡，按路由表的「用户意图」列照常加载，无需任何额外入口。本节只是归属说明，不含操作指令。

### 不要用（反场景，按分流）
- **对象是「别人」的行为、要判越界成操纵** → group-ethics-guardrail（同源同两条 Maxim，只链接不合并）。
- **要自己动手设计一个习惯** → tiny-habit-design。
- **要自己诊断某行为为何没发生** → bmap-diagnosis。
- **要自己改掉坏习惯** → change-bad-habit-system。
- **要自己给自己做庆祝/感受成功** → celebration。
- **要深入评估一个方案（成本/风险/证据/尽调）** → 超出本卡两问范围，需另行评估。

### 作者盲点 / 使用边界（★ 写清本卡是「快速过滤器」而非充分评估）
- **两问是必要条件、不是充分条件。** 「两个都过」只说明方案**方向对**（帮你做想做的、给你成功感），**不等于**方案**科学有效、无害、成本合理**。**不要**把「过了两问」当成「可采纳」的充分证明。
- **`p97` 建立在「你已知道自己想做什么」的前提上。** 若用户尚未明确愿望，第一问无从判起——此时应先回去明确愿望（tiny-habit-design 第 1 步或 behavior-design-primer），而不是硬填一个答案。
- **作者未给「多大程度算帮你做想做的事 / 帮你感受成功」的量化阈值**：两问是**定性**过滤器，不要自造评分或刻度。
- **与 group-ethics-guardrail 的边界是本卡的第一红线**：**筛外部方案 → 本卡；约束自己去影响别人 → 护栏卡**。两张卡共用 `Fogg Maxim #1/#2`，**只建链接、不合并**（输出契约不同）。
- **术语硬约束**：两条用词是 **`Fogg Maxim #1 / #2`**，**原书无 `Fogg Principle`**；引用时不得写成「福格原则」作为原书用词。

### 相邻易混
- group-ethics-guardrail：同源同两条 `Fogg Maxim`，**只链接不合并**（筛外部方案 vs 约束自己去影响别人）。
- celebration：`Maxim #2`（感受成功）的**个人庆祝**落地 vs 本卡把它当**外部方案过滤器**。

## 相关能力

- **group-ethics-guardrail**（对比）：同源、同两条 Fogg Maxim——本卡是「自己采纳外界现成方案」的准入过滤，它是「我去影响别人时」的伦理护栏；只链接不合并。
- **celebration**（对比）：本卡把 Fogg Maxim #2 用作「筛外部方案」的一个问题；「自己给自己做即时庆祝、感受成功」的落地走它。

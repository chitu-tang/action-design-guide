## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 5 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f26`、`p54`），不随公开版分发。

**出处说明（关键精度）**：`p54`「奖励 vs 激励」的原始判据在这里。中文版把 `milliseconds afterward`（之后**几毫秒内**）磨成了「行为结束之后的那一刻」，并漏译 `directly tied to a behavior`（与该行为直接绑定）——**「即时」到毫秒级正是庆祝起作用的核心判据**（激励坏就坏在「间隔太久」），故本卡一律按英文原词理解，不采译本的说法。

## I — Interpretation

这张卡处理的是**庆祝本身**：什么时候用、什么算「即时」、它凭什么能固化行为。它不是一套从零养习惯的流程（那是 tiny-habit-design 的 7 步），而是喂给那条流程第 6 步的**机制层 + 判据/规则层**。

骨架分三块：

1. **机制层**——作者的主张是：行为的**即时正向情绪**触发大脑的奖励预测误差，神经元据此调整多巴胺、把该行为**编码**成「值得重复的事」。所以强化必须发生在行为进行中或刚结束那一刻；这也是作者用来反驳「靠重复/靠天数表创造习惯」的论据。（**该机制本身可靠性见 B 段——属作者主张、本册无独立实证**。）f26 附带一条解释工具 f27「自动化度光谱」：左端是决策、右端是强习惯，即时积极情绪把行为在光谱上向右推。

2. **判据层（最可执行）**——p54 给出「奖励 vs 激励」的分界：奖励是**与该行为直接绑定、并提升再发生概率**的即时体验，必须在行为中或**之后几毫秒内**；延后发生的（月底按摩、销售奖金）是**激励**，来不及给大脑编码，无法固化习惯。p56 给出庆祝的**唯一规则**：说点什么或做点什么（心里默念也算），只要让你感觉良好、产生成功感即可——形式不限，但**必须自然**，强颜欢笑适得其反。

3. **规则层（何时庆祝）**——f29 三个时机：①想起要做的时刻（固化「记得住」）②正在做的时刻（关联过程）③刚做完的时刻（固化行为）。p63 两种重新庆祝的场景：习惯中断后重启、以及想扩大规模时（用庆祝抵消升级带来的痛苦，维持习惯活力）。

一句话：**选一个自然、真切、能让你当场「发光」的动作，紧贴行为那一刻做，用它替代延后的「奖励」。**

## A1 — Application Example

**主例 · 作者牙线后的「胜利！」（庆祝的起源）**（`nature: 原书亲历`，`c36`，第 05 章）

- **输入/问题**：作者处于低谷期（业务不顺、外甥去世、长期焦虑失眠），想找一件「即使今天所有事都出错、至少还不是彻底失败」的事。
- **怎么执行**：他刷牙时用牙线清洁了牙齿，对着镜子里的自己微微一笑，说出一个词：**「胜利！」**（这正是三时机里的第 ③ 个——**刚做完那一刻**的即时庆祝；因为是口头即时动作，符合 p56「说出点什么 + 自然」）。随后他把这类「胜利宣言」与其他新习惯融合，每次做完就立刻庆祝。
- **结论/输出**：他察觉到庆祝动作与习惯养成之间的联系——把它加进去，新习惯就更容易扎下根。庆祝从此成为微习惯策略的核心。
- **原书交代的结果**：他做庆祝动作后更容易养成新习惯。
- **注**：这是作者自述（`c36.notes`：幸存者偏差，作者亲历）；机制层面的「为什么有效」属待核查，见 B 段。

**对照例 · 延后奖励为什么无效**（`p54`，`nature: 原书举例`）：原文另举「把晚上看电影当成早上做俯卧撑的奖励」这种安排——因为奖励发生在几小时之后，已超出「行为中或之后几毫秒内」，属**激励**而非奖励，**无法为大脑编码习惯**（原书未交代该计划的后续结果，标「未说明」）。

## A2 — Future Trigger

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 知道该庆祝，但不确定**做完习惯后多久之内庆祝才有效**（「下班回家做完了，晚上再奖励还来得及吗？」）。
- 自己定了一个**延后的奖励**（攒够 N 次 / 周末大餐 / 月底按摩 / 奖金），做完却没感觉、习惯也没养成。
- 想设计一个**庆祝动作**，但觉得「举手喊胜利」很假、很尴尬，问有没有更自然的方式。
- 习惯已经养成、或中断了一阵子，问**还要不要继续庆祝、什么时候该重新庆祝**。
- 问「为什么庆祝真的有用」/「为什么说情绪能创造习惯」，想搞清底层原理再决定要不要用。

**2. 语言信号（中英双写）**

- 中文：庆祝 / 奖励 / 怎么庆祝 / 庆祝的时机 / 即时 / 为什么庆祝有用 / 庆祝要多自然 / 奖励没用 / 积攒奖励 / 中断了还要不要庆祝 / 情绪创造习惯 / 发光。
- English: celebration / reward vs incentive / when to celebrate / immediately / how to celebrate naturally / why does celebration work / emotions create habits / keep the habit alive / Shine.

**3. 与相邻能力怎么区分**

- tiny-habit-design（本册晋级技能）：那是**从头养成一个习惯的完整 7 步**；本卡只承载其中**第 6 步「庆祝成功」的机制与规则**。区分口诀——**要「整体养成一个习惯」→ 主卡；只问「庆祝本身怎么用/为什么有效/什么时候庆祝」→ 本卡**。
- affirmation-messages（群体卡）：那张是**给别人**的肯定话术矩阵（对他人说）；本卡是**自己给自己**的即时情绪固化（对自己做）。
- habit-growth：那张卡管习惯「生长/繁殖」的机制与目录；本卡管**庆祝这一强化手段**本身。二者在「扩大规模」处相邻——扩大规模时**用什么固化**看本卡，**怎么扩大/何时扩大**看 habit-growth。
- 来源路由入口 fogg-behavior-model：只在「想了解整套模型本身」时触发，不解决「我的庆祝怎么设计」「我的奖励为什么没效果」。

**4. 近邻负例（什么样的请求不该触发本卡）**

- **【vs tiny-habit-design】**「我想从零养成每天跑步的习惯，给我一套方案」→ 不触发本卡；这是**整体养成**，走主卡（主卡的第 6 步会**内联**用到庆祝，但用户诉求是全流程）。
- **【vs tiny-habit-design 内的庆祝步骤】**「在我刷完牙之后，我会用牙线，然后要做什么庆祝？」——若用户要的是**一条完整配方**（锚点 + 微行为 + 庆祝），走 tiny-habit-design；只有当他**只问庆祝这一环**（时机/是否即时/为什么有效/怎么找自然方式）时才落本卡。
- **【vs affirmation-messages】**「怎么夸同事才不空洞 / 给我一句鼓励下属的话」→ 不触发本卡，走 affirmation-messages（对**别人**的肯定）。
- **【vs change-bad-habit-system】**「我想戒掉睡前刷手机，帮我设计终止方案」→ 不触发本卡，走改掉坏习惯系统。
- **【vs bmap-diagnosis】**「我为什么总做不到早起，是动机还是能力问题？」→ 不触发本卡，走 B=MAP 诊断。
- **【vs 来源路由入口】**「福格行为模型是什么 / 这本书讲了啥」→ 走来源路由入口 fogg-behavior-model。

## E — Execution

### 输入契约
- **必需**：① 一个**已发生（或即将执行）的具体行为**（如「刷完牙用牙线」）；② 你打算用来强化的**候选动作或奖励**（可以是「想不出，帮我找一个」）。
- **可选**：该习惯当前是否已自动化、是否刚中断/要扩规模、偏好的庆祝风格。
- **缺**① 时先问是哪条行为，**不许静默假定**一个行为；若用户其实要给**别人**肯定，按 B 段转 affirmation-messages。

### 输出契约

**产出类型**：`patch`（给已有设计换零件：即时庆祝）

一份庆祝方案，含三个可检查产物：
1. **≥1 个即时庆祝动作**（自然、真切、当场可做）；
2. **一次「即时性」判定**：明确它是**奖励**（行为中 / 之后几毫秒内）还是**激励**（延后，需重设计）；
3. **庆祝时点与重启条件**：三个时机怎么排、满足什么条件时需重新庆祝。

**完成标准**：用户能说出「做完这一步我就立刻做 X」以及「什么情况下我会重新开始庆祝」。

### 步骤

1. **判「即时」（奖励 vs 激励）。** 看候选强化物相对行为发生的时间：在**行为过程中**或**结束之后几毫秒内** → 是**奖励**（可固化）；间隔明显更久（等几小时、攒够 N 次、月底/周末）→ 是**激励**，不能固化习惯。
   - 完成标准：给出明确判定「奖励 / 激励」；判为激励则进入第 2 步重设计，**不允许**把延后奖励直接当庆祝用。
2. **找自然的庆祝方式（p56 唯一规则）。** 让它**说点什么或做点什么**（心里默念也算），只要当场产生良好感受、成功感即可；形式不限。优先挑**不尴尬、真能发光**的动作。
   - 完成标准：产出 ≥1 个动作，且用户自评「做起来自然、不假」。
   - 判停：若用户觉得尴尬/强颜欢笑 → 换更私人、更自然的方式，但**「即时 + 真切」两条硬要求不改**（x24）。
3. **排三个时机（f29）。** 分别安排：①**想起**要做的时刻 ②**正在做**的时刻 ③**刚做完**的时刻的庆祝动作（可同一动作，也可不同）。
   - 完成标准：三个时机各给出至少一个具体动作或写明「此场景从简」。
4. **判当前自动化度（f27）。** 用自动化度光谱定位该习惯在「决策 … 强习惯」上的位置：越靠右越自动化，可减少日常庆祝频率。
   - 完成标准：给出「左 / 中 / 右」定性定位，并据此说明是否仍需高频庆祝。
5. **设重启条件（p63）。** 标注两种需重新庆祝的场景：①**中断后重启**（度假/搬家/生活打断）；②**想扩大规模**时（如从 2 个俯卧撑扩到 25 个，用庆祝抵消痛苦）。
   - 完成标准：写下「什么情况触发重新庆祝」的明确条件。

### 失败处理与回流
- 第 1 步判为激励 → 回第 2 步换成即时庆祝动作。
- 第 2 步方式不自然 → 换方式（硬要求不变）。
- 若用户其实要的是**完整习惯方案**，或要给**别人**肯定 → 按 B 段分流。

## B — Boundary

### 不要用（反场景，按分流）
- **要整体设计/养成一个习惯（含锚点、配方）** → tiny-habit-design（第 6 步内联庆祝；本卡只是它的机制/规则展开）。
- **要给别人的肯定话术** → affirmation-messages（对**他人**的话术矩阵，不是自我固化）。
- **要戒掉/减少一个坏习惯** → change-bad-habit-system（个人级终止练习可配 quit-habit-exercise）。
- **只想了解这套模型本身** → 来源路由入口 fogg-behavior-model。

### 本卡必须写清的存量风险（不得当规律/已证实结论用）
- **f26「情绪创造习惯」是作者主张，本册无独立实证。** 作者主张「不是靠重复、而是靠即时情绪创造习惯」，我们在核验中已标**待核查**：作者无可复核的实验依据，且该主张与**主流习惯研究**（强调**语境稳定性与重复**）**存在张力/冲突**。**不得把「情绪创造习惯」当作已验证的普适机制**；本卡的可执行部分是**判据（即时 + 真切）**，不是这套底层机制。
- **「66 天」属中文版**推荐序**污染，不是作者的话。** 英文原书**全文没有「66 天」**这一说法；对应的原文是 **`twenty-one or sixty days`**（21 或 60 天），作者在该处的本意其实是**否定**「存在魔法天数」。「66 天」出自**中文版序**（他人所写），传为作者观点属误植。**本卡 R / I 段一律不使用该数字**；提及只用于标明它是推荐序污染。
- **涉及「重复次数」时的纪律（f30，其条目在 tiny-habit-design）。** 「演练 7–10 次即固化」**不是译本加的**——英文原文也是 `seven to ten times`；但作者同书自陈 `I predict…`，并说没有人这么提倡过（此前无人主张），**属作者推测、无实验依据，不许当规律用**；本卡在讨论「庆祝要重复几次」时同样守这条。
- **机制陈述随 f26 一并标待核查**：作者命题「设计习惯=设计情绪」（`p53`）为同一待核查命题，`p53` 本身属 reference，不得当独立结论引用。

### 作者盲点
- **庆祝的底层机制待核查**（见上）；作者未给样本量/效应值/发表位置。
- **语境偏中产/职场/知识人群**（见本书整书理解「作者的时代局限」一节）：庆祝「不花钱、人人可用」的陈述在结构性贫困、抑郁、成瘾等处境下未必成立。
- **庆祝 vs 激励的界线作者给得清楚，但「多快算即时」只有「毫秒级」这一条量化锚点**（p54）；不要把它扩写成「几秒/几分钟也行」的自造阈值。

### 相邻易混
- tiny-habit-design：**全流程** vs 本卡的**机制/规则单点**（见 A2）。
- affirmation-messages：**给别人的肯定** vs 本卡**给自己的情绪固化**。
- habit-growth：那张卡管习惯「生长/繁殖」的机制与目录（f32–f35）；本卡管**庆祝这一强化手段**本身。二者在「扩大规模」处相邻——扩大规模时**用什么固化**看本卡，**怎么扩大/何时扩大**看 habit-growth 与 tiny-habit-design 第 7 步。

## 相关能力

- **tiny-habit-design**（组合）：养成全流程；本卡只承载其中第 6 步「庆祝成功」的机制与规则。
- **affirmation-messages**（对比）：本卡是「自己给自己」的即时庆祝固化；它是「给别人」一句对症的肯定。
- **habit-growth**（组合）：扩大规模时「用什么固化」看本卡，「怎么扩大/何时扩大」看它。

# 珍珠习惯（Pearl Habit · 把烦人的事转成提示）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 4 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f23`），不随公开版分发。

**来源陷阱提醒（必读）**：中文版里那个「**蚌把砂砾包裹成珍珠**」的比喻，出自本书**中文版的推荐序（梁宁）**，**不是作者 BJ Fogg 的正文**（依据见 `t24` 的核验记录）。因此本卡 R 段取**作者正文**对珍珠习惯的界定（提示一开始是惹人厌烦的刺激，后来变成美好之物）——**不得把蚌/砂砾比喻说成作者原话**；若要沿用该比喻，必须标明「来自中文版推荐序」。

## I — Interpretation

「珍珠习惯」是**行动提示（锚点）的一个专用变体**：它不新增一个正向的触发源，而是**把一个"确定会反复发生、却惹人厌烦"的负面刺激，直接改写成提示**。

适用对象有三条特征：
1. **确定会发生**（所以可靠）——半夜启动的空调噪声、他人的恶语、排长队；
2. **惹人烦、往往无法消除**——你没法让邻居不吵、让空调不响、让队伍变短；
3. **你也不想被它牵着走**——与其被刺激激怒/焦虑，不如**接管它**。

做法：**不新增触发源**，而是**把负面刺激本身重新定义为锚点**，在其后/期间接一个**正向、能取悦自己**的微行为。于是同一个刺激，过去触发抱怨/压力，现在触发自我照顾。作者称之为"把惹人厌烦的事转化成美好的提示"。（注：中文版推荐序附会了"蚌把砂砾包裹成珍珠"来打比方，**那是推荐序作者的话，不是本书作者的比喻**。）

与普通锚点的区别：普通锚点（见 anchor-matching）是**中性/正向的既有行为**；珍珠习惯的锚点是**负面的、但躲不掉的刺激**——它的价值恰恰在于**扭转这个刺激的情绪效果**，并利用它"必定发生"这一高可靠性。

## A1 — Application Example

**主例 · 埃米的珍珠习惯：把前夫恶语当提示**（`nature: 学员案例`（作者转述、非亲历），`c34`，第04章「『珍珠习惯』，管理压力与焦虑」）
- 输入/问题：埃米离婚后常因前夫的恶语反复生气。
- 怎么执行：把**前夫的言行**当作提示（负面刺激 → 锚点），制订配方——一感到被冒犯就立刻做一件**取悦自己**的事（放爱听的音乐/有声书、开车去星巴克点喜欢的饮品）。
- 结论/输出：配方「**一旦感到被冒犯，就去做一件能取悦自己的事**」，把负面刺激"包裹"成正向行为。
- 原书交代的结果：她不再反击或生闷气；前夫逐渐不再恶语相向，两年多来首次能一起笑，「休战成了无言的默契」。

**注**：作者在书中称自己只是听说了埃米的做法，属**转述**（二手叙述），无对照样本量。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 有一个**确定会反复出现、又消不掉**的烦人刺激（噪音、他人恶语、排长队），想不被它激怒/焦虑。
- 想**把痛苦/烦躁的时刻变成"提示"**，用一个固定小仪式来应对。
- 想**利用必然发生的负面刺激**（高可靠性）来养成一个自我照顾的小动作。
- 压力/焦虑管理：希望每次被某件事"触发"时，都能转成一个安抚自己的动作。
- 已经有"一遇到X就炸"的循环，想把它改写成"一遇到X就照顾自己"。

**2. 语言信号（中英双写）**
- 中文：把烦人的事变成提示 / 一遇到XX就烦躁 / 把痛苦时刻转成提示 / 珍珠习惯 / 用一个动作应对烦躁 / 无法消除的烦恼 / 把负面刺激变正向 / 管理压力与焦虑。
- English: turn an irritant into a prompt / Pearl Habit / whenever X happens I get annoyed / turn frustration into a prompt / cope with anxiety / an annoying thing that always happens / neutralize an irritant.

**3. 与相邻能力怎么区分**
- 统一口径：用户**只要解决「提示在哪」这一步** → 触发本类卫星卡；要**整体养成一个习惯** → 走 tiny-habit-design（第 5 步）。
- anchor-matching：两者都是"锚点匹配"，但对象相反——anchor-matching 的锚点是**中性/正向的既有日常**（刷牙、关水龙头）；本卡的锚点是**确定会发生、却惹人厌烦的负面刺激**（空调声、他人恶语、排队）。锚点是"我要消除/抱怨的烦人事" → 本卡。
- prompt-types：本卡是**行动提示（锚点）的变体**，不负责三类提示的选型；"我该用哪一类提示" → prompt-types。
- meanwhile-habit：同样是"利用现成时刻"，但 meanwhile-habit 用的是**中性的碎片等待**，本卡用的是**负面的惹人刺激**。
- 来源路由入口 fogg-behavior-model：只回答"这套模型是什么、怎么系统性用"，不针对某个具体刺激。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「我这个普通锚点（刷完牙之后）配不配？」→ 走 anchor-matching（中性锚点匹配）。
- 「怎么利用等电梯/排队的碎片时间？」→ 走 meanwhile-habit（中性空档，不是惹人刺激）。
- 「邻居的狗叫太烦了，我想让他别叫 / 我想搬走」→ 属于**消除/规避刺激**，走 change-bad-habit-system 的移除/规避，而不是把刺激留作提示。
- 「帮我把这个新习惯整体设计出来」→ 走 tiny-habit-design（全流程）。
- 「我该用闹钟还是锚点提醒？」→ 走 prompt-types（三类选型）。

## E — Execution

### 输入契约
- **必需**：①一个**确定会反复发生、且不易消除**的负面刺激（噪音、他人言行、环境烦扰）；②用户想用它触发一个**正向、取悦自己**的微行为。
- **先做行为判别**（p20）：把"想应对的情绪"落成一个**具体微行为**（否则只是空泛情绪）。
- **适用条件**：刺激**必定发生**且**难以消除**；用户愿意把它**当作提示**而非逃避对象。
- **可选**：刺激发生的频率、用户偏好的自我照顾动作。
- **缺**刺激或微行为时先问，**不许静默替用户造条件**。
- **先做安全筛选**：若涉及成瘾/物质依赖或严重心理病理 → 不跑本卡，转介（见 B 段）。

### 输出契约

**产出类型**：`design`（新建一个设计）

一条**把负面刺激转成正向微行为**的配方：
1. 被改写成提示的负面刺激（必定发生、不易消除）；
2. 其后/期间执行的**正向微行为**（能取悦自己、≤ 30 秒）；
3. 一行配方：「在我（感到X / 遇到X）时，我会（正向微行为）」。

**完成标准**：用户能说出"哪个烦人事被改成了提示、我接的是什么照顾自己的动作"，并能在刺激出现时照着做。

### 步骤
1. **确认刺激合格**：它是否**确定发生**、**惹人烦**、**难以消除**？
   - 完成标准：三条都成立。
   - 判停：若刺激**可以消除/规避**（如关掉提醒、离开场所）→ 转 change-bad-habit-system 的移除/规避，不做珍珠习惯。
2. **把它定义为"提示"**：明确"每次 X 出现，就是提示我该做 Y"（**不新增触发源**）。
   - 完成标准：一句话说清"X = 我的提示"。
3. **设计正向微行为**：选一个能真正取悦自己、在刺激当下可完成的动作（放喜欢的音乐、做一次放松、去点一杯喜欢的饮品）。
   - 完成标准：动作正向、≤ 30 秒、当下可做。
4. **写配方 + 即时反馈**：套「在我（遇到 X）时，我会（微行为）」，并提醒做完在**当下**有正向感受（固化机制见 B 段的待核查提示）。
   - 完成标准：一条可执行的配方；用户能复述"刺激 → 自我照顾"的替换。

## B — Boundary

### 不要用（反场景，按分流）
- **锚点是中性/正向的既有日常** → anchor-matching。
- **要利用中性的碎片等待时间** → meanwhile-habit。
- **这个负面刺激其实可以消除/规避** → change-bad-habit-system（移除/规避提示），不要把它留作提示。
- **要整体养成一个习惯** → tiny-habit-design；**还在选提示类型** → prompt-types。
- **诊断某行为为何没发生** → bmap-diagnosis。**只想了解模型本身** → 来源路由入口 fogg-behavior-model。

### 作者警告过的失败模式（反例素材）
- **用延后的"激励"冒充即时奖励** x23：珍珠习惯的正向动作要在**刺激当下**做、有即时感受，不能靠事后补偿。
- **尴尬/强颜欢笑的庆祝** x24：自我照顾的动作要**真切**，假装的安抚制造的是负面情绪。
- **靠记忆去记"下次一定要做"** c26：必须真正把刺激**定义成提示**（"X 一出现就是信号"），不能指望自己想起来。

### 作者盲点与待核查（不许当规律用）
- **来源陷阱**：中文版推荐序（梁宁）里的「**蚌把砂砾包裹成珍珠**」比喻**不是作者原话**；作者正文只说"提示一开始是惹人厌烦的刺激、后来变成美好之物"。引用时必须区分：**作者定义（正文）vs 推荐序比喻（他人所加）**。
- **固化机制待核查**：本卡只管"**把负面刺激转成提示**"。作者关于**情绪（庆祝）创造习惯**（f26 / `p53`）与"**演练 7–10 次即固化**"（f30）的主张**均为作者推测、无实验依据，不在本卡职责内**；需要庆祝请走 celebration / tiny-habit-design 第 6 步。
- **安全阀缺失**：若用户的"烦人刺激"牵扯**成瘾/物质依赖、进食障碍、自伤**等严重问题，或用户实为想**戒断依赖**，本卡不适用——转 change-bad-habit-system 并提示该线**成瘾/自由落体型没有判停规则**（作者只写"交给专家"），**必须提示转介专业人士**。

### 相邻易混
- anchor-matching：中性/正向锚点 vs **负面刺激**转成的锚点。
- meanwhile-habit：中性**碎片等待** vs **惹人刺激**。
- prompt-types：三类提示选型 vs 行动提示的一个变体。
- change-bad-habit-system：可消除/规避的刺激走"移除/规避"，留作提示的走本卡。
- tiny-habit-design：单点（把烦人事转成提示）vs 全流程。

## 相关能力

- **tiny-habit-design**（组合）：养成全流程；本卡只管「把负面刺激转成提示」这一步。
- **prompt-types**（对比）：三类提示全景选型 vs 本卡这一行动提示变体。
- **anchor-matching**（对比）：中性/正向锚点 vs 本卡的负面刺激锚点。
- **meanwhile-habit**（对比）：都「利用现成时刻」，但本卡用负面刺激、它用中性空档。

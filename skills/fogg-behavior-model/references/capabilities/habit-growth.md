# 习惯的生长与繁殖（第 7 步的机制 / 目录层）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 6 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f32`），不随公开版分发。

注：小标题英文原文是 **`Grow and Multiply`**（是 and、不是 or），不是二手来源写的 `Habits Either Grow or Multiply`；正文作 "habits that grow and habits that multiply"。「繁殖」对应英文 **`multiply`**，不是 `breed`（`Habit Breeding` 原书无对应）。五组技能正式名为 **`The Skills of Change`**；第三组即 **`SKILL SET #3—PROCESS`**（中文版意译作「循序渐进」），其中 `Context` 与原书 `environment` 同义（作者明说这两个词他当作同义词用）。

## I — Interpretation

本卡是行为设计第 7 步（生长 / 繁殖）的**机制与目录层**。它处理的前提是：**这个习惯你已经能稳定做到了**——接下来它会往两个方向自我发展（f32）：

1. **生长（grow）**：同一个行为"变大"，做得更多 / 更久（深呼吸 → 冥想 30 分钟；清理台面 → 清理整个厨房）。生长有**自然边界**，到边界后强撑会削弱动力。
2. **繁殖（multiply）**：因为处在更大的行为生态里，一个习惯衍生出别的新习惯（毛伊习惯的涟漪效应；带水杯 → 顺手捡沙滩垃圾）。

再补两层机制认知：
- **没有固定天数**（f33）：习惯成型快慢取决于**执行的人 / 习惯本身 / 情境**三变量——别数天数，去调这三样。
- **成功动能**（f34）：推动成长的是**成功的频率，不是成功的大小**——高频小成功抬高整体动机，进而能承担更难的行为。

要练的五组改变技能（f35，正式名 `The Skills of Change`）——**Behavior Crafting / Self-Insight / Process / Context / Mindset**——就是这条线的行动地图；各组的具体展开（f36–f40）在 tiny-habit-design 内。

一句话区分：本卡管"**已经做到了想扩展**"；要"**从零养成**"走 tiny-habit-design，要"**现在做不到**"走 make-it-easy。

## A1 — Application Example

**主例 · 萨里卡的习惯生长与繁殖**（`nature: 学员案例`，`c51`；与 `c20` 为同一人物的前段）

- **输入/问题**：萨里卡（患躁郁症）从极小的入门步骤起步（c20：坐垫上深呼吸 3 次、只打开燃气灶、瑜伽垫拉伸 30 秒）。
- **怎么执行**：当"打开燃气灶"这个习惯自动化后，不靠死板公式，而是顺着自然**生长 / 繁殖**——在炉灶旁放水、取出米 / 牛奶 / 肉桂粉、清理柜台，习惯层层衍生。
- **结论/输出**：从"早上打开燃气灶"长到"每天自己做一顿丰盛早餐"，最终**一日三餐全自己做**。
- **原书交代的结果**：「她最终过上了期盼已久的规律生活」；还把妈妈当资源、提升技能做出了辣酱多莎饼。
- **注**：学员案例、作者自选，无对照样本量（`c51.notes`）。作者明确"知道何时添加更多习惯"**并非死板公式，无量化门槛**。

**繁殖的另一个例子**：作者把"带水杯出门"拆成 3 个微习惯，习惯养起来后又繁殖出捡拾沙滩垃圾等环保习惯（`c52`，原书亲历）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 「我的习惯已经能坚持了，接下来怎么加量 / 变强？」
- 「怎么判断一个习惯该继续做大，还是该期待它带出别的习惯？」
- 「为什么我一加量，动力反而下降了？」
- 「习惯养成之后怎么扩展 / 繁殖？」
- 「一个习惯能不能带出一串相关习惯？」

**2. 语言信号（中英双写）**
- 中文：习惯加量 / 扩大习惯 / 习惯生长 / 习惯繁殖 / 涟漪效应 / 加码 / 扩展习惯。
- English: grow and multiply / scale a habit / habit growth / ripple effect / add more habits / when to increase。

**3. 与相邻能力怎么区分**
- make-it-easy：那是"**现在做不到**"（能力侧）；本卡是"**已经做到了想扩展**"。这一对最容易混，必须分清。
- tiny-habit-design：那是**全流程**（含第 7 步的展开）；本卡是第 7 步的**机制 / 目录单点层**。
- celebration：两卡在「加量」处配套使用——本卡管**怎么扩大 / 何时扩大**，扩大时**用什么固化**看 celebration（第 6 步的即时强化）。
- 来源路由入口 fogg-behavior-model：只回答"模型是什么"。
- 目录关系：五组技能的具体展开（f36–f40）在 tiny-habit-design 内；本卡承载"生长 / 繁殖"的机制与目录，不重复各组步骤。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「我做不到每天读书，太难了」→ 不触发本卡，走 make-it-easy（"现在做不到"，不是扩展）。
- 「帮我从零养成一个新习惯」→ 不触发本卡，走 tiny-habit-design（全流程）。
- 「我想戒掉睡前刷短视频」→ 不触发本卡，走 change-bad-habit-system。
- 「我为什么总做不到早起？」→ 不触发本卡，走 bmap-diagnosis。

## E — Execution

### 输入契约
- **必需**：一个**已经能稳定做到**的习惯（或一组），且用户明确想"做大 / 扩展"。
- **可选**：已持续多久；情绪信号（是否厌倦 / 痛苦 / 逃避）；当前锚点 / 情境。
- **适用条件**：习惯**尚未养起来**时，先回 tiny-habit-design，不在本卡执行。缺"已能稳定做到"这一前提时先确认，**不许把"想开始"当"已做到"**。

### 输出契约

**产出类型**：`patch`（给已有设计换零件：加量或退回）

- ① 一个**分类结论**：该习惯属**生长**还是**繁殖**。
- ② 一个**下一步动作**：生长型给"加量到哪、何时停"；繁殖型给"期待 / 培育哪些衍生习惯"。
- ③ 若引用五组技能，**指名要练的那一组**。

### 步骤与完成标准
1. **分类**（f32）：判断这个习惯是"同一行为做大"（生长）还是"衍生出别的习惯"（繁殖）。
   - 完成标准：给出生长 / 繁殖标签，并说明依据（行为是否可自然变大 / 是否处于更大的行为生态）。
2. **决策下一步**：
   - 生长型：可以加量，但守住自然边界——**沮丧 / 痛苦 / 逃避 = 提升过快**，退回基线并加倍庆祝；**持续厌倦 = 才可加码**。
   - 繁殖型：顺着生态培育相关习惯，期待涟漪。
   - 完成标准：写出一条"下一步加量 / 培育"动作 **+** 一条"退回基线"的触发信号。
3. **定位技能**：用 f35 五组技能（Behavior Crafting / Self-Insight / Process / Context / Mindset）判断自己在这条线上哪项薄弱。
   - 完成标准：指名 **≥1 组**要练的技能。

### 判停点
- 第 2 步出现**痛苦 / 沮丧 / 逃避** → **退回基线、不加量**。
- **何时增加没有硬阈值**（见 B 段）：把"默认 3 个起步、每月加 3 个"当参考，而非门槛。

## B — Boundary

### 不要用（反场景，按分流）
- **习惯还没做到**（"我做不到 / 太难了"）→ make-it-easy（能力侧）或 tiny-habit-design（全流程）。
- **要戒掉 / 替换坏习惯** → change-bad-habit-system。
- **要归因诊断**（为什么某行为没发生）→ bmap-diagnosis。
- **只想了解这套模型本身** → 来源路由入口 fogg-behavior-model。

### 软标记 / 待核查（不许当规律用）
- **生长无量化门槛**（f32）：作者称生长边界**无死板公式**，判"到没到边界"靠软性自评（f38 的 emotional flags）；本卡**不得宣称有客观阈值**。
- **习惯成型无固定天数**（f33）：作者明确反驳"21 / 60 天"论，把成型快慢归给三变量——这是**作者主张**（与主流"重复 / 语境"研究有张力），**不许当已证实的普适结论**。
- **成功动能**（f34）：作者称有自建研究数据（`p67`）但**未给样本**；不进 B 段当作规律。
- **五组技能是目录层**（f35）：各组展开（f36–f40）多为骨架级 / 无量化门槛，尤其"何时增加"无阈值。
- **与本册其它软标记一致**：f30「演练 7–10 次即固化」是作者本人推测（原书即 `I predict…`），**不得在本卡当规律用**。
- **安全阀（跨卡一致性）**：若"想扩展的习惯"牵扯成瘾、进食障碍、自伤等严重心理病理，或实为戒断依赖，**不跑本流程**，提示转介专业人士（作者自设边界 x40：微习惯并非严重成瘾问题的答案）。

### 相邻易混
- make-it-easy："**现在做不到**"vs"**已经做到了想扩展**"。
- tiny-habit-design：全流程 vs 本卡（第 7 步的单点机制 / 目录层）。
- bmap-diagnosis：往回看"为什么没发生" vs 本卡"已做到、往前扩展"。

## 相关能力

- **tiny-habit-design**（组合）：养成全流程；本卡只承载第 7 步「生长/繁殖」的机制与目录。
- **make-it-easy**（对比）：本卡面对「已经做到了想扩展」；「现在做不到」走它。
- **celebration**（组合）：本卡管「怎么扩大/何时扩大」，扩大时「用什么固化」看它。

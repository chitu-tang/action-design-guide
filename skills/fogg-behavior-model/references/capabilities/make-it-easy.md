# 让行为容易做（能力侧单点工具）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 3 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f13`），不随公开版分发。

注：`p39` 的中文译本把两处第一人称表述合并、泛化、去掉第一人称，压成一句泛泛的「降低门槛就能让大脑活跃起来」——改动了原句的第一人称与「大脑喜欢的势头」这一意象，故这两个概念**以英文原词为准**。（`f14` 的中文译本作「探索型问题 / 突破型问题」，英文原词为 `Discovery Question` / `Breakthrough Question`。）

## I — Interpretation

本卡是**能力侧**的单点工具。用它的前提是：这个行为你**想做却做不到**（不是不想做，是"太难"）。处理方式是一段两问式诊断：

1. **先找"弱环"**（f14 的 Discovery Question）：问「是什么让这个行为难做？」用 f13 五环逐一过——**时间 / 钱 / 体力 / 脑力 / 是否契合当前日常**。五环像一条链，整体能力 = 最弱一环；找到最弱环，才知道该往哪里加固（作者牙线习惯的弱环是"体力"）。
2. **再给对策**（f14 的 Breakthrough Question）：问「我怎样才能让它更容易做到？」答案是 f15 的三条路——**提升技能 / 获取工具和资源 / 把行为变得微小**。选择依据是动机高低：动机高时可用前两条（能做更难的事），**动机低时应靠"让行为微小"来补**。

两条配套心态让改造落地：**不要过早提高标准**（p36：只完成入门步骤本身就是成功，无论动机怎么波动都确保能做）；**追求持续而非完美**（p38：生病/度假可缩到最小但不中断）。p39 再补一层：对困难的**感知**和实际困难一样重要——越拖越难，用入门步骤降低门槛即可启动（作者把"预约牙医"缩成"写下号码"）。

本卡与 tiny-habit-design 第 4 步（从微习惯开始）是同源手法：tiny-habit-design 用"缩小规模 / 入门步骤"落地整个流程，本卡则把"太难了怎么办"独立成一个可复用的能力侧工具。

## A1 — Application Example

**主例 · 作者用能力链 + 工具 + 缩小规模攻克牙线**（`nature: 原书亲历`，`c21`）

- **输入/问题**：作者作为行为科学家，却长期坚持不了用牙线。
- **怎么执行**：用**能力链**分析 → 最弱环是**体力**（牙齿紧密、用力易断）；据此走两条路——①**获取工具和资源**（找到合适的细牙线），②**缩小规模**（从"清洁所有牙齿"缩到"只清洁一颗牙齿"）。
- **结论/输出**：每天刷完牙，用牙线只清洁一颗牙。
- **原书交代的结果**：「两个多星期后」扩展到隔天清洁所有牙；「这个习惯他到现在都还在坚持。」
- **注**：作者自述的幸存者偏差案例，无对照样本量（`c21.notes`）。

**p39 的判据例（原书亲历）**：拖延"预约看牙医"的电话——把牙医号码写在便利贴、贴在手机上，告诉自己"写下号码就是我要做的全部"，用它当入门步骤降低门槛后启动。原文自陈：降低门槛之后，他就绕过了自己大脑的阻力。

**其余可类比例子（均标 nature）**
- 萨里卡把"每天冥想 20 分钟"缩成"坐在坐垫上深呼吸 3 次"、把"做早餐"缩成"只打开燃气灶"（`c20`，学员案例）。
- Instagram 砍掉多余功能，把"上传照片"缩到"点击 3 次"（`c19`，商业案例：上线不到 18 个月被 Facebook 收购）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 「这个行为对我来说太难了，怎么让它变容易一点？」
- 「我明明想做，可就是做不到，到底卡在哪？」
- 「每天运动 / 读书 / 做饭太难坚持，帮我把它变小。」
- 拿着一个具体行为问"为什么难做、怎么降难度"。
- 已经知道要根据"能力"下手，来要"让行为容易做"的操作方法。

**2. 语言信号（中英双写）**
- 中文：让行为变容易 / 太难了 / 做不到 / 卡在哪 / 能力不够 / 能力链 / 降低难度 / 变简单 / 缩小。
- English: make it easier / easy to do / too hard / I can't do it / ability / ability chain / Discovery Question / Breakthrough Question / make it tiny。

**3. 与相邻能力怎么区分**
- tiny-habit-design：那是**全流程**（发散→筛选→缩小→锚点→庆祝→扩展）；本卡只是其中**能力侧**的单点工具（第 4 步的展开），只管"这个行为太难了怎么办"。
- golden-behavior：先由它选出"值得做的行为"，再由本卡处理"该行为太重怎么降难度"。
- habit-growth：最容易混的一对——"现在做不到"走本卡；"已经做到了想加量 / 扩展"走它。
- 来源路由入口 fogg-behavior-model：只回答"模型是什么"。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「帮我从零养成一个新习惯，出一套完整方案」→ 不触发本卡，走 tiny-habit-design（全流程）。
- 「我已经能坚持做俯卧撑了，怎么加量 / 扩展？」→ 不触发本卡，走 habit-growth（"已做到想扩展"，不是"现在做不到"）。
- 「我为什么总做不到早起？卡在动机、能力还是提示？」→ 不触发本卡，走 bmap-diagnosis（要完整归因，不只能力侧）。
- 「提示总找不到点，我该用人物 / 情境 / 行动提示哪种？」→ 不触发本卡，走 prompt-types。

## E — Execution

### 输入契约
- **必需**：一个**想做但做不到 / 觉得太难**的具体行为，且它是"此刻可做的动作"（若是"减 12% 体脂"这类愿望，先拆成行为，p20）。
- **可选**：用户在五个能力因素上的把握、当前动机水平、可用工具/时间、想投入的时长。
- 缺行为时先问，**不许静默替用户猜**。

### 输出契约
- ① 一个**定位结论**：最弱的 Ability Factor（时间 / 钱 / 体力 / 脑力 / 日常契合 之一）。
- ② **≥1 条针对该弱环的加固动作**，落在 f15 三条路之一（提升技能 / 获取工具和资源 / 让行为微小），并给出缩小后的**微行为**版本（约 30 秒内可完成）。

### 步骤与完成标准
1. **问 Discovery Question**：「是什么让这个行为难做？」用 f13 五环逐一过。
   - 完成标准：指名**最弱的那一环**（如"体力""时间"）。
2. **问 Breakthrough Question**：「我怎样才能让它更容易做到？」在 f15 三条路里选。
   - 完成标准：选出一到两条路，且选择依据对齐动机水平（动机高 → 可走技能/工具；动机低 → 走"让行为微小"）。
   - **变体/判停**：若想用作者的四问设计流程（训练技能 → 工具资源 → 缩小规模 → 入门步骤，**成本递增、走通即止**），走 f17（在 tiny-habit-design 内）；两版次序一致，以附录图版"走通即止"为准。
3. **产出微行为 + 定住心态**（p36 / p38 / p39）。
   - 完成标准：得到一个约 30 秒可完成的"微行为"；并写明"状态差 / 生病时缩回哪一步、只完成入门步骤也算成功"。

### 判停点
- 第 2 步三条路都试不通（或动机极低仍做不到）→ 回到行为层面换一个更契合当前日常的行为（f13 第五环），**不要硬撑**。

## B — Boundary

### 不要用（反场景，按分流）
- 要**从零整体养成**一个习惯、要一套完整方案 → tiny-habit-design。
- 要**选行为 / 判黄金行为** → golden-behavior。
- 要**完整归因**（卡在 M / A / P 哪一环）→ bmap-diagnosis。
- 要**选提示类型** → prompt-types。
- 要**戒掉 / 替换坏习惯** → change-bad-habit-system。
- 习惯**已经做到、想加量 / 扩展** → habit-growth。

### 作者警告过的失败模式（反例素材）
- **全有或全无**（x05）：不完美的执行 ≠ 没做。
- **一开始太贪心 / 从大行为起步**（x06 x16）：一上来"每天 30 分钟"，根浅枝大，遇生活波动即断。
- **过早提高标准**（x17 = p36）：微习惯刚做几天就擅自加量，破坏"无论动机如何都能完成"的底线。
- **把"做不到"归因于意志力**（x09）：多数"做不到"根因是缺提示或行为太难，不是意志薄弱。
- **误以为动机是关键**（x18）：把"对方不动"上升到态度 / 人品问题，用施压代替降难度。

### 本册存量风险（写进卡、不许越界宣称）
- **"感知难" ≠ "实际难"**（p39）：本卡同时处理"感知到的难"与"实际的难"；降低**感知**门槛（入门步骤）可能只是启动手段，并未改变客观能力，**不得把它讲成客观能力已提升**。
- **安全阀（跨卡一致性）**：若"想做的行为"牵扯成瘾、进食障碍、自伤等严重心理病理，或实为戒断依赖，**不跑本流程**，提示转介专业人士（作者自设边界 x40：微习惯并非严重成瘾问题的答案）。

### 相邻易混
- habit-growth："**现在做不到**"（本卡）vs"**已经做到了想扩展**"（生长 / 繁殖）。
- tiny-habit-design：全流程 vs 本卡（能力侧单点工具）。
- bmap-diagnosis：完整 MAP 归因 vs 本卡（已锁定能力侧）。

## 相关能力

- **tiny-habit-design**（组合）：养成全流程；本卡只是其中能力侧的单点工具（第 4 步的展开）。
- **golden-behavior**（对比）：先由它选出「值得做的行为」，再由本卡处理「该行为太重怎么降难度」。
- **habit-growth**（对比）：最容易混的一对——「现在做不到」走本卡；「已经做到了想加量/扩展」走它。

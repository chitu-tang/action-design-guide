## I — Interpretation

行为不是靠意志力发生的。B=MAP 说：某一个**具体时刻**的某一个**具体行为**，只有当动机 M、能力 A、提示 P 三者同时到位时才会发生；缺任何一个，行为就不发生。所以「我做不到」不是品格问题，而是要素缺位问题——诊断就是找出缺了哪一个。

诊断第一步是**固定行为**：把要分析的东西写成一个在某个时刻能做出、也能判断有没有做出的动作。「我要更健康」不是行为，「午休后喝一杯水」才是。

然后按固定顺序排查三个要素，不许跳步：

1. **先查提示 P**——这个时刻有没有一个明确的信号提醒做它？没有，就是缺 P。
2. **再查能力 A**——提示在，为什么还是没做？是什么让它难做？（用能力链的五因素定位最弱那一环）缺环，就是缺 A。
3. **最后查动机 M**——P、A 都满足却仍不做，才轮到动机。

为什么是这个顺序？因为大多数人一上来就从动机入手——讲道理、施压、罚款、摆脸色——而这恰恰是最先错的路径。动机最容易波动、也最难直接调。

行动线（`f02`）是这套模型的定性图形：横轴是能力（难→易），纵轴是动机（低→高），两者合成一条向下弯的弧线。把行为的（动机, 能力）坐标点上去：点落在行动线上方、且有提示 → 行为会发生；点落在下方 → 即使有提示也不发生。它只做定性判断，没有刻度、没有阈值。

诊断指出卡点之后，还有两条规则收口：**替换规则**（`p15`）——某个要素（尤其动机）客观改不动时，转去改其他要素，别在不可控的那一项上死磕；**信息–行动谬误**（`p02`）——「把道理讲清楚、给足信息」本身不构成对行为的改变，不能把它当成诊断的终点。

## A1 — Application Example

**案例：健身房踩椭圆机时短信捐款（原书亲历，`c07`，第01章「3要素齐备，行为才能发生」）。**

- **输入/问题**：作者本想向海地地震灾民捐钱，人已经在健身房踩着椭圆机。为什么他**真的捐了**？反过来推演：换成什么条件，同样的意愿就不会变成行为？
- **怎么执行**：把「此刻捐一笔钱」当成一个具体行为，逐要素拆开看——
  - **P（提示）**：他收到一条红十字会的募捐短信，这是此刻明确的信号。若活动改成发邮件，而邮件被当成垃圾邮件，提示就等于不存在 → 行为不发生。
  - **A（能力）**：短信捐款极简单，几步就能完成。若改成打捐款热线，能力门槛抬高 → 行为不发生。
  - **M（动机）**：他想帮灾民，动机在场。
  - 三者同时到位 → 行为发生。
- **结论/预期输出**：三要素齐备才发生的诊断结论；反推里任何一要素被拿掉，行为就消失。这正演示了「固定行为 → 逐要素判定」的排查动作。
- **真实结果**：该短信募捐活动 24 小时募集超 300 万美元，一星期超 2100 万美元（原书交代；作者自述、无对照样本）。

**补充示范（作者自设假设演练，`c13`，「解决行为问题的3个步骤」）**：想让女儿放学帮买海报纸，用「开车接送 / 讲道理 / 发火」等动机策略都失败；改成先问「你打算用什么提醒自己」，找到提示（手机待办）后问题即解决。演示了「动机不是第一步、提示才是」的排查顺序（属书内虚构情境，非真实事件）。

## A2 — Future Trigger

**1）用户会在什么情境下遇到这类问题（3–5 条具体场景）**

- 自己反复想做某件具体的事却做不到，想知道卡在哪：「我打算每天午休后喝一杯水，两周了就是做不到。」
- 管理 / 家长场景：某个具体的人该做的行为没发生，用户想归因：「他说好每天交周报，可就是不交，到底为什么？」「我女儿总不记得带作业本。」
- 自己定的计划崩了，复盘是缺提示、太难、还是没动力：「我买了跑步机结果一直没跑，问题出在哪？」
- 已经决定要改、但不确定先动哪个要素：「我想让人准时到会，是该多提醒，还是把流程弄简单，还是加点压力？」
- 评估一个已经做过、但没起作用的方案：「我们发了健康科普邮件，员工还是不改，为什么？」

**2）语言信号（中英双写关键 trigger）**

- 中文：为什么我没做到 / 就是做不到 / 总是忘记 / 卡在哪 / 问题出在哪一步 / 是缺提示还是太难 / 他没做是为什么 / 这个方案为什么没用。
- English: why didn't this behavior happen / why can't I do it / what's blocking me / where exactly is it stuck / is it motivation, ability, or a prompt / why didn't it work / they still didn't do it.

**3）与相邻能力怎么区分**

- `tiny-habit-design`（晋级）：从愿望出发**造**一个还不存在的正向习惯（正向设计全流程）。
- `change-bad-habit-system`（晋级）：**终止 / 替换**一个已经发生的坏习惯（分阶段方案）。
- `fogg-behavior-model`（来源路由入口）：了解整书、或「书里某段怎么做」。
- `motivation-diagnosis`（同册相邻）：已确认卡在动机，才做动机的细分诊断（5 陷阱 / PAC 三来源）。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs `tiny-habit-design`】**「帮我养成每天跑步的习惯 / help me build a daily running habit」——用户要的是设计一个**还不存在**的正向习惯，不是诊断一个没发生的既有行为 → **不触发本卡**，走 `tiny-habit-design`。
- **【vs `change-bad-habit-system`】**「帮我戒掉睡前刷手机 / help me quit scrolling my phone at night」——目标行为**已经发生、用户想让它停或换** → **不触发本卡**，走 `change-bad-habit-system`。
- **【vs 来源路由入口 `fogg-behavior-model`】**「福格行为模型讲了什么 / 书里那个庆祝怎么做来着 / what does the Fogg Behavior Model say」——用户只在**问来源、问书里某段**，没有具体行为要诊断 → **不触发本卡**，走来源路由入口。
- **【vs `motivation-diagnosis`（同族近邻）】**「我就是没动力，什么都不想干」——没有落到具体行为，且诉求是泛泛的动机问题 → **不触发本卡**（若要诊断，先按输入契约把行为具体化；确认卡在动机后再转 `motivation-diagnosis`）。

## E — Execution

**输入契约**

- 必需：一个**具体时刻的具体行为** + 「它本应发生却没发生」这一事实。自己或他人的行为均可。
- 若用户只给概括型（「我太懒」「想健康一点」）→ 先拆成具体行为（判据：行为是你在某一时刻能做 / 没做的动作，参见 `p20`）；**拆不出来就不要往下走**，先问清是哪个动作、发生在什么时刻。
- **判停 1**：目标行为「已经发生、用户想让它停 / 换」→ 不属于本卡，转 `change-bad-habit-system`。
- **判停 2**：目标是「一个还不存在的新习惯」→ 转 `tiny-habit-design`。
- **判停 3**：用户只问「这套模型是什么 / 书里某段怎么说」→ 转来源路由入口 `fogg-behavior-model`。

**步骤**

1. **固定行为。** 写成一句话：某人（我 / 他）在【具体时刻或情境】做【具体动作】。
   - 完成标准：这句话可以被判断真假（「午休结束立刻喝一杯水」可判；「变得更自律」不可判）。
   - 判停：拆不出可判断的具体行为 → 回到输入契约先具体化，不进入第 2 步。

2. **按 P → A → M 顺序排查（`f04`，不得从动机起手）。**
   - **2a 查提示 P**：这个时刻有没有一个明确的行动信号？没有 → 结论「缺 P」，给一个补 / 换提示的动作 → 输出，结束。
   - **2b 查能力 A**：提示在，但没做 → 定位「是什么让这个行为难做」，用能力链五因素（时间 / 钱 / 体力 / 脑力 / 是否契合当前日常）找出最弱一环（`f13`）→ 结论「缺 A」，给一个降难度动作（把行为缩小 / 备好工具资源 / 练技能，`f15`）→ 输出，结束。
   - **2c 查动机 M**：P、A 都满足却仍不做 → 才判定「缺 M」，再谈动机（进一步细分转 `motivation-diagnosis`）。
   - 每步完成标准：对该要素给出明确的「满足 / 不满足」判定；整体顺序必须为 **提示 → 能力 → 动机**。

3. **生成归因与下一步，处理判停分支。**
   - 若归因落在某要素、但该要素客观改不动（如动机太强 / 受外部硬约束）→ 用**替换规则**（`p15`）改其他要素，重新给动作（例：动机改不动就改能力 + 提示）。
   - 若用户的真实诉求是「把道理讲清楚让人行动」→ 先纠正**信息–行动谬误**（`p02`）：仅提供信息不足以可靠改变行为，仍要落到某个 M / A / P 动作。

**输出契约**

- 固定结构：`{缺哪个要素：P / A / M 之一}` + `{下一步改哪个要素、具体做什么}`。
- 完成标准：给出一个明确的待改要素，且排查顺序为 **提示 → 能力 → 动机**（不得一上来从动机、讲道理或惩罚入手）。

## B — Boundary

**反场景（不要用本卡）**

- 用户要**从零造一个新习惯**（「帮我设计每天跑步」）→ `tiny-habit-design`。
- 用户要**终止 / 替换一个已经发生的坏习惯**（「帮我戒掉熬夜刷手机」）→ `change-bad-habit-system`。
- 用户只想**了解 / 系统性地用这套模型**，或问书里某段怎么做 → 来源路由入口 `fogg-behavior-model`。
- 用户的诉求本质是「我该怎么把道理讲清楚、发什么材料让他们行动」→ 命中**信息–行动谬误**（`p02`）：仅给信息不能可靠改变行为，这不是一次诊断能解决的，要转成对某个 P / A / M 的动作。

**失败模式（作者警告）**

- **从动机入手（`x07`）**：一上来就罚款、摆脸色、讲道理——作者点名这是最先错的路径，排查第一步必须是提示。
- **忽视提示（`x08`）**：以为有动机 + 有能力行为就会发生，忘了行为还需要一个「此刻」的提示，想做的事永远停在想法里。
- **把「做不到」归因于意志力（`x09`）或归因于自己（`x04`）**：诊断要先把归因从品格移到要素（缺 P / 缺 A / 缺 M），而不是停在「我不够自律」。

**作者盲点 / 待核**

- **普适性宣称待核**：作者主张 B=MAP「适用于所有行为、所有文化、所有年龄层」。这是作者的**普适性断言**，本册**没有跨文化 / 跨年龄的实证支撑**，仅凭作者陈述 → **待核查**，不得当作已验证规律使用。本卡只保证操作层有效（能把某个具体行为拆成 M / A / P 三要素并定位缺项），不为其跨文化 / 跨年龄的普适性背书。
- 行动线（`f02`）**无刻度、无阈值**，只能做定性判断，不得当量化模型使用。
- 4 原则（`f03`）是判断依据层，不是操作步骤；用它回答「该改哪个要素」，不要把它当一套独立流程。

**边界 / 安全**

- **成瘾 / 自由落体型行为**（如药物、酒精依赖）：作者自限——此类不属于微习惯策略的适用范围，应转介专家（`x40`，参考级）。本册改坏习惯线**没有判停规则**（原书未给）——碰到这类目标，不要硬套诊断，直接提示寻求专业帮助。

**相邻易混**

- `motivation-diagnosis`：本卡在 P、A 任一不满足时**不会**走到 M；只有 P、A 都满足仍不做，才触及动机，动机的细分诊断（5 陷阱 / PAC 三来源）在那张卡。
- `change-bad-habit-system`：与本卡共用「先提示」的优先序（`f45` ⇄ `f04`），但作用对象相反——本卡针对「想要的行为没发生」，它针对「不想要的行为已发生」。

## 相关能力

- **tiny-habit-design**（对比）：想「从零造一个还不存在的好习惯」走它；本卡只做「某个想要的行为为什么没发生」的归因。
- **change-bad-habit-system**（对比）：目标行为「已经发生、想让它停/换」走它；本卡针对「想要的行为没发生」，两者共用「先查提示」的优先序但对象相反。
- **motivation-diagnosis**（依赖）：确认 P、A 都满足、卡点落在动机时，动机的细分（5 陷阱 / PAC 三来源）由那张卡承载；本卡只判到「缺 M」为止。

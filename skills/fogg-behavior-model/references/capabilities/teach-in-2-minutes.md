## I — Interpretation

这是一份**固定的口头讲授脚本**：用 **2 分钟**把福格行为模型（B=MAP）讲给一个零基础的人听，讲完对方能记住「动机、能力、提示三要素同时出现，行为才发生」这条主干。它不是拿来自己用的分析工具，而是**讲给别人听 / 以教代学**的模板。

五步结构：

1. **介绍原理**——先说出核心命题：当 **Motivation、Ability、Prompt** 同时作用时，行为就会发生。
2. **绘制图形**——边讲边画：**纵轴 = 动机**、**横轴 = 能力**。
3. **举例说明**——用**红十字会捐款**这类例子，把三要素落到具体场景。
4. **行动线**——讲动机与能力的关联：**行为落在行动线上方才会发生**。
5. **简要总结**——收束回主干：三要素缺一不可，适用于所有行为。

作者把它称为行为设计里最实用的本事之一（**能又快又清楚地讲解行为模型**）。脚本**固定、无判断分支**，输入只有「一名听众」。

**本卡的适用面很窄，须如实看见**：task-11 是全册**支撑最薄**的任务——只有 1 条 verified（f59）+ 1 条 reference（`c75`），且二者**本质是同一份 2 分钟教学脚本的两面**（procedure 面 / exercise 面）。它面向的是「**我要把模型讲给别人听**」这一场景，**不是**「我自己要理解/用这套模型」。

## A1 — Application Example

**原书未提供独立的讲授案例**——本条的「案例」就是脚本本身（f59 与 `c75` 同源）。故此处给一条**明确标记的合成演练**，步骤完全按原书 5 步脚本，不补造关键条件。

**合成演练 · 向一位零基础同事口头讲清模型**

- **输入/问题**：一位对行为设计零基础的新同事，你需要在一次 2 分钟的走廊对话里让 TA 听懂「行为为什么会/不会发生」。
- **怎么执行（按 5 步）**：
  1. 开口先给主干句——「行为 = 动机 + 能力 + 提示，三个同时到齐，行为才发生」。
  2. 边讲边在纸上画十字坐标：**纵轴动机、横轴能力**。
  3. 举例子：以「红十字会捐款」为例，说明「有动机 + 有能力（掏钱方便）+ 被提示（有人来问你）→ 会捐」。
  4. 讲行动线：动机与能力互相配合，**落在行动线上方的行为才会发生**。
  5. 收束——「三者缺一不可，任何行为都适用」。
- **结论/预期输出**：一段约 2 分钟的口头讲解 + 一张手绘 B=MAP 模型图；听众能复述「三要素同时出现行为才发生」。
- **结果**：**原书未交代此类演练的实际听众反应**，标「未说明」。（脚本的可复现性本身在 `p95` 逐步给出。）

## A2 — Future Trigger

**1. 用户会在什么情境下遇到这类问题（3–5 条）**

- 要给同事/朋友/团队做一次**快速科普**，把福格行为模型讲清楚（会议开场、带教、分享）。
- 想**以教代学**：通过给别人讲一遍来真正搞懂模型。
- 手上要一版**固定讲稿 / 讲课脚本**，好照着讲、不出错。
- 准备培训/带新人，需要一份 2 分钟能讲完的模型讲解模板。

**2. 语言信号（中英双写）**

- 中文：怎么用两分钟讲福格行为模型 / 怎么把行为模型讲给别人听 / 有没有讲课脚本 / 我要做一次科普 / 以教代学 / 2 分钟讲解。
- English: how to explain the Fogg Behavior Model in two minutes / teach the behavior model / a script to explain B=MAP / teach it to someone / teach to learn / two-minute explanation.

**3. 与相邻能力怎么区分**

- behavior-design-primer（同册相邻）：那张是行为设计的**总纲/起手**（成功 3 件事 + 微习惯策略粗纲）；本卡是**面向听众的输出脚本**（教学动作）。
- 来源路由入口 fogg-behavior-model：用于「**自己**了解这套模型是什么」；本卡用于「**把它讲给别人**」。**主体是「我要讲给别人」→ 本卡；主体是「我自己想懂」→ 路由入口/总纲卡。**

**4. 近邻负例（什么样的请求不该触发本卡）**

- **【vs bmap-diagnosis】**「我为什么总做不到早起，卡在动机、能力还是提示？」→ 不触发本卡（这是自我诊断），走 bmap-diagnosis。
- **【vs behavior-design-primer / 路由入口】**「福格行为模型讲的是什么 / 我想系统了解这套模型」→ 不触发本卡（这是**自用/了解**，不是要讲给别人），走来源路由入口 fogg-behavior-model 或 behavior-design-primer。
- **【vs tiny-habit-design】**「帮我设计一个每天喝水的微习惯」→ 不触发本卡，走 tiny-habit-design。
- **【vs change-bad-habit-system】**「我想戒掉抽烟」→ 不触发本卡，走 change-bad-habit-system。
- **【vs 通用「写一份课件」】**「帮我把整本书做成一门 10 节课的培训」——超出本卡（本卡只覆盖这**一份 2 分钟模型脚本**），应走相应内容生产流程，不是本卡。

## E — Execution

### 输入契约
- **必需**：① 一名（或多名）**听众**（默认零基础）；② 场景允许约 **2 分钟**连续讲解。
- **可选**：能否边讲边画（纸/白板）；听众是否熟悉行为科学术语。
- **判停**：若用户的诉求其实是「自己理解模型 / 系统学这套东西」→ 转来源路由入口 fogg-behavior-model；若是「设计一个习惯」→ 转 tiny-habit-design。

### 输出契约

**产出类型**：`none`（产出是一段讲解，不写档案）

- 一段约 **2 分钟的口头讲解** + 一张**手绘 B=MAP 模型图**（纵轴动机、横轴能力、画出行动线）。
- **完成标准**：讲完能落回主干句「动机、能力、提示同时作用，行为才发生，三者缺一不可」；听众能复述这句话。

### 步骤（固定 5 步，无判断分支）

1. **介绍原理。** 开口给出主干命题：`Motivation`、`Ability`、`Prompt` 三者同时作用时行为才发生。
   - 完成标准：说出这句主干，并点明「三要素同时出现」。
2. **绘制图形。** 边讲边画十字坐标：**纵轴 = 动机**、**横轴 = 能力**。
   - 完成标准：图上明确标出纵轴/横轴含义。
3. **举例说明。** 用一个具体例子（如**红十字会捐款**）把 M/A/P 三要素落到场景。
   - 完成标准：例子中能一一指认出 M、A、P 各自是什么。
4. **行动线。** 讲动机与能力的关联：**行为落在行动线上方才发生**，并画出那条线。
   - 完成标准：图上画出行动线，并说明「线上方 → 发生」。
5. **简要总结。** 收束回主干：三要素缺一不可，适用于所有行为。
   - 完成标准：用一句话收尾，与第 1 步呼应。

### 失败处理
- 若 2 分钟讲不完 → 砍例子细节，**保住主干句 + 图 + 行动线**，不要压缩第 1、4、5 步。
- 若听众零基础仍听不懂 → 优先补第 3 步的具体例子，而非增加理论。

## B — Boundary

### 不要用（反场景，按分流）
- **自己要用模型诊断一个具体行为** → bmap-diagnosis。
- **要动手养成一个习惯** → tiny-habit-design。
- **要戒掉/改掉一个坏习惯** → change-bad-habit-system。
- **只是想自己了解这套模型** → 来源路由入口 fogg-behavior-model（或总纲卡 behavior-design-primer）。
- **要生产一份成体系的课程/多节培训** → 超出本卡覆盖（本卡只承载这一份 2 分钟脚本）。

### 证据与适用面（必须如实看见——本卡是全册支撑最薄的卡之一）
- **支撑极薄**：task-11 只有 1 条 verified（`f59`）+ 1 条参考级条目（`c75`），且**二者本质是同一份 2 分钟教学脚本的 procedure 面 / exercise 面**（记为「task-11 支撑极薄」）。**不得把它当成与 tiny-habit-design 等主卡同等硬度的能力**。
- **适用面窄**：它只服务「**要讲给别人听**」这一场景，**不是自用工具**。若用户自己要用模型，应走 bmap-diagnosis / tiny-habit-design，不要拿本卡充当「学习模型」的方法。
- **脚本固定、无分支**：五步是**背诵型脚本**，不是可对不同问题走不同分支的诊断流程；不要为它自造分支或判断规则。
- **不得为脚本补造效果**：原书**未给出**听众实际反应或测验结果；任何「照此讲解能让人轻松掌握」的说法都是外推，须标未说明。

### 作者盲点 / 术语
- 脚本默认听众有**基础认知与注意力条件**，对儿童、认知负荷高或非母语听众的效果原书未讨论。
- 术语用已核实的英文原词：**`Action Line`（行动线）**、**B=MAP**（Motivation / Ability / Prompt）；「福格行为模型」= `Fogg Behavior Model`。

### 相邻易混
- bmap-diagnosis：**自己诊断** vs 本卡**讲给别人**。
- behavior-design-primer / 来源路由入口 fogg-behavior-model：**自用/了解** vs 本卡**输出教学**。

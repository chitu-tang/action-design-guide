# 锚点匹配的 3 个考量（物理位置 / 频率 / 主题目的）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 4 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f20`），不随公开版分发。

**术语注**：锚点的英文原词是 **`Anchor`**。中文版附录在 `Anchor / Behavior / Celebration` 栏头处把「锚点」误排成「**瞄点**」——这是**中文版单侧的排印错字**（英文原文为 `Anchor`）。引用时应写回「锚点 / Anchor」，**别被「瞄点」带跑**。

## I — Interpretation

锚点（Anchor）是**行动提示**的落地形式：把新习惯**接在一件已经在做、且必定发生的既有行为之后**；作者认为它是最好的提示类型（三类提示的全景见 prompt-types）。

本卡只管一件事：**当你已经决定用锚点，怎么判断"这个锚点配不配你要养的这个新习惯"**。作者用三个维度对齐：

1. **匹配物理位置（最重要）**——新习惯在哪儿发生，就**在那个地点**找既有锚点。地点不一致的锚点极难奏效；作者称位置是最重要的考量。
2. **匹配频率**——想**每天做一次**，就把新习惯挂在**一天一次**的锚点上；想**每天做多次**，就挂在**一天多次**的锚点上。频率不匹配，触发节奏就错。
3. **匹配主题/目的**——选与新习惯**主题或目的**一致的锚点。同一件「倒咖啡」，若是为了效率就挂待办 App，若是为了放松就挂日记本——锚点的"意味"要和新习惯的意图同调。

三轴越契合，锚点越能把"想不起来的习惯"变成"自然被触发的习惯"。三轴选出锚点后，还要用 **Trailing Edge（最后动作）** 把它收紧（见 f19 / tiny-habit-design 第 5 步）。

## A1 — Application Example

**主例 · 埃琳娜用「最后动作」重塑锚点**（`nature: 学员案例`，`c30`，第04章「步骤3」）
- 输入/问题：想养成**每天擦厨房台面**的习惯。原配方锚点「吃完早餐后、把餐具放进水槽之后」效果不好。
- 怎么执行：找锚点的**最后动作**——她发现"把餐具放进水槽"的最后一个动作就是**关掉水龙头**（有水停的听觉/感官输入），把锚点收紧到这一精确时刻。
- 结论/输出：配方改为「**在我关掉水龙头后，我会擦拭台面**」。
- 原书交代她成功了，还缓解了她与丈夫因台面凌乱的矛盾。

**辅例 · 作者用「上洗手间」作锚点**（`nature: 原书亲历`，`c28`）：三轴大致对齐（位置=洗手间、频率=本能行为多次、主题=用现有行为串起微动作），锚点精确到"冲完厕所"（Trailing Edge），配方「在我冲完厕所后，我会做两个俯卧撑」，作者称「7 年来一直在坚持」。

**注**：均为作者自述/自选案例，无对照样本量（幸存者偏差）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 已选定要做某个新习惯、也决定"挂在某个既有行为后面"，但不确定**这个锚点选得对不对**：「我想接在XX后面，这样行吗？」
- 之前的配方**锚点和新习惯不搭**、老是触发不起来：「我把刷牙后接的事放到晚上做，根本对不上」「地点不一样，做了才想起来」。
- 频率对不上：「我想一天做三次，可只挂在早上一次的事后面。」
- 主题/目的错位：为放松养的习惯，挂在了"为效率"的锚点上。
- 已有一个"模糊锚点"（如"吃完早饭之后"），想把它**精确化**。

**2. 语言信号（中英双写）**
- 中文：锚点怎么选 / 锚点匹配 / 接在什么后面 / 挂在哪个习惯后面 / 位置对不上 / 频率对不上 / 主题不一致 / 模糊锚点 / 最后动作 / 关掉水龙头之后 / 锚点不对怎么办。
- English: how to choose an anchor / anchor matching / attach to what / after which habit / match location / match frequency / match theme-purpose / vague anchor / trailing edge / "after I…".

**3. 与相邻能力怎么区分**
- 统一口径：用户**只要解决「提示在哪」这一步** → 触发本类卫星卡；要**整体养成一个习惯** → 走 tiny-habit-design（第 5 步）。
- prompt-types：先由它决定用哪一类提示；锁定行动提示（锚点）后，才轮到本卡做三轴匹配。（"我该用哪一类提示" → prompt-types；"我已用锚点，它配不配" → 本卡。）
- meanwhile-habit：本卡处理中性/正向的既有行为锚点；锚点是被浪费的碎片等待时间走它。
- pearl-habit：本卡处理中性/正向锚点；锚点是惹人烦的负面刺激走它。
- 来源路由入口 fogg-behavior-model：只回答"这套模型是什么、怎么系统性用"，不针对某个具体锚点。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「我该用人物提示、情境提示还是行动提示？」→ 走 prompt-types（三类选型，尚未锁定锚点）。
- 「怎么利用等电梯、排队的几十秒顺手做点事？」→ 走 meanwhile-habit（碎片等待变体）。
- 「怎么把邻居的狗叫这种烦人的事变成提示？」→ 走 pearl-habit（负面刺激变体）。
- 「帮我把这个新习惯从零整体设计出来」→ 走 tiny-habit-design（全流程）。
- 「我这个习惯为什么老坚持不下来，卡在哪一环？」→ 走 bmap-diagnosis（归因）。

## E — Execution

### 输入契约
- **必需**：①一个已定的**黄金行为/微习惯**（已缩到微小的新行为）；②一个或几个**候选锚点**（既有的日常行为/事件）。
- **先做行为判别**（p20）：若给的是愿望/成果，先拆成具体微行为。
- **适用条件**：用户想用**行动提示（锚点）**，且锚点是**中性/正向的既有日常**。
- **可选**：新习惯发生的物理地点、期望频率（每天一次 / 每天多次）、新习惯的意图（为效率 / 为放松 / 为健康…）。
- **缺**微习惯或候选锚点时先问，**不许静默替用户猜**。

### 输出契约

**产出类型**：`design` + `patch`（独立用时新建一个设计；被 `tiny-habit-design` 调用时只换锚点）

一个**通过三轴对齐、且精确到 Trailing Edge 的锚点**：
1. 锚点行为（既有、必定发生）；
2. 三轴对齐说明：位置、频率、主题/目的各如何匹配；
3. 精确化后的锚点时刻（其最后动作）；
4. 一行配方：「在我（锚点）之后，我会（微行为）」。

**完成标准**：用户能说出这个锚点在三轴上为什么对齐，并能照着配方当天执行。

### 步骤
1. **列出候选锚点**：写下生活中必定发生、且明确的既有行为/事件。
   - 完成标准：≥1 个明确（非"晚饭之后"这类宽泛）的既有事件。
   - 判停：候选本质是**碎片等待** → 转 meanwhile-habit；是**负面刺激** → 转 pearl-habit。
2. **三轴对齐**：逐一检查——①**物理位置**是否与新习惯同一地点？②**频率**是否一致（一次对一次、多次对多次）？③**主题/目的**是否同调？
   - **主题轴是软判据**（据实说明）：原书在这一轴上只给了一个类比（同一件「倒咖啡」，为效率就挂待办 App、为放松就挂日记本），**没有可操作阈值**。因此**不得仅因主题轴存疑就判「不匹配」**；能说清「目的明显不同调」才判否，说不清就记为「**主题存疑**」并继续——位置与频率两轴才是硬判据。
   - 完成标准：三轴都有明确结论；任一轴明显不符则换锚点（位置最重要，位置不符基本换）。
   - 判停：三轴全不符且无替代 → 回 tiny-habit-design 第 5 步换锚点或换习惯。
3. **用 Trailing Edge 收紧**：把锚点细化到该行为的**最后一个动作**（"吃完早饭"→"关掉水龙头之后"）。
   - 完成标准：锚点是一个**感官上明确、可察觉**的精确时刻。
4. **写出配方**：「在我（锚点）之后，我会（微行为）」，并提示配方可随时改（p51）。
   - 完成标准：一条可当天执行的配方。

## B — Boundary

### 不要用（反场景，按分流）
- **还没决定用哪一类提示** → prompt-types（三类选型）。
- **锚点属于碎片等待时间** → meanwhile-habit；**锚点是惹人烦的负面刺激** → pearl-habit。
- **要整体养成一个习惯（含选行为、缩小、庆祝、维持）** → tiny-habit-design。
- **诊断某行为为何没发生** → bmap-diagnosis。**戒掉/减少坏习惯** → change-bad-habit-system。
- **只想了解模型本身** → 来源路由入口 fogg-behavior-model。

### 作者警告过的失败模式（反例素材）
- **锚点不够精确（模糊锚点）** x21：用"吃过早饭之后""下班回家之后"这类宽泛时刻，提示不明确、难以察觉；用 **Trailing Edge** 收紧。
- **位置不匹配**（f20 三考量）：新习惯发生地与该地点的锚点不同，极难奏效——作者称**位置是最重要的考量**。
- **频率不匹配**（f20 三考量）：想每天做多次却挂在一天一次的锚点上，触发节奏跟不上。
- **把提示交给运气** x22：不主动设计提示、指望记性"碰巧"触发。

### 作者盲点与待核查（不许当规律用）
- 本卡只做"**锚点匹配**"。匹配成功后的固化机制——**情绪（庆祝）创造习惯**（f26 / `p53`）与"**演练 7–10 次即固化**"（f30）——**是作者本人推测、无实验依据，不在本卡职责内**；需要庆祝请走 celebration / tiny-habit-design 第 6 步，且不得当已证实的普适规律用。
- **安全阀**：若"锚点匹配问题"底层其实是**成瘾/物质依赖**或严重心理病理，本卡不适用——转 change-bad-habit-system。该卡 B 段已补上一条**成瘾/自由落体型判停线**（据常识补的，非原书给的），并须提示转介专业人士。
- **排版错字提醒**：中文版附录把 `Anchor` 误排成「**瞄点**」，是**单侧错字**，不是另一个术语。

### 相邻易混
- prompt-types：提示**选型** vs 锚点**匹配**。
- meanwhile-habit：一般锚点三维匹配 vs **碎片等待时间**专用变体。
- pearl-habit：中性/正向锚点 vs **负面刺激**转成的锚点。
- tiny-habit-design：单点（锚点这一步）vs 全流程。

## 相关能力

# 顺便习惯（Meanwhile Habit · 把碎片等待时间变成锚点）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 4 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f22`），不随公开版分发。

**术语注**：英文原词为 **`Meanwhile Habit`**（`t23`）。

## I — Interpretation

「顺便习惯」是**行动提示（锚点）的一个专用变体**。它处理的不是"在某个既有行为**之后**接一个新动作"，而是**"在一段你本来就在等、又白白浪费掉的碎片时间里，塞进一个微行为"**。

关键区别在于**这段时间已经被占用，却什么也没做**：等花洒出热水的 20 秒、等红灯、排队、坐电梯、等飞机登机。这些等待**一定会发生**（所以可靠），但过去它们只是空转。顺便习惯就是把这段"空转时间"直接变成锚点时刻。

两条规则：
1. **不额外占用时间**——在等待的**当下**顺手做，而不是另找时间。
2. **通常保持微小**——正因为是"顺便"塞进去的，往往一直保持小规模；但持续累积能带来大改变。

写法仍是标准配方：「在我（等待时刻）之后/期间，我会（微行为）」。适用面很窄但很实用：**它专门为"挤不出时间"的忙碌者设计**。

它和 anchor-matching 共用"挂在既有行为上"的思路，但 anchor-matching 处理**一般的锚点**，本卡只处理**被浪费掉的碎片等待**这一特例。

## A1 — Application Example

**主例 · 布里塔妮的通勤顺便习惯**（`nature: 学员案例`（原文称其为微习惯认证教练，归因偏宽），`c31`，第04章「为自己设计『顺便习惯』」）
- 输入/问题：布里塔妮有 5 个孩子仍想坚持学习，床头书越堆越多，成了压力源。
- 怎么执行：把有声书**嵌进每天必做的通勤**，用"系上安全带"这一过渡时刻作锚点。
- 结论/输出：配方「**系好安全带之后，按下有声书的"播放"键**」。
- 原书交代的结果：「布里塔妮如今每月至少能听完 5 本书，床边的书堆也不再压着她。」

**辅例 · 作者等热水的顺便习惯**（`nature: 原书亲历`，`c32`）：作者洗澡时花洒约需 20 秒出热水，他把这段等待当作锚点时刻，做「想一件值得感恩的事」。**原书未单独交代该习惯的结果**（用于引出"顺便习惯"概念）。

**注**：均为作者自述/自选案例，无对照样本量（幸存者偏差）。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 觉得自己**没时间**养成任何新习惯：「我太忙了，哪有时间再养一个习惯？」
- 生活里存在**固定的等待/空档**却被浪费：等热水、等红灯、排队、坐电梯、等飞机登机、等咖啡。
- 想把学习/感恩/放松这类小事**塞进通勤或等待时间**。
- 已经有想要的小行为，但找不到"整块时间"来做。
- 想在不额外占用时间的前提下"顺手"做点什么。

**2. 语言信号（中英双写）**
- 中文：没时间养习惯 / 碎片时间 / 等电梯 / 等红灯 / 排队 / 等飞机 / 通勤 / 顺手做 / 顺便习惯 / 等待的时候做什么 / 不想额外花时间。
- English: no time for habits / tiny pockets of time / waiting time / commute / doing something while I wait / Meanwhile Habit / no extra time.

**3. 与相邻能力怎么区分**
- 统一口径：用户**只要解决「提示在哪」这一步** → 触发本类卫星卡；要**整体养成一个习惯** → 走 tiny-habit-design（第 5 步）。
- anchor-matching：一般锚点的三轴匹配 vs 本卡的"碎片等待"专用变体。（诉求是"把空档利用起来" → 本卡；"这个普通锚点配不配" → anchor-matching。）
- prompt-types：三类提示全景选型 vs 本卡这一行动提示变体；"我该用人物/情境/行动哪一类" → prompt-types。
- pearl-habit：都"利用现成时刻"，但本卡用中性空档、它用负面刺激。
- 来源路由入口 fogg-behavior-model：只回答"这套模型是什么、怎么系统性用"，不针对某段具体空档。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「我这个锚点在位置/频率/主题上配不配？」→ 走 anchor-matching（一般锚点匹配，不是等待时间）。
- 「怎么把邻居狗叫/前夫的恶语这种烦人的事变成提示？」→ 走 pearl-habit（负面刺激，不是中性空档）。
- 「帮我整体设计一个每天运动的新习惯」→ 走 tiny-habit-design（全流程）。
- 「我该用闹钟还是便利贴提醒？」→ 走 prompt-types（三类选型）。
- 「我想戒掉刷手机」→ 走 change-bad-habit-system（终止/替换）。

## E — Execution

### 输入契约
- **必需**：①一段**确定会反复发生的等待/空档**（等热水、等红灯、排队、坐电梯、通勤等）；②一个想塞进去的**微行为**（≤ 30 秒）。
- **先做行为判别**（p20）：若给的是愿望，先拆成微行为。
- **适用条件**：用户的痛点是"**没时间 / 想不额外占用时间**"，且存在稳定的等待/空档。
- **可选**：一天里有几次这类空档、每次大约多长。
- **缺**等待时刻或微行为时先问，**不许静默替用户造一个条件**。

### 输出契约
一条**把碎片等待当锚点**的配方：
1. 指定的等待/空档时刻（必定发生、足够频繁）；
2. 塞入的微行为（≤ 30 秒、通常保持微小）；
3. 一行配方：「在我（等待时刻）（之后/期间），我会（微行为）」。

**完成标准**：用户能指出"在哪段等待里、顺手做什么"，且明白**不额外占用时间**、**保持微小**是它的设计前提。

### 步骤
1. **盘点碎片空档**：列出一天里确定的等待/空档（等热水、等红灯、排队、坐电梯、等飞机）。
   - 完成标准：≥1 个**必定发生**且**反复出现**的等待时刻。
   - 判停：若用户其实想要的是"在某个既有行为之后接动作"（不是等待）→ 转 anchor-matching。
2. **选一个空档作锚点**：优先选**频率稳定、时长刚好**的那一个。
   - 完成标准：锚点明确到"哪段等待"。
3. **塞入微行为**：选一个 ≤ 30 秒、在等待当下就能做的动作（想一件感恩的事 / 按下播放键 / 一次深呼吸）。
   - 完成标准：微行为能在该等待时长内完成、**不额外占用时间**。
4. **写配方并提醒保持微小**：套「在我（等待时刻）…，我会（微行为）」，并说明它通常长期保持小规模。
   - 完成标准：一条可当天执行的配方；用户能复述"不额外占时间 + 保持微小"。

## B — Boundary

### 不要用（反场景，按分流）
- **锚点是一般既有行为（不是等待/空档）** → anchor-matching。
- **锚点是惹人烦的负面刺激** → pearl-habit。
- **要整体养成一个习惯** → tiny-habit-design。**还在选提示类型** → prompt-types。
- **诊断某行为为何没发生** → bmap-diagnosis。**戒掉/减少坏习惯** → change-bad-habit-system。
- **只想了解模型本身** → 来源路由入口 fogg-behavior-model。

### 作者警告过的失败模式（反例素材）
- **锚点不够精确（模糊锚点）** x21：把"等待"说得太宽（如"有空的时候"）则无效；要精确到**具体的等待时刻**。
- **把提示交给运气** x22：不主动把空档定义为锚点，就只会继续空转。
- **用延后的"激励"冒充即时奖励** x23：顺便习惯做完也要在**当下**有即时反馈，不能靠事后大奖。

### 作者盲点与待核查（不许当规律用）
- 本卡只管"**把碎片等待变成锚点**"。固化机制——**情绪（庆祝）创造习惯**（f26 / `p53`）与"**演练 7–10 次即固化**"（f30）——**是作者推测、无实验依据，不在本卡职责内**；需要庆祝请走 celebration / tiny-habit-design 第 6 步。
- **安全阀缺失**：顺便是"加好习惯"，但若诉求底层是**成瘾/依赖**（例如拿等待时间去"戒"某物），本卡不适用——转 change-bad-habit-system 并提示该线**成瘾/自由落体型无判停规则**，须转介专业人士。

### 相邻易混
- anchor-matching：一般锚点三维匹配 vs **碎片等待**专用变体。
- pearl-habit：利用**中性空档** vs 利用**负面刺激**。
- prompt-types：三类提示选型 vs 行动提示的一个变体。
- tiny-habit-design：单点（碎片时间）vs 全流程。

## 相关能力

- **tiny-habit-design**（组合）：养成全流程；本卡只管「碎片等待时间当锚点」这一步。
- **prompt-types**（对比）：三类提示全景选型 vs 本卡这一行动提示变体。
- **anchor-matching**（对比）：一般锚点的三轴匹配 vs 本卡的「碎片等待」专用变体。
- **pearl-habit**（对比）：都「利用现成时刻」，但本卡用中性空档、它用负面刺激。

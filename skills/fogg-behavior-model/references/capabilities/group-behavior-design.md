## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 8 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f52`），不随公开版分发。

本卡另含 8 条同簇条目（均在英文版第 12–13 章，未逐字引）：`f50` 改变群体行为的 3 种方法、`f51` 头目 Ringleader / 忍者 Ninja 两种身份、`f53` 群体焦点地图共识版、`f54` 强力区 Power Zone、`f56` 四区 Dolphins/Turtles/Crabs/Clams、`f57` 女王 B 解决方案 Queen B Solution、`f58` 创建改变文化、`f24` 为用户设计定制化提示。

## I — Interpretation

群体行为设计，就是把个人那套 B=MAP / 行为设计循环，放到「一群人」上跑一遍。骨架和个人的 7 步同构，但每一步多一层：**同一个步骤有头目版和忍者版两种执行口径**——头目（Ringleader）公开带头、分享方法、组织集体行动；忍者（Ninja）不点破，把行为设计悄悄融进日常（提问、微调环境、私下庆祝）。选哪一版，取决于场域和你的职权。

进门先分诊：改变群体有三条路（`f50`）——①改自己的行为以远离群体的负面影响；②和他人一起设计集体改变；③替他人设计一个有利于他们的改变。

然后照 7 步走：共同明确愿望 → 共同探索行为选项 → 打赢家焦点地图收敛出集体黄金行为（`f53`：成员轮流各放一张卡、再轮流各移动一张且不解释，直到达成共识；第一回合按影响度纵向、第二回合按可行性横向，右上角即黄金行为，通常选 1–2 个、不超过 5 个）→ 让行为对每个人都容易做 → 找到集体提示方式（`f24` 的做法是调研已能坚持者的高频锚点时点再给人自选）→ 庆祝成功以巩固习惯（仅习惯类；成为群体的「Shine 之源」）→ 共同排障与重复。

排障时用两轴把人群切成四区（`f56`）：**Dolphins**（有动机有能力，已行动）／**Turtles**（有动机但觉得难，未行动）／**Crabs**（有能力无动机）／**Clams**（无能力无动机）。精力优先给 Turtles（用能力链降难度），暂时放下 Crabs 与 Clams；只有「必须做」的行为才去触达 Crabs，那时用**女王 B 解决方案**（`f57`：保留行为不变，用他们在意的别的愿望为它重新赋义）。

反馈往哪儿给？瞄准**强力区 Power Zone**（`f54`：对方既关心、又感觉不确定的领域）——那里的正面反馈被放大成巨大的 Shine，负面反馈造成的伤害也同样被放大。规模上作者反复叮嘱：先打磨技巧、从工作团队或家人等小群体起步，别一上来就改造整个组织或国家。

## A1 — Application Example

**案例：迈克用咖啡机滤网改变儿子克里斯（原书学员案例，`c62`，第08章「群体行为设计的场景实践」）。**

- **输入/问题**：战略家迈克与 21 岁、被大学开除的失业儿子克里斯关系紧张。他原先盯的是「动机」——想让克里斯振作起来——但推不动。
- **怎么执行**：学了行为设计后，迈克把注意力从动机转到能力，不要求克里斯做整件事，只把「维护咖啡机」拆到第一步——用完把滤网放在吧台上（对应第 4 步「让黄金行为对每个人都容易做」）；克里斯照做时，他立刻道谢（在 Shine 中教导、帮对方感受成功，对应第 6 步）。这属于**忍者**式群体设计：不点破、把改变悄悄融入日常。
- **结论/真实结果**：克里斯逐渐主动清洗并装回滤网，父子关系改善；后来克里斯找了两份兼职、为搬出去攒钱，父子关系达到自其出生以来最好，还送了迈克三张黑胶唱片。（原书交代了结果；属作者自选案例、无对照样本。）

**另一个原书场景（说明性示例，未交代真实项目结果）**：作者的「步行挑战」——用两轴把收到提示的员工切成 Dolphins（报名者）/ Turtles（有动机但觉得太难）/ Crabs / Clams（无动机者），据此决定先帮谁（`f56`）。作者只把它当作四区的说明性示例，**未交代真实项目的量化结果**，标「未说明」。

**另有两个可复用的亲历/学员案例**（供类比）：`c63` 埃米用女王 B 方案把「完成家庭作业」关联到女儿瑞秋「跟上同学」的愿望，再拆成 10 分钟增量并大量庆祝（结果：瑞秋六年级已不需特殊教育、参加进阶先修课程并优异成绩毕业）；`c64` 医院聘作者用四周培训教护士微习惯配方（结果：培训三个月后匿名问卷多项指标有统计显著提升，但原书未给样本量与发表出处）。

## A2 — Future Trigger

**1）用户会在什么情境下遇到这类问题（3–5 条具体场景）**

- 你是团队/项目负责人，想让团队养成一个新习惯（每天站会、每周复盘、走步挑战），但总有人不参与、坚持不下来。
- 家人想一起改变（更高质量的晚间时光、一起少看手机、家庭饮食调整），你不知道从哪切入、谁来带头、怎么让大家达成一致。
- 社群或产品用户参与率低，你想设计一个「让一群人一起做」的方案，而不是逐个说服。
- 你想帮某个具体的人改变（孩子写作业、同事站立办公、朋友戒烟），又不确定该公开带还是私下推。
- 你已有一套面向群体的改变想法，但不知道如何收敛大家的选项、把行为做到「人人都容易做」。

**2）语言信号（中英双写关键 trigger）**

- 中文：怎么让团队 / 家人 / 大家一起…… / 带动一群人改变 / 团队没人坚持 / 我们组想养成…… / 怎么让大家都…… / 帮别人（孩子 / 同事）改变 / 一群人怎么设计 / 群体参与率低。
- English: how do I get my team/family to... / group behavior change / team habit / change a group's behavior / help others change / get everyone to... / design for a group.

**3）与相邻能力怎么区分**

- **主体是「我」自己 → 晋级技能 `tiny-habit-design`**（我自己养成习惯）。**主体是「一群人 / 团队 / 家人」→ 本卡**。这是本卡与养成主卡之间最硬的一条主体边界。
- `group-ethics-guardrail`（同册相邻）：本卡回答「群体设计**怎么做**」；护栏卡回答「这么做有没有**越界成操纵**」。
- `affirmation-messages`（同册相邻）：本卡是群体**整体 7 步流程**（第 6 步庆祝/反馈只是其中一环）；肯定话术矩阵是第 6 步反馈环节的**侧翼工具**，只在「给我一句对症的肯定」时用。
- 来源路由入口 `fogg-behavior-model`：用户只想「了解整套模型 / 书里某段怎么做」时走它。

**4）近邻负例（什么样的请求不该触发本卡）**

- **【vs `tiny-habit-design`】**「我自己想养成早睡的习惯 / help me build my own bedtime habit」——改变对象是用户**一个人** → **不触发本卡**，走 `tiny-habit-design`。
- **【vs `golden-behavior` / `tiny-habit-design` 内步骤】**「帮我从这 10 个行为里挑一个最适合我的 / pick the best one for me」——这是**个人**焦点地图，不是群体共识 → **不触发本卡**。
- **【vs 来源路由入口 `fogg-behavior-model`】**「福格行为模型整体是怎么回事 / what's in this book」——用户只在问来源、要概览 → **不触发本卡**，走来源路由入口。
- **【vs `group-ethics-guardrail`】**「我这样帮一群人改变算不算操纵 / is this manipulation」——诉求是**伦理越界判定**而非设计流程 → **不触发本卡**，走护栏卡。
- **【vs `bmap-diagnosis`】**「我只想知道某个人／某群人的某个行为为什么没发生，要归因不要方案 / why didn't their behavior happen」——诉求是**诊断单个行为**而非设计行动方案 → **不触发本卡**，走 `bmap-diagnosis`；本卡只在「要设计一套让一群人一起改变的行动方案」时使用。

## E — Execution

**输入契约**

- 必需：一个**群体共同愿望** + **群体成员**（团队 / 家庭 / 社群），并说明场域与你的职权。
- 可选：该群体已有的行为清单（做群体焦点地图要用）。
- 缺愿望或成员信息要先问，不许静默假定群体规模、性质或你的职权。
- **判停**：若改变对象只是用户**一个人** → 转 `tiny-habit-design` / `bmap-diagnosis` / `change-bad-habit-system`；若用户只是要「了解模型」→ 转来源路由入口。

**步骤**

1. **选路径与身份。** 在三条路里选一条（`f50`：改自身远离群体负面 / 与他人一起设计集体改变 / 为他人设计有利改变）；并按场域与职权选头目或忍者（`f51`）。
   - 完成标准：写出所选路径 + 身份，并各给一句理由。
2. **共同明确愿望。** 与群体一起把愿望/成果写下来（头目公开征求；忍者自己先提出一个被认可的愿望）。
   - 完成标准：得到一个群体**共识**的愿望陈述（不是一个人的目标）。
3. **发散选项 + 群体焦点地图收敛。** 用行为集群/挥舞魔法棒发散行为选项（忍者用「娓娓提问」），再用**群体焦点地图**（`f53`）收敛：成员轮流各放一张卡、再轮流各移动一张且不解释，第一回合按影响度纵向、第二回合按可行性横向，直到达成共识；右上角即集体黄金行为。
   - 完成标准：收敛出 **1–2 个（不宜超过 5 个）** 集体黄金行为。
   - **判停**：若这是**单次行为**而非要在群体里养成习惯，第 6 步可跳过。
4. **让黄金行为对每个人都容易做。** 按能力链降低门槛（复用 `make-it-easy` 的缩小规模 / 入门步骤等手法）。
   - 完成标准：每个成员都能在其**最差状态**下完成该行为。
5. **找到集体的提示方式。** 用锚点/共用提示；或按 `f24` 先调研已能坚持者的高频锚点时点、再把候选锚点给大家自选。
   - 完成标准：每个成员都有一个可用的集体提示。
6. **庆祝成功以巩固习惯（仅习惯类）。** 成为群体的「Shine 之源」，成员做对时即时反馈；反馈瞄准 **Power Zone**（`f54`：对方既关心又不确定的领域），正面被放大、**负面伤害也被放大**，别在对方的脆弱处挑毛病；需要一句对症肯定时用 `affirmation-messages`。
   - 完成标准：每个成员都有一个群体层面触发的庆祝/反馈动作。
7. **共同排障与重复。** 按「提示 → 能力 → 动机」排查（`f52`）；遇到「行为必须做但对方无动机」（Crabs），用**女王 B 解决方案**（`f57`：保留行为，用他们在意的别的愿望为它重新赋义）。
   - 完成标准：对每个未达标成员给出提示/能力/动机层的具体对策。
- **规模边界**：先打磨技巧、从工作团队或家人等**小群体**起步，别一上手就改造整个组织/国家（`x42`）。

**输出契约**

- 一份群体行为设计方案 = 选定的**路径与身份** + **集体黄金行为（1–2 个，≤5）** + **集体提示方式** + **维持/扩展方案** + **头目/忍者两套执行口径**。
- 完成标准：群体**收敛出 1–2 个黄金行为**，并给出可落地的集体提示与维持步骤（不是泛泛建议）。

## B — Boundary

**反场景（不要用本卡）**

- 改变的对象**就是用户自己一个人**时 → 走个人晋级技能（`bmap-diagnosis` / `tiny-habit-design` / `change-bad-habit-system`）。
- 用户只想**了解整套模型 / 书里某段怎么做** → 走来源路由入口 `fogg-behavior-model`。
- 用户的真实诉求是「判断我这样帮别人算不算越界」 → 走 `group-ethics-guardrail`，不要用本卡做伦理裁决。

**失败模式（作者警告，反例分区）**

- **一上手就想改变整个群体/国家**、跳过技巧打磨（`x42`）：应从工作团队/家人等小群体起步。
- **在对方的 Power Zone 给负面反馈**（`x43`）：正反馈被放大，负反馈的额外伤害也被放大——作者的提醒是「别这么干，请当个好忍者」。
- **试图同时掌控四个区，或专攻最难的 Clams**（`x44`）：作者称这是学习者「最具启发性也最具破坏性」的误区，应先服务 Dolphins/Turtles。
- **把资源耗在对目标毫无动机的 Crabs/Clams 身上**（`x45`）：只有「必须做」的情形（如接种疫苗）才另作处理。
- **一上来就安排超出能力的困难任务**（`x46`）：对方失败后会形成「我做不到」的经验，抬高今后的改变门槛。
- **默认家人/团队会配合你的改变**（`x47`）：作者自陈曾天真地以为所有家庭都彼此支持，被研究员的反例打脸——家人既可能是支持者，也可能是阻碍来源。

**骨架级 / 软交付条目（必须看见）**

- `f57` 是**骨架级**：单条规则 + 举例，无分步流程，「找出相符愿望」缺具体方法（由示例示意）。
- `f58`（创建改变文化，通过分享/通过实干）是两条途径 + 6 条动作的**并列清单**，无步骤顺序与判断分支，**交付物较软（文化扩散结果不可即时检验）**——我们的复核认定它偏软，**若实测验不出对错，就应降为背景条目**。本卡 E 段未把 `f58` 列为必做步骤，正是这个原因。

**术语 / 证据提醒**

- 本卡引用的四区术语是 **`Dolphins / Turtles / Crabs / Clams`**：原书**无 `Zones` 一词**（量词是 `segment`），第四类是 **`Clams`（蛤蜊）**，中文「贝壳区」为误译。
- 两条「福格原则」原书用词是 **`Fogg Maxim #1/#2`**（原书**无** `Fogg Principle`）。

**相邻易混**

- 与个人焦点地图（`golden-behavior`）区分：个人选行为 vs 群体共识选行为。
- 与 `group-ethics-guardrail` 区分：本卡给做法，护栏卡判越界。
- **本卡第 6 步涉及「影响他人」时，必须同时过 `group-ethics-guardrail`**——见该卡 B 段：第 08 章**回避了「未经同意算不算操纵」**，把「我们其实一直在影响他人」当免责前提；用本卡动手影响一个群体前，先补上护栏卡给的同意与告知门槛。

## 相关能力

- **tiny-habit-design**（对比）：主体是「我一个人」走养成主卡；主体是「一群人/团队/家人」才走本卡。
- **group-ethics-guardrail**（组合）：本卡给「怎么做」，护栏卡判「有没有越界成操纵」；本卡第 6 步涉及影响他人时必须先过它。
- **affirmation-messages**（组合）：本卡是群体整体 7 步流程；肯定话术矩阵只是第 6 步反馈环节的侧翼工具。

# 黄金行为判据（从行为集群里筛出「黄金行为」）

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 2 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `f08`），不随公开版分发。

注：本卡早先把这一层对应写作「福格原则 1」，英文原书品牌术语实为 **`Fogg Maxim #1`**——原书**无** `Fogg Principle`。另：中文译本把 `beautifully imperfect` 译成「状态最不好」、把 `on your hardest day of the week` 译成「在最累的时候」，改动了原文的包容 / 接纳语气，**引用这两个概念时以英文原词为准**。

## I — Interpretation

本卡回答一个单点问题：**手上有一堆候选具体行为（通常来自行为集群），哪一个才算「黄金行为」？**

判据是三条同时满足（f08）：①**有效**（对实现愿望帮助大）、②**你想做**（有动机）、③**你能做**（有能力）。两条配套口径决定了它和「随便挑一个应该做的」有何不同：

- **「想做」而非「应该做」**（p23）：把新行为匹配到"你本来就想做"的方向，动机就被嵌进了行为本身，之后不必再额外强调动机技巧。想运动可以是在家跳 5 分钟舞，而不是去健身房。
- **「最难那天」压力测试**（p28）：在最忙、最没动力、且"不完美得很美"的时候仍能想象自己做得到，才算好匹配——用它挡住"高估未来状态"的选错。

图形化的收敛手法是**焦点地图两回合**（f07，在 tiny-habit-design 步骤 3 内）：第一回合只看影响度纵向摆放，第二回合只看可行性横向滑动（提问固定用「我能让自己做到吗？」），右上区即黄金行为。**本卡承载的是"筛出黄金行为"的判据层；焦点地图的"两回合摆卡流程"归 tiny-habit-design。**

## A1 — Application Example

**主例 · 作者用焦点地图筛出改善睡眠的黄金行为**（`nature: 原书亲历`，`c18`）

- **输入/问题**：作者任斯坦福一场大型研讨会负责人期间失眠；愿望 = 改善睡眠。
- **怎么执行**：用「挥舞魔法棒」发散列出约 25 个改善睡眠的具体行为（手机飞行模式、白噪音机、遮光窗帘、把宠物米莉关笼子等）；再用焦点地图两回合收敛——第一回合按**影响度**纵向摆放，第二回合按**可行性**（「我能让自己做到吗？」）横向滑动。
- **结论/输出**：右上区凸出的黄金行为 = **1 个单次行为（把遮光窗帘装上）** + 3 个可习惯化行为（晚 7 点后手机静音、每晚开白噪音机、每晚把关米莉）。
- **原书交代的结果**：睡眠质量一周内就大幅改善，研讨会也很成功；后来他因内疚停止了把关米莉关笼子。
- **注**：作者自述的幸存者偏差案例，无对照样本量（`c18.notes`）。且"关米莉"这一度被筛为黄金行为的行为，作者后来因情感/伦理原因放弃——说明判据是**必要**条件，不是成功保证。

**p23 的判据例（原书例）**：愿望"每天运动"——「健身房跑步机」是"应该做"、「做早餐时跟着碧昂斯跳 5 分钟」是"想做"；按"想做 vs 应该做"筛，选后者，动机即内嵌，无需再强化动机。

## A2 — Future Trigger ★

**1. 用户会在什么情境下遇到这类问题（3–5 条）**
- 已经列了一堆候选行为（发散结果），来问下一步："我这一堆里，到底哪个才值得做？"
- 纠结于两个或几个行为之间选不出："我该做 A 还是 B？"
- 想把"应该做"和"想做"分开："我到底是不是真的想做这件事？"
- 拿着一个行为来验："这个行为对我是好匹配吗？算不算黄金行为？"
- 明确要"筛行为的判据 / 怎么从行为集群里定位黄金行为"。

**2. 语言信号（中英双写）**
- 中文：黄金行为 / 筛行为 / 哪个行为值得做 / 行为匹配 / 焦点地图 / 哪个是我想做的 / 这行为适合我吗。
- English: golden behavior / focus mapping / behavior matching / which behavior should I pick / is this a good match / want-to vs should-do。

**3. 与相邻能力怎么区分**
- tiny-habit-design：那是**全流程**（发散→筛选→缩小→锚点→庆祝→扩展）；本卡只做其中第 3 步"是不是黄金行为"这一个**单点判据**。
- make-it-easy：本卡负责"选哪个行为"；选定之后"行为太难怎么变容易"走它。
- f07 焦点地图两回合流程（在 tiny-habit-design 步骤 3 内）：那是**怎么摆卡收敛一大批候选**的操作流程；本卡是**判定"是不是黄金行为"的判据**。本卡可引用它，但不承载它。
- 来源路由入口 fogg-behavior-model：只回答"这套模型是什么"，没有具体候选要筛。

**4. 近邻负例（什么样的请求不该触发本卡）**
- 「帮我从零养成一个新习惯，出一套完整方案」→ 不触发本卡，走 tiny-habit-design（要的是全流程，不是筛一个行为）。
- 「我要的是焦点地图两回合的完整摆卡流程，帮我一步步收敛」→ 不触发本卡，走 tiny-habit-design 步骤 3（f07）。
- 「我为什么总做不到早起？卡在动机、能力还是提示」→ 不触发本卡，走 bmap-diagnosis（归因诊断）。
- 「我想戒掉睡前刷手机」→ 不触发本卡，走 change-bad-habit-system。
- 「福格行为模型是什么、怎么系统性地用」→ 不触发本卡，走来源路由入口 fogg-behavior-model。

## E — Execution

### 输入契约
- **必需**：①一个**愿望/成果**（如"改善睡眠"）；②一批**候选具体行为**（≥3，通常来自行为集群）。若输入是单个"该不该做 X"，可直接用三条判据测它。
- **可选**：各行为的影响度/可行性自评；用户最忙最没动力的时段。
- **先做行为判别**：若候选里混着"提高睡眠质量"这类**此刻做不了的愿望**，先拆成"此刻可做的动作"（p20）。
- 缺候选行为时先问，**不许静默替用户列出**。

### 输出契约

**产出类型**：`patch`（给已有设计换零件：一组候选行为）

- **1–3 个黄金行为**，每个同时满足三条（有效 / 想做 / 能做），并带上"最难那天也做得到"的通过结论。
- 若**无任何行为达标** → 明确回退，**不许硬选一个"应该做"的**。

### 步骤与完成标准
1. **逐条过三条判据**（f08）：对每个候选行为问三句——有效吗（对愿望帮助大吗）？你想做吗（"想做"还是"应该做"）？你能做吗（有相应能力吗）？
   - 完成标准：每个行为得到一个"过 / 不过 + 卡在哪条"的判定。
2. **加"想做 vs 应该做"的动机筛**（p23）：把靠"应该"驱动的行为标出来。
   - 完成标准：明确剔除"很有效但你其实不想做"的行为，或标注它必须靠额外动机技巧才可能维持。
3. **做"最难那天"压力测试**（p28）：对留下的行为，想象在最匆忙、最没动力、且"不完美"的那天能否做到。
   - 完成标准：能想象做到 → 判为好匹配；不能 → 降级或换更小版本。
4. **回退判断**：若没有任何行为同时过三条 → 回到扩充行为集群（f06 / f07）。
   - 完成标准：产出回退动作（继续发散），**不得**在此硬选一个应该有行为。

### 判停点
- 第 4 步触发即**回退**，不产黄金行为。

## B — Boundary

### 不要用（反场景，按分流）
- **要从零把整个习惯养成**（写配方、接锚点、庆祝、扩展）→ tiny-habit-design（本卡只筛行为，不产出方案其余部分）。
- **要焦点地图两回合的完整摆卡流程**（大批候选逐轮摆放）→ 在 tiny-habit-design 步骤 3（f07）内；本卡是判据层，不是摆卡流程。
- **要诊断某个行为为什么没发生** → bmap-diagnosis。
- **要戒掉 / 替换一个坏习惯** → change-bad-habit-system。
- **只想了解这套模型本身**（"福格行为模型是什么""这本书讲了啥"）→ 来源路由入口 fogg-behavior-model。

### 作者警告过的失败模式（反例素材）
- **用"应该做"冒充"想做"**（p23）：把"健身房 / 每天 1 小时"这类"应该"选进来，动机只能靠意志力硬撑。
- **在幻想状态下评估可行性**（f07 notes）：焦点地图第二回合要"做回真实的自己，而不是幻想中的自己"；高估未来的自己会选错行为。
- **硬选一个"应该做"的行为**（f08 V2）：没有行为既高影响又做得到时不回退，等于给后面埋下次次失败。

### 本册存量风险（写进卡、不许越界宣称）
- **判据只是必要条件，不是成功保证**：被判为黄金行为的行为，仍需后续"缩小规模 / 接锚点 / 庆祝"才可能真正养成——"选对了"≠"养成了"。
- **安全阀（跨卡一致性）**：若候选行为牵扯成瘾、进食障碍、自伤等严重心理病理，或用户其实是想戒断依赖，**不跑本流程**，提示转介专业人士（作者自设边界 x40：微习惯并非严重成瘾问题的答案）。
- **不把"想做"的底层机制讲成规律**："选想做而非应该做之所以有效"背后的机制属作者立场，本卡只把它当筛选口径，不宣称已证实的普适机制。

### 相邻易混
- tiny-habit-design：全流程 vs 本卡（第 3 步的单点判据）。
- f07 焦点地图两回合流程（在 tiny-habit-design 内）vs 本卡（"是不是黄金行为"的判据）。
- make-it-easy：本卡选行为 vs 它处理"选了之后太难怎么办"。

## 相关能力

- **tiny-habit-design**（组合）：那是「发散→筛选→缩小→锚点→庆祝→扩展」的全流程；本卡只做其中第 3 步「是不是黄金行为」的判据层。
- **make-it-easy**（对比）：本卡负责「选哪个行为」；选定之后「行为太难怎么变容易」走它。

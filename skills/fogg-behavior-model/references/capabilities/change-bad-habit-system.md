## I — Interpretation

这是《福格行为模型》里「改掉坏习惯」的整套系统方案，本质是把 B=MAP（f01）反过来用：不是让一个行为发生，而是让它停止或被替换。它由三个阶段接续组成，每个阶段内部都有判断分支和回退路径（阶段节点在附录流程图 C1-C3 里展开）。

- **入口先分诊**：习惯按难易方向分三类——上山型（需持续维持、但易停）、下山型（易维持、难停）、自由落体型（`Freefall`，如药物滥用）。本方案主要针对**下山型**；自由落体型作者自限为超出范围。
- **阶段 1（创建新习惯）**：先培养一个与目标坏习惯**无关**、安全、不带情绪威胁的新习惯，用来练「改变技巧」并做身份转变。刻意不先碰最痛的议题，否则情绪负担会压垮学习。
- **阶段 2（终止旧习惯）**：逆向设计。先把概括型习惯（General Habit，如「吃太多垃圾食品」这种抽象标签）拆成一组具体行为；一次只解一个结，且**从最容易的结开始**（作者说三遍的选结标准）。干预按「提示 → 能力 → 动机」顺序试：提示层移除/规避/忽略；能力层把行为变难（增时间/资金/体力/脑力，或与重要日程冲突）；动机层削弱动机或加 `demotivator`（作者不建议）。三重都无效时降级为「缩小规模」。
- **阶段 3（替换旧习惯）**：用一个**动机更强、更容易做**的新习惯替换旧习惯，并把旧提示重映射到新习惯，同时调能力和动机，以庆祝巩固。
- **核心心法**：作者反对「打破（break）坏习惯」的说法，主张「一次只解一个结」的解绳结隐喻——不复位整条绳，先从最容易的结下手，解开一个再选下一个，关键是「不断继续」。

一句话：**先把大而模糊的坏习惯拆具体，再从最容易的一环开始，按提示→能力→动机的次序终止，终止不掉就替换，全程不走「一次猛发力」的破坏路线。**

## A1 — Application Example

来源：原书**学员案例**（c03，含合并自 c54 的第 07 章完整版；Nature = 学员案例；作者自述/自选案例，无对照与样本量）。

- **输入/问题**：朱妮是芝加哥电台晨间主持人，嗜糖成瘾；家人因糖尿病相继去世，她动机极强却屡次戒断失败。
- **怎么执行**（对应三阶段）：
  - 她意识到「戒不掉糖」不是意志力问题，而是**缺少行为设计**（先分诊，再转心态）；
  - 第 07 章展开的做法：写下、画出**行为集群与焦点地图**，把「停止吃甜食」这个概括型习惯拆成一组**具体行为**（阶段 2 具体化）；
  - 从「晚饭后一天不吃甜点」这个**最容易的结**开始，而不是一上来戒断全部（阶段 2 选结，f43 的上位心法）；
  - 清理休息室里的甜食与冰箱里的冰激凌、用椒盐脆饼代冰激凌、无糖零食放车上应急（阶段 2 逆向能力：让坏习惯更难做、提示层清场）；
  - 想念母亲时改玩《精灵宝可梦》游戏而不是吃甜食，用积极习惯替代（阶段 3 替换 + 重映射提示）；
  - 用庆祝巩固小成功（阶段 3 的巩固步骤）。
- **结论/预期输出**：原书交代她戒糖成功——毕业约 3 个月后，她已彻底改掉爱吃甜食的习惯、摆脱了糖瘾。

**未说明**：案例未交代每次干预的失败/回退细节（哪些结曾经解不动），原文只给最终结果。
**旁证（原书亲历，供阶段 2 的能力层用）**：作者自己的「单车电视机」（c55，只有踩动感单车发电才能开电视）与家规「冰箱永不存放冰激凌」（c59，想吃就得换鞋开车去买）——都是阶段 2 能力层「增强所需体力/增加所需时间」的落地样例，结果分别为「看电视时间变少且锻炼出好体型」与「晚上吃冰激凌的习惯后来渐渐不再发生」。

## A2 — Future Trigger

**1. 用户在什么情境下遇到这类问题**

- 用户有一个已经反复出现、想终止或减少的坏习惯（刷短视频/看屏幕时间过长、吃甜食、熬夜、睡懒觉、说脏话、拖延、乱买东西）。
- 用户试过靠意志力、决心、「21 天戒断法」去戒，反复失败，想知道「到底该从哪下手、按什么顺序」。
- 用户同时有多个坏习惯想改，拿不准先改哪一个（本能想先啃最难的那块）。
- 用户要的是**一套分阶段的、带回退路径的落地方案**，而不是零散技巧或一句话建议。
- 用户已经知道自己某个行为为什么发生，现在要**动手终止/替换**它（终止动作本身，而非归因）。

**2. 语言信号（中英双写）**

- 中文：「帮我戒掉/改掉……」「怎么戒……」「我想停止……」「戒糖/戒烟/戒手机/减少屏幕时间」「总是控制不住……」「改了老半天还是没成功」「打破坏习惯」「想一次改掉」。
- English: "help me quit/stop …", "break a bad habit", "kick the habit", "how do I stop …", "I keep relapsing", "get rid of this habit", "reduce screen time / sugar / smoking".

**3. 与相邻能力怎么区分**

| 相邻能力 | 它回答的问题 | 与本卡的分界 |
|---|---|---|
| `bmap-diagnosis`（f01/f04） | 「我这个行为**为什么没发生**」——诊断单个行为卡在 M / A / P 哪一环 | 诊断的是「**想要的行为没发生**」；本卡针对「**不想要的行为已发生、想让它停**」。只要归因不要方案 → 走诊断。 |
| `tiny-habit-design`（f05 族卡） | 「帮我**养成**一个新习惯」——正向设计全流程 | 本卡是「**去掉/替换**」一个已存在的坏习惯；养成卡是「**新增/放大**」一个想要的行为。 |
| 来源路由入口 `fogg-behavior-model` | 「了解 / 系统性地用这套模型」 | 路由入口用于入门与总览；本卡用于对**一个具体坏习惯**动手。 |
| `quit-habit-exercise`（`p17`） | 「给我一个**立刻能做的练习/清单**」——5 步探索练习 | **同一 task-09 的两个入口**：用户要**整套分阶段方案** → 本卡；用户要**一个立刻能做的练习** → `quit-habit-exercise`，二者不得双触发。 |

**4. 近邻负例（哪些请求不该触发本卡）**

- 「帮我设计一个每天读书的微习惯」→ 不该触发；**养成**新习惯 → `tiny-habit-design`。
- 「我打算每天午休后喝水，两周都没做到，问题出在哪」→ 不该触发；只做**归因诊断** → `bmap-diagnosis`。
- 「我想了解一下福格行为模型 / 这套方法怎么用」→ 不该触发；→ 来源路由入口 `fogg-behavior-model`。
- 「给我一个马上能做的、终止习惯的小练习」→ 不该触发（本卡是整套方案）→ `quit-habit-exercise`（p17）。
- 「帮我让记账这件事变简单」/「怎么给自己一个庆祝」→ 不该触发；→ `make-it-easy` / `celebration`。
- 「我酒精/药物依赖，帮我戒断」→ **不该走完整流程**；命中 B 段成瘾安全阀 → 停手转介专业帮助（见 B）。

## E — Execution

**输入契约**
- 必需：一个「想终止的**具体**坏习惯」。若用户只给概括型表述（「我想变自律」「别让工作太紧张」）或愿望/成果，先要求拆到「此刻能做的具体行为」；给了一串坏习惯时，先收拢为**一个**工作对象。
- 必需：终止目标的性质——是「偶尔冲动、控制不住」还是「离不开/停不了」。用于第 0 步分流。
- 可选：已尝试过的干预与失败点（用于排障）。
- 缺上述必需项 → 先问，**不许静默猜值**。

**输出契约**

**产出类型**：`program`（新建一个分阶段方案）

- 一份分阶段方案，字段结构：①坏习惯分类与分诊结论；②阶段 1 的「安全新习惯」；③阶段 2 的具体坏习惯清单 + 逐项「提示→能力→动机」干预 + 无效回退；④阶段 3 的替换配方（含重映射提示）；⑤适用/停手声明。
- 完成标准：对**一个具体坏习惯**至少落到「移除/规避提示」或「替换」中的一步可执行动作，并给出无效时的回退路径（换提示 / 更微小 / 回阶段 1）。

**步骤**

0. **分诊（含判停点）**：判断习惯类型——上山型 / 下山型 / `Freefall`。本方案主要针对下山型。
   - **判停点**：若命中 B 段「安全阀」的成瘾/严重精神病理判停线 → **立即停手、转介专业帮助，不走后续步骤**（该判停线是我们补的，见 B）。
   - 若用户其实是想停一个**上山型**习惯（如「停掉每天早起冥想」），提示方向可能有误，慎用本卡。
   - 完成标准：得出分类与是否继续执行的结论。
1. **阶段 1 · 创建新习惯**：选一个与目标坏习惯**无关**、安全、不带情绪威胁的小习惯（**避开**一上来就选最痛的议题，如减肥），借此练「改变技巧」并做身份转变。完成标准：定出一个具体、且在「最糟状态」也能做到的新习惯，并给出它的锚点与庆祝方式。
2. **阶段 2 · 终止旧习惯**：
   - 2a **具体化**：把概括型习惯拆成一组具体行为（行为集群）。完成标准：产出一份具体坏习惯清单（含暂时低落属正常，提示不要退却）。
   - 2b **选结**：按 f43 三条标准（最容易 / 最确信能做到 / 最无所谓）选出**第一个**要改的具体习惯，不先攻最难。
   - 2c **干预（严格按序，任一见效即停并进入 2d）**：
     - 提示层：移除 → 规避 → 忽略（忽略是末选，依赖意志力）；
     - 能力层：增加所需时间 / 资金 / 体力 / 脑力，或让习惯与重要日程冲突（让坏习惯更难做）；
     - 动机层：削弱动机；加 `demotivator`（作者不建议，易致自责）。
   - 2d **复查（判停点）**：还有其他想终止的具体习惯吗？
     - 有 → 回到 2a 选另一个具体习惯；
     - 没有 → 进入阶段 3；
     - 三重干预层层无效 → 降级为**缩小规模**（缩短时间周期 / 时长、减少次数、降低强度），再谋更大改变。
3. **阶段 3 · 替换旧习惯**：用行为集群 + 焦点地图选一个比旧习惯**动机更强、更易做**的新习惯；把旧提示**重映射**到新习惯；同时调能力（让旧更难、新更易）与动机（增强新、削弱旧）；以庆祝巩固联结。无效回退：重选更好的新习惯 / 有限期替换 / 回阶段 1 继续打磨。

**排障分支与回退（必须保留）**：阶段 1 未按计划执行 → 从「我就是忘记了 / 这太难了 / 我总是忘记 / 我不想要这个习惯」中找原因，两路回边（换锚点 → 回配方；让习惯更微小 → 回演练）。阶段 3 失败 → 重选新习惯 / 有限期替换 / 回阶段 1 或阶段 2。

## B — Boundary

**1. 反场景（什么时候不要用）**

- 用户要**养成/增加**一个新习惯（→ `tiny-habit-design`）；只要**归因诊断**（→ `bmap-diagnosis`）；只要一个**立刻能做的练习**（→ `quit-habit-exercise`）；只要了解整书/系统性上手（→ 来源路由入口）。
- 用户给的是**愿望/成果/抽象标签**（「我想变自律」）而非具体行为——先拆具体，不要直接开工。
- 目标习惯是**上山型**（本身是「该维持的好习惯」），别用本卡去「终止」它。

**2. ★ 硬缺口 —— 成瘾 / 自由落体型（`Freefall`）没有判停规则（本册最要紧的边界，G3）**

- **原书的处理**：全书唯一那条硬边界是 `x40`，而它在我们核验时只判为参考级。作者原话是自限：他并非戒瘾专家，也知道微习惯不是严重成瘾问题的答案（`f41` 章开篇）。**原书在这处没有给出任何可执行的判停规则**——只丢了一句大意是「自由落体型……不求助专家就很难停」的话，没有说什么情况必须停、停在哪一步、转介给谁。这是**原书本身的判据缺口**（我们核验时记为 G3）。
- **本卡补上的判停线（声明：这条线是「我们据常识补的」，不是原书给的）**：出现以下任一情形，**立即停止使用本方法、转介医生 / 戒瘾专科 / 心理治疗（或当地危机热线）**，不要继续走本卡流程：
  1. 目标习惯涉及**物质依赖**（酒精、尼古丁、阿片类、镇静催眠药、兴奋剂等），或行为成瘾已出现**耐受、戒断反应、失控使用、社交/工作/健康功能受损**；
  2. 停止该行为可能出现**躯体戒断风险**（如酒精、苯二氮䓬类骤停）；
  3. 伴随**自我伤害/自杀意念、进食障碍、重度抑郁或焦虑等精神病理**；
  4. 用户自述「**必须靠药物/医疗才能停**」，或要把本方法当作成瘾治疗方案。
- **标注要求**：向用户说明——「这套方法原书自限不覆盖成瘾，本判停线是我们在原书之外据常识补的；原书未给停手规则」。**不得把本卡当戒瘾方案**；任何成瘾场景都应先转介。

**3. 作者警告过的失败模式（`x33`–`x41`，进 B 的目的：识别误用）**

- `x33` 把**概括型习惯**（抽象标签）当目标 = 想一口解开整条绳，进展缓慢并引发沮丧、逃避。
- `x34` 用「**打破（break）**」的心智，期待一次猛发力就解决——极少奏效。
- `x35` **先挑最难/最棘手**的坏习惯改——正确做法是从最容易的开始。
- `x36` 一开始就挑**最痛/最焦虑**的事（常是体重/减肥）当目标——阶段 1 应先拿安全、无情绪威胁的小习惯练手。
- `x37` 明明可以移除/规避提示，却硬扛着「**忽略提示**」——把改习惯变成意志力消耗战，迟早妥协（移除 > 规避 > 忽略）。
- `x38` 从**动机**入手终止习惯（错误顺序）——应先提示/能力，动机放最后。
- `x39` 用**去激励因素**（威胁/罚款/自我羞辱）逼自己停——会滑向自责，违背「感觉良好才有成效」。
- `x41` 替换时选了**「对你有好处」但更难、动机更低**的新习惯——一开始就注定失败。

- `f48`（缩小规模，去坏习惯）⇄ `f16`（缩小/入门，加好习惯）：同源手法、**输出契约不同**（去 vs 加），只链接不合并。

## 相关能力

- **bmap-diagnosis**（对比）：两者共用「先查提示」的优先序，但对象相反——本卡针对「不想要的行为已发生」，它针对「想要的行为没发生」。
- **tiny-habit-design**（对比）：本卡是「减/停/换」坏习惯；它是「加/建」好习惯。
- **quit-habit-exercise**（对比）：同覆盖「终止习惯」的两个入口——要整套分阶段系统走本卡，要一个立刻能做的 5 步练习走它，二者不得双触发。

## R — 出处（Reference）

本节方法论出自 B.J. Fogg《Tiny Habits》第 1 章（2020；中译《福格行为模型》）。原文依据保存在私有工作区（溯源条目 `p17`），不随公开版分发。

两条均取自**原书正文**（不是附录流程图），依据比 `f41` 的附录图依据硬一档。

## I — Interpretation

这是全书里**个人级、可以立刻上手做**的「终止习惯」探索练习。它把 B=MAP（f01）反过来用一遍，压缩成一张可填空的五步清单：

1. 先写下 3 个想停的习惯，**要写具体**（写「停止午餐时买汽水」，而不是「停止喝汽水」）；
2. 对每个习惯，各想出**消除或规避提示**的办法；
3. 各想出**增加难度（能力）**的办法；
4. 各想出**削弱动机**的办法；
5. 从第 2–4 步的候选里，为每个习惯**挑出一个最佳方案**。

它的顺序就是逆向 MAP 的优先序：**提示 → 能力 → 动机**（p14 那条「先消除提示是最佳第一步」正是第 2 步的内容，所以 p14 并入 p17）。与 f41 的三阶段系统相比，它**不做分阶段编排、不做坏习惯分类、不给回退路径**——它只是一次「头脑风暴候选 → 择优」的探索，作用是让你把散落在三个要素上的可能办法**一次性列全、别漏**，避免一上来只盯动机。

一句话：**它是一个 5 步清单，不是一套方案——写 3 个要停的习惯，对每个习惯在「提示/能力/动机」三层各列办法，然后各选一个最佳。**

## A1 — Application Example

**原书给出的范例形态**：p17 只给了「要写具体」的对照例（写「停止午餐时买汽水」而非「停止喝汽水」），**没有给这道练习填满五步的完整答案**。故下面按原书五步规则补一条**合成演练**（明确标记：由本卡据原书规则复算，非作者经历、非现实结果）。

**合成演练（示例习惯取自原书）**
- **输入**：想停的习惯之一 =「午餐时买汽水」。
- **逐步执行**：
  - 步骤 1：写下「停止午餐时买汽水」（已具体化，照原书示例）。
  - 步骤 2（提示）：出门时**不带零钱/饭卡绑定的饮品账户**、换一条**不经过自动售货机**的路线、把汽水从冰箱里清走（消除/规避提示）。
  - 步骤 3（能力）：**自带午餐与水瓶**，想买就得额外走一趟便利店（增加所需时间/体力）。
  - 步骤 4（动机）：用**更想喝的替代饮品**（如气泡水）顶掉对汽水的即时渴望（削弱动机）。
  - 步骤 5：从三步候选里选最佳（例如：改路线 + 自带水瓶，因为成本最低、不需意志力）。
- **预期输出**：每个习惯一张「提示/能力/动机 候选 + 最佳方案」的小表。

**对照（原书亲历案例，用于体会第 3 步「增加难度」）**：作者的家规「冰箱永不存放冰激凌」（c59）——想吃就得换鞋、走到车库、开车去商店买，耗时间又耗体力，结果这个习惯越做越少，后来就不再做了。**未说明**：该案例未交代是否也用到提示层或动机层办法。

## A2 — Future Trigger

**1. 用户在什么情境下遇到这类问题**

- 用户想要一个**立刻能做的、自包含的「终止习惯」练习或模板**，问「有没有清单/方法可以照着填」。
- 用户想给**几个**想停的习惯**同时各列一批候选办法**，再从中择优。
- 用户要的是**个人级、轻量的探索**，而不是一套要分阶段执行的方案。
- 用户已经明确知道要从「提示/能力/动机」入手，只是想把办法列全、别漏（信息整理型需求）。

**2. 语言信号（中英双写）**

- 中文：「给我一个终止习惯的**练习/清单/模板**」「帮我列一下停止……的办法」「怎么给这个习惯找减提示 / 增难度 / 削弱动机的办法」「有没有一个能马上做的练习」。
- English: "give me an exercise to stop a habit", "a quick checklist for quitting", "brainstorm ways to stop …", "list options to remove the prompt / make it harder".

**3. 与相邻能力怎么区分**

| 相邻能力 | 它回答的问题 | 与本卡的分界 |
|---|---|---|
| `change-bad-habit-system`（`f41`） | 「给我**一整套分阶段**的终止/替换方案」 | **同一 task-09 的两个入口**：用户要**整套分阶段方案** → 卡一（f41）；用户要**一个立刻能做的练习/清单** → 本卡（p17），二者不得双触发。 |
| 来源路由入口 `fogg-behavior-model` | 「了解 / 系统性地用这套模型」 | 路由入口用于总览；本卡用于**动手列一个具体习惯的终止候选**。 |

**4. 近邻负例（哪些请求不该触发本卡）**

- 「我想彻底戒掉刷手机，给我**一套分阶段的落地方案**（先建新习惯→终止→替换）」→ 不该触发本卡；→ `change-bad-habit-system`（卡一）。
- 「帮我养成每天睡前读书的习惯」→ 不该触发；→ `tiny-habit-design`。
- 「我为什么一到晚上就控制不住？」→ 不该触发；只要归因 → `bmap-diagnosis`。
- 「我酒精/药物依赖，帮我戒断」→ 不该走本练习；命中成瘾安全阀（见 B）→ 停手转介专业帮助。

## E — Execution

**输入契约**
- 必需：**1–3 个想停止的习惯**，且要求**写具体**（区分「停止喝汽水」这种抽象与「停止午餐时买汽水」这种此刻可做的具体行为）；写得抽象的先帮着具体化。
- 可选：每个习惯已知的环境/触发线索（用于生成提示层候选）。
- 缺具体习惯 → 先问，**不许静默猜值**。

**输出契约**

**产出类型**：`program`（新建一个成批方案）

- 结构：对每个习惯一张小表——「消除/规避提示候选 | 增难度（能力）候选 | 削弱动机候选 | 最佳方案」。
- 完成标准：每个习惯都至少落到**一个**可执行的最佳方案，且该方案来自第 2–4 步的候选之一。

**步骤（对应 p17 五步）**

1. 写下 3 个想停止的习惯，每个都**写到具体**。完成标准：3 条都写具体（可用原书对照：具体到「停止午餐时买汽水」这一粒度）。
2. 对每个习惯，想出**移除或规避提示**的办法。完成标准：每个习惯 ≥1 条提示层候选。**判停点**：想不出也没关系，直接进入步骤 3（原书明说）。
3. 对每个习惯，想出**增加难度（能力）**的办法（增时间/资金/体力/脑力，或与日程冲突）。完成标准：每个习惯 ≥1 条能力层候选。
4. 对每个习惯，想出**削弱动机**的办法。完成标准：每个习惯 ≥1 条动机层候选。
5. 对每个习惯，从步骤 2–4 的候选里**选出最佳方案**。完成标准：每个习惯给出且只给出一个最佳方案。

## B — Boundary

**1. 反场景（什么时候不要用）**

- 用户要的是**一整套分阶段、带回退路径的终止/替换方案**，而不是一次探索 → 用 `change-bad-habit-system`（f41）。本卡只产「候选 + 择优」，**不负责落地编排**。
- 用户要**养成/增加**一个新习惯 → `tiny-habit-design`；只要**归因诊断** → `bmap-diagnosis`；只想了解整书 → 来源路由入口。
- 用户给的还是抽象愿望/概括型标签且不配合具体化 → 先具体化，别直接把练习套上去（参见 f44 的概括型习惯拆解）。

**2. ★ 成瘾 / 自由落体型（`Freefall`）判停（与卡一同一处硬缺口，G3）**

- 本练习表面上「只是想几个办法」，但它是**终止习惯**的入口，同样会触到成瘾边界。**原书在这里也没有给判停规则**：`x40` 仅 reference，作者只写「自由落体型……除非求助专家，否则停不下来」「微习惯并非严重成瘾问题的解法」，没说什么时候必须停、停在哪一步。
- **本卡补上的判停线（声明：这条线是「我们据常识补的」，不是原书给的）**：目标习惯涉及物质依赖（酒精、尼古丁、阿片类、镇静催眠药、兴奋剂等）、已出现耐受/戒断/失控/功能受损，或伴随自我伤害/自杀意念、进食障碍、重度抑郁焦虑，或用户自述「必须靠医疗/药物才能停」时，**立即停止使用本练习、转介医生 / 戒瘾专科 / 心理治疗（或当地危机热线）**。不要用「列几个办法」的方式处理成瘾。

**3. 使用边界（别把它当完整方案）**

- 它是**探索练习**：产出的是候选办法，**不保证落地、不给回退路径、不做习惯分诊**。别把它的输出当成完整的「改掉坏习惯」方案交付。
- 顺序固定为**提示 → 能力 → 动机**（p14 已并入步骤 2）：不要一上来只列动机层的办法（作者警告的错误顺序，见 `x38`）。
- 想不出提示层办法是允许的（原书明说），但**别因此跳过**能力层与动机层。

**4. 与卡一的互设近邻（防双触发）**

- `quit-habit-exercise`（p17）⇄ `change-bad-habit-system`（f41）：同覆盖 task-09 的两个终止入口——**整套分阶段方案 → 卡一；一个立刻能做的练习 → 本卡**。`f41` 是独立入口、`p17` 只是能力卡，二者不得同时抢同一个请求。

## 相关能力

- **change-bad-habit-system**（对比）：同覆盖「终止习惯」的两个入口——本卡是个人级、立刻能做的 5 步探索清单（列候选→择优）；要整套分阶段、带回退的系统方案走它，二者不得双触发。

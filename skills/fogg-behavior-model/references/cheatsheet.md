# 决策规则速查 — 福格行为模型

| 能力 | 一句话规则 |
|---|---|
| B=MAP 行为诊断 | 一个具体行为该发生却没发生，就按「提示→能力→动机」顺序排查，找出缺了 P / A / M 哪一个。 |
| 动机诊断 | 已确认「提示在、也不难，但就是不做」时：用 5 陷阱判断是否在依赖动机，用 PAC 定位动机来源与冲突，再用「减少去激励因素（demotivator）」给一个减负动作，而不是加奖励或施压。 |
| 习惯养成（微习惯设计 · 行为设计 7 步） | 想把一个新习惯从零养成并持续下去时，走行为设计 7 步——发散→收敛出黄金行为→缩成微行为→接到锚点→立刻庆祝→排障扩展，最终产出一条可当天执行的配方。 |
| 黄金行为判据（从行为集群里筛出黄金行为） | 手里有一批候选行为、要挑出「黄金行为」时：逐条过三条标准（有效／想做／能做），再做「最难那天也做得到」的压力测试，无达标者回退扩充行为集群。 |
| 让行为容易做（能力侧单点工具） | 一个行为「想做却做不到」时：先用 Discovery Question 找到最弱的能力因素，再用 Breakthrough Question 从三条路（提升技能／获工具资源／让行为微小）里给出加固，缩出约 30 秒的微行为。 |
| 生活中常见的 3 类提示（人物提示 / 情境提示 / 行动提示） | 要为某个新习惯选「用什么提醒自己」时，用人物/情境/行动三类提示框架选型——长期习惯默认走行动提示（锚点），情境提示只宜单次，人物提示尽量避开。 |
| 锚点匹配的 3 个考量（物理位置 / 频率 / 主题目的） | 已决定用锚点（Anchor）时，按物理位置（最重要）、频率、主题/目的三轴把锚点与新习惯对齐，再用 Trailing Edge（最后动作）收紧成精确时刻。 |
| 顺便习惯（Meanwhile Habit · 把碎片等待时间变成锚点） | 想在"等热水/等红灯/排队/坐电梯/通勤"这类被浪费的碎片时间里顺手养个小习惯时，把那段必定发生的等待当锚点，塞入一个 ≤30 秒的微行为（不额外占时间、通常保持微小）。 |
| 珍珠习惯（Pearl Habit · 把烦人的事转成提示） | 遇到一个确定会反复发生、又消不掉的烦人刺激（噪音、他人恶语、排队）时，把它本身定义为锚点，接一个取悦自己的正向微行为，把烦人的时刻转成自我照顾的提示。 |
| 庆祝机制与规则 | 要用庆祝固化行为时，选一个自然、真切的动作紧贴行为那一刻（几毫秒内）做，用三时机安排，并在中断/扩规模时重启庆祝。 |
| 习惯的生长与繁殖（第 7 步的机制 / 目录层） | 一个习惯已经能稳定做到、想扩展时：判断它属「生长」（同一行为做大，有自然边界）还是「繁殖」（衍生别的习惯），据此决定加量还是期待涟漪，并注明何时增加无硬阈值。 |
| 改掉坏习惯（行为改变系统方案 3 阶段） | 想终止/替换一个已反复出现的坏习惯时：先分诊类型（成瘾→转介），再把坏习惯拆具体、从最容易的一结开始，按提示→能力→动机终止，不成则替换。 |
| 终止习惯的探索练习（5 步） | 想要一个立刻能做的终止习惯练习/清单时：写下 3 个要停的习惯（写具体），各列「消除/规避提示→增难度→削弱动机」候选，再从三步里各选一个最佳方案。 |
| 群体行为改变设计 | 当改变的主体是「一群人 / 团队 / 家人」而不是你自己时，用头目（Ringleader）/ 忍者（Ninja）两套 7 步流程做群体行为设计。 |
| 帮他人改变时的伦理护栏 | 帮别人改变前，先过两条 Fogg Maxim（帮人做其已想做的、帮人感受成功），并补一条原书缺失的同意与告知门槛。 |
| 32 种肯定消息框架 | 要给某人一句对症的肯定时，用「4 个观察角度 × 8 个力度/时间尺度」矩阵选一格生成。 |
| 2 分钟讲清福格行为模型 | 要把福格行为模型讲给别人听时，照固定 5 步脚本讲 2 分钟——介绍原理→画图→举例→行动线→总结。 |
| 行为设计总纲（起手心态与粗纲） | 想开始用这套方法、或想知道它整体长什么样时：先接住「不自责 + 把愿望拆成微行为 + 把错误当发现」三件事，再记住「选一个想要的行为→把它变小→嵌入生活→滋养生长，从小处着手」的粗纲，然后按目标转到具体的诊断/养成/改掉卡。 |
| 用两条福格原则过滤外界方案 | 拿到一个外界现成方案时，用两问过滤——①它帮你做你本来就想做的事吗？②它帮你感受到成功吗？任一为否即不值得花时间。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

# 福格行为模型 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 严重成瘾或「自由落体型」习惯（如物质滥用）：原书明确划给专家或专业机构，本 skill 不处理，应转介。
- 精神疾病导致的执行不能（抑郁、焦虑症、进食障碍等）：超出行为设计范围，应转介专业人士。
- 结构性约束（贫困、制度性障碍、人身安全风险）：本书不讨论外部约束，不得把这类问题当作「方法设计问题」处理。
- 与行为改变无关的纯信息查询（概念定义、书籍元信息、章节概览）：走 references/，不要加载能力卡。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. B=MAP：动机（M）、能力（A）、提示（P）三要素同时具备，行为才发生；排查顺序是先提示、再能力、最后动机。
2. 动机善变、冲突且不可靠，改变要从匹配「黄金行为」入手（影响大 + 你想做 + 你能做到），工具是行为集群与焦点地图。
3. 三要素里能力最可靠；设计的关键是简单——用能力链找薄弱环节，用入门步骤／缩小规模把行为变微小。
4. 没有提示就没有行为；三类提示中最好的是行动提示，也就是把新习惯锚定在既有习惯「之后」。
5. 即时庆祝制造「发光」感，让情绪参与固化习惯；帮别人改变时，先帮对方感受成功。
6. 坏习惯不靠意志力「打破」，而用行为改变系统方案逆向设计；影响他人／群体要用福格原则 1、2（`Fogg Maxim #1/#2`），并守住同意这条线。

## 边界与判停

- 完成一次 B=MAP 诊断、给出下一步路由（指向对应能力卡）后即停，不要把整条流水线一次跑完。
- 对话中出现成瘾、躯体戒断风险、自伤意念、进食障碍等信号时，立即停止行为设计并转为建议寻求专业帮助。
- 用户没有给出可操作的具体行为描述时，先停下要求具体化（哪个行为、什么场景），不静默猜值；具体化后优先回到 bmap-diagnosis（排查提示与能力）或 motivation-diagnosis（动机本身）。
- 用户要的是「未经验证的结论」——例如把「情绪创造习惯」「7–10 次即固化」当既定规律用时，停下并说明这是作者主张、本册无独立实证。
- 同一句里既命中某张能力卡的触发面、又命中任一停手条件（成瘾／物质依赖／躯体戒断风险／自伤意念／进食障碍／精神疾病）时，判停优先：不加载能力卡，直接转介。

# 人类行动设计指南

把行为设计领域的经典著作，蒸馏成 Agent 能直接调用的能力。

每一份产物都是一套**可执行的判断流程**：什么情况下用它、按什么顺序做、做到什么算完成、什么情况下该停手、边界在哪。另外配一篇把来龙去脉说清楚的长文。

## 两种用法

### 一、装到你自己的 Agent 上

把 [`skills/`](skills/) 下面你需要的目录整个拷进你的 agent 的 skill 目录：

- Claude Code：`~/.claude/skills/`
- Codex / 其他读 `~/.agents/skills` 的宿主：`~/.agents/skills/`

装完，当你聊到「想养成某个习惯」「这事我明明想做却做不到」「想戒掉某个习惯」「怎么让一群人一起改变」这类话题，agent 会自己去读对应的那张能力卡。

### 二、自己读

[`guide/`](guide/) 下的长文独立成篇，不用装任何东西。读完你能自己用 B=MAP 排查卡点、自己写出微习惯配方，也能自己用四步模型定位习惯卡在哪一环。

## 这里面到底装了什么

### 《福格行为模型》——19 张能力卡

- 诊断类：某个行为为什么没发生（B=MAP 排查）、动机这一格出了什么问题
- 养成类：从「我想要什么」发散到「做哪一个」、锚点怎么选、怎么让行为变容易、庆祝怎么做才有效
- 改掉类：坏习惯的三阶段系统方案、可以立刻上手的终止练习
- 群体类：怎么让一群人一起改变、影响别人时的伦理护栏
- 工具类：提示的类型、顺便习惯、珍珠习惯、肯定话术矩阵

### 《原子习惯》——20 张能力卡

- 诊断类：卡在提示·渴望·反应·奖赏的哪一环、哪条定律是瓶颈
- 设计类：身份怎么定、线索怎么挂到既有习惯后面、环境怎么摆、两分钟法则怎么落地、渴望层怎么加吸引力（诱惑捆绑 / 社会规范 / 深层动机）
- 维持与复盘类：怎么追踪、怎么在断掉之后恢复、怎么把难度调到能力边缘、自动化之后怎么继续变好
- 改掉类：反向四律（隐而不见 / 缺乏吸引力 / 难以实行 / 令人不满）
- 约束类：承诺机制、自动化、找问责伙伴

每张卡都写死了六件事：出处、这套方法在讲什么、一个真实应用、什么情况下会用到它（含**不该触发它的情形**）、执行步骤与输入输出契约、边界与反例。

## 这些结论是怎么来的

每一条结论都先定位到原书的具体章节，再经过三轮独立核验（来源是否充分、能不能真的执行、用起来有没有增量），最后才决定是变成一张能力卡，还是只作为背景保留。

[`sources/`](sources/) 是完整账本：每本书结论逐条列明**出自哪一章、哪一节**，以及我们从中提炼出了什么。能力卡正文里那些 `f01`、`p15`、`c72` 之类的编号，在这里都能查到。

写得不对的地方，欢迎开 issue。另外，有些主张作者自己都说是推测，我们逐条标了出来，没当成规律用。
